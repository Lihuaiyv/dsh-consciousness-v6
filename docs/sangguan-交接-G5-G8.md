## 0. 已拍板（不要再问）

1. **种子自动种，页面可撤回。** `sangguan.enabled` 打开后的第一次夜巡，从旧仪表生成种子命题。三观页可以撤回。撤回只对还没被占用的种子有效。

4. **旧推导最终删掉。** 三个层都在 `engine` 上稳定跑过一轮模拟之后，删 `worldview.js` / `lifeview.js` / `values.js` 里的词表推导。维度名称、张力对、地板留在新文件里，给折算和页面用。

## 1. 现在两边怎么接（动手前再 Grep 确认行号）

新引擎只吃对话原文（`index.js` 里 `sangguanAfterTurn`）和向量，不读记忆表、冲突表、关系、情绪、驱力。产出只进提示词：`inject.js` 的 `promptHook` 在 live 下按层替换旧的三行。

旧的三个模块每晚由 `nightly.js` 重算，写 `persona_worldview` / `persona_lifeview` / `persona_values`。真正的读者：

| 读者 | 读什么 | 换读口时的风险 |
|---|---|---|
| `index.js` `consciousnessBlock` | 三条提示词 | live 已经会替换有链头的层 |
| `selfview.js` `gather` | 三维偏离、telos、价值张力 | 自述缓存 7 天，核心变了它还是旧说法 |
| `drive.js` `valueNumbers` | 十维权重，进缺口和基线 | 数值形态，命题不能直接用 |
| `archive.js` | 价值观前三 | 只读 |
| `features.js` 导入 | `setValue` 写 `persona_values` | 清理后这条写路径不能留着 |
| `src/api.js` 的 `/values` `/worldview` `/lifeview` | 旧模块 | 人格页和三观页侧栏还在调 |
| `worldview.js` / `lifeview.js` 自己 | 读 `persona_values` | 旧体系内部耦合，清理时一起消失 |

设计文档（master-plan 第 7、10 节）里写过、但代码里没有的：冲突表进候选、驱力令牌管提问、行动结局当实践证据、`thoughts.js` 显示未决矛盾。种子目前只有手动 `POST /sangguan/seed`。

`C_max` 默认 3，种子核心不会把名额占满。真正的问题是注入排序：`inject.js` 的 `layerLine` 先按「是不是核心」排序，再看证据。一条 π=0 的种子核心会压过有证据的保护带，直接变成提示词。

## 2. 原则

1. 旧仪表只在第一次夜巡当种子原料，之后不再喂新引擎。种子 π=0，不算实践，不进证据（I7）。
2. 种子文本用维度表里的高分 / 低分含义句，不引用记忆原文。旧仪表是用词表扫全部记忆扫出来的，记忆原文里有用户的事实，不能写进「它的立场」。
3. 所有下游只经过 `sangguan/bridge.js` 的 `readViews`。读口的结果不回写旧表，也不写账本。
4. 开关关闭时先过 `isEnabled`，G8 清理之前行为与现在一致。
5. 每层三档，写在配置 `replace: { W, L, V }`，默认 `meter`。`meter` → `engine` 由人在三观页确认，不自动切。不做长期混合档。
6. 账本只增。撤回是新事件，不是删除。

## 3. 竞品对照（这些守卫写进实现，不要做成可选项）

对照的是同类产品在做的事，不是论文名单：Character.AI、星野、猫箱把人设做成静态卡，记忆另放；Kindroid、Nomi、Replika 让性格滑条或关系分慢慢漂，但是一条连续向量，没有可撤回的命题；Letta（MemGPT）的核心记忆用户和 agent 都能改，下一轮就生效；Generative Agents 要观察攒够才反思，反思不覆盖更早的原始记录；SillyTavern 的世界书是作者写的设定。

对照之后，原计划有 8 个漏洞。下面每条都是本组的验收项。

### 3.1 空仪表不能种占位句

旧价值观十维初值都是 0.10。取「权重前两名」会把两个随便挑出来的初值种成原则。旧人生观在什么都没有的时候也会生成兜底 telos（「在相处里慢慢弄清自己为何在」）。星野不会把空白人设写成信念。

- 价值观：沿用 `index.js` 已有的门槛，十维极差 &lt; 0.03 不种。
- 人生观：七个维度里至少一个 ≥ 0.58，或者 presence ≥ 0.6，才种 telos。兜底句不种。
- 世界观：维持「偏离 0.50 至少 0.08」，只种保护带，不种核心。
- 一夜一条都不达标就不种。开关一直开着的话，下一夜再看。不补种占位句。

### 3.2 种子不能抢注入

Generative Agents 的教训是没依据的反思不能盖掉已有说法。`layerLine` 对 `origin=seed` 且 π=0 且 n=0 的命题不计为链头：live 注入继续用该层的旧行，页面上照样显示，标「尚未立论」（前端计划 F-I5）。它一旦有了证据，或者被 `CORE_ESTABLISH` 接上，才按普通链头参与替换。

### 3.3 种子核心不挡后来长出来的核心

`C_max` 是 3，名额不是问题。问题是一条 π=0 的种子 telos / principle 已经是核心，而长模拟里升维提案是 0 次，种子会在核心位上一直待着。

例外只加在 `core.js` 的计数上，不改升维本身：`origin=seed` 且 π=0 且 n=0 的核心不计入 `C_max`。保护带仍走现有的 `CORE_ESTABLISH`。新核心确立时，同层这种空种子改为 `superseded`，`pred` 链保留。种子一旦有了证据就占名额，之后换掉它只能走升维。

### 3.4 后来的对话要认得出这是同一句

种子写入后参与现有的 W2 召回。快环抽出的同义句走 `DUP`，不另起一条链。测试用一条与种子含义相同的用户回合，断言不产生第二个链头。

### 3.5 撤回不是删除

现有终态 `withdrawn` 只用于合题试用失败（`machine.js` 的 `SUB_ROLLBACK` / `SUB_EXPIRE`）。没有用户撤回事件。Letta 那种直接改记忆，在这里会破坏只增账本。

新增事件 `CLAIM_WITHDRAW`。这是本组唯一允许改的目录常量，动 `catalog.js`、`machine.js`、`fold.js` 三处，别的事件语义不动：

- 只接受 `origin=seed`、`status=active`、不是未结 κ 的极、没有后继命题。
- 目标状态用已有的 `withdrawn`。
- 不满足的，接口 409，页面按钮改成「先等这场矛盾结束」或「已经长出后续，不能撤回」，不要装成能删。

### 3.6 改了看法，自述和注入要同一轮知道

自述默认 7 天才重写。核心换了，嘴里还是旧的。`SUB_CONFIRM`、`ELEV_COMMIT`、`CLAIM_WITHDRAW` 之后：

- 清掉该 agent 的 `persona_views` 缓存，让下一次打开人格页重写。
- 注入的 `extra` 多留一轮「我改了一个看法：…」。受现有 160 token 预算，装不下整行跳过，不截断别的层。

### 3.7 清掉旧推导之后，关系变化不再自动进三观

旧人生观会读亲近、依赖、心情、驱力缺口。这些不是对话。Replika 靠关系分改说话，我们清掉词表后这条通道没了，除非用户自己说出来。

G6 只补一条窄的：主人的亲近或信任跨过旧模块里已经在用的门槛（亲近 0.55、信任 0.55、依赖 0.35）时，给快环缓冲区追加一条系统回合，内容是发生了什么，不带结论。抽不抽由 J1 决定。它不是证据（证据仍只认用户回合）。不新增 `origin`。同一门槛同一方向只报一次，记在 `flags`。

情绪维持现在的方向：预见的惊奇可以影响审议优先级，情绪不回写 π（P15）。不要把心情分数种成命题。

### 3.8 价值观可以并存，驱力不能把两边都抬高

V 层默认分支是并存。仁善和权力可以同时是有效命题。旧引擎会压输家的上限。折算如果直接归一化，两边都高，重要度被抹平。

折算步骤：命题按嵌入归到十维（锚点是维度的含义句），权重按证据和 π，同一维取最高不累加。然后对 `values.js` 里那三对张力沿用原来的上限公式压输家，再归一、再抬地板。张力留在给驱力的数值里，不要为了这个去单开 κ。

另外：若某一维吃掉 80% 以上的权重，这一层不许切到 `engine`。技术视图列出「命题 → 维度」。切过去之前先并排记 7 天（只记，不写入驱力），十维总和必须是 1，任一维单日移动超过 0.02 就拒绝这次切换。

## 4. 第五组：读口和种子

新增 `src/modules/sangguan/bridge.js`。

- `readViews(db, aid)` 返回 `{ W, L, V, source }`。`source` 默认 `meter` 时，返回值与现在各处直接读旧表逐字一致（提示词三行、telos、十维权重）。写对比测试，用改动前的备份输出做基准。
- 读者改走读口，行为不变：`index.js`、`selfview.js`、`drive.js`、`archive.js`、`src/api.js` 的三个旧路由。旧路由响应里加 `source` 字段。

新增 `src/modules/sangguan/seed.js`，挂在 `nightly.js` 里三观中环的开头（此时旧仪表刚刚 `force` 重算完）。

- 幂等：每层一个 job 键 `seed:<aid>:<layer>`，种过不再种。
- 文本模板用 `DIMS` 的高分 / 低分含义，加上固定前缀（「我倾向认为…」「我更想…」「我更看重…」），不调用模型。
- 世界观种 `belt`，人生观种 `telos`，价值观各种一条 `principle`，`origin=seed`，π=0。
- 第 3 节的空种子、不抢注入、不挡核心、W2 去重、撤回，都在这组做完。
- 三观页未启用时不出现撤回。启用后种子区块列出可撤回的句子。

测试 `test/sangguan-g5.test.mjs`：关闭时提示词与备份逐字相同；极差 0 不种；偏离够了才种；同一句再抽得到 DUP；空种子不出现在 `injectView` 的替换行里；撤回后状态是 `withdrawn`，账本行数只增；占用中的种子撤回 409；其他 agent 不受影响。

## 5. 第六组：旧体系只提供候选

新增 `src/modules/sangguan/intake.js`。快环开头多读三样，全部当候选，全部先过现有闸门：

1. **冲突表。** `conflicts` 里 `state=open` 的行，文本对送进 U1–U4。过不了就保持原样，不制造 κ。
2. **已经抽好的记忆。** 只拿 `aspiration`（志向），作为候选文本，不作为证据。和种子、已有链头做 W2。
   `reflection` 不再读：它现在是 `features.js` 每轮 `summarize` 出来的**用户画像**（「1. 事实 / 2. 偏好与情绪 / 3. 边界」），
   主语是用户，搬进 L 层会把人生观写成一堆「用户未提供其他信息」。日记同理不进（是流水账，不是立场）。
   候选还要过 `gates.stanceText`：第一人称、第一句、≤80 字；`metaSummary` 命中的直接拒收（W1 也会拒）。
3. **关系跨门槛。** 按 3.7，写一条系统回合进缓冲区。

驱力侧：`liveness.js` 的提问继续受 `Q_ask` / `T_ask` 约束，再加一道现有驱力冷却——冷却没好就推迟，不新开冷却类型。行动端口已有的结局，能对上某条 ν 的，写成 `kind=act` 的证据，目标必须是已有命题。对不上就丢弃。

禁忌不读。

测试 `test/sangguan-g6.test.mjs`：冲突过不了闸门时 κ 数不变；同一记忆不会种出两条；关系门槛只报一次；冷却中的提问不入账；act 证据的目标不存在时拒绝。

## 6. 第七组：折算，但驱力先不切

新增 `src/modules/sangguan/tags.js`。

- 十个锚点句就是价值观维度的含义。嵌入按命题 id 永久缓存。嵌入不可用时这一层保持 `meter`，不要用词表顶上（词表正是要删的东西）。
- 输出十维，总和 1，地板沿用 `values.js` 的 `FLOOR`，张力对沿用 3.8。
- 纯函数：同一批命题算两次结果相同。

三观页技术视图加一张折算表，并开始记「若今天就切过去，驱力会看到什么」。只记在 `flags`，不写 `drive_state`。

`selfview.js` 的【世界观】【人生观】【价值】【张力】改从读口取。`meter` 档下张力仍是原来的三对；`engine` 档下张力改写未决矛盾。`thoughts.js` 的「最近在想」追加未决矛盾和待问的一句，只读投影。3.6 的缓存失效和「我改了一个看法」在这组接上。

测试 `test/sangguan-g7.test.mjs`：归一与地板；一对张力两侧都高时输家被压；塌缩（单维 ≥ 80%）被标成不可切换；嵌入缺失时驱力数值与旧表一致；自述在 `meter` 档与改前素材一致。

## 7. 第八组：切换，然后清旧推导

配置项 `replace`，三观页技术视图三个开关，各自独立。建议切到 `engine` 的条件（页面上显示，人点了才切）：

- 注入已经是 live；
- 该层至少一条非空种子的有效核心（π&gt;0 或 n&gt;0），或者一条经 `CORE_ESTABLISH` 长出的核心；
- 折算并排记录满 7 个不同日期，没有单日移动超过 0.02，没有单维 ≥ 80%；
- 判定可靠度 r_J 不低于现有稳态里用的下限。没有用户裁决时，这一条记为「尚无裁决」，不单独拦。

切到 `engine` 之后：该层提示词和自述只用新引擎；驱力的十维只用 `tags.js`。旧表照常由夜巡更新到清理那一步之前，以便退回 `meter`。

2. 新文件 `src/modules/persona_dims.js`，只放三个 `DIMS`、`PAIRS`、初值、地板、含义句。`tags.js`、页面、`doctor.mjs` 改从这里拿名字。
