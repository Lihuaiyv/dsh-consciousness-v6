# 三观料修正 · 完成报告 v3

> 计划：[sangguan-三观料修正-计划-v3.md](sangguan-三观料修正-计划-v3.md)
> 起因：页首长出「电脑关机或插件没开，这套服务就不存在」「先做开机自启和后台守护，再考虑上服务器」——工程记录冒充三观。

## 1. 改了什么

### P1 立场闸（`gates.js` + `stanceGate`）

挂在 `fieldCheck` 最后一步，所有进 `CLAIM_EXP` 的路径自动带上（`fast.js` 的抽取、`classify`、`values_intake`）。

判定只有三条：有取向词就放行；没取向词又提到工程语汇的拒；没取向词又是明确待办的拒。拒收记 `REJECT + gate_report.reason='not_stance'`，不静默丢。

原有 `selfEval / metaSummary / instructionLike` 三条全部保留，顺序在前——立场闸是补漏，不是替换。

### P2 进料补漏（`intake.js`）

- 冲突 → W 层原来是 `a.slice(0,300)` 裸塞，现在逐条过闸。
- 志向 → L 层原来只过 `stanceText`，现在再过 `stanceGate`（记忆层会把「先做自启再上服务器」判成志向）。

### P3 承诺归位（`pledge.js` + `client.js`）

- 抽取前先排疑问句（`？` / 是不是 / 有没有 / 要不要 / 吗呢），判断句也不再算（加 `ACTION` 动作词要求、`NEG` 补 `不是|没有`）。
- `claimText` 拿不出动作就返回空，整条不登记（以前会存成「我答应：不是今天哪个设置改了…」这种碎片）。
- 三观页 `belts()` 过滤 `kind='commit'`：承诺是到点要兑现的账，只在「预见与回流」露，不再冒充价值观。

### P4 生长序（`theta.js` + `fast.js`）

新增 Θ 参数 `growth_order`，默认 **0（关）**，范围 0–1。开了之后：V 层一条活的都没有时，W 层新增候选直接记 `REJECT + reason='growth_order'`。对应图纸的生长序（V 取舍 → PRESSURE → L → W）。

### P5 清库（`scripts/sangguan-prune-facts.mjs`）

dry-run 先列清单，`--yes` 才写；写前自动备份。只清保护带、只清 `origin≠user`、只清 `stanceGate` 判为不是立场的。清退方式是 `CLAIM_RETIRE`（账本只增，不删行）。

活库实清 6 条（5 条工程记录 + 1 条承诺碎片），备份 `app.db.bak-prune-20261102063239`。

### P6 页面收尾（`client.js`）

- 空层不再只写「尚未立论」四个字，下面加一句为什么空着（每层一句不同的）。
- 三个数下面加「这三个数怎么来的」折叠，把三个口径和「为什么都是 0」写清楚。

## 5. 已知边界

- 立场闸是字面规则，不是语义理解。写到「我更看重把系统跑稳」这种既像立场又像工程的句子会放行（有取向词优先）。这是有意的：宁可放过一句暧昧的，也不误杀一句真的。
- 清库只清了「一看就不是立场」的。L 层那段日记（`cl_01M6BT19BDH806XK3YK60ZKQNA`）留着——它是自传，不是世界观。
