## 节律

由 `heart.note.*` 实例参数（读 `agent_params`，没有就回落默认）：

| 参数 | 默认 | 说明 |
|---|---|---|
| `heart.note.min_gap_minutes` | 10 | 两拍之间最少隔多少分钟 |
| `heart.note.max_beats_per_day` | 48 | 一天最多落几拍 |
| `heart.note.quiet_from` / `quiet_to` | 无 | 静默窗（`HH:mm`），例如 `23:30` / `07:30` |

判断顺序：静默窗 → 冷却 → 日上限。被挡的那拍只记 `lastSkip`，不动别的。

## 注入

`consciousnessBlock` 在 `...selfNoteLines` 后面加了 `...heartNote,`，两行：

```
(我上一条留给自己的话：……)
(留于本拍/几拍前，已搁 N 分钟；还惦记就用 heart_note 原样再写一遍，想换就写新的，什么都不做它下一拍就没了)
```

读到就算「露过」（`shownAtBeat = 当前拍`）；之后再没 `write`，下一拍散掉。

## 工具

`heart_note`：`read` / `write` / `clear` / `status`。
- `write`：同样的文字再写一遍 = 保留，年龄不重算；
- 超过 120 字 / 空：拒绝（裁决缝只验格式）。
