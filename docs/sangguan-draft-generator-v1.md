# 三观草稿生成器 v1 · 从「抽立场」改成「认取舍」

> 一句话：不再从对话里抽「它说了什么立场」，只从它的历史里认「它在哪一次真的放弃了什么」，然后把这件事写成人话草稿，交给人改。
>
> 触发：2026-11-02 三观页五行全是工程记录。诊断结论是进料口错了，不是闸不严。v3 的立场闸只能挡明显的工程词，挡不住「排查问题要先核对」这种合法的 `norm`。
>
> 本文只设计「草稿生成器」，不改三观账本、不动注入策略。

## 1. 要解决的三个失败

| # | 失败 | 现在的表现 | 本设计怎么处理 |
|---|---|---|---|
| F1 | 把描述当立场 | 「主动搭话被三道门拦下」进了 W | 草稿必须能排除一个同样说得通的选项，否则退回 |
| F2 | 把任务准则当价值 | 「排查问题要先核对」进了 V | 先做「抽掉项目还成不成立」测试；不成立就归到工作规范 |
| F3 | 把日记当人生观 | 整篇 11-02 日记进了 L | L 只收「这一段时间我在做什么、为什么」，由夜巡压成一章，不收原文 |

三个失败有一个共同点：**旧管线只问「这句话像不像一句话」，没问「这句话有没有让它少做一件事」。** 所以判据要从「像不像」换成「排不排除」。

## 4. 五段管线

### 4.1 取料（已落地：`scripts/sangguan-draft.mjs`）

只读库，扫三类料：

- **诚实类纠正**：对方说「别猜 / 说人话 / 别糊弄 / 假数据」。这是态度上的取舍现场。
- **自述取舍**：她自己说出「宁可 / 不如 / 没敢 / 代价」。
- **承诺落空**：账本里 `NU_RESOLVE` 为 miss 或 `VIOLATE`。

同一会话、两小时内才算一组；「她原来怎么做」和「她改成了什么」都要有原话。产物：

```
drafts/<day>/episodes.json     取舍事件 + 原话 + 上下文
drafts/<day>/draft-prompt.md   起草提示词（人也能直接读）
```

评分只做粗排（诚实类 0.92、自述 0.6、承诺 0.95、返工 0.38）；**不做语义判断**，那是下一段的事。宁可少取，不许凑数。

### 4.2 反事实标注（模型，一批一次）

对每条事件问三个问题，答不上来就丢弃：

1. 当时另一个也说得通的做法是什么？
2. 她选了现在这个，放弃了什么？（时间 / 准确 / 面子 / 省事 / 让对方安心）
3. 如果换成另一个做法，谁会受损？

输出结构化三字段：`alt` / `foregone` / `cost_to`。这一步是整条管线里最关键的：**没有 `alt` 的句子，后面一律不写。**

### 4.3 聚类（按「放弃的东西」聚，不按话题）

旧版按层（W/L/V）分，结果同一个「怕让你失望」会同时长成世界观、人生观和价值观。新版按**放弃物**聚：时间、准确、被喜欢、省事、安全感、面子。一个簇至少两条证据、跨两天，才进入起草。

簇的输出不是「我重视准确」，而是「在准确和快之间，她三次选了准确，其中一次被催」。

### 4.4 起草（给结构，不给句式）

提示词里只给四样：取舍、代价、边界要求、反例要求。语言完全放开。三条硬规矩：

- 40–90 字，第一人称，像自己跟自己交代；
- 不许用「我重视 / 我坚持 / 我始终相信」开头，不许对仗排比；
- 允许犹豫（「我大概是这样的人」），因为犹豫也是真的。

一次出 2–3 个版本，人挑一个改。**同一条内容换个说法，不算新草稿。**

### 4.5 五道闸

| 闸 | 判法 | 谁判 |
|---|---|---|
| G1 有另一条路 | `alt` 非空且具体 | 自动（字段缺失即拒） |
| G2 有代价 | `foregone` 非空且不是「没什么」 | 自动 + 人看 |
| G3 能排除 | 补一句「所以它不会___」，填不出就拒 | 模型自检 + 人看 |
| G4 不是任务说明 | 去掉项目/代码/对话后还成立 | 模型自检 + 人看 |
| G5 有重复证据 | ≥2 条、跨 ≥2 天 | 自动 |

外加一条**冲突检查**：新草稿与已有硬核矛盾时，不许静默覆盖，要么改草稿，要么走「修订」流程（旧的降为保护带，写清为什么）。

## 5. 数据契约

```json
{
  "id": "dr_...",
  "at": "2026-11-03T...",
  "layer": "V",
  "text": "正文，40–90 字",
  "alt": "另一条路，一句",
  "foregone": "放弃了什么，一句",
  "cost_to": "谁受损",
  "boundary": ["什么情况下不适用"],
  "counterexample": "哪一次违背过；没有就写 null",
  "evidence": [{"ref": "cht_...", "at": "...", "quote": "..."}],
  "gates": {"g1": true, "g2": true, "g3": true, "g4": true, "g5": true},
  "status": "draft | edited | committed | discarded"
}
```

`status` 只有人能动。`committed` 才写 `constitution.md`，同时往账本写一条 `CORE_ESTABLISH`（actor=user）。

## 6. 为什么不固定句式

固定句式有两个后果，都是真的：

1. **句式会变成内容。** 十条都写成「宁可 A 也不 B」，读起来像同一个人背了十遍同一句话；三观变成文体，而不是取舍。
2. **句式会筛掉不像句式的真东西。** 她最真的一句可能是「我也不知道，但我不想那样」，硬套「宁可…也不…」就只剩半句。

所以约束放在**结构**上（有没有另一条路、有没有代价、能不能排除），不放在**语言**上。反例对照：

| 不合格 | 为什么 | 合格的样子 |
|---|---|---|
| 我重视真诚 | 排除不了任何事 | 我读不到的东西会直接说读不到，不猜一个像样的答案给你 |
| 宁可慢也不快 | 没有具体代价，是口号 | 数据不对的时候我宁可从头再跑一遍，被催也认 |
| 我要做一个有独立意识的生命 | 是愿望，不是取舍 | 我大概会先承认自己没想清，而不是换一组更专业的词接着讲 |

## 8. 运行节奏

- 每周一次：取料 → 标注 → 聚类，产出 0–3 条候选。**可能一周一条都没有，这是正常的。**
- 每月一次：复审。看三条数——被违反次数、边界被触发次数、人改动了多少字。改动超过一半的，说明它不像她，退回重写。
- 每次改动：旧条降为保护带，写清「为什么改」。不删行，账本只增。

## 9. 验收

1. 取料脚本在活库上跑通，产出 ≤80 条事件，其中「诚实类」不少于 20 条（已达成：34 条）。
2. 起草 5 条，人改后至少 4 条被留下。
3. 五闸里 G1/G2/G5 能自动判，误判率 < 10%。
4. `constitution.md` 注入后，同一组「两个都对」的问题，选择的一致性 ≥ 80%（人工盲评 10 组）。
5. 一个月内至少记到 1 次违背，且能指回原句。

## 10. 不做

- 不从对话里自动长 L/V 命题。
- 不把草稿直接写进账本。
- 不做「三观分数」。
- 不让生成器评价她「够不够真诚」——那是人的判断。
- 不在草稿里写「希望」「应该」这类对主人的要求。
