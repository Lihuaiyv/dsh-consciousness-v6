# 小汐 · 全身 CT（2026-11-04）

> 首版。目的不是「按目录整理」，是回答一件事：**改任何东西之前，先知道自己在动哪一层。**
> 图：`docs/解剖-2026-11-04.png`

## 怎么拍的

不按目录分，按「它在这个系统里干什么」分。拿任何一个文件来，问六个问题：

1. 它产生行为吗？——不产生、只约束行为 → **基因**
2. 它决定「做不做 / 改不改」吗？→ **大脑**
3. 它保存「发生过什么」吗？→ **骨架**
4. 它算出「这轮用哪个 / 多少」吗？→ **器官**
5. 它跟外界说话吗？→ **四肢**
6. 它只是给人看吗？→ **皮肤**
7. 它在记录「有没有坏」吗？→ **免疫**

## 每层在哪儿、为什么

**基因**：`src/ports/`（接口与表归属）、`db.js`（schema / 迁移 / 恢复）、`kernel.js`（参数表 / 事务 / 事件）、`algo/registry.js`（注册协议）、`host/dsh.js`（唯一认识 DSH 的适配层）、`selfmod_targets.js`（可改面注册表）、`sangguan/schema|config|bridge`（三观契约）。共同点：不产生行为，只约束行为；平时看不见，坏了全是零件一起坏。

**大脑**：`index.js`（装配、事件、路由）、`features.js`（决策集合）、`gate.js`（写准入）、`owner_gate.js`（身份闸）、`selfmod.js`（改自己的流程）、`pack.js`（注入决策）、`expression_state.js`（表达档）、`style_mode.js`（chat/work）、`surfacing.js`（浮现选择）、`heartbeat.js`（节拍）、`memory_source.js`（写入闸）、`passport.js`（身份陈述）。

**骨架**：`api.js`（信封路由，脊柱）、`archive/timeline/asof`（三层档案与时间）、`memory.js`（记忆存储）、`tiers.js`（热度）、`binding/conversations`（会话归属）、`artifacts.js`（工件版本）、`entities.js`（实体表）、`mindstate.js`（token 计量）、`selfmod_store.js`（自修改存储）。

**器官**：按能力分——召回（`algo/recall`、`retrieve`、`memory_tag/fade`）、情绪（`affect`、`algo/appraise`、`algo/affect_dyn`、`feel`、`felt_snapshot`、`poisons`）、驱力（`drive`、`algo/deficit`、`proxies`、`edges`）、鱼格（`traits`、`persona_dims`、`axis_evidence`）、关系（`relations`、`relations_extract`、`conflict*`、`contradict`）、三观（`sangguan/*`）、自我（`self_*`、`selfview`、`selfnote`）、生活与主动（`life`、`lifeview`、`loops`、`pulse`、`thoughts`、`surfacing`）、记忆整理（`nightly`、`consolidate`、`diary`、`extract_queue`、`episode_distill`）、自修改信号（`selfmod_drivers`）。

**四肢**：`modules/actions/{channels,bilibili,research,wechat,credibility,util,index}`、`browse.js`、`qq_bridge/qq_watch/qq_push`。

**皮肤**：`client.js`、`src/catalog.json`。

**免疫**：`eval.js`（验收硬门槛）、`judge.js`、`persona_judge.js`、`ops.js`、`self_scan.js`、`stale_pair.js`、`retrieval_log.js`、`scripts/check-*`、`scripts/doctor.mjs`。

## 8 处跨层（真正的雷）

| 文件 | 现在混了什么 | 该拆成 | 风险 |
|---|---|---|---|
| `features.js` | 2,757 行里 8 种能力：关系 / 价值观 / 主动 / 注入 / 参数 / 指标… | 各自独立模块 + 大脑只留裁决 | 改 A 会误伤 B；测试只能整文件跑 |
| `api.js` | 协议 + 路由 + 业务读写 | 路由表 + 各域 handler | 加路由时容易碰到别人的读 |
| `memory.js` | 存储 + 打分 + 写入 | store / scorer / writer | 打分改坏了会丢记忆 |
| `gate.js` | 判定 + 真正写库 | judge / apply | 判定和副作用一起回滚不了 |
| `selfmod.js` | 流程 + 存储 + 影子评估 | plan / store / shadow | 改流程时碰到审计 |
| `relations.js` | 抽取 + 打分 + 工具定义 | extract / score / tools | 工具坏了像抽取坏了 |
| `heartbeat.js` | 节拍 + 浮现 + 主动开口 | tick / surface / decide | 节拍一变，行为全变 |
| `sangguan/bridge.js` | 适配层同时承担契约 | adapter / contract | 换三观存储会牵动注入 |

## 三个发现

1. **大脑只有 12 个文件，却要裁决 120+ 个器官**；而且裁决逻辑一半在 `index.js`、一半在 `features.js`。不是缺代码，是缺一个「大脑盒」——「我不变」这件事没有物理落点。
2. **基因 17 个文件，被自动守住的只有 4 条**（厂商名 / 参数 / 表归属 / 依赖图）。schema 版本、参数默认值、注册协议没有自动守——基因现在靠自觉。
3. **器官 120+，只有 5 个在注册表里能换版本**（recall / decay / deficit / appraise / affect_dyn）。其余是「焊死的器官」：能改，不能换。要插拔，先给它们做考卷。
