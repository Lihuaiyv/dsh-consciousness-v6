## 三、适配六库：每个库改什么

### T0 自我（人格 / 关系 / 禁忌 / 价值）
- 现状：不进检索，没有时态。
- 改动：偏好/关系变化时，人格段标「以前…现在…」（只标一次，不每轮重复）。低优先。
- 不做：不把 T0 拉进护照/检索。

### T1 事实（memory_items + fact_archive + memory_timeline）
- 现状：有 valid_from / invalid_at / supersede，但注入侧不读。
- 改动：
  - S1 护照：注入时读 timeline 的 `valid_from` / `REVISE` / `INVALIDATE`。
  - S4 写侧：gate 的 UPDATE 同时写「被取代」语义（REVISE 或 supersede，二选一规则）。
  - S5 状态词：写入时打 `state_pending` 标记（复用 fact_key 后缀或新增字段？——**不新增字段**，用 `fact_key` 后缀 + `terms` 标记）。
- 开关：`memory.passport`（默认 on）、`memory.stale.eject`（默认 on）。

### T2 纪要（episodes）
- 现状：有 start_at/end_at/day，无失效；bridge 只取一条。
- 改动：
  - S2：护照的 occurred 取 start_at；valid_until 用「之后同主题新纪要/新事实」判定。
  - S3：bridge 取最近 3 条，优先今天；标「那时」。
  - F12：T2 不整段进 S1，但「最新进展」作为一条带护照的引用进注入。

### T3 日记（diaries）
- 现状：有 day、refs，无失效。
- 改动：
  - S2：护照 occurred=day；若 refs 指向的事实后来被改，标「后来改过」。
  - 注入时带「写于哪天」。

### T4 原文 / 存根（raw_turns / fact_archive）
- 现状：只追加、几乎不读；payload 有 episode/day/seg 但没人用。
- 改动：
  - S1：derived_from 从这里取（episode_id / turn_id）。
  - S2：仲裁的证据来源；只读，不写入。

### 索引（memory_timeline / heat / temp_state）
- 现状：timeline 只给 asof；heat/temp 只管「进不进 S1」。
- 改动：
  - S1：作为护照的唯一时态来源（不新存）。
  - S3：被取代的条在 temp_state 里不直接改，注入层用护照判定。

### 装运层（pack / index 注入拼装）
- 改动：
  - S7：pack 加 `requirePassport` 门槛；无护照降级。
  - S3：失效条优先丢；`clampInjection` 增加一行「已失效」的丢弃档。

## 四、数据流（改完后）

```
写入：ingest → gate（S4 分工）→ memory_items + fact_archive + timeline
        └─ 状态词打标（S5）
读取：retrieve（T1/T2/T3/T4）→ 护照申领（S1）
      └─ 跨库失效（S2）
装箱：pack（S7 门槛）→ 失效先丢（S3）→ 注入
整理：reflect（S6 聚类/hedge）→ 合并稿回链
观测：retrieval_log + 三问覆盖率（S8）
```

## 五、实施顺序（合并所有版本后的最终顺序）

1. **S0 只读体检**：护照 dry-run（S1）+ 跨库回放集（S8）+ 冲突现状复核。
2. **S1 护照（T1 先行）**：只做「失效/生效」标注，不挤出。
3. **S2 跨库失效（T2 → T3 → T4）**：先接 T2 纪要这一路，验证有效再加 T3/T4。
4. **S3 旧条挤出 + pack 门槛**：这一步才真正改变注入内容。
5. **S4 写侧分工**：状态词、gate UPDATE、冲突/过时规则。
6. **S5/S6 整理侧**：reflect 聚类、状态保护、hedge、fade 停手。
7. **S7/S8 收口**：界面三类事件分开、指标、回归。

每步先 dry-run，再上开关；任一步出问题，关开关回退到上一步。

## 六、验收（不变量）

1. **三问覆盖**：抽 20 条注入行，必须答出「什么时候的 / 现在还作数吗 / 从哪来」；覆盖率 100%。
2. **证据链**：任何被取代的 T1，能在 T2/T3/T4 找到至少一条证据。
3. **回放集**：20–50 对「旧结论 + 新进展」，修复后回答「现在怎样」的准确率高于基线。
4. **不误伤**：旧条抽查 20 条，错标率 < 10%。
5. **只读**：护照/仲裁不 touch、不加热。
6. **回归**：`eval:memory`、`sim:days`、`float`、`recent` 小回放集全绿。

## 七、不做 / 回滚

- 不新增表、不改 schema、不引图数据库、不重写 T2/T3/T4。
- 全部用开关：`memory.passport`、`memory.stale.eject`、`memory.recent.inject`、`memory.asof.auto`、`memory.write.flip_policy`。
- 关开关即回到现状；已作废的旧条仍可深查。

- v3 的六库角色与跨库仲裁 → 变成 S2 的跨库失效。
- v4 的四时间与护照 → 变成 S1/S7 的统一产物。
