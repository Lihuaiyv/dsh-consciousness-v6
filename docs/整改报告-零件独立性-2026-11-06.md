> 接上午的[复查](复查-零件基本定义-2026-11-06.md)：那次查出「十件里只有开环是真零件」，这一页记怎么改的、改完的数据、还剩什么。

## 一、四步做了什么

1. **补登记 + 写权归口**
   - 新域 `queue`（`src/modules/proactive.js`）：`proactive` 这张队列表只由它写。开口、冲突提问、投递（`push` / `qq_push`）、作废、按事由撤销，全改调它的公开函数。
   - 新域 `speak`：主动开口八个文件进名单，只写 `proactive_decisions` / `proactive_stats`。
   - 新域 `expression`：说话分寸两个纯函数文件进名单（不碰表）。
   - `memory_source.js` 并进 writegate 域；`reldyn.js` / `desensitize.js` 并进 relations 域。
   - `WRITES.memory` 移除 `proactive`，单写手成立。
2. **搬家（只搬不改）**
   - `clampInjection` 从 `features.js`（2439 行的大宿主）搬进 `src/modules/pack.js`；`features.js` 只留一行 re-export，老 import 不用改。
3. **摘接线**
   - 主动开口的 `files` 从 13 个减到 8 个：`features.js` / `index.js` / `push.js` / `qq_push.js` / `client.js` 全是接线，写进 `entry` 与说明页，不再冒充零件文件。
   - 召回去掉 `pack.js`（它本来就不 import pack，登记多了）和宿主 `index.js`。
   - 情绪评价、写入闸、注入去掉 `features.js`；写入闸说明页写明「落库车道在宿主，不算零件文件」。
4. **上界桩**
   - `check-parts` 新增三条：回退点必须是真 git tag、入口函数必须真导出着、说明页必须存在。
   - 独立性检查接进 `check:arch`，以后每笔提交都过。

## 三、找到并修掉的 bug

1. **衰减零件的入口登记错了**：写着 `targetTemp` 在 `tiers.js`，实际在 `temps.js`。新加的入口检查第一条就抓住它。
2. **说话模拟的假模型过期**：词表提示词早就从「只输出一行中文」改成 JSON `{"line":…}`，假模型还在按老暗号识别，于是每句都被判成非中文、词表 0 接收，「改后」退化成「改前」。修好后模拟才真的在测改后。
3. **多轮模拟的断言过期**：感受行抬头从「感觉现在大概」改成「这会儿大概」，断言还在找老词，一直误报红。
4. **队列没有自己的单测**：补了 23 条，钉住 pending / 投递 / 回应 / 忽略 / 划掉 / 作废 / 按事由撤销 / 两个 agent 不串。

## 四、行为没变的证据

- 搬家前 564/564，搬家后 564/564；注入考卷 49/49 两次一致。
- `clampInjection` 是整段照搬，只换文件；`features.js` 保留同名导出，所有老调用（`index.js`、7 个测试、bench）不用改。
- 参数一个没动：气头线 0.68、迟滞 0.08、丢弃次序、配额都原样。
- 队列的 SQL 语句是原文搬进 `modules/proactive.js`（含 `delivered_at` 留空这种旧行为），只把调用点改成函数。

## 五、还剩什么（不藏）

1. **主动开口没有打假用例**：其余九件都有坏版本被拦的记录，它是唯一一张没被塞过坏版本的卷子。
2. **人味基准里「200/150 预算下保住情绪」两行还是「否」**：这是基准自己的老场景，跟这次搬家无关，但还没修。
