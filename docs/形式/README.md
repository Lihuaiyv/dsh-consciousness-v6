## 规矩

1. **形式是一份文件，不是一段口头约定。** 没写下来的形式，下次就变回我随手写。
2. **用了哪种形式，在新文档头上写清楚**（`> 形式：夯实`），别让人猜。
3. **想改形式，改那份形式文件**，别就地发挥。
4. 形式文件本身放在这里，跟功能无关——功能目录里放的是内容。
