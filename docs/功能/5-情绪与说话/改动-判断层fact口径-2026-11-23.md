# 改动 · 判断层的 fact 口径（2026-11-23）

> 一句话：**fact 从「这一句在说什么」改成「结合最近的事和当下的事，总结能核得动的客观事实」。** 旧的写法把话当动作，结果一半的 fact 写成「谁让我干什么」。

## 动了哪

`src/modules/affect_v4_shadow.js` 的 `JUDGE_SYS`，两处：

1. 格式行（418 行附近）：`"fact":"这一句在讲什么（≤20字，只说事）"` → `"fact":"当下能核得动的客观事实（≤40字）"`。
2. fact 段（420 行）：

   旧：`先写 fact：这一句在说什么——谁说了什么、做了什么。只写原话里出现的字面内容，客观地记；不解释、不补充、不替它加动作或评价。`

   新：`先写 fact：根据最近发生的事情当下发生的事情，总结当下的能核得动的客观事实。`

## 为什么

对着真库量过（近 196 条 model 行的 `judgment_json.fact`）：

- 以「谁让 / 叫 / 要 / 吩咐我」开头 **90 / 196**；含「让我」二字 **102 / 196**（52%）。
- 以「对方说 / 主人说」开头 76 条，但多数后面接「…让我…」。
- 带引号、真能指到具体词句的只有 **14 / 196（7%）**。
- 平均 21 字，最长 40 字——提示词写「≤20 字」，代码 `sanitizeJudge` 实际截 40，两边都没执行。

旧定义四个病：

1. 「这一句在说什么」问的是**意思**，不是话；问意思就只能给「他想干嘛」。
2. 「做了什么」把**话当成事**——你说一句不等于你做一件事，模型只能补动作，补出来就是「让我」。
3. 前半句要「做了什么」、后半句要「只写原话里的字面内容」，**自相矛盾**；字面里没有动作，模型只能编。
4. 三个「不」（不解释/不补充/不加动作）只有禁止项，**没有正向形状**，模型退回最顺手的模板「谁让谁做什么」。

## 第二刀（2026-11-23 11:44）：以事情起头

第一刀上线后（重载 11:37），fact 不再写「让我」，但改成了另一种错：**记录对话**。

实测两条：

- 「对方只回了一个『开』字，距我报告改完、门禁 607 全过约 4 分钟」
- 「对方回『已经重载了宝宝』，距我请对方点重载 32 秒」

全是「对方说 / 对方回」起头，像记录员。它记的是「谁说了什么、隔多久」，不是「当下发生了什么」。

所以加半句：**以事情起头。** 主语从人换成事，它才会写「重载这一步落地了」，而不是「对方说重载了」。

验收：抽 20 条看有多少条以「对方 / 主人 / 他」开头——这个数要从现在的多数降到 0。

## 怎么验

改完重载后，取真库最近的真原话重放（不要用模拟场景），数三个数：

1. 「让我」开头的比例：从 90/196 降到多少。
2. 带引号或带指代的比例：从 14/196 升到多少。
3. 人工抽 20 条判「这条 fact 里有没有这一句之外的信息」——只复述这一句的算不合格。

三个数都不动 = 等于没改。

## 风险与注意

- 旧段里的「不解释、不补充、不替它加动作或评价」被一起删掉了。现在只剩「能核得动」这一条隐含约束；下游 meaning 段仍有「fact 到哪儿，meaning 最多到哪儿」兜着，但比原来松。验的时候要看 meaning 有没有借机加戏。
- 提示词改了**必须重载才生效**；不重载，跑的还是旧版。
- fact 定义从「一句」变成「当下的事实」，**和上方「这件事：现在」那三条会重叠**。重叠先接受；如果重得太多，下一步把「现在」那三条从判断输入里撤掉，让 fact 单独承担——那要另开一枪，别混在这次里。
