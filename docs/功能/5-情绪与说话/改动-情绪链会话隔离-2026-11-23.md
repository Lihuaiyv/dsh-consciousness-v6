# 改动 · 情绪链的会话隔离（2026-11-23）

> 一句话：**同一个 agent 下两个会话平行跑的时候，链上有三处状态没按会话分开**，导致同一句话被反复判、罢工标记互相清除。这次全按会话隔离。

## 动了哪

1. **`index.js` 去重槽**（preStep 里 `lastAffectTurn`）：`get/set` 的键从 `agent` 改成 `agent|会话`。
2. **`affect_v4_shadow.js` 罢工标记**：`affect.v4.strike` 改成 `affect.v4.strike|<会话>`，清除也只清自己那段。
3. **`index.js` 读罢工**：先读本会话的 `affect.v4.strike|<会话>`，读不到再退全局（兼容旧数据）。

## 为什么

**去重槽**：只按 agent 存一个「最后一句」。A 会话判完写 key，B 会话进来把同一格覆盖，A 下次对不上就再判一遍。实测（11-23 10:02–10:24）`26a427` 和 `864d81` 严格交替，同一句「你先修一下吧」在两个会话里各被判了十几遍，`26a427` 自己的 d 从 0.81 一路刷到 1.00，s 钉在 0.64。**不是跨会话叠加 d**，是同一段会话里同一句被算很多遍。

**罢工标记**：读的时候有 `sameConv` 过滤，清的时候没有。A 判失败写标记，B 判成功 `clearFlag` 把全局槽抹掉，A 的「情绪模块罢工」提示就凭空消失。

## 怎么验

1. 门禁：`node test/run-tests.mjs` → **608 / 608**（改动前后都跑过）。
2. 真库数据（重载后）：两个会话交替时，同一句原话在该会话里只应落一条 `model` 行；按 `conversation_id + fact` 分组，连续重复应从「十几条」降到 1。
3. 罢工：A 会话故意判失败、B 会话判成功，A 的 `affect.v4.strike|<A>` 应该还在。

## 怎么退

三处逐条回：

1. `index.js` 去重：把 `const slot = aid2 + '|' + sid2` 去掉，`get/set` 改回 `aid2`。
2. `affect_v4_shadow.js` 罢工：`strikeKey` 改回常量 `'affect.v4.strike'`。
3. `index.js` 读罢工：改回只读 `'affect.v4.strike'`。

## 还没隔离的（有意留着）

- `affect.v4.summary.diag` / `affect.v4.judge.diag` / `affect.v4.judge.incomplete`：全局诊断，并发会互相覆盖，只丢诊断信息，不影响判定。
- `affect.v4.valence`（无会话后缀那份）：页面「现在」用的全局投影，设计如此；按会话的那份是给「这一段自己的 total」。
- `affect.v3.slow` / `affect.v4.cross.*`：agent 级，**本来就该跨会话**（底色），不动。

## 注意

改动要**重载**才生效。
