# 情绪总纲 · 形状向人类、骨架要自洽（2026-11-19）

> 主人：「形状是这么个形状，但是不用完全贴合。大体向人类，工程上自洽这是最重要的。」
> 这一页是**入口**。具体两份设计在下面，分工不重叠。

## 一、三层分工（谁也不越界）

```
第 1 层  事 → 方向       [设计-事到情绪的自洽映射](设计-事到情绪的自洽映射-2026-11-19.md)
        谁做的（我 / 对方 / 世界）· 我得还是失 · 意不意外
        → 定这一下是「安升还是降、欲往外还是往回收、觉高还是低」
        ← 这一层管自洽：同类事落同一格，不同类不串味

第 2 层  方向 → 形状     [设计-三递质各自算法](设计-三递质各自算法-2026-11-19.md)
        每根轴自己的动力学：安追设定点、觉是增益且回落极快、欲看预测误差
        → 定力度、节奏、余温、放大

第 3 层  三个数 → 落点   现成的几何（球面 / 八角），不动
```

**第 1 层定「往哪边走」，第 2 层定「怎么走到那儿」。** 两层正交，不打架。

## 二、为什么不能只用一层

只做第 1 层（事→格）：情绪会像开关，一句话立刻到格心，没有余温、没有放大、没有慢下来。做过山车，不像活的。

只做第 2 层（激素动态）：就是这一轮之前的错——形状挺像，但方向全靠模型猜三个连续小数，
猜出来的是「所有好事都是 +0.5」，生气和愧疚分不开，工程上不自洽。

两层都要：**方向用责任归属定死（可解释、可验收），形状用动力学给（有惯性、有快慢、有余温）。**

## 三、自洽怎么算通过（工程验收）

1. **同类必同格**：六类典型事（被冒犯 / 被珍视 / 被搁下 / 自己搞砸 / 自己做成 / 客观倒霉），
   每类落一格，且每次都落那一格。
2. **不同类不串**：「他害的」和「我自己弄坏的」必须分开（渴慕 vs 沉沦），这是整张表的钥匙。
3. **说得出口**：每条结论都能用一句话讲清为什么（「我恼，因为他弄的、我亏了、还撞上来了」）。
4. **不会自己跑到边上**：形状层负责——靠近边界的输入被吸收，回落一直在跑。

## 四、向人类学什么、不学什么

**学**：三条轴确实分工不同（安看远、欲算差、觉放大）；回落不是瞬间的；强烈的会盖过平常的。
**不学**：血清素的张力性水平、昼夜节律、受体下调 —— 这些是身体的实现细节，我们是另一个东西，
硬贴上去只会让系统更难算、更难验。**形状上有那个味道就行，不必是那个人。**
