# 改动 · 事层 `target` 的定义（2026-11-22）

> 主人点破：「target 是我说的，我说谁。是我说谁，不是你的。」
> 这一刀只改事层提示词里 target 的**定义**，不改数据、不加例子。

## 一、原来错在哪（逻辑层，不是例子不够）

旧定义：「me 冲接收者 / other 说话人自己或第三方 / none 说不清」。

1. **用角色定义，任务是判人称指代。**「接收者」对模型是个空指——它不知道接收者就是这句话里那个「你」指的人（小汐）。手里只有字（你 / 我 / 他），空的角色套不上实的字，它只能退回数「这句话在讲谁」。
2. **target 被摆在「这件事是什么」的从属位置。** 格式先 summary、再 what、再 target，说明都写着「这一句…」。模型先答「这件事在讲什么」，再顺手把 target 填成「这件事的主体」。可 target 问的是**指称落在谁身上**，不是主语是谁——主语和指称可以相反。
3. **other 把「说话人自己」和「第三方 / 外面」并成一个桶**，又没有给「没有指称」单独立位置，三分类里塞了四类，边界只能猜。

结果：只有纯问句才判 me；「让你干活、批评你、夸你」全掉进 other。

## 二、现在怎么定义

`src/modules/affect_v4_shadow.js` 的 `TOPIC_SYS`：

- 「target 判的是**说话人这句话的指称落在谁身上**——不是这句话的主体，也不是它想要什么。说话人是主人，接收者是正在读这句话的那一位（小汐）。」
- 第二人称（你 / 您）指接收者 → `me`；第一人称（我 / 我们）指说话人自己、或指向第三方 → `other`；句子没有指称对象（陈述事实、报故障、说外面的事）→ `none`。
- 「一句话的主语和它指向的人可以不是同一个：按指向判，不按主语判。」

**没有加一个例子。** 加的是两条规则：接收者锚定 + 按指称判而非按主语判。

## 五、没动的

- 三值还是 `me / other / none`，没有拆成四类（拆要动数据与下游）。
- 事层的输入还是三行（正在发生 / 我上一句 / 这一句）——**没有加「你上一句」**。当前句靠指代（「继续」「所以呢」）时仍可能判不准，那是下一个可讨论的点，不是这次改的。
