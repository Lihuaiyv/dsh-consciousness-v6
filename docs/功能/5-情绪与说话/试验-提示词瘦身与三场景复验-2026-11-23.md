### 讪讪标注补「对方」——试过，**退回**（2026-11-23 08:44–08:48）

**起因**：H#5「你别当回事，我就是随口一说」落「被点破」——那是被揭穿，不是自己往后退。

**根因（查出来的）**：`讪讪` 的 `GRID_ANNOT` 是 `[["我"],["冲自己","无"],0]`，by 只标「我」；现实里「讪讪」多半是「他让我讪讪」（by=other）。判官判 by=other 时它差一档、典型度掉到 0.28，被 0.6 门槛剔出候选。补上「对方」后 H#5 立刻变成「讪讪」，六场泛用词 33%→30%。

**但评审判它净负**（同一批评审口径，讪讪修正前后对比）：

| | 讪讪修正前 | 讪讪修正后 |
|---|---|---|
| 词 贴 / 偏 / 错 | 35 / 25 / 4 | **34 / 23 / 7** |
| 讪讪出现 | 0 次 | 5–6 次 |

评审逐条看：讪讪 3 次里 2 错 1 对——D#9「我困了」、D#10「明天见」（收场道别不该讪讪）、C#9「差点被你吓死」（受惊讪笑的是他）都是借来用的；只有 E#2「有些地方不太稳」对。**贴少 1、错多 3，不值得**，已回退 `[["我"],...]`。

**教训**：单个 H#5 变对，不等于整体变好。补标注会让一个词在别的格子里冒出来——「这里变对了」和「别处没被弄坏」是两件事，都要验。

**同法试「惆怅」（by 加「对方」）——零变化，已退**：六场词一个都没变，说明它根本没被算进候选，补标注是白改。

**「讪讪」那条方法的边界**：只有当那个词本来就该出现在某句上、只因 by/to 标窄被门槛剔掉时，补标注才有效；词根本没进候选的（惆怅），补了也没用。

- 坐标：`踏实` s 0.66 / n 0.252 / d 0.48；`舒坦` s 0.70 / n 0.252 / d 0.46；`空落落` s 0.42 / n 0.303 / d 0.34；`被晾着` s 0.36 / n 0.235 / d 0.30。

- 但 `踏实` 的 GRID_ANNOT 标了 [我, 对方, 外面, 无] 四个 by，典型度任何句都过得了 0.6 门槛；`空落落 / 被晾着` 标注窄。于是典型度一拉开，距离那 0.02 就被吃掉，`踏实` 在球心附近通吃。
- 所以问题不在坐标本身（0.02 的差不算错），在**「踏实/舒坦」这类泛用词的典型度标注太宽**——它们既是「安住」该用的词，又到处都能过闸。
- 两条可选改法（都动词库，**今晚没动，等主人点头**）：
  1. 收窄 `踏实 / 舒坦` 的 GRID_ANNOT by（例如只留 [我, 无]），让出球心附近那格；风险：这类词一收窄，30% 的命中可能掉（`心里软` 收窄那次从 30% 掉到 16%，已回退）。
  2. 把 `踏实 / 舒坦` 的 s 往上挪一点（0.66→0.72 左右），让它们在「真安住」时才赢；风险：挪坐标曾一次改 7 个词把格子打乱（28%→17%），必须一个词一动、逐次验。

## 四、结论

1. **词变好**：C 被指责句 心里发虚→心里堵/空落落；被推开句 忧伤→懊恼；B 那声「嗯」 有点空→厌倦；A 等待句 空落落。瘦身后模型更愿意按事实推，不是抄模板。
2. **to 没有错判，只有 7 条半**：集中在他「抬头看屏幕、不看我」那几句（C#6「还是不行」、C#8「下去了」、B#3「嗯」）——系统把「我在场」当成「他在冲我」。这是判据/位置层的结构问题，**不是提示词能压的**；「别默认 me」那句实测反效（none 8→2）。
3. **选词层有一个真 bug**：B#2「没事，你先忙」——label 直接成了「没事」，抄的是我嘴上说的话，不是心里的状态。属于词库/注解问题，与提示词无关。
   - 根因已查：`lexicon_v4.js:201` 有词条 `没事`（s 0.52 / n 0.16 / d 0.5），同时 `grid_pick.js:83` 把它放进了 `NOEVENT`（「真没事」族，永远进候选）。这句判决是 g+0.06 / e−0.55 / f−0.08，噪声门把 g、f 抹成 0，落点回到球心附近 → 选词层认为「真没事」，就给了「没事」。问题不在判据，在这个词本身有歧义：它既是状态词，又天天出现在话里；选词层看不到「这是嘴上说的」。
   - 不能靠加规则解决（用户明确不许叠规则）。可选的路：把 `没事` 从 NOEVENT 里拿出来（球心附近让「如常/平静/还好」顶上），或换一个不容易被话面触发的词。两条都动词库，先记档，等主人点头。
4. 偏的 10 条集中在「把话听太满」：一声「嗯」→厌倦、派活→舒坦、「查到了吗」→空落落。
