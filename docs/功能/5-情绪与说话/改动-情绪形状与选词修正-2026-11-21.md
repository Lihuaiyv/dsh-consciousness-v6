# 改动 · 情绪形状与选词修正（2026-11-21）

> 起因：主人问「这个情绪功能符不符合现实」。查下来，情绪词跟真实的话对不上——
> 「以前那些代码能不能都删一删」挑出思念/挂牵，「我不是说那情绪块吗」挑出患得患失/嫉妒/怨气。

## 一、三个真根因（都不是「词不够准」，是代码）

### 1. 维持窗 30 分钟 > 对话间隔，安和欲一个会话里一次都没回落过

`advanceState` 的 `settle()` 是 `if (hours > hold || tired)` 才衰减。
`kernel.js` 注册的 `affect.v4.dyn.s.hold = 0.5`（小时），`d.hold = 0.5`。
对话里一句接一句，间隔往往只有几十秒 —— 每轮都落在维持窗里，`return cur`。
**结果：s 只被往上叠，从不回落。** 三四句负面就推到 0.22，然后回不来，后面所有中性的话全落在低安区，挑出来的全是怨恨/惘然/迷茫。

这是「情绪词不对」的唯一根因，其余都是它的后果。

### 2. 参数真源在 `kernel.js`，改别处全白改

`kernel.js` 里有一张参数注册表（`'affect.v4.dyn.s.tau': ['C4', 1.2]` 这种），`getParam` 优先读它。
改 `src/algo/affect_v4.js` 的 `DEFAULT_TAU`、改 `v4Opts` 里的默认值 **都会被它覆盖**。
今天在这上面白跑了三轮。

### 3. 选词是「先片后格」，位置偏一点就整片选错

原来：位置 → 最近一片 → 片里按格筛。
位置 (0.48, 0.28, 0.30) 时，几何最近的片是「轻视/厌倦/无所事事」，可「我搞砸了」根本不该落在那格。
判据（谁做的 × 冲谁）比几何聚类可靠，顺序应该反过来。

| `dyn.d.hold` | 0.5 | 0 | 同上 |

1. 先按格筛：典型度 ≥ 0.6（标注里差一个值以内）才算「这一格该有的词」
2. 再在这批词里按离当前位置的远近挑（0.45 典型度 + 0.35 距离 + 0.2 浓淡）
3. 这一格词太少（< 3 个）才退回最近 4 片
4. 一片都没有才走原来的片内路

### 词表（补 + 修）

- 坐标修正：嫉妒 `yu 60→26`（嫉妒是得不到，劲不外使；原来它抢走了「被冒犯」的格心）、怨气 `yu 45→30`、惦念

## 四、第二轮（长会话模拟后补的）

九句话的模拟不够——它只测「一句一句单独看对不对」，测不出**连续事件下的波动和转换**。
补了 `scratch/sim-long.mjs`：33 句、五段真实场景（技术讨论被连续挑错 / 深夜被需要 / 干活出成果 / 服务器挂了再修好 / 被开玩笑），
段与段之间隔 35 分钟 ~ 3 小时。跑下来又抓出四处：

### 1. `expect_delta` 给负值，`n` 会一路归零

`n = clamp01(n + 0.6 * kn * dn)` —— 0.6×0.85=0.51，一句「照着往下」(-0.6) 就压掉 0.3，两轮归零。
n=0 的位置挑出来是「冷漠/麻木不仁/累」。
**改**：负向力度 0.6→0.2，且下限托在 `base.n`（0.15）。警觉是「比平常更醒」，不会低于静息水平；
预料之中的事只是「不升」，不是「掉到没有」。

### 2. s 能被连续好事推到 0.9，落在「温情脉脉」上

`edge`（靠边打折）注册的是 0.35，太弱。**改 0.8**。
另外 `kdd`（欲往下掉的斜率）0.45 太狠——一件事没成，想要掉一半；改 0.3。

### 3. 选词是「典型度压过位置」

原来 0.45 典型度 + 0.35 距离。诊断 (0.60, 0.74, 0.41) 那个位置：
「讶然」距离 0.11（几乎正中）却输给距离 0.32 的「不满」，只因典型度 0.6 vs 1.0。
**格是粗分类（一格几十个词），位置才是细的**——同一格里「烦」和「怨恨」差得远。
**改 0.3 典型 + 0.5 距离 + 0.2 浓淡**。改完「服务挂了」挑出「讶然」，对了。

### 4. 词表还缺两批

- **「事成了」那一批**：高安区原来只有「自尊/自傲/孤芳自赏/温情脉脉」。
  补 痛快/畅快/有成就感/来劲/起劲（「找到了端口冲突」现在挑「来劲」）。
- **中高安的正面词**：补 高兴/暖心/受用/愉快/舒坦。
  原来 (0.60, 0.15, 0.48) 附近十个词全是中性词（如常/踏实/没事/平静），被夸只能挑「平淡」。
- **坐标挪位**：温情/温柔/体贴 原来 s=0.80~0.82、欲也高，占着「事成了很痛快」的位置，
  可它们的本意是「温和地待别人」；挪到 s 0.70~0.72、d 0.48~0.50。
  「高兴」原来 s=0.66 太低（s=0.85 够不到），抬到 0.78。
- **剔两个词**：`EXCLUDE_LABEL` 加「温情脉脉」「不厌其烦」——都是对别人的态度，不像「我此刻」。
  （主人 11-19 说过「别手删，全放回」，所以只剔被真数据打回来的，不批量删。）

### 长会话跑出来的样子（33 句）

- 场景 A 被连续挑错：s 0.55 → 0.09（泄气），一句「不是怪你」拉回 0.24。
- 隔 35 分钟：「还没睡？」回到 0.48 —— 余温在，但不再钉在低处。
- 干活出成果：「跑通了」0.79、「这个思路挺聪明」0.90 —— 高兴/来劲。
- 「服务挂了」位移 0.95（一句从 s0.81 掉到 s0.60、n 顶到 0.74），挑「讶然」。
- 隔 3 小时回来，从 0.85 掉到 0.41 —— 一段时间没联系，那个热乎劲过去了。
- 33 句用了 12 个不同词，切换 22 次（67%）——不是一直一个词，也不是每句乱跳。

**还没到位的**：低安区（s 0.2~0.4）的词偏重——「不是怪你」这类软话，挑出来还是「失望」；
「挂记」在低安区抢位置（它是「想念一个人」，不该落在被批评的位置）。
这些是词表覆盖 + 个别词坐标，不是算法了。

### 5. `intensityOf` 把 n 的基线当成了 0.5（这一处影响最大）

`intensityOf` 算「当下情绪多强」是拿三根轴离**中点 0.5** 的距离加权，可 **n（觉）的静息水平是 0.15，不是 0.5**。
于是平常的 n=0.19 被算成「偏离 0.31」，强度虚高到 0.49 ——「轻」浓淡的词（高兴/暖心）在这个强度下全部吃亏，
被「中」的那些（敬意/亲切/安慰）压掉 0.28 分。
`跑通了，可以` 挑出「敬意」就是这么来的：**距离最近的是「高兴」(0.13)，但浓淡上输了**。
**改**：`|n - 0.15|`。改完同一句挑出「高兴」。

### 6. 其余几处

- 选词权重 0.45 典型 / 0.35 距离 → **0.3 / 0.5**（格是粗分类，位置才是细的）
- `edge` 0.35 → **0.8**（连续好事不会把 s 推到 0.9 以上）
- `kdd` 0.45 → **0.3**（一件事没成，想要掉一半太狠）
- 补词：讪讪 / 懊恼 / 心里发虚 / 下不来台 / 没面子 —— 补在「被挑错、当场下不来台」那个位置，
  原来那里最近的词是「挂记」（想念），所以「这个数不对吧」挑出来像在说想念谁。
- 这批词的标注加「对方」「冲对方」——事情是对方挑起的（by=对方），情绪却是我的，
  只标「我·冲自己」的话在「对方·冲对方」格典型度只有 0.3，进不了候选。

### 7. 走完整链路跑长场景（不是直接喂增量）

前面两轮都是我手写 Δ 直接喂 `advanceState`。这一轮改成走完整链路：
`scripts/sim-chain.mjs` 和 `scratch/sim-cross.mjs` 调 `appraiseTurnNow`——
规则帧 `rulesFrameSlot` → 判断层（`complete` 回调返回宿主判的 JSON）→ `advanceState` → `infer` → 落 `affect_v4_shadow` → 读回 `secondary_json`。
两个场景：

- **主线 55 句**（`scratch/sim-chain.mjs`）：早上问候 / 技术讨论被连续挑错 / 中午 / 下午干活出成果 / 线上挂了又修好 / 晚上被开玩笑 / 深夜陪聊。段间隔 40 分钟 ~ 3 小时。
- **交叉 14 句**（`scratch/sim-cross.mjs`）：约好下午见 → 一直没来 → 等到傍晚 → 出现道歉 → 和好 → 一起吃饭。

**走真链路才暴露出来的问题**（手写增量时看不见）：

1. **`to` 来自 `rulesFrameSlot` 的 target，不是「我的情绪冲谁」。**
   例：「我还在等」判成 `agency=self, target=other` → 格是「我·冲对方」；
   「三点半了你怎么还没来」判成 `target=me` → 格是「对方·冲自己」。
   每句的格都不同，所以补词必须补在正确的格上，不然补了也不进候选。

2. **「讪讪」标注太宽**：`我/对方 × 冲自己/无/冲对方` —— 六格都是 1.0，它在哪都赢，
   于是等待的四句全挑「讪讪」（它是「不好意思」，不是「等不到人的闷」）。收窄到「我 · 冲自己」。
   「豁达」同样宽，收窄到「我 · 无」。

3. **s 能被推到 0.98**。`edge` 打折挡不住连续累积，加软顶 0.95（只有 `applyShock` 允许到 0.98）。

4. **「想念」家族（思念/挂牵/挂记/暧昧/心疼）的安被放得太低**（s 0.30~0.55）。
   安低 = 被否、受挫；可「想念一个人」不是受挫。上调到 0.52~0.60，
   把低安区让给讪讪 / 懊恼 / 没面子 / 等急了。

5. **补「等不到人」那批**：空落落 / 等急了 / 被晾着 / 有点慌。
   (0.34~0.47, 0.15, 0.36~0.45) 这一带原来最近的词是「讪讪」。

6. **强度算出来才 0.07，所以「轻」的字永远赢**。地点 (0.44,0.15,0.45) 离中点很近——那不是 bug，
   是「等两小时没来，安只掉了 0.06」本身不合理。判定层给「有点不顺」该是 -0.2~-0.3，不是 -0.1。

### 第三轮之后（真链路）

**主线 55 句**：23 个不同词 —— 舒坦/踏实/平淡/愉快/空落落/被晾着/遗憾/忧伤/挂记/温馨/暖心/豁达/畅快/亲昵/高兴/愕然/烦恼/愁眉苦脸/懊恼/讪讪/来劲/受用/等急了。
走势：早上 0.55 → 被挑错掉到 0.11（忧伤）→ 道歉拉回 0.28（懊恼）→ 干活涨到 0.95 → 出事一句砸到 0.44/0.29（愕然/烦恼）→ 修好回到 0.78（畅快）→ 深夜 0.76（温馨）。
s 范围 0.11~0.95，位移中位 0.17、最大 1.45。

**交叉 14 句**：挂记 → 挂记 → **空落落** → **等急了** → 讪讪 → 懊恼 → **感动** → **心疼** → **愉快** → 畅快 → 亲昵 → 安慰。

两个场景的词都和情境对得上，而且**能转换**：同一个人从「等急了」到「感动」到「畅快」，
不是一直一个词、也不是每句乱跳。

**还剩的**：s 0.9 以上那一段偏「亲昵/安慰」，`高兴` 在 0.82 还是够不到 0.95；
`rulesFrameSlot` 的 target 和「情绪冲谁」错位这条没从根本上解（只是把词补对了格）。

### 8. 第四轮：把「格」修对，把撞车的坐标分开

这一轮开始跑**三个不同走向的完整链路长场景**（都是 `appraiseTurnNow` 全流程）：

- `scratch/sim-chain.mjs` — 55 句，七段（问候 / 被连续挑错 / 中午 / 干活出成果 / 线上挂了又修好 / 被开玩笑 / 深夜）
- `scratch/sim-cross.mjs` — 14 句（约好下午见 → 一直没来 → 等到傍晚 → 道歉 → 和好）
- `scratch/sim-care.mjs` — 10 句（主人说头疼 → 我担心 → 他说没事 → 还是惦记 → 好了 → 放心）

**修掉的结构问题**

1. **`slotOf` 里 `frame.target` 是「这句话冲谁说」，不是「我的情绪冲谁」。**
   只处理唯一讲不通的组合：事情是我做的（`by=我`）情绪却冲对方 → 归到「无」。
   我惹的错，情绪要么冲自己、要么不指向谁，不会泼给对方。

2. **好几批词的标注太宽，在哪儿都赢。** 收窄：
   讪讪 → 我·冲自己/无；豁达 → 我·无；舒坦 → 我·无；挂记 → 我·无/冲自己。
   宽标注（`我/对方 × 冲自己/无/冲对方` 六格全 1.0）会让一个词把整片区域都占住。

3. **坐标撞车**（同一处挤着语义完全不同的词）：
   被晾着 (0.36,0.32,0.34) / 等急了 / 空落落 原来都压在「被挑错」那一格上；
   懊恼的欲给低了（30）——懊恼是有劲没处使，调到 42；讪讪调到 46（想补救）。
   想念家族（思念/挂牵/挂记/暧昧/心疼）的安从 0.30~0.55 抬到 0.52~0.62——想念不是受挫。

4. **补了四批词**：
   - 担心/挂心/放不下（主人说不舒服时，那一带最近的是「踏实」）
   - 释然/松了口气/心落下来（被说「不是你的问题」那一刻，最近的是「懊恼」）

### 第四轮之后（三个场景）

**主线 55 句**：22 个词 —— 释然/踏实/松了口气/愉快/稳住/遗憾/忧伤/懊恼/暖心/豁达/欢欣/亲昵/开心/愕然/烦恼/愁眉苦脸/被晾着/讪讪/来劲/畅快/受用/温馨。

### 9. 第五轮：判断层交给子代理，覆盖度按格子铺

**这一轮最重要的一条**：前面几轮我手写「判断数据」喂进 `complete`，那测的是我的判断，不是真链路。
主人在这一步点明「正常是宿主判情绪，所以用子代理出数据」——于是改成：

- 子代理按 `JUDGE_SYS` **原文**逐句判（它自己读文件，不是我贴档位），产出 `scratch/judge-{A,B,C}.json`
- `scratch/sim-sub.mjs` 读这份 JSON 当判断层返回，其余全走 `appraiseTurnNow`

**真判断数据把问题暴露得更狠**（模型／子代理给的量比人手写重得多）：
「算了不用你看了」一句就把 s 压到 0.03，之后所有回暖都在低位打转。

**这一轮修的（都是系统性的，不是逐句补）**

1. **s 的地板 0 → 0.12**，并且 `s < 0.20` 时负向增量按比例打折。
   人被连否到底，底下还留着「我还在」那点底；不是归零。

2. **覆盖度盘点**（`scratch/cover-map.mjs`）：把 (s,n,d) 切成 4×3×4=48 格数词。
   原来只有 **38 格**有词、**10 格全空**，很多格只有 1 个词——「被道歉」那格整格只有「憎恶/愣神」。
   按空格补到 **48 格无空格**（258 词）。这是这一轮最见效的一步：空格的语义必然挑错。

3. **书面腔降权**：`grid_pick.js` 加了 `LITERARY`（如梦初醒/闻宠若惊/恨入骨髓…34 个），
   打分扣 0.18。不删（主人说过别手删），只让口语词先被挑走。
   未删的极端词仍在池里，只是不再占住日常位置。

4. **词族分层**（每一族给一段区域，不是逐个词微调）：
   - 想念族（思念/挂牵/挂记/惦念/暧昧）→ 安 0.60~0.66，欲 0.42~0.55
   - 暖族（熨帖/心里软/塌下来/暖烘烘/想靠近）→ 安 0.68~0.74，**欲 0.62~0.68**
     （原来暖族的欲只有 0.50~0.55，于是「他憋着难受」时 s 一高就只剩「畅快」）
   - 怨族（心里堵/埋怨/不痛快）→ 安 0.54~0.58；委屈从 0.18 提到 0.42
   - 缓过来族（缓过来/松快/缓过神/消了气）→ 安 0.48~0.52

5. **`edge` 0.9 → 1.0**，`v4Opts` 上限同步；另加 s 软顶 0.95。

### 10. 第六轮：高安区分层 + 第四个场景

覆盖盘点发现高安区 `(s>0.7, n<0.35, d>0.7)` **整格只有「兴冲冲」一个词**——
所以 A 的「好了恢复了」、B 的「别气了好不好」、C 的「说出来好多了」全挑到同一个词。
这是「爽」没分层：事成了的痛快、被夸的得意、缓过来的松快、想扑上去的雀跃是四种。

按这一族补了 美滋滋 / 浑身是劲 / 松快下来了 / 心花怒放（「雀跃」原有），
并把「兴冲冲」的欲抬到 0.82（它是「冲出去」，欲最满，位置更高）。

另修两处「我把别人对我的态度当成了自己的感觉」：

- 「我以为你会来的」挑出「暧昧」→ 心里堵（安 0.58 / 觉 0.38）补上，暧昧的觉一路抬到 0.76

**新造第四个场景（D，工作中）**：接任务 → 被检查 → 被指出注释少 → 补完 → 被认可 → 下班。
