# 改动 · 兜底补 by + rules-fallback 留痕（2026-11-22）

> 第二刀。计划见 [计划-事帧往下修-2026-11-22.md](计划-事帧往下修-2026-11-22.md)。
> 一句话：**判断层掉线时，规则不再只给「三个增量」，也给出「谁造成的」；兜底行终于能自己说是兜底。**

## 一、动了哪

| 文件 | 改动 |
|---|---|
| `src/modules/affect_v4_shadow.js` | ① `rulesJudgment(act, frame)` 新增第二参，按 `frame.target` 推 `by`（冲我来→`other`，说他自己→`me`，其余→`world`）；② 两个调用点传 frame/slot；③ `judge` 来源改成在 fallback 赋值**之后**定，兜底对象自己的 `judge:'rules-fallback'` 不再被覆盖 |
| `scripts/check-appraise-turn.mjs` | 断言从 `judge === 'rules'` 改成 `=== 'rules-fallback'`，并加两条：`fallbackWhy` 要有、兜底行要有 `by` |

**没动**：判断层提示词、三个增量的数值、选词权重、表结构、调用次数。

## 二、为什么

1. **`by` 只有 61.7%**（真库副本，11-21 起 381 条 model 行）。逐条看样本：缺 `by` 的全是判层落兜底的行
   （`{"judge":"rules","fallbackWhy":"unparsed"}`），而 `rulesJudgment()` 只产 `goal_cong / expectation / future`，
   不产 `by`。选词的 `slotOf()` 靠 `by × to` 落格——`by` 空就落到「无·无」，
   等于**三分之一的行，情绪词是在「谁做的、冲谁」都没判出来的情况下挑的**。
2. **兜底留痕被覆盖**。11-21 写了 `judge:'rules-fallback'`，但那行 `const judge = judgment ? 'host' : 'rules'`
   在 fallback 赋值之前执行——兜底对象后来被 `{ ...judgment, judge }` 覆盖回 `'rules'`。
   真库里 model 行 `rules-fallback` 是 0 条，就是这条覆盖的后果。附带影响：`strike`（情绪模块罢工）标记
   按 `judge === 'host'` 判断，覆盖后兜底也被当成 host，**罢工提示不会亮**。

## 三、怎么验

```powershell
node ..\scratch\frame-core\verify-frame-fallback.mjs   # 13 项
node scripts/check-appraise-turn.mjs                   # 18 项
node test/run-tests.mjs                                # 门禁
```

`verify-frame-fallback.mjs`（内存库）验：
1. `rulesJudgment` 的 by 推导：`target=me → other`、`target=other → me`、`target=none → world`、不带 frame 也不炸。
2. 判层抛错时：仍写两行；rules 行带 by；model 行 `judge='rules-fallback'`、带 `fallbackWhy`、`frame.by` 有值、
   `missing` 不再记 `by`、`strike` 标记被写上。
3. 正常路径：`judge='host'`，`strike` 被清掉。

实测：`verify-frame-fallback` **13/13**、`check-appraise-turn` **18/18**。

## 四、怎么退

- 只退 by：把 `rulesJudgment` 里 `target/by` 那三行与返回里的 `by` 删掉，两个调用点的第二参可留可删。
- 只退留痕：把 `const judge = ...rules-fallback...` 改回 `const judge = judgment ? 'host' : 'rules'`
  （但这会退回「兜底装 host」的旧 bug）。

## 五、影响面

- `judgment.judge` 这个字段全仓只有本文件在写，没找到别的读侧按 `'rules'` 判——改语义不会打穿别处。
- rules 行的 `judgment_json` 现在也多一个 `by`：**这是有用的**，规则行垫底时选词也能落到正确的格，
  不再等 model 行才纠正。
- 已有历史行不回填（只追加）。

## 六、还没做（下一刀）

事层失败时判断输入要写明「事层没回来，只按原话判」——现在 `act` 空只是 frame 里记了 `missing`，
判断层看不到，仍会把空白当完整输入。
