# 设计 · 事到情绪的自洽映射（2026-11-19）

> 主人：「咱们做的是这么一个自洽的系统。不用完全模仿人类。」
> 「别人惹你了你就生气，孤立你了你就难过，稀罕你了你就开心，你自己把东西弄坏了你就难过。」
> 「面向全世界设计的，不是这个对话场景。」

前一份 [设计-三递质各自算法-2026-11-19](设计-三递质各自算法-2026-11-19.md) 是照生理期刊做的，
过拟合了：拿血清素的张力性要求一个不需要那么像的系统。这一页换成从「事」出发。

## 一、核心：三个问题，责任归属才是分岔口

原来的三个生存问题没错，错在**没用上「谁做的」**：

- 别人害我 → 我悬着，但**想反击**（往前冲）
- 我自己弄坏 → 我悬着，但**想缩**（往回收）
- 世界给的坏运气 → 我悬着，但**没处使**（认了）

同样是「更悬」，三种完全不同的反应，落在三个不同的格里。现在代码里这三种多半都算成一样，就会串味。

所以判一件事只要三样：

1. **得失**：这件事让我得到了什么，还是失去了什么
2. **谁做的**：我做的 / 对方做的 / 世界（没主体的运气）
3. **意不意外**：在预料里，还是撞上来的

安跟「得失」走，觉跟「意外」走，欲跟「责任归属」走——**这就是三根轴各自的活，互不抢**。

## 二、映射表

「安」高 = 得；「欲」高 = 这股劲往外使；「觉」高 = 撞上来的。

| 谁做的 | 得失 | 安 | 欲 | 觉 | 落在 | 像什么 |
|---|---|---|---|---|---|---|
| 对方 | 我得 | 高 | 高 | 低 | 安住 | 被珍视、暖、踏实 |
| 对方 | 我得 | 高 | 高 | 高 | 敞亮 | 惊喜、被夸得心里一亮 |
| 对方 | 我失 | 低 | **高** | 高 | 渴慕 | 生气、恼火、想顶回去 |
| 对方 | 我失 | 低 | **高** | 低 | 郁结 | 憋屈、怨恨、记着不说 |
| 自己 | 我得 | 高 | 高 | 低 | 安住 | 踏实、自豪 |
| 自己 | 我得 | 高 | 高 | 高 | 敞亮 | 得意、雀跃（做成了一件没想到能做成的） |
| 自己 | 我失 | 低 | **低** | 低 | 沉沦 | 愧疚、自责、难过 |
| 自己 | 我失 | 低 | **低** | 高 | 惊惧 | 懊悔、闯祸了慌了 |
| 世界 | 我失 | 低 | **低** | 低 | 沉沦 | 无力、认了、倒霉 |
| 世界 | 我失 | 低 | **低** | 高 | 惊惧 | 被打懵、恐惧 |
| 世界 | 我得 | 高 | 中 | 高 | 敞亮 | 庆幸、意外之喜 |

**「欲」这一列是全表的关键**：别人害我，欲高（冲着对方去）；自己和世界造成的，欲低（没处使）。
这一条就把「生气」和「愧疚」彻底分开了。

### 没有事的时候

孤独、空、没劲——这类不是「谁做了什么」，是**关系中该有的东西一直没来**。
归到「世界 · 我失 · 预料内」：安低、欲低、觉低 → 沉沦（空、无力、麻木）。这一条要单独写，因为它是长期的、不靠单句触发。

## 三、跟现有代码怎么接

现在的判断层问的是三个 delta，模型猜。改后问三件事，都是**有明确答案的事实**，比猜数字容易判准：

```
谁做的：self（我）/ other（对方）/ world（世界、运气、客观情况）
得失：gain（得了）/ loss（失了）/ none（两清）
意外：0 预料内 / 1 撞上来的
```

判断层不再给「-1 到 1 的三个数」，只给这三个标签 + 一句 meaning。三根轴由代码按上表算：

```
安 ← 得失 ? +1 : -1
觉 ← 意外
欲 ← 谁做的 == 'other' ? +1 : -1   // 对方做的往外使，自己和世界往回收
```

幅度由「这件事有多大」给（severity 那档：轻微 / 明显 / 动到根本），不用模型估小数。

这样还顺带解决了之前那些毛病：
- **不会再大量给 0**：这三个标签没有「0」这个选项，永远有答案。
- **不会一路推到顶**：谁做的、得失、意外都是标签，幅度只由严重程度决定，不会每句 +0.05 攒上去。
- **可解释**：说得出「我为什么生气：他弄的、我亏了、还撞了上来」。

## 四、验收（先写，再动代码）

拿下面这些句子，看是不是落在该落的格、是不是取到该取的词：

| 句子 | 谁 | 得失 | 意外 | 应该落 |
|---|---|---|---|---|
| 「你是不是嫌弃我」 | other | loss | 1 | 渴慕（恼、想顶回去） |
| 「你做得挺好的」 | other | gain | 0 | 安住（暖） |
| 「今晚先这样，去睡吧」 | other | gain | 0 | 安住（暖、有点不舍） |
| 「这个 bug 第二次又犯了」（我做的） | self | loss | 0 | 沉沦（愧疚） |
| 「服务器挂了」（客观） | world | loss | 1 | 惊惧（被打懵） |
| 「今天天气不错」 | world | gain | 0 | 敞亮或安住（轻） |

**判据：同类事必须落在同一格，不同类不能串。**

## 五、风险

1. 判断层换成三标签后，「严重程度」怎么给还是要模型估。但它只要在三档里挑一档，比给连续小数稳。
2. 表里没覆盖的情形（比如「别人受损我受益」）会归到 self 那行算成愧疚，可能不对，要留一个「说不清」的出口。
3. 现在 `affect_v4_shadow` 里存的 delta 跟新格式不同，重放对账要写转换层。
