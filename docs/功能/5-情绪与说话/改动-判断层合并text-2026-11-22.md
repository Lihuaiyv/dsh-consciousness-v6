# 改动 · 判断层两处 text 合成一段（2026-11-22）

> 主人：「把这两个参数合并一下」——「正在发生」和「最近几件事」是同一份前置 text（一个现在、一个之前），判断层读了两遍。
> 之前查库确认：`affair_rows` 最新一行跟 flag 当前 text 一字不差。

## 一、动了哪

`src/modules/affect_v4_shadow.js`

1. **判断输入合并**（新路 `appraiseTurnNow`）：删掉「正在发生：」和「最近几件事：」两行，换成一段
   ```
   这件事：
   现在：
   <当前那份前置 text>
   之前：
   <更早的，每份一行>
   ```
   「之前」只留**更早的 3 份**（原来抓 10 份、贴 6 份，其中最新一份与「现在」重复）。
2. **删掉回退兜底**（`buildMaterial`）：原来「没有 `affair_rows` 表就退回影子表的 `frame_json.summary`」——
   影子表里存的已经是前置原文，退回去还是同一份；删掉，没有表就空着。按主人定的「不兜底」。
3. **验收脚本跟进**：`scripts/check-affect-chain-e2e.mjs` 的断言从「判断输入是『正在发生：』」改成
   「判断输入是『这件事：现在：』」。

**没动**：旧路 `refineShadow`（默认 off）里同样删掉了「最近几件事」那一行，但它自己的「正在发生」没并；它不在新链上，等清旧路时一起处理。

## 二、为什么留 3 份

11-22 量了前置 text 的相邻相似度：29 份，平均 0.13，最高 0.29——每份都在换措辞重写，没有复述。
但按话题分段落很清楚（事帧 → target 指称 → 删 summary → 参数核查 → 重载验收），一段大概 5~10 份。
判断层要的是「这条线现在走到哪」，给最近 3 份（≈ 当前段内）+ 「现在」那份，正好一段；给 6 份就开始跨段。

## 三、怎么验

重载后看真链路：判断输入开头应该是「这件事：」，里面「现在：」下面一份、「之前：」最多 3 条，且不再出现与「现在」重复的那份；「最近几件事：」这行应该彻底没有了。
