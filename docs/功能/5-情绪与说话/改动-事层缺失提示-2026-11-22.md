# 改动 · 事层缺失时判断输入写明缺了什么（2026-11-22）

> 第三刀。计划见 [计划-事帧往下修-2026-11-22.md](计划-事帧往下修-2026-11-22.md)。
> 一句话：**事层（本地 14B）没回来时，判断层不再把空白当完整输入——输入里直接写「事层没回来，只按原话判」。**

## 一、动了哪

`src/modules/affect_v4_shadow.js` 的 `appraiseTurnNow`，判断输入 `frameText` 里（只在 `affect.v4.frame.ctx=on` 时）：

```js
(Array.isArray(frame.missing) && (frame.missing.includes('act') || frame.missing.includes('summary')))
  ? '（事层没回来：这句没有摘要和动作，只按原话判，别把空白当完整。）'
  : ''
```

**没动**：事层提示词、`missing` 的记法（第一刀已加）、判断层提示词本身、调用次数、任何数值。

## 二、为什么

只读盘点（11-21 起 381 条 model 行）：`act` 填满率 **79.5%**，78 条是空；`summary` 有 6 条是占位「（新事）」。
第一刀让这些缺记进 `frame.missing`，但判断层看不到 `missing`——它照着「正在发生：（新事）」判，
把空白当成了完整的事实。设计-事帧-v2 原则 3：「填不满就留空 + 记一笔 missing，不瞎猜」——
留空和留痕都有了，缺的是**把「这是缺的」告诉判层那一步**。

**不给规则兜底猜 `act`**：主人 11-21 明确「事帧这块一点关键词规则也不要」。所以这里只提示缺，不补值。

## 三、怎么验

```powershell
node ..\scratch\frame-core\verify-frame-ctx.mjs   # 23 项（新增 1 条：开 ctx 且缺 act 时输入含「事层没回来」）
node scripts/check-appraise-turn.mjs              # 18 项
node test/run-tests.mjs                           # 门禁
```

- 测试里不传 `complete` 时不会跑本地事层，`act` 必空 → 用来验「缺了会提示」；
- `ctx=off`（默认）时这行不出现，判断输入与改动前逐字一致——由 `verify-frame-ctx` 原本那条
  「ctx 默认 off：判断输入不含『距上一句』」同路径保证。

实测：`verify-frame-ctx` **23/23**、`check-appraise-turn` **18/18**、门禁 **600/600**。

## 四、怎么退

删掉 `frameText` 的 `ctxOn` 块里那段三元表达式即回原样（`ctx=off` 时本来就不生效）。

## 五、还剩

- 线上要**重载插件**才生效；重载后先看 `frame.missing` 的真实分布，再决定 `affect.v4.frame.ctx` 开不开。
