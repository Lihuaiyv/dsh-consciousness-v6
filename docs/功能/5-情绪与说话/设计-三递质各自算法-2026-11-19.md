# 设计 · 三条激素各走各的算法（2026-11-19）

> 主人：「反正就是模拟人类的吧。这三个激素，各有各的算法，那是最好的。」
> 这一页只定公式，不动代码。三套算法互不相同，不是同一个「位置 + k×Δ」套三个名字。

## 一、依据

| 轴 | 激素 | 主要文献 | 给出的东西 |

| 安 | 5-HT 血清素 | [低血清素 → 延迟奖励折扣更陡（J Neurosci 2008）](https://www.jneurosci.org/node/367860.full.print)；[稳态强化学习（Keramati & Gutkin 2014）](https://pmc.ncbi.nlm.nih.gov/articles/PMC4270100/) | 5-HT 管「愿意为多远以后的事等」；奖励不是绝对值，是「偏离设定点的减少量」；**设定点本身不是固定点，是几个力平衡出来的稳定态** |

| 八格 | 三条一起 | [Lövheim 情绪立方体 + NEST 复现（BICA 2018）](https://www.sciencedirect.com/science/article/pii/S1877050918323639) | 三条单胺各取高低 = 八种基本情绪，跟我们八个格是同一结构 |

## 二、三套算法

### 安（5-HT）：设定点在动，位置追设定点

现在的写法是「位置 + k×Δ」，位置被直接推。真实的样子是：**被你推的是「设定点」，位置慢慢追过去**。

```
每轮：
  sTarget ← clamp01(sTarget + ks * goal_delta)     // ks 很小，0.08~0.12
  s       ← sTarget + (s − sTarget) * exp(−Δt / tau_s)   // tau_s 按天：12~24h
```

- 新增一个状态 `sTarget`，默认 0.5。它才是「我该在哪儿」。
- 事件改的是 `sTarget`，`s` 自己慢慢追。所以情绪不「一下到位」，也不「推完就钉住」。
- 回落的目标不是 0.5，是 `sTarget`。这就是文献里说的「稳定态」而不是「设定点」——它自己就在漂。
- 对应「愿意等多远」：`sTarget` 高 = 我这个人现在能看远；`s` 只是当下追上没有。

### 欲（DA）：奖励预测误差

现在是「模型说这一下多好 → 位置加多少」。真实的多巴胺报的是**差**。

```
每轮：
  δ = R + γ * V_next − V          // γ≈0.95
  d ← clamp01(d + kd * δ)
  V ← clamp01(V + α * δ)          // V 是「我原本预期这件事会怎样」，跟着学
```

- 新增状态 `V`（预期）。判断层要改成给两个数：`expected`（我以为会怎样）和 `actual`（实际怎样），代码算差。
- **预期内的好事不产生多巴胺**：夸一句，如果本来就在等你夸，δ≈0，d 几乎不动。反过来突然被夸，δ 大，d 跳。
- 这解释了为什么「同一句话在不同语境下效果完全不同」——现在系统全靠模型判，其实该由「预期有没有被超出」决定。

### 觉（NE）：增益，不是强度

现在是「意外多大 → n 多高」，然后 n 自己待着。真实的 NE 是**放大器**。

```
每轮：
  n ← max(n * exp(−Δt / tau_n), CALM.n + kn * max(0, expect_delta))   // tau_n≈2 分钟
  g = 0.5 + n        // 增益 0.5~1.5
  安和欲收到的输入先乘 g
```

- n 的回落极快（分钟级），因为去甲肾上腺素半衰期就是一两分钟。
- **n 不自己产生情绪，它放大别的**：同一句批评，n 低时只是「有点不顺」，n 高时就是「砸在脸上」。
- 这也解释了为什么「被猛地撞一下」之后那几秒，什么都会放大。

## 三、判断层要改什么

现在问的是三个「变了多少」。改后要问两组：

```
expected：我以为这件事会怎样（0~1，0.5=说不上）
actual  ：实际发生了，对我来说怎样（0~1，0.5=说不上）
expect_delta：这一下比我预想的更意外 / 更平常多少（-1~+1）
```

`goal_delta` 不再直接推位置，它改的是安的设定点。

**注意：这样改完，「大量 0」是对的，不是 bug。** 按 RPE 模型，没有超出预期的事，多巴胺就该不动；安没事，设定点就该原地。之前那 93.4% 的 0，大部分不是模型懒，是「本来就没什么事」——真正的病是**有事的时候动得太猛**（夸一句 +0.5，等于直接推了四分之一个刻度）。

所以「别习惯性给 0」那条提示词要撤回，改回「没超出预期就给 0」；要盯的不是「0 太多」，是「有值时幅度对不对」。

## 四、分步落地（一步一验，都能单独退）

1. **安**：加 `sTarget`，`s` 改成追它。验：800 轮重放，看 s 的中位是不是不再贴 0.78，而是围着 `sTarget` 散开。
2. **觉**：改成脉冲 + 增益，放大安和欲的输入。验：同一段对话，n 高的那几句，安和欲的摆动是否真的更大。
3. **欲**：加 `V` 和 `R/expected` 两个字段，判断层提示词跟着改。验：同 800 轮，看 d 的分布是不是「大部分不动、少数跳」而不是「一路爬」。

每步都留 `affect.v4.*` 开关，能单独关掉退回现在的线性累积。

## 五、风险

1. **判断层要多给两个数**（expected / actual），模型肯不肯老实给，未知。可以先只做安和觉（不需要新字段），欲最后做。
2. **`sTarget` 会漂到边上再也回不来**。要加一个极慢的「往中间拉」的力（文献里是设定点本身受长期状态影响）。参数待定。
3. 这套改完，八格分布会跟现在完全不同，之前基于旧分布做的判断（比如「安住 59% 正常吗」）要重做。
