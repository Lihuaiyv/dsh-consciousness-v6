# 改动 · 判断层记账与思考档（2026-11-24）

## 为什么动

判断层判决只有 134–200 字节，却要 5~29 秒；昨天 4 次空回全是 `finish=max-tokens`、正文零 token。
结论「时间全在思考上、额度被推理吃光」是**推**出来的——因为 `src/model.js` 的宿主适配器只收 `text-delta`，
思考那块一个字节都没记。没有这个数，调额度、调档位都还是猜。

所以这一刀只做两件事：**把「想了多少」变成可测的量**，**把额度与思考档变成参数**。行为默认不变。

## 动了哪

| 位置 | 改动 |
|---|---|
| `src/model.js` `HostLlmAdapter.complete` | 透传 `reasoningEffort` 与 `stats` 两个键（不传就是老行为） |
| `src/model.js` `HostLlmAdapter._chat` | ① 收 `reasoning-delta` / `usage` / `block-start` / `block-end(reasoning)`，填 `stats`：`reasoningChars / outputChars / finish / effort / blocks / usage / ms`；② 思考档经 `prepareCall` 的 `configure` 回调选，**只从模型声明的 efforts 里挑**，没声明就不传（硬塞会被 `resolveCallConfig` 直接拒）；③ `truncated` / `empty` 两个报错里带上「思考 N 字 / 出 N token（其中思考 N）/ 档 x」 |
| `src/modules/affect_v4_shadow.js` `appraiseTurnNow` | ① 新增参数 `affect.v4.judge.maxTokens`（默认 **3000**，跟以前一样）与 `affect.v4.judge.effort`（默认空 = 不传）；② 每次尝试（成功也写）落一格 `affect.v4.judge.think`；③ `chain_steps` 的 `judge` 步 `output` 多一个 `think` |
| `test/host-reasoning-stats.test.mjs`（新） | 7 条：思考字数/正文长度/用量/档位都收得到；整块思考也数得到；吃光额度必抛且带字数；没声明的档不硬塞；不声明档时传了也不塞；不传 stats/档与以前一致；空正文必抛且带量 |
| `test/run-tests.mjs` | 挂上这 7 条 |

⚠️ 测试里一律走 `completeStrict`：普通 `complete` 会落到规则兜底，返回一段假 JSON，**空正文也会看起来「成功」**——
这正是「看着跑通了、其实没算成」的那类坑。

## 怎么退

- 行为零变化：不设 `affect.v4.judge.maxTokens` / `affect.v4.judge.effort` 就是老样子（3000、不传档）。
- 要把记账也关掉：删掉 `setFlag('affect.v4.judge.think', ...)` 那一段即可，不影响判断；
  报错文案里的「思考 N 字」不影响任何调用方（全仓没有按这句匹配的测试，已核过）。
- 想彻底回退：`git checkout -- src/model.js src/modules/affect_v4_shadow.js test/run-tests.mjs`，删掉新测试文件。
