# 改动 · 二级情绪接线（2026-11-17）

> 主人：「二级不都是两个字的吗？怎么是一个字的？」
> 结论：对，是我接错了——`label` 直接取了一级 8 角的单字名（安/怡/惊/悲/怯/惧/怒·慌），
> 二级枚举词（安心/害怕/愤怒/委屈/焦虑……）那张原型表写了但没接进 label。

## 动了哪

| 文件 | 改动 |
|---|---|
| `src/algo/affect_v4.js` | `infer()` 的 `label` 改为 `secondary[0].name`（二级原型距离 × 事件门控的 top1，两字枚举词）；`primary` 仍是 8 角向量，`tie` 仍标记一级两角并列。tie 时不再统一给「说不清」，而是给二级 top1 + 低置信 |
| `test/affect-v4.test.mjs` | 三条 label 断言从「等于 primary 第一 / 说不清」改成「是 SECONDARY_PROTOTYPES 里的词」 |
| `test/affect-v4-shadow.test.mjs` | 中立一句的 label 断言同上 |
| `test/affect-v4-refine.test.mjs` | 「两次调用」改成「一次调用（只有判断层）」；槽位合并断言改成「target 按规则」 |

## 口径（设计文档）

- **一级**：8 个角，单字（安 / 怡 / 惊 / 乐 / 悲 / 怯 / 惧 / 怒·慌），输出 8 维分布 `primary`。
- **二级**：20~40 个枚举词，两字（安心 / 踏实 / 满足 / 雀跃 / 兴奋 / 期待 / 好奇 / 惊讶 / 警觉 / 紧张 / 焦虑 / 慌 / 害怕 / 恐惧 / 恼火 / 生气 / 愤怒 / 委屈 / 难过 / 失落 / 空 / 无聊 / 羡慕 / 嫉妒 / 心疼 / 愧疚 / 羞耻 / 骄傲）。
  算：三递质 (S,N,D) 到每个原型的距离 → 软分数 × 事件门控（target=other 才允许怒/委屈等）→ top1。
- `空` 在设计表里本身就是单字，是唯一例外。
