# 改动 · 动机表 P2（每步检查，只记账不拦）

日期：2026-11-24
范围：P2 一步。每步之前查一次「交过没有 / 落后没有」，**只写事件，不拦、不强制**。

## 动了哪

- `src/modules/motivation.js`：表加一列 `step`（新库直接建，老库 `ALTER`）；`rememberMotivationTurn` 带 `step`；`submitPlan` 把交表那一刻的步骤号记进表；新增 `motivationTick(db, aid, { step })`：
  - 这一轮还没有任何一版 → `stale=true, reason='no-plan'`
  - 最新一版交在更早的步骤（中间发生过工具往返却没更新）→ `stale=true, reason='step-lag'`
  - 其余 → `stale=false`
  每次检查都写一笔 `plan.check`。
- `index.js`：preStep 里每个模型步查一次，**只有 `motivation.on=on` 才跑**（默认 off，等于不存在）。
- `src/modules/actions/index.js`：修 `plan` 工具里一个潜在空指针——原来写 `aidOfSession(null)`，改成 `aidOfSession(exec) || aid()`，和别的工具一致。

## 怎么验

`node scratch/p2-plan-check.mjs`：空轮 → `no-plan`；同一拍交完再看 → 不落后；隔一步再看 → `step-lag`；三次检查都记了 `plan.check`；表里 `step=0` 对得上。

回归：`node scratch/p1-plan-check.mjs` 仍全过；门禁 610 / 610。
