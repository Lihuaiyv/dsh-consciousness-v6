## 二、四类问题分开写（别再混成一个结论）

### P1 空回：根子确实是「思考吃光额度」，但只是**间接**证据

- 昨天 4 次空回全部 `finish=max-tokens`、`sawDelta=no`：正文一个 token 都没出，额度先见底。
- 耗时跟额度同向：1200 时 ~8 秒（8125 / 7921 / 8343），3000 时 16.5 / 17.8 秒。→ **加额度是让空回烧更久，不是解**。
- 成功判决只有 134–200 字节（中位 157），所以不是「正文写不完」，是思考先把额度占了。
- ⚠️ **这里以前是推的，不是量的**：我们只收 `text-delta`，思考那块一个字都没记（`src/model.js` 只认 text-delta）。
  11-24 已经补上量（见 P7），一天后就能拿真数：`affect.v4.judge.think` 里的 `reasoningChars` / `usage.reasoningTokens`。

### P2 熔断连坐：已拆，且已验

- 现在：11-24 重载后 0 条 0 毫秒空手。
