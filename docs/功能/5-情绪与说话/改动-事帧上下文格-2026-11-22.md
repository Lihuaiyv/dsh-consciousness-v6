# 改动 · 事帧上下文格（2026-11-22）

> 第一刀：从事帧的产生往下修。计划见 [计划-事帧往下修-2026-11-22.md](计划-事帧往下修-2026-11-22.md)。
> 一句话：**给事帧补上「距上一句多久 / 这件事第几轮 / 我上一轮什么词 / 对面是谁 / 缺了什么」，并把材料分成「主人说的 / 我说的」。默认影子期，判断层输入一个字不改。**

## 一、动了哪

| 文件 | 改动 |
|---|---|
| `src/modules/affect_v4_shadow.js` | ① `buildMaterial` 多产一份 `lines`（带 role）；② 新增 `lastModelRow()` 按会话取上一轮最终行、`gapText()`；③ `appraiseTurnNow` 签名加 `channel`；④ frame 增 `gapMs / prevLabel / turnIndex / with / missing`；⑤ 事层写完 summary 后算 `turnIndex`、记 `missing.act/summary`；⑥ 判断后缺 `by` 记 `missing.by`；⑦ 开关 `affect.v4.frame.ctx` 控制判断层输入是否加三行、原话是否带「主人：/我：」 |
| `src/kernel.js` | 注册 `affect.v4.frame.ctx`，默认 **off** |
| `index.js` | `appraiseTurnNow` 调用处传 `channel`（qq / web） |

**没动**：事层提示词、判断层提示词、三递质参数、选词权重、表结构、调用次数（仍是事层本地 1 次 + 判层宿主 1 次）。

## 二、为什么

真库副本只读盘点（11-21 起 381 条 model 行）发现五格全 0%：`scene / with / gapMs / turnIndex / prevLabel`
——设计-事帧-v2（2026-11-19）§二 C 组要求、§五 验收 1/4 条判过的上下文格，代码从没实现。
判断层因此判不出「越说越急」「同一件事第 5 轮该钝了」。

`by` 只有 61.7%：缺的样本全是判层落兜底（`judge:'rules'` + `fallbackWhy:'unparsed'`），
而 `rulesJudgment()` 不产 `by`。这一刀先把「缺了要留痕」补上，真正的兜底 by 在第二刀。

## 三、怎么验

```powershell
node ..\scratch\frame-core\verify-frame-ctx.mjs   # 22 项
node scripts/check-appraise-turn.mjs              # 16 项
node test/run-tests.mjs                           # 门禁
```

`verify-frame-ctx.mjs`（内存库，不碰真库）验：
1. 第一轮：`gapMs=null`、`with='web'`、`turnIndex=1`、`missing` 是数组且记到 `act`（测试不跑本地事层）。
2. `material.lines` 每项 `{role,text}`、条数与 `quotes` 对齐；`quotes` 仍是字符串数组（旧形状不破）。
3. 第二轮：`gapMs` 为正、`prevLabel` 等于第一轮 label、`turnIndex=2`、`missing` 不含 `by`。
4. 开 `ctx=on` 后判断输入出现「距上一句：」「这件事第 3 轮」「我上一轮的状态：」，最近原话带「主人：/我：」。
5. 默认 `ctx=off` 时判断输入**不含**「距上一句」（与改动前一致）。

实测：`verify-frame-ctx` **22/22**、`check-appraise-turn` **16/16**。

## 四、怎么退

- 影子期本来就是 `affect.v4.frame.ctx=off`（默认），判断层输入与改动前逐字一致。
- 要连 frame 里的新字段也去掉：删 `appraiseTurnNow` 里 `gapMs/prevLabel/turnIndex/with/missing` 那几行与 `find lastModelRow` 调用即回原样。
- `material.lines` 是纯增字段，删掉不影响任何读侧。

## 五、还没做（下一刀）

1. **兜底给 `by`**：`rulesJudgment` 按 `frame.target` 推 `by`，让 38% 的「无·无」格落回正确的格。
2. **`act` 20.5% 空**：事层失败时判断输入应写明「事层没回来，只按原话判」，而不是把空白当完整。
3. **`scene`**：要模型给，等前两刀稳了再动提示词。
