# 改动 · 参照点（防漂移换了做法）（2026-11-23）

> 一句话：**删掉入口的噪声门之后，用「参照点」在出口防漂移**——它记着「最近这一段大概什么样」，位置冲出带子就把超出那截折掉；一次重击让它直接搬家。只给安和欲，觉不设。

## 动了哪

1. `src/modules/affect_v4_shadow.js` 的 `nextPosition`：在 `advanceState` 之后加参照点处理（`sRef` / `dRef`），结果覆盖 `position.s` / `position.d`，并写回 `sRef` / `dRef`。
2. `v4Opts`：加 `affect.v4.refpoint`（默认 on）、`affect.v4.ref.alpha`（0.06）、`affect.v4.ref.band`（0.25）、`affect.v4.ref.cut`（0.2）、`affect.v4.ref.exempt`（0.35）。
3. `readState`：白名单补 `sRef` / `dRef`——**不补就等于没存**（存了状态、读的时候丢掉，每轮从当前位置重起）。
4. （上一步）`nextPosition` 里入口噪声门已删。

## 为什么

删门之后位置会累积：拿真库 499 条增量重放，s 标准差 **0.230**、最低掉到 **0.00**。参照点是把「小话累积」和「真事」分开：

- 小推：参照点慢慢跟（α），位置离它不远就放行；
- 冲出带子（band）：超出那截只留两成；
- 重击（单轮推动 ≥ exempt）：参照点直接搬家，位置完整落地。

和噪声门的区别：门在入口「看你给的数小就丢」，真实小推动也一起丢；参照点在出口「看位置离平时多远」，一句真话都不丢。

只给安和欲：觉是事件性的（同一次惊吓不会因为最近被吓多了就不突然），代码里本来就是尖峰包络，不需要参照点。

## 参数怎么定的

499 条真实增量，从 0.61 起重放，扫 α（0.03/0.06/0.1）× 带（0.15/0.25/0.35）：

| 配置 | 范围 | 标准差 |
|---|---|---|
| 无参照点 | 0.00–0.82 | 0.230 |
| α0.03 带0.15 | 0.31–0.64 | 0.079 |
| **α0.06 带0.25**（选它） | **0.18–0.65** | **0.090** |
| α0.10 带0.25 | 0.14–0.65 | 0.123 |
| 带0.35 各组 | 0.15–0.65 | 0.16~0.18（管不住） |

选 α0.06 / 带0.25：抖动少六成多（0.230→0.090），同时最低还能到 0.18——真难过的时候跌得下去；带 0.15 那组收太紧，最低只到 0.31。

## 怎么退

`affect.v4.refpoint=off` 一行关掉，回到「无参照点」的行为（仍保留删门后的累积特性）。

## 踩过的坑（记下来）

1. **`Number(prev && prev.sRef)` 在 `prev` 为 null 时等于 0**——`null` 转数字是 0，是有限数，所以「没有就用当前位置」的判断失效，参照点从 0 起步，第一轮把位置从 0.68 拉回 0.37。必须显式判 `!= null`。
2. **`readState` 是白名单**：新字段不写进 return 就等于没存。这次存了 `sRef`/`dRef` 却没读回来，参照点每轮重置。
3. 日上限（0.5）**还没实现**——扫参数时算过，但代码里没有跨日累计状态，等真实跨天数据再上。
