# 情绪链：13 条错判的三族改法候选（2026-11-23）

> 只写方案，不动代码。主人点一族，我改一族，改完立刻跑 `node scratch/sim/verify-all.mjs` 复验。
> 基线数字（2026-11-23 01:44）：64 轮，泛用词命中 32（50%），词判错 13、判偏 23、贴 28；to 对 52 / 半 12 / 错 0。

## A 族：负的「突然」没落到「安」（5 条）

**条目**：F#1「你先玩」、F#2「别吵我」、E#8「跑完了？」、E#9「讲人话」、E#2「没事先这样」

**机制**：这几句 e 是 −0.5~−0.6（很突然），但 g≈0。安只看 goal，goal 0 落点就在球心，球心那格只有踏实/舒坦/没事，所以落它们。

**改法（判断口径，不是 if 规则）**：在 goal_delta 的定义里补一句，说清「被催、被支开、被嫌吵」这类事对「还能不能待得稳」算轻微影响：

> goal_delta（现状）：这件事让我现在过得更好还是更差——我还能不能待在这儿，往后还能不能接着过。**被他催一句、被支去一边、被嫌吵——我的「待得稳」是会松一下的，goal 给 −0.05~−0.15；他不是在骂我，所以别给重。**

**风险**：这条一加，所有「被催」类句子都会掉一点安，可能出现「他随口说一句也在掉」的过度敏感。要复验六场景，看 D/E/F 的「被催」句会不会全掉到低安。

**回退**：提示词删这一句即可。

## B 族：原话里的泛用词直接成词（4 条）

**条目**：B#2「没事，你先忙」→ 没事；E#2「没事，先这样」→ 舒坦；E#8「跑完了？」→ 没事；E#9「讲人话」→ 没事

**机制**：`grid_pick.js:83` 的 `NOEVENT` 集合含「没事」，它永远进候选、还给典型度 0.85（位置在球心以上时）。于是球心附近的负向句子（e 很负但 g≈0）被「没事」抢走。

**改法（动词库，一处）**：把 `没事` 从 `NOEVENT` 拿掉，让「如常 / 平静 / 还好」顶球心那格。

**预期**：B#2 会改落「空落落」或「平淡」；E#8/E#9 会改落「有点空」或「懊恼」。
**风险**：球心那格少一个词，可能影响「真没事」的句子（如 A#3「我自己弄了」现在落踏实）。复验时看「真没事」那几句会不会掉到偏负。
**回退**：一行，加回去。

## C 族：定向词在「他挑我 / 他难受」时靠距离赢（6 条）

**条目**：E#3「别塞假数据」→ 暖；E#6「别中间塞数据」→ 松快；D#1「我有点难过」→ 踏实；D#5「硬熬」→ 暖心；D#8「我困了」→ 踏实；D#3「陪一会儿」→ 舒坦

**机制**：这些句子 g 是正的（+0.1）或接近 0，暖/松快/踏实坐标离落点最近，靠距离赢；但语境方向反了（他防我 / 他难受 / 他收线）。

**改法候选（都不加 if 规则）**：
1. 把「暖 / 暖心」的 GRID_ANNOT by 收窄（现在 `["对方","外面","我"]`，太宽），让它们只在真该暖的格子里出现。
2. 把「松快」的坐标往上挪（它现在太容易在「被派活」时出现）。
3. D#1「他难过」那句的问题在 goal（g −0.05 太轻），跟 A 族同源，放 A 族里一起看。

**风险**：这三条都比 A、B 危险（「心里软」收窄那次 30%→16% 崩过）。建议最后动，且一次只动一个词、逐次验。
**回退**：每个词单独一份备份。
