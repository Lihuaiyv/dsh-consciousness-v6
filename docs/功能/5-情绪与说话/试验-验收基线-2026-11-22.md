> 为什么要有这一页：之前一直「凭感觉说像不像」。现在定一个可复现的基线——人工写每句「能接受的词」，
> 机器跑出来落在集合里算对。以后每次改完都跑这个，数字说话。

## 二·再补（2026-11-23 00:05）

查出来「心里沉 (0.54,0.64,0.50)」「不是滋味 (0.52,0.61,0.46)」这两个**负向词坐在高安区**——正向句子不会因为它们负就避开，反而因为位置近挑到它们（C10 就这么来的）。坐标改到低安：心里沉 (0.30,0.60,0.40)、不是滋味 (0.34,0.55,0.40)；片重算 63 片。

## 二·测量方法修正（2026-11-23 00:10）

发现两件事，比数字本身重要：

1. **判断层有方差**：同一句「你先忙你的」，前一次 judge 给 goal −0.1（挑担忧），后一次给 +0.15（挑心里软）。所以「重跑六场景再比正确率」波动能到 17~28%，不是引擎在变，是判断在变。
2. **手写基准太窄**：A1 引擎挑「心里软」，我写的是「如常/平静」——可「他体谅我先忙」被暖到，引擎说得通，是我只认自己想到的词。

以后做法：
- 固定判断数据：`scratch/sim/real-out-A–F.json` 当快照，改选词只跑 `re-pick.mjs`（固定位置 + 判据，只重挑词），数字才可比。
- 验收口径用独立评审（对/半/错），不用手写集合。手写集合只做快速回归。
- 歪摆的词要修，但一次只修确凿的（如「心里沉」坐高安），修完用同一份快照重跑，看是否真变好——上一轮一次改 7 个词坐标，片被挤乱，28% → 17%，已整体回退。

## 三、用快照做单点（2026-11-23 00:12）

快照固定后（`re-pick`：位置+判据不动，只重挑词），一次只改一处、立刻看数：

| 改动 | 结果 |
|---|---|
| 「不爽」标注从 `[对方,外面,无]×[无,冲自己]` 收窄成 `[对方,外面]×[冲对方,无]`（它是有气，劲该冲对方） | 23% → 28% ✓ |
| 「被指出」签名放宽：只看 `by=other && goal<-0.15`，不再要求 expect>0.1 | 28% → 30% ✓ |
| 「心里发虚」从被指出族拿掉 | 30% → 25%，退回 ✗ |
| 「心里软」标注收窄成 `[对方]×[无]` | 30% → 16%（温暖/暖顶上），退回 ✗ |

**当前 30%（19/64）**，门禁 603/603。剩下的错集中在「心里软」（被体谅时该不该暖）、「心里发虚」（被说之后持续发虚）——这两处还要回头看是基准窄还是引擎宽。

### 又试了两档，都退回（00:13）

- 「心里发虚」单独提高到 `goal<-0.25` 才算被指出（原来和心里一紧同档 -0.15）：30% → 27%，退回。「闷了一下」立刻补上，说明这一族四个词是连着的，拆一个就换一个顶上。
- 把「闷了一下」也挪进深档：28%，还是不如 30%。

结论：被指出这一族（心里一紧 / 闷了一下 / 心里发虚 / 被说中）是一体的，要么一起加分要么一起不加；动单个体只会换个人霸榜。要真分开，得靠「位置」本身（发虚该在低安高觉、一紧该在更尖的点），不是靠分数门槛。

### 噪声门放宽试过，退回（00:15）

把 normal 档的噪声门从 0.12 放宽到 0.20（想让「普通一句」不再拖位置）：完整链路 30% → 20%。
说明那 -0.1 不是在跑噪声，它在真推位置——放宽等于把真变化也吞了。退回 0.12。
（同时给低安区补了三个中性轻词：有点空 / 淡淡的 / 说不上来。它们出现了，但数字没动——缺词只是一半，另一半是那片位置分不开。）

### 评审口径：第二次评审（00:20）

同一份场景，独立评审（A–C 对16/半16/错2，D–F 对12/半16/错2），合计**对 28 / 半 32 / 错 4**。

## 四、靠这个基线改，不靠感觉

下一步两条（都要用这个基线验）：
1. 判断层：中性/安排类句子该给 0 而不是 -0.1（这是判断层的定义问题，不是加规则——`goal_delta` 就是「我亏没亏」，没亏就是 0）。
