# 改动：二级情绪词表扩充 28 → 55（2026-11-17）

> 一句话：二级词从 28 个扩到 55 个，同一个 S/N/D 向量算出来不再总是「骄傲 / 满足 / 期待」那几个大词。

## 一、为什么

晚上看判定结果时发现：0.75 / 0.41 / 0.75 这种「中上偏正」的向量被判成「骄傲」，太重。词表太粗，中等正面的词不够，一进正面区域就被「骄傲 / 满足 / 期待」吃掉。

## 二、动了哪

`src/algo/affect_v4.js` 的 `SECONDARY_PROTOTYPES`：

- 28 词 → **55 词**，全部按 S/N/D 三轴位置 + gate（other / self / me）排。
- 新增细词：
  - 松：安心、心安、松弛、惬意、释然、平静、欣慰
  - 高兴：欣喜、激动、专注
  - 意外：错愕、迷惑
  - 不安：忐忑、不安、戒备
  - 闷气：烦躁、气闷、憋屈
  - 低迷：低落、倦怠、疲惫、疏离
  - 亲近：依恋、亲近、温情、心动
  - 自责：自责、懊悔、羞怯
  - 自荣：自豪
- 公式不变（原型距离 × 门控，σ=0.6，归一化取 top1）；`SCORED_MAX=28` 只是返回条数上限，不限制词表大小。

旧 28 词 top1 分布：期待 21、满足 11、焦虑 9、骄傲 4、雀跃 4、好奇 3、紧张 3、兴奋 1、无聊 1、羡慕 1、心疼 1、失落 1

换了名字的 52 / 60 条。几个典型：
- `0.95/0.41/0.75`（全过验收）满足 → **欣喜**
- `0.75/0.41/0.75`（被认可）骄傲 → **自豪**
- `0.35/0.75/0.30`（警觉）紧张 → **戒备**
- `0.35/0.58/0.70`（技术讨论）好奇 → **专注**
- `0.65/0.41/0.60`（温和肯定）满足 → **欣慰**
