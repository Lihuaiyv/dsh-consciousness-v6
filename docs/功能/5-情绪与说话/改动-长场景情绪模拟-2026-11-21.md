# 改动 · 长场景情绪模拟（2026-11-21）

> 起因：主人要求「跑完整链路、用子代理出判断数据、造十轮以上的真实长场景，
> 连续事件下的情绪波动和转换要像人；没过新场景不许汇报」。
> 这一份记**动了哪、为什么、怎么验、怎么退**，不写成「已完成」。

## 一、验证方法（这一轮定下来的）

1. **场景**：`scratch/scenes/<id>.json`，每段 14 句主人发言，gap 是分钟。全部从空库、平静基线起跑。
2. **判断层**：子代理按 `JUDGE_SYS` 原文逐句判，产出 `scratch/judge-<id>.json`；
   **不是人手写档位**。子代理只看该句之前的上下文。
3. **全链路**：`node scratch/sim-scene.mjs <id>`，走 `appraiseTurnNow`：
   规则帧 → 判断 → `advanceState` → `infer` → 落 `affect_v4_shadow` → 读回 `secondary_json`。
4. **独立评审**：另起一个子代理，只读对话和输出，逐句判「对/半对/错」、判走势、判连续三类毛病。
5. 场景分两批：第一批 F–J 调参用；第二批 N–P（及之后的 Q–S）只做验收，不参与调参。

## 二、找到的结构问题（按层）

### 状态累积层

| # | 问题 | 证据 | 改法 |
|---|---|---|---|
| 1 | **震后锁死**：`shock` 写进状态后永不过期，之后每轮 `hold=1h`，两句间隔不到一小时就永不回落 | F 场景 60 分钟那句 s 仍 0.95 | 记 `shockAt`，超过 `shockHold` 小时交回正常回落 |
| 2 | **重复打折断线**：`dStreak/dLast` 写进 flag，`readState` 没读回来，D 的「同方向第二句打折」在真链路里从没生效 | 代码核对 + 状态 flag | `readState` 补读；`writeState` 带 `last` |
| 3 | **地板抬升**：`max(0.12, …)` 把被通天砸到 0.02 的情绪在下一句负面里抬到 0.12，方向反了 | F 场景第 3 句 | 地板取 `min(0.12, 当前值)`，只挡上面压下来的 |
| 4 | **顺向放大器**：同号增量连续累加 + 回落慢，S 能被 8 句好话一路推到 0.95 不动 | G 场景 s 0.59→0.94 | ① 每轮 S 步长封顶（涨 0.18 / 跌 0.35）② 同方向增量从第二句起 ×0.8 递减 ③ 0.87 以上正向推力渐近归零 |
| 5 | **失而复得没有反弹**：D 被压到 0.05 后，按 0.25 的慢涨要四五轮才爬回来，中间全落在「思念/心里发虚/平淡」 | F 场景修复段 | `d < 0.35` 时正向 future 用 0.5 的反弹速度 |

### 判据层

| # | 问题 | 改法 |
|---|---|---|
| 6 | 只有「冲我来的好坏」，没有「他在难受，我想接住」这条通道，主人倒苦水被判成无事 | `JUDGE_SYS` 补「涉他难受」条款：goal 小负、future 小正 |
| 7 | 解释/道歉/久别回来，第一句就把账一笔勾销，久别的亏欠在状态里不存在 | `JUDGE_SYS` 补「第一句别把账一笔勾销」条款 |
| 8 | `frame.target` 是「这句话对谁说」，不是「这份情绪冲谁」，日常闲聊全被判成冲我/冲对方 | 判断层新增 `to` 字段（me/other/world/none）；`slotOf` 优先用它，旧数据退回 frame.target |

### 选词层

| # | 问题 | 改法 |
|---|---|---|
| 9 | 「片」这一层本来没参与打分，两个不相干的词只要坐标近就撞 | `gridDistribution` 加片先验（权重 0.06，只当平手时的偏置） |
| 10 | 平静基线 (0.5,0.15,0.5) 附近没有「今天没什么事」的词，最近的是「松了口气/起劲」 | 基线 0.20 范围内给如常/寻常/平淡/踏实/还好/没事一族加 0.10 |
| 11 | 「松了口气/释然/缓过来」是转折词，不是状态词；没先悬着也挑得出来 | 用位置帧里的 `peak.s`：这段没掉过（> -0.10）就降一档 |
| 12 | 每句都在换近义词（112 句换 95 次） | 滞回：状态没大动（<0.18）且上一个词分数没掉出 0.06，就沿用 |
| 13 | 「他在难受」时词落在「憋着/懊恼」这些「我自己被压住」的词上 | 判据签名 `goal<0 && future>0 && by!=me` 时，担心/心疼/挂心一族进候选并加 0.18 |
| 14 | 「自尊/认真/上心/用心」是概念或态度，不是此刻感受 | 概念词降权 0.10（不删） |

### 数据修正

- 剔除标签池（`scratch/gen-lexicon-v4.mjs` 的 `EXCLUDE_LABEL`）：
  `恶劣 / 机灵 / 乡愁 / 混混僵僵 / 落魄 / 豁达 / 用心`——都是评人或评处境，不是「我此刻」。
- 收窄标注（`scratch/词-抽屉标注-2026-11-20.md`）：
  `心疼` → 对方·冲对方；`被说中/被戳到/被点破` → 对方·冲自己；
  `有点不好意思` → 我·冲自己；`平淡/轻松` → 冲谁只留「无」。
- 修坐标（`scratch/lexicon/anchors-final-2026-11-19.json`）：
  `心里堵` an 58→28、`不痛快` 60→32、`埋怨` 62→38、`后怕` 72→40、`闷了一下` 56→42。
  这五个是明显的负向词却坐在高安区， steals 了「被夸/被陪」的位置。

  前两条已按上表处理，第三条的滞回已加，「共变约束」（新词方向必须跟 Δs/Δd 同号）**还没做**。

## 四、还没做 / 不能吹的

- 词的语义半径还是会错：`心疼`/`挂牵`/`认真` 这一类在特定位置仍会冒出来。
- 判断层是宿主模型，档位有方差；同一句换个宿主可能给不同增量。系统要能扛，但现在只是「不炸」。
- O 场景「三天没消息」的亏欠，场景本身是从空库起跑的，前三天不在数据里；
  真实宿主会在会话起点带底色，模拟里没有。这一条是模拟口径的缺口，不是引擎的。
- 新的验收场景（Q/R/S）还没造；按主人的规矩，新场景全过之前不汇报。

- 状态层：`affect.v4.dyn.step.up/down=0`、`affect.v4.dyn.kdu.rebound=0.25`、
  `affect.v4.dyn.shock.hold` 改回旧值；`S 饱和`两行删掉。
- 判据层：`JUDGE_SYS` 新增的三段删掉；`to` 字段不认（`slotOf` 退回 frame.target）。
- 选词层：`gridDistribution` 里片先验/基线先验/转折词/滞回/担心族/概念词六段各自删掉即可，
  删完退回 2026-11-21 早上的「0.3 典型 + 0.5 距离 + 0.2 浓淡」。
- 数据：`EXCLUDE_LABEL` 删新增行；标注表按原行改回；坐标改回上表旧值，重跑
  `node scratch/gen-lexicon-v4.mjs --from196` + `node scratch/gen-grid-data.mjs`。
