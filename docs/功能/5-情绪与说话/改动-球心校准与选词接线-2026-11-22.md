# 改动 · 球心校准与选词接线（2026-11-22 深夜）

> 起因：六段长场景用真模型跑，判断层实打实跑通了，但选词老是「缓过来 / 受用 / 挂牵」——
> 查出来是**球心错位**：三个数都中性（= 没什么事）的位置上，坐的是「受用、释然」，而「如常、平静」被摆到了安偏高的边上。
> 这一页记动了哪、为什么、怎么验。

## 一、动的东西

### 1. 词坐标（`src/algo/lexicon_v4.js`，17 个词）

- **「真没事」挪到正中**：如常 (0.52,0.16,0.50)、平静 (0.50,0.15,0.50)、寻常、没事、还好、平淡。
  依据：三轴中性 = 没有事情推我 = 「如常」；原来它们 s 在 0.62~0.70，中被「受用」占着。
- **「转折词」挪到边上**：缓过来 (0.72,0.12,0.58)、释然 (0.78,0.10,0.62)、松了口气、心落下来、松快、消了气。
  依据：它们要「先紧后松」才成立，不该坐在「无事」的位置上。
- **「担心」类挪到低安高觉**：挂心 (0.34,0.52,0.40)、担心、担忧、心疼。

### 2. 分片重算（`src/algo/lexicon_grid.js` 的 `GRID_CELLS`）

按新坐标 k-means 重切成 **63 片**（每片 ≤8 词，片心=片内词均值）。
球心那一片现在是「平淡 平静 如常 没事 寻常 还好 消了气」。

### 3. 中性词标注改宽（`GRID_ANNOT`，10 个词）

如常/平静/寻常/没事/还好/平淡/轻松/放松/安宁/舒坦：`by` 从「外面」改成「我/对方/外面/无」，`to` 只留「无」。
依据：没事发生可以是任何人弄的，不该只挂「外面」——否则判据只要是「对方·冲自己」，中性词永远被格筛掉。

### 4. 选词打分（`src/algo/grid_pick.js`）

- **方向闸**：这一下我赚了（goal>0.05）就别选低安位置的负向词（s<0.46），亏了就别选高安的正向词（s>0.54），各 −0.15。
- **真没事闸**：`NOEVENT`（如常/寻常/平淡/平静/还好/没事/安宁/安稳）在 |goal|>0.08 或 |future|>0.10 时 −0.18，别在有事的句子上抢位置。
- **concern 条件**：`by!=me && goal<-0.05 && (future>0.05 或 meaning 含 难过/难受/累/委屈/不开心/心事/睡不着/没睡/痛苦/烦)` → 担心/心疼/挂心 +0.18。
- **needed 条件**：`by=other && goal>-0.05 && future>0.20` → 心里软/想靠近/亲近/暖 +0.15；同条件里「真没事」族 −0.20、「挂牵/挂心/放不下」−0.12。
