## 三、判据 v4（最重要的一节，全文照抄）

规则原文在 `scratch/lexicon/prompt-score-v4.md`。核心是**两条判据并用**，这是走通的关键。

### 3.1 开头那句话

> 情绪是身体里那几套东西跑出来的**结果**，词只是人后来给这个结果起的名字。
> 所以判一个词，不是问"它听起来像哪个格子"，而是问：**一个正处在"这个词所说的那种感觉"里的人，身体里大概是什么样。**

方向必须是这个方向：先想身体，再报数。反过来（给词，感觉像几分激素）判出来会飘。

### 3.2 三个轴，每个轴两条判据

**安（血清素）**
- 感觉判据：0=悬着、随时会被拿走；50=说不上；100=稳稳的，被接住
- 激素判据：低的时候人处在"随时要防、什么都抓不住"；高的时候是"松下来、这事我能承受"

**欲（多巴胺）**
- 感觉判据：0=想退开、想躲；50=说不上；100=很想过去、一心想往那边去
- 激素判据：低的时候身体不给"往前的劲"；高的时候是"有意思、想够一够"

**觉（去甲肾上腺素）**
- ⚠️ **这根不是强度**。很重的情绪可以没有那一下（悲伤很重但慢慢化开），很轻的情绪也可能带一下（忽然的尴尬）
- 感觉判据：0=什么都没突然撞上来，情绪慢慢铺开；100=突然一下被拉起来、猛地一紧
- 激素判据：冲一下的时候人是"猛地警觉、心里一紧、事情砸在眼前"；没起来时是"平平地铺着"

**用法**：两边都过一遍，取向对得上的那个数。两边差太远说明没想透，再想。

### 3.3 最重要的判据（这条不写进 prompt 就会全部判歪）

判的是**这个词本身给人的感觉**，不是它指的那件事。

- 乡愁：不是"离家在外"这件事，是念着这两个字时心里"悬着、想回去、闷"。所以它该跟忧愁挨着，不该跟悲伤挨着。
- 沉迷：就是投入进去、一发不可收的样子。不因为它常被说成坏的就往低处打。
- 可怕：说的是那个东西让人害怕，但念着这个词时自己是缩着、提着心的。
- 绝望：坏事突然压下来、一下就没了路 → 觉高。但那是"一下"，不是"一直很重"。
- 悲伤：慢慢化开的，很重但没那一下 → 觉低。
- 评价别人的词（刻薄、吝啬、做作）：按你念它时自己的感觉打。

不是感受的词（人名、地名、物件、动作、虚词）→ 0 0 0。

## 四、为什么前面六版都不行（别重走）

| 版本 | 做法 | 为什么废 |
|---|---|---|
| 1. 整词词频（SUBTLEX） | 按字幕词频砍词 | 只覆盖 45%，且成语被拆成单字，七上八下、不是滋味全查不到 |
| 2. 字频门槛 | 词里最生僻那个字够不够常用 | 会连坐：「凄」121 次，凄切凄婉凄楚全被砍；「怵」5 次，发怵一起走 |
| 3. 语义合并（连通分量） | 余弦相似度聚簇 | **会链式爆炸**：A 近 B、B 近 C，最后整片负面词串成一个大簇（无奈/遗憾/绝望/恐慌全在一个簇里） |
| 4. 语义合并（贪心取簇） | 每轮只跟种子比，最多 5 个 | 只跟种子比，不跟其他成员比。「遗憾」跟「舍不得」0.807 就进了那个簇，结果跟「绝望」同簇 |
| 5. 质心 + 逐一比对 | 新成员要同时跟质心和每个成员过门槛 | 这个是对的，留下来了。但阈值压低到 0.66 时「痴迷」和「烦恼」还是会合（见坑 1） |
| 6. 只合真重复（0.85） | 阈值拉到最高 | 干净，但压不下来（2,398 个，几乎没动）。而且还在误合悲痛/痛心 |
| 7. 砍词（词频+字频双低） | 两个都低才砍 | 最稳的砍法，但**砍不动**：2,472 → 2,262，只削 8% |

**教训**：语义聚类能把"变体写法"合干净（惊惶失措/惊惶无措/惊皇失措、心如刀割/刀绞/刀锯），但合不了"意思相近的不同词"（痴迷/沉迷是一类，痴迷/烦恼是两类，向量给的分却只差 0.09）。**向量分不出"同类"和"相关"。**

## 五、跟三递质设计的关系（对上了，但要看清命名）

### 5.1 轴是同一套，顺序不同

[设计-三递质情绪引擎-2026-11-16](设计-三递质情绪引擎-2026-11-16.md) 里是 **S / N / D**；我们这里是 **安 / 欲 / 觉 = S / D / N**。同一个东西，只是书写顺序不同。

**但 N 的基线不一样**：设计里 `N = 0.15 + 0.85·意外`，基线是 **0.15**，不是 0.5。这一段很关键——

> 我们判出来的觉中位数是 **35**（0-100 制），七成词在 50 以下。一开始误以为是"判分偏低"，差点去按排名重算。
> 一查设计才发现：**N 本来就该偏低**，中性点是 0.15 不是 0.5。所以觉低是设计预期，不是数据坏了。

### 5.2 八格名字跟八角的不是一套 —— **2026-11-19 已定：用两字八格，单字八角废弃**

设计里的 8 角（单字）↔ 我们这版 8 格（两字）的对应：

| S | D | N | 设计里的角（废） | 我们这版的格（定） | 原来对得上吗 |
|---|---|---|---|---|---|
| 高 | 高 | 高 | 乐 | 敞亮 | ✓ |
| 高 | 高 | 低 | 怡 | 安住 | ✓ |
| 高 | 低 | 高 | 惊 | 警醒 | ✓ |
| 高 | 低 | 低 | 安 | 疏淡 | ✗ |
| 低 | 高 | 高 | 怒/慌 | 渴慕 | ✗ |
| 低 | 高 | 低 | 怯 | 郁结 | ✗ |
| 低 | 低 | 高 | 惧 | 惊惧 | ✓ |
| 低 | 低 | 低 | 悲 | 沉沦 | ✓ |

**主人 2026-11-19 拍板：按两字八格，单字那套废掉。理由是两字这套是从三轴逻辑推出来的**——每个名字都钉在一个顶点上，而且在人话里说得通：

- 疏淡（不是"安"）：安高、欲低、觉低——稳着，但什么都不想要。这是"淡"，不是"安"。
- 渴慕（不是"怒/慌"）：安低、欲高、觉高——没有底、很想要、还被猛地拉起来了。这是"渴"，不是"怒"。
- 郁结（不是"怯"）：安低、欲高、觉低——没有底、想要、但门没开，堵在那儿。这是"结"，不是"怯"。

单字那套的毛病：它按"我有没有危险"给的（安/惊/惧/悲都指向危险方向），把"想要但要不到"这一类全压成了一个"怒/慌"。两字这套是按三根轴分别想的，能分开。

**影响面**：
- ✅ `src/algo/affect_v4.js` 一级 8 角的名字：**2026-11-19 已改成两字八格**（key 保留旧值不断账），门禁 596/596，见 [改动-一级八角改两字八格名-2026-11-19](改动-一级八角改两字八格名-2026-11-19.md)。
- ⬜ `SECONDARY_PROTOTYPES` 的 60 词还是手摆位置，没吃 2,284 词的判分——**先要定 `jue` 0–100 怎么进 `n`（基线是 0.15 不是 0.5），不然一定飘**。
- ✅ 前端查过：`client/` 里没有单字角名，不用重建。


### 5.3 分布不均是真的，别去拉平

v4 判完的分布：

```
敞亮 133   安住 517   警醒 2   疏淡 171
渴慕 132   郁结  73   惊惧 410  沉沦 846
```

警醒只有 2 个（彻悟、讶然），敞亮只有 133。**这是真实分布，不要均衡化。**

- 沉沦多，因为负面词本来就多于正面词
- 警醒少，因为要同时满足"安高、欲低、觉高"——猛地明白了但不想抓住什么，这种状态本来就罕见（顿悟一族都落在敞亮了，因为"想抓住那个明白"把欲推高了）
- 如果按排名重算强行拉平，等于把"罕见的感受"平均成"常见"

50 就是 50，它的意思是"说不上"，在尺子上是固定的，跟这批词里有多少踩在上面无关。

## 七、踩过的坑（别再踩）

1. **通用 embedding 分不出"同类"和"相关"**。qwen3-embedding 里「痴迷」的最近邻是沉迷 0.86、执着 0.78、迷茫 0.78、惊奇 0.78、烦恼 0.77、恐惧 0.77——**惊奇和恐惧离它一样近**。到这个距离上，向量已经不携带"这是哪种情绪"的信息了，只剩"这是个心理词"。想靠它分情绪类别，阈值压到 0.66 就会开始乱合。

2. **连通分量聚类会链式爆炸**。必须用"质心 + 逐一比对"：新成员要同时跟质心和簇里每个成员过门槛。只跟种子比，就会把「遗憾」拉进「舍不得」那一簇。

3. **中库不需要坐标，也不需要"塞进情绪里"**。它的用途是查表：某个词 → 找最近锚 → 取锚的坐标。曾经把它当成要进运行时的东西，是理解错了层次。

4. **"没词频"不等于"没人说"**。SUBTLEX 是电影字幕语料，成语会被拆开分词（七上八下、不是滋味全查不到），「心疼」也会输给「心疼」的字形变体。砍词只能砍"整词没出现 + 字也冷"的，两个条件都满足才砍。

5. **词频表编码是 GB18030**，不是 UTF-8。SUBTLEX-CH-WF 直接按 UTF-8 读会一个字都匹配不上（覆盖率 0%）。

6. **SUBTLEX 官方下载地址**：GitHub raw 会超时，走 PLOS 补充材料能下到——
   `https://journals.plos.org/plosone/article/file?id=10.1371/journal.pone.0010729.s002&type=supplementary`

7. **12 个 subagent 并行判分没问题，但上限 8 个**。超了报 `subagent limit reached (active child limit: 8)`，等前面完成再补。

8. **subagent 写文件是 UTF-8，PowerShell `Get-Content` 默认按 GBK 解会显示乱码**。用 python 读，别被乱码骗了以为文件坏了。

9. **别拿"好事应该安心"的常识去套"安"**。安是"我心里有没有底"，不是"这是不是好事"。惊喜安 50（没料到、接不住那一下）、激动安 35（等结果时心是悬的）——都对。心疼安 55（我稳稳地看着你疼，我还托着你）——也对。这些曾经被我判成"可疑"，是常识盖过了判据。

10. **`axes-v8.json` 没有 `oct` 字段**，格子要用坐标现算：`(an>=50, yu>=50, jue>=50)`。
