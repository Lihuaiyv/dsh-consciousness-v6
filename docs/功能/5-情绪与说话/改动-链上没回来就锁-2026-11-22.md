# 改动 · 情绪链上任何一个模型没回来就锁住（2026-11-22）

> 主人：「只要有一次没返回，就往上传导，说没有值，然后整个的情绪就别动了，直接报错。」
> 背景：查截断时发现两种断法——吐一半（18:21，JSON 断在 `why`）和空手回来（19:20，len 0、raw 空）。

## 一、规则

判断层调用之前先看链条有没有缺料：

- 事层没回来（`frame.missing` 里有 `topic`）→ 缺 `topic`
- 前置没回来（`affairs` 为空）→ 缺 `affairs`

缺任意一环就不调判断层，直接给一个 `incomplete`，`missing` 里写缺的是哪一环；后续照旧：不推进状态、词停在上一位置、写 `affect.v4.strike` 报警。

判断层自己没回来 / 没写全，走原来的十键检查，同样锁住。

## 二、补的空壳漏洞

事层原来「只要返回能解析的 JSON 就算回来」——`{}`、`{"what":"","target":""}` 这种空壳也算成功，判断层就拿着空白照判。
现在改成：`what` 和 `target` **至少有一个真写了内容**才算回来，两个都空就当没回来（记 `missing.topic`，按上面的规则锁住）。
