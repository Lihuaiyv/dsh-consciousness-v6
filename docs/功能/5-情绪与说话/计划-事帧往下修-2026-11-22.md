## 二、问题清单（从事帧产生往下，按根因排）

1. **事帧缺上下文五格**：`gapMs`（距上一句多久）、`turnIndex`（同一件事第几轮）、
   `prevLabel`（我上一轮的情绪词）、`scene`（哪一类事）、`with`（对面是谁）。
   判断层因此判不出「越说越急」「论持久战该麻木」。设计 v2 §五 的验收 1/4 条从没跑过。
2. **兜底路径没有 `by`**（38.3%）：判断层掉线时，事帧有 `target`，但 `by` 丢了，
   选词的「谁做的 × 冲谁」直接塌成「无·无」。
3. **材料不分角色**：`material.quotes` 只有字符串，判断层看不出哪句是主人说的、哪句是我说的。
4. **`act` 20.5% 空 / 6 条「（新事）」没有 missing 标记**：事层没回来时，事帧不告诉判断层「这是缺的」，
   判断层会照常当完整输入判。设计 v2 原则 3 明确要求「填不满就留空 + 记一笔 missing，不瞎猜」。
5. **判层兜底的 `judge` 留痕没进 model 行**：11-21 的留痕写了 `judge:'rules-fallback'`，
   但 `const judge = judgment ? 'host' : 'rules'` 在它之后执行，把标记覆盖成了 `host`。
   真库里 model 行 `rules-fallback` 是 0 —— 与代码意图不符。

## 三、修复顺序（一次一刀，每刀带开关 + 退路）

### 第一刀：事帧补上下文（本刀）

- frame 增 `gapMs` / `turnIndex` / `prevLabel` / `with`，全部**代码填，零模型成本**：
  - `gapMs`：这一轮 `now` 与上一轮影子行 `at` 的差（没有上一行 = null）。
  - `turnIndex`：同一帧内第几轮（续帧 +1，新帧 = 1）。从上一帧的位置状态 `turns` 取，已有算好。
  - `prevLabel`：上一轮 model 行的 `label`（取 `affect_v4_shadow` 上一轮最终行）。
  - `with`：渠道（web / qq / wechat / self），由调用方传 `channel`；不传=null。
- 新增 `material.lines`：`[{role:'user'|'agent', text}]`，带角色；**`material.quotes` 保持旧字符串数组不动**
  （旧测试与旧读侧依赖它，一次只动一条链）。判断层输入改用 `lines` 拼「主人：/我：」。
- 缺字段记 `missing: []`：`act` 空、`summary` 为「（新事）」、`by` 空时各记一条。
- 判层输入 `frameText`（只在 `affect.v4.frame.ctx=on` 时）追加三行：
  `距上一句：N 秒 / N 分钟`、`这件事第 N 轮`、`我上一轮的状态：<prevLabel>`。
- 开关：`affect.v4.frame.ctx`，默认 **off**（先影子：只写进 frame，不改判断层输入）。
  验收通过后再开 `on` 改输入。
- 退路：开关 off 时 frame 与现在一字不差（只多 `missing` 字段，可选不写）。

**验收（先写死）**
