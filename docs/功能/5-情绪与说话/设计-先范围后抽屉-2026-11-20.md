# 情绪选词：先范围，后抽屉（定稿）· 2026-11-20

## 一句话

情绪坐标先落进一片**词组范围**（位置近的一堆词），片里再按**判据格子**（谁做的 × 冲谁）分开，格子里按**浓淡**排成一条强度轴，最后按**典型度**挑一个词。

## 四层结构

### 第一层：片 = 词组范围

位置就近的一堆词。比如「烦 担忧 怨望 烦恼 尴尬 憎恶」是一片。

聚片规则：

- 从每一个词各自一片开始，反复把「片心最近、且合起来不超标」的两片并起来
- 一片最多 5 个词（例外：厌烦、暧昧、尴尬、恶劣、憎恶、同病相怜、惦念、痛快、体贴、安慰 这 10 个不占名额）
- 片内最远两个词距离 ≤ 0.22
- 片半径 ≤ 0.16

现在：191 个词 → 50 片。

### 第二层：格 = 判据组合（13 格）

| 谁做的 \ 冲谁 | 冲自己 | 冲对方 | 冲外面 | 无 |
|---|---|---|---|---|
| 我 | ✓ | ✓ | ✓ | ✓ |
| 对方 | ✓ | ✓ | ✓ | ✓ |
| 外面 | ✓ | ✓ | ✓ | ✓ |
| 无 | — | — | — | ✓（只有这一格） |

- 「谁做的」= 这情绪是谁弄出来的（我 / 对方 / 外面）
- 「冲谁」= 这情绪往哪儿去（自己 / 对方 / 外面 / 谁都不冲）
- 「无·无」= 说不清是谁弄的、也说不上冲谁——就是没来由地在那儿

原来凑过 4×3 = 12 格，删掉了「无·冲自己」「无·冲对方」：**既然不知道是谁做的，也就谈不上冲着谁**，这两格讲不通，从没用上过。

### 第三层：浓淡 = 格子里的强度轴

每个词有一个浓淡：轻 / 中 / 重。

同一格里，浓淡不同就是两个词，排在一条线上：

```
对方·冲对方：烦(轻) → 怨望(中) → 憎恶(重)
```

挑的时候按当前情绪多重来取，不是按顺序。

**浓淡不同才算是两个词**；浓淡一样、意思也一样的，合并成一个（如 温柔→温情、懒惰→懒、畏惧→害怕）。

### 第四层：典型度 = 这格像不像它

每个词对每个格子都有分，0.1~1.0，**永远不为 0**，所以没有空格。

| 距离 | 分 |
|---|---|
| 正好是它标注的组合 | 1.0 |
| 差一个值 | 0.6 |
| 差两个值 | 0.3 |
| 差三个以上 | 0.1 |

这样格子不空，又有区分度：每格都有词能落，但落进来的词分得出谁更对路。

## 挑词怎么走

1. 情绪坐标 → 落进哪一片
2. 判断层给「谁做的」「冲谁」→ 落进那片哪一格
3. 那一格里所有词按典型度排，再按浓淡对齐当前强度
4. 取分最高的那个
