# 改动 · 判断层「这一句」带来源（2026-11-22）

> 主人定：来源只标两值——「对方」和「我」；不用再分主人/别人/世界。
> 「这一句」直接给原话 + 来源，判断层不再从「我/你/他」猜说话人。by / to 按来源判，不按人称判。

## 一、动了哪

`src/modules/affect_v4_shadow.js`

1. **新函数 `speakerOf(db, turnId)`**：查 `chat_turns` 里这条 turn 的 `role`——`user` → 「对方」，`agent` → 「我」；查不到就按「对方」（对话轮都是有人在说）。这是硬事实，不交给模型猜。
2. **判断输入换行**（`appraiseTurnNow` 的 `frameText`）：
   - 删掉 `这一句：${frame.what}`（事层概括）和 `冲谁：${frame.target}`；
   - 换成 `这一句（来源：对方｜我）：<原话>`。
   判断层现在读原话本身，不是读事层压过的概括；来源写在括号里。
3. **`JUDGE_SYS` 的 by / to 缩成身份映射**：
   - by：来源是「对方」→ other（哪怕话里说「我刚才设置了」，造成的是他）；来源是「我」→ me；谁也没做 → world。按来源判，不按句子里出现哪个字判。
   - to：来源是「对方」——冲我说/让我做事/问我 → me；指第三方 → other；没指向 → none。来源是「我」——冲自己 me，冲对方 other，说不上 none。

**没动**：事层（what/target 仍产，喂别处）、十键严格模式、增量刻度、severity。

## 二、为什么

之前 by/to 错 6/25，补规则补不完——根子是材料里全是代词，「我」可能是主人，「你」可能是我，模型只能猜。
这次把「谁说的」当事实写进输入，by/to 从「猜代词」变成「读字段」，规则才缩得下来。

## 三、怎么验

```powershell
node test/run-tests.mjs
```

门禁只保证没碰坏别的；提示词与输入形状进不了单测。重载后真验收看两处：
判断输入里是不是 `这一句（来源：对方）：<原话>`；以及「我刚才设置了」「那你查查他」这类句子 by/to 是否落对。

## 四、怎么退
