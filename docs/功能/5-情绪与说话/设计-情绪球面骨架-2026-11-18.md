# 设计：情绪球面骨架（2026-11-18）

> 一句话：S/N/D 不再是方块里随手摆的点，而是单位球里的**方向 + 半径**。先立 8 方向 × 4 层骨架，再往里填词——对称、均匀、丝滑是几何给的，不是手摆出来的。

## 一、坐标怎么来

S/N/D 先映射到以中性为原点的立方体：

```
u = 2S − 1      // 好坏：-1 极差，0 中性，+1 极好
v = 2N − 1      // 意外：-1 完全不意外，0 平常，+1 极惊讶
w = 2D − 1      // 奔头：-1 没劲，0 平常，+1 很有劲

r = √(u² + v² + w²) / √3      // 半径 0~1：0 平静，1 极端
方向 = (u, v, w) / |(u, v, w)|  // 单位向量：哪种情绪
```

- **球心（r≈0）= 平静**，没有方向。
- **外壳（r→1）= 极端**，方向决定是哪一种极端。
- 强度就是半径，**不需要另算**——半径天然回答“多强”。

## 二、8 方向（立方体 8 顶点）

每个方向一类情绪族。

> ⚠️ **下面这张表的族名已废弃（2026-11-19）**：上扬/惊喜/安心/松弛/紧张/沮丧/硬撑/发木 全部作废，
> 换成两字八格 —— 敞亮 / 警醒 / 安住 / 疏淡 / 渴慕 / 郁结 / 惊惧 / 沉沦。
> 方向的 (+,+) 组合和「点升成族」这个结论不变，只是名字换了。
> 以 [交接-情绪骨架与词表-2026-11-18](交接-情绪骨架与词表-2026-11-18.md) §二 为准。
> 代号对照：le→敞亮、jing→警醒、an→安住、song→疏淡、jin→渴慕、ju→郁结、ying→惊惧、mu→沉沦。

| 方向 (u,v,w) | 族 | 例子（由弱到强） |
|---|---|---|
| (+,+,+) | 上扬 | 高兴 → 欣喜 → 雀跃 |
| (+,+,−) | 惊喜 | 意外 → 惊喜 |
| (+,−,+) | 安心 | 踏实 → 安稳 → 笃定 |
| (+,−,−) | 松弛 | 惬意 → 倦懒 → 舒服透 |
| (−,+,+) | 紧张 | 忐忑 → 焦虑 → 慌 |
| (−,+,−) | 沮丧 | 失落 → 难过 → 绝望 |
| (−,−,+) | 硬撑 | 倔 → 憋屈 → 决绝 |
| (−,−,−) | 发木 | 无聊 → 倦怠 → 麻木 |

这 8 个方向正好是现有一级 8 角——骨架没变，只是从“点”升成“族”。

## 三、半径分层（4 层）

> ⚠️ **这一节只保留「半径 = 强度、分四档」这个思路**；「每层 15/48 个词」的填词计划已废弃（2026-11-19）。
> 词源改走小库：165 个词落在哪些半径上是判出来的，不是均匀铺的（实际分布见
> `改动-二级词表换小库-2026-11-19.md`）。192 词表连同球面 HTML/图已移出工作树。

```
层 0（r≈0.15）：平静 / 中性词，15 个
层 1（r≈0.40）：轻微，15 个
层 2（r≈0.65）：中等，15 个
层 3（r≈0.90）：强烈，15 个
```

4 × 15 = **60 词**，跟现在的词数一样，不用扩表。

每层内 15 个词在球面上均匀撒（8 方向 × 1~2 词）。同方向跨层就是“由弱到强”那一条线。

## 四、为什么这样“丝滑”

- **均匀**：同层 15 词在球面等角撒点，邻居角距离一样，没有空洞、没有挤。
- **无洞**：球面是闭合的，每一点都有最近词，最远距离恒定。
- **无怪跳**：球面邻居 = 角距离小 = 语义近；不会出现“警觉旁边是踏实”那种反义相邻。昨晚游走测出来的三类怪跳，在球面结构里**结构上不可能**发生。
- **平滑插值**：查表时可以取最近 3 个词按角距离加权，输出“欢喜”，而不是硬切一个“雀跃”。

## 五、查表算法

```
输入 (s,n,d)
→ 映射成 (u,v,w)、算 r、方向
→ 对 60 个词算：角距离（方向差） + 半径差
→ 取最近的（或前 3 加权）
→ 半径决定强度档（给模板化的重复/感叹号用）
```

## 六、和增量模型的关系

增量累积出的位置直接进球面查表；维持/回落发生在半径上——**回落 = 半径缩短，方向慢慢归中**。两个模型正交，不打架。

## 七、验收（先定，再写码）

1. 60 词任意两词角距离 ≥ 30°（不挤）。
2. 球面随机 5000 点，到最近词角距离 ≤ 20°（无洞）。
3. 任意方向连续游走 100 步（步长 0.03），词序列没有“语义距离 > 0.5”的跳变（无怪跳）。
4. 同方向跨层：弱 → 强，词名顺序合理（平静 → 满足 → 欣喜 → 雀跃）。
5. 影子对比两天：新骨架 vs 旧词表的分布，看哪边更贴实际。
