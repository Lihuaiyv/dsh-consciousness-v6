## 一、这一批改了什么

### 状态层

- **未消的账（debt）**：负向事件往 `debt` 记一笔，按 0.75h 半衰期褪；有 debt 时正向回升被压（`1-0.55*debt`，下限 0.25）。
  针对评审说的「被放鸽子 / 被晾两天，一句道歉就单调爬回满格，没有折痕」。
  读数 / 写回在 `affect_v4_shadow.js` 的 `readState/writeState`（`debt`）。
- **存在级文字闸**：`applyShock` 只在 `fact/from` 真的含「删/换/断开/关掉/不该在/不要你/离开…」时才一步通天。
  宿主把「他喜欢别人了」标成 existence 时不再砸到 0.02（P 场景）。
- 验收夹具：`check-affect-cross.mjs` / `check-affect-delta.mjs` 的假判断补上 `from`，不改断言语义。

### 选词层

- **惯性只看慢轴**：`moved = |Δs| + 0.5|Δd|`，不再把 n（意外尖峰）算进「状态动了没」。
  评审指出 n 每轮 0.1~0.3 的抖动让 11 段里 10 段「每句必换」。
- **状态粗格黏性**：s/d 的 0.1 粗格没变、上一个词还在候选里，就沿用它，最多三连（`bin`）。
- **族从硬筛改成加分**：`+0.10`（0.05 太弱、0.15 会把 F 拉回「心里堵×2」）。
- **事件效价闸**：状态明显在 0.5 一侧时，不挑 `s` 在另一侧超过 0.12 的词；
  `心疼` 只在 goal<0 时出现，`受用` 只在 goal>0 时出现。
- **重复控制**：最近五轮用过的词降权（每次 -0.10，封顶 -0.30）；连着第 4 次直接跳过。
- **重字降档**：浓淡「重」且强度 <0.6 时 -0.16。

### 数据

- 剔标签池：`稳住 / 定下来 / 沉住气 / 豁达 / 用心`（指令、态度、性子，不是此刻感受）。
- 收窄标注：`羡慕` 只冲对方、`懒散` 只我·无、`受用` 只对方·冲自己、`憋着` 只我·无。
- 族修正：`鼻子一酸/眼眶热/热泪盈眶/动容` → nuan（被触动）；`羡慕` → pan。
- 坐标：`挂牵` an 60→46、yu 60→55（它原来坐在暖区正中心，E/J 全段被它占住）。

## 三、还差的（不吹）

- 词层还是有「旁观词」冒出来（羡慕/赞叹/受用/盼着），根子是这些词的坐标坐在中性偏暖的中心，加上判断层 `family` 时对时错。

  真实宿主是同一个模型，刻度会稳一些。这一条是模拟口径的缺口。
- 低强度段（I）词退化成「如常/寻常/踏实」，语义对、情绪感弱。

## 四、位置近这一层（2026-11-21 主人追问）
