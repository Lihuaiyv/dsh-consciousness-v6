## 为什么

真库里有两类宿主通报被当成「主人说的话」写进了 `fragments`：

- `The user changed the approval policy from "ask the user for approval" to "never ask the user for approval".` —— **44 条**（11-08 ~ 11-18，user 角色、带 `turn_id`、`meta` 为 null）
- `You are repeating the exact same tool call with identical arguments...` —— **15 条**

写碎片的路是 `index.js:1885`，已经过了 `cleanUserText`；但 `text.js` 的 `NOISE_LINE` 只认 `The approval policy changed`，漏了 `The user changed ...` 这个句式，于是剥不干净、原样落库。

后果不是「库里多几条」而已：v4 四天的产物（`切出来v4-2026-11-14/15/16/17.md` 与 `切出来v4-plain-2026-11-16.md`）**各有一件的起句就是这句英文**，那条件的检索锚直接是运行时噪音。
