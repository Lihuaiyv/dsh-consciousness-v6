# 改动：切事件的出件质量（标题/摘要/线索）（2026-11-19）

- 日期：2026-11-19（接 11-18 深夜）
- 起因：抽 11-17 重切后的 44 件，四个问题——标题重名 1 处、几个标题没对象、摘要把第一段经过和最后段结果拼成两句、4 件线索为空。
- 链条：切事 v4 出件层（只改出件，不动切段和判缝）。

## 动了哪

`src/modules/event_cut_v4.js` 出件处新增两个小函数，改 `merged.map`：

| 问题 | 修法 |
|---|---|
| 标题重名 | 维护当天已用标题集合；重名时用第二个专名区分，再不够加序号 |
| 泛标题没对象 | 标题里一个专名都没有 → 补「·第一个专名」 |
| 摘要像两件事硬接 | 只取第一段的「经过」（`head.process`），不再拼 `tail.result` |
| 线索为空/只有一个 | 合并 head+tail 的专名；仍不足两个就从该件原文里挑像专名的词补（泛词、半句过滤掉）；再不够留现有的，不造假 |

## 怎么验

```
node scripts/check-event-cut-v2.mjs   # 12/12（新增：标题不重名、每件线索至少两个）
node test/run-tests.mjs               # 门禁 596/596
```

改动只在**下次切事**时生效；11-17 现有 44 件是旧出件逻辑产的，要看新效果得重跑那天。

## 怎么退

出件处恢复旧的三行（title/summary/cues）即可；数据不用动。
