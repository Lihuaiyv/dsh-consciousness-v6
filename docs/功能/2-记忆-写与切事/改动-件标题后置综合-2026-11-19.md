# 改动 · 件标题后置综合（2026-11-19）

> 问题：D89。件标题原来捡第一段记叙的 title，是「这一段在干嘛」，不是整件事的名字；
> 而且记叙的 anchors 经常交回空数组，标题没专名可补（例：11-16 13:00 那件 732 字的汇报，标题只剩「报告主人结论」）。
> 主人 2026-11-19 拍板：模型综合，每件多一次调用。

## 动了哪

`src/modules/event_cut_v4.js`

1. 新增 `TITLE_SYS`：给「一件事」起名的提示词，只输出 `{title, anchors}`；要求标题带具体对象+结果、不用「汇报/讨论」开头、专名必须出现在原文里。
2. `cutDayV4` 签名加 `titleSynth = true`。
3. 出件循环（`merged` → `events`）从 `map` 改成 `for` + `await`：
   - 件的成员定下来后，把各段记叙（title/cause/process/result/anchors）+ 件首两句 + 件尾两句喂模型，写一次标题；
   - 缓存键 `t|<首碎片id>|<末碎片id>|1`，按件成员算，重切同一天不重算标题；
   - 兜底链：综合标题 → 段标题；专名 = 模型交回 → 各段 anchors 并集 → 清洗后的抓手（都保证在原文里）；`titleOf` 仍做「标题不含专名就补·专名」「重名加第二个专名」。
4. `stats` 加 `titleCalls`（这次跑了几次标题调用）。

`src/host/workers.js`：读 `events.cut.v2.title.synth`（默认 on），传给 `cutDayV4`。

`scripts/check-event-cut-v2.mjs`：假模型加「你在给」分支；新增 3 条断言——一件一次综合调用、综合标题带专名、关掉开关回退段标题。

## 为什么这样修

- 标题必须在件定形之后写：段级记叙看不到同件的其他段，捡第一段的结果就是过程词。
- 缓存键按成员算，重切同一天不会因为件顺序变化而重复调用。
- 兜底两层，模型交空也不至于回到「报告主人结论」那种空标题。

## 怎么退

- `events.cut.v2.title.synth=off`（或调用方传 `titleSynth:false`）：回到「第一段标题 + 专名」的旧行为，不多调用。
- 删 `TITLE_SYS` 和循环里的标题块即可完全回退；`titleCalls` 字段留着无副作用。
