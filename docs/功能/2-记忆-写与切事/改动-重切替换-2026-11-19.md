# 改动 · 重切替换旧件（2026-11-19）

> 问题：D90。重切同一天时旧件不清，新件 id 又含标题（标题一改 id 就变），结果新旧叠加。
> 主人 2026-11-19 拍板：**重切 = 把那天旧件清掉重写。**

## 动了哪

1. `src/modules/event_split_v2.js` `writeEventsV2` 加 `replace` 参数（默认 `false`，旧行为不变）：
   - 整批先验（缺 title/summary/碎片 → 整批不写、也不删）；
   - 验过进事务后，先删该 agent 该天的 `event_members` + `events_v2`，再写新件；
   - 输出加 `removed`（删了几件），事务回滚时旧件一条不丢。
2. `src/host/workers.js`：切事 tick 写库传 `replace`，开关 `events.cut.v2.replace`（默认 on；off 退回「只追加、幂等跳过」）。
3. `scratch/run-shadow-real.mjs`：手动跑一天时传 `replace: true`。
4. `scripts/check-events-v2.mjs` 新增 3 条：旧两件清掉只留新一件 / 成员跟着换 / 别的天一行不动。

## 为什么这样修

- 只删「这一天、这个 agent」的件，别的天和冷/热库一行不动。
- 先整批验再删：模型输出坏的那批不会把旧件误删。
- 加开关而不是写死：错判时 `events.cut.v2.replace=off` 即回旧语义。
