# 改动：本地切事模型换 qwen3:14b（关思考、num_ctx 16384）

- 日期：2026-11-15
- 起因：主人下好了 qwen3，要对比哪个好用。A/B 实测（3 段真实工作段）：qwen2.5 平均 8.6s、qwen3 开思考 15.0s、**qwen3 关思考 2.3s**；摘要质量持平。同时发现 14k 字长段三个模型全空回（`num_ctx` 8192 装不下）。
- 链条：写链（切事 · 本地摘要）。未动读链、未动主模型。

## 动了哪

| 文件 | 改了什么 |
|---|---|
| `src/modules/local_llm.js` | 默认模型 `qwen2.5:14b-instruct` → **`qwen3:14b`**；请求体对匹配 `/qwen3/i` 的模型加 `think:false`；`num_ctx` 8192 → **16384** |
| `scratch/verify-local-qwen3.mjs` | 新验收：走真的 `localComplete`，用「生产尺寸 7723 字」和「14k/18996 字长段」两段，要求都返回可解析 JSON |

## 为什么

- qwen3 开着思考时慢一倍、多耗 350~500 输出 token，摘要没更好；关了思考快近四倍、质量持平。
- 8192 上下文装不下 8000 字一块的工作段（含系统提示），超了模型直接不吐 JSON → 静默退词法。抬到 16384 后 18996 字也能切。

## 怎么验（数字）

- `node scratch/verify-local-qwen3.mjs` → **全过**
  - A 生产尺寸 7723 字：**5.9 秒**、JSON 可解析、digest「提示词规则调整，删除重复规则，确认帧位置和关系行修改」
  - B 长段 18996 字：**3.2 秒**、JSON 可解析、digest「调试帧和张力，优化提示词规则，讨论feel和新功能设计」
- 门禁：`node test/run-tests.mjs` → **577 / 577 全过**
- 切事链路不依赖本地模型时照旧（本地失败仍落词法兜底）。

## 怎么退

```powershell
git checkout -- src/modules/local_llm.js
# 或者只把模型换回去（flags）：
# memory.cut.local.model = qwen2.5:14b-instruct
```

## 注意

- 要**重载插件**才生效。
- `think:false` 只对 qwen3 加；老模型不认这个字段，不传。
- 如果以后 qwen3 模型被删掉，本地会直接失败 → 词法兜底（不报错、不丢数据，但摘要会变糙）。
