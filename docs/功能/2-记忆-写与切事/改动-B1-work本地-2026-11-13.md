## B1b · daily 主模型失败 → 本地逐件兜底

- 触发：daily 块主模型**抛错或空回**（不是默认替代；平时仍是主模型）。
- 做法：`localDailyEvents` 用逐件提示（ONE_SYSTEM）按 20 轮窗口跑本地；**不用批切提示**——14B 会吐一个对象，解析成 0 件。
- 标记：兜底事件 weight 压到 ≤0.35（低信心）；`results[].fallbackLocal` / 汇总 `fallbackCalls` 可查；cues 规则补专名。
- 开关：`memory.cut.daily.local_fallback`（代码默认 off；线上 2026-11-13 16:41 设 1）。
- 验收：`scripts/check-daily-fallback.mjs`（5 项）挂进门禁；**568/568 exit=0**。

## B1c · 保活 / 重连 / 词法兜底 / 质量标记（2026-11-13 16:5x）

- **保活**：插件启动 + 首次调用前 `ensureLocalServer`；spawn 带 `CREATE_NO_WINDOW`、detached；并发共用同一个 promise；失败后 5 分钟内不再重拉——重启时不会再闪一堆黑框。
- **重连**：`localComplete` 连不上先强制重连一次；仍不行：work 段走词法，daily 段走本地逐件兜底（B1b）。
- **词法**：不连模型，直接读碎片现拼「第一句；后来：最后一句」+ 规则抓手；`quality=lexical`、weight 0.25、0 API。只当占位和软联想，不冒充完整的事。
- **质量标记**：`cold_events` / `hot_events` 加 `quality` 列，值 `model` / `local` / `lexical` / `local_fallback`；旧数据默认 `model`。
- 验收：`check-work-local` 7 项、`check-daily-fallback` 5 项、门禁 **568/568**、路径闸 ok。

## 怎么退
- 开关关掉即回旧路（`memory.cut.work.local` 置 0）；代码是纯加法，没有改 daily 分支。
- 本地服务不在 → `localComplete` 抛错 → 自动回退主模型，事件不丢。

## 风险

- 本地模型慢（~1 秒/块）但 0 费用；如果哪天显存被占，回退会让这批 work 块回到主模型计费。
- 现在 work 块偏碎（今天平均 1.6k 字），因为 work/空 mode 交替；纯工作日块才会接近 8k 字，省得更多。
- 仍需一次插件重载才能加载本改动；flag 本身是读库的，重载后改 flag 立即生效。
