# 调研 · 叙事因果与事件关系（2026-11-23）

> **用途：只当「读过什么」的索引。** 设计结论不在本篇，见 [`设计-判边-2026-11-23.md`](设计-判边-2026-11-23.md)。
> 一句话结论：事件关系有四条腿（共指 / 时间 / 因果 / **子事件**），我们缺「子事件」；LLM 会拿先后顺序当因果；「同一批活」= 事件剧本（schema）；篇章里「展开」是独立大类。

## 2 对我们最有用的四个判断

1. **「子事件」在学术上是与因果并列的一等关系。** 我们九类里没有它，11-22 那 20 个 `none` 里很可能大半属于「同一个更大的事下的子事」。→ 设计补一类 `subevent`。
2. **候选不能按「相邻」取。** LLM 会拿顺序当因果（2410.23884），而我们恰好把顺序当候选条件。→ 设计改成「先分组、组内判」。
3. **「同一批活」有现成名字：事件剧本（schema）。** 专名簇就是一个小剧本。→ 设计把「组」当剧本，体仍从密度长。
4. **「展开 / 接着说」在篇章学里是独立大类（PDTB Expansion）。** 我们的 `continue` 只是它的一角。→ 保留 `continue`，但只当叙事、只由规则给。

## 3 没做什么

- 没有落库、没有改代码（这篇是调研）
- 没有抄别人的模型/训练方法（我们不需要重训）
- 没有引入「时间关系」当独立一类（时间仍是点的属性，见主设计 §1）
