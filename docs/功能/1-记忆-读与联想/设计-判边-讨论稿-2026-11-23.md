## 这篇为什么留着

正式稿把四类做法（纯因果判定 / 事件关系全集 / 叙事篇章 / 记忆系统）拆开各借一点。这份记的是**拆之前**的状态：我们是从「九类 + 相邻判」出发，一个个试出来的。

## 讨论里定下的五件事

1. **判边不是「一对一对问像不像」**，是「一组本来就有关系的事里，判是不是因果 / 同一件事 / 子事件」。
2. **`continue` 不该交给模型**——它只说「接着办」，不是因果；交给模型会被判成 none（11-22 实测 20/21 是 none）。
3. **词表补 `subevent`**——MAVEN-ERE 里它是一等关系；11-22 那些「同一天修一串子问题」多数属于它。
4. **候选从「相邻」改成「先分组」**——相邻不等于接续，且顺序信号会误导模型。
5. **一对只留一条主关系**——互斥规则只在写入前校验，读路径照旧不看 `kind`。
