# 改动 · 汇流口令与三层 · 2026-11-15

## 动了哪
`src/modules/confluence.js` · `parseBackCommand`
1. **词法放宽**：
   - 原来只认 `回到 YYYY-MM-DD`（可带 `15:00`）；
   - 现在认「回到 / 翻回 / 回看 / 看看」+ 任意时间说法：
     - 绝对日期 `2026-11-12`
     - 相对日期交给 `timeparse.parseTimeRange`：「上周三」「11月5日」「前天」「三天前」
   - 「回到汇流」这类没时间的，仍然不触发（返回 null）。
2. **三层开口**：
   - 默认 **L1**（轻量重建）；
   - 说「整段 / 重放」→ **L2**（从 `scene_archive` 整段重放）；
   - 说「一眼 / 只看看 / 轻一点」→ **L0**（轻截面）。

## 怎么验（命令行实测）
| 说法 | 结果 |
|---|---|
| 回到 2026-11-12 | L1 · 11-12 15:00 |
| 回到上周三 | L1 · 11-03 |
| 回到 11月5日 | L1 · 11-04 |
| 翻回 2026-11-12 整段 | **L2** |
| 看看 2026-11-05 一眼 | **L0** |
| 回到汇流 | null（正确不触发） |

门禁：**573 / 573，exit=0**。

## 没做的
- 时间只解析到「日」，不解析「那天下午三点」这种口语钟点（`timeparse` 目前不支持）。
- L2 整段重放只在 `scene_archive` 有那一轮原文时才有效，旧日子可能没有照片。

## 怎么退
`parseBackCommand` 整段还原成旧版（只认 `YYYY-MM-DD`、固定 L1）；删掉 `timeparse` import。
