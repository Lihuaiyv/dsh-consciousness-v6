# 设计 · 记忆与联想（v3 · 2026-11-12）

> 一句话：**碎片记「这一刻说了什么」，事件记「那一段发生了什么」，联想决定「什么话会把哪件事带回来」。**
>
> 这一版合并了《设计-事件库-最终版》和《设计-联想-人类版》，并写进了今天真库上跑出来的数字。
> 之前那两份作废，冲突以这份为准。

---

## 一、三层结构

```
你说的话
  │
  ├─► 碎片 fragments        一句一行，只追加。带「当时的状态快照」和「接自」。
  │                         14 列；来源四样（主人/我/其他人/世界），形式五样（文字/声音/图/文件/数据）。
  │
  └─► 夜里切事（清醒段结束后）
        │
        ├─► 事件冷库 cold_events   第一刀切出来的事。只追加、永不改；补切追加新的。
        │                          名字 / 经过 / 引文 / 轮次 / 抓手 / 过没过 / 重量
        │
        └─► 事件热库 hot_events    当前在用的那版。可合并、拆分、改名、沉底，每变一次出新版。
              │                    想头 / 天花板 / 来源（只记冷库 id）
              ▼
           联想：三条路（见第五节）
```

**追溯**：热库 → 冷库 → 碎片，**两跳到底**。

---

## 二、碎片层（已跑通）

- **只追加**，不改不删。
- **来源四样**：`owner` 主人 / `self` 我 / `other` 其他人 / `world` 世界（鸟叫、系统通报、工具结果）。
  库里历史值仍是 `user` / `assistant` / `agent`，读时归一——因为 `id` 的哈希里含来源，改老行会让 id 和内容脱钩。
- **形式五样**：`text` / `voice` / `image` / `file` / `data`（波形、采样）。
- **快照**：只写出生那一刻（回答那条带；问话那条不带，两人共用同一份，不重复算）。
- **接自**：回答接自那句问话，同一轮里最硬的一条边。

## 三、事件层

### 3.1 一件事是什么

**名字 + 经过 + 证据 + 抓手。**

- 名字 ≤20 字。
- 经过写起因、经过、结果，带当时的语气和细节；**不写「这说明什么」**。
- 证据是一两句原话，**必须能在碎片里一字不差找到**；对不上就不算。
- 抓手 3~5 个，答案一个检验：**现在有人说起这个词，我会真的想起这件事吗？**

### 3.2 怎么切

- **单位是清醒段**：相邻两句间隔 ≥4 小时就断开。不按零点。
- **边界三样**：换了目的 / 换了话题主体 / 告一段落。同一件里的情绪起伏不算。
- **只追加，不覆盖**：同一段重切 = 补切一批新的，旧的留着。
- **允许重叠**：一条长线里夹进来一件小事（定时体检、一条提醒），小事可以单列，两件时间重叠。冷库记的是「事」，不是「时间片」。
- **喂模型前剔机器消息**：定时提醒、运行环境、领队提示、后台汇报——不剔会被切成「发了一个提醒」这种假事。

### 3.3 抓手必须专名优先

排序是：① 专名（文件名、作品名、人名、地名）——标题里的专名必须列；② 具体物件或动作（回滚、重排、定妆照）；③ **禁列**语气词（退啊、嗯）、内部结构词（上下半）、泛词（聊天、代码、一般般）。

> 今天真踩过：一件「花.md 重排错范围」的抓手被给成「退啊 / 上下半 / 七条原话」，三个都不能用。改成「花.md / 回滚 / 缺口花 / 整段重排」之后立刻能撞上。

### 3.4 温度与额度

事件是温库：不是每轮都进，被带出来才进；名字 + 经过一起进，**另开额度**，不占记忆那 800；一轮最多一条。

> **已落地（2026-11-12 晚）**：`event.inject.budget`，默认 **400 字**（≈400 token）。裁的时候只砍「经过」，**名字和出口半句永远留着**——名字砍了就不知道想起的是哪件事；出口半句没了，放下又没由头。每次注入都记一条 `event.inject`（多少字、有没有裁），以后能查它到底占了多少。

## 四、人类是怎么想起的（依据）

| 事实 | 对我们的意思 |
|---|---|
| 线索有强弱：言语词最弱，气味最强（[PMC 综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC9236260/)、[嗅觉意象](https://rd.springer.com/article/10.1007/s00426-022-01701-y)） | 我们只有文字，所以不能指望「精准命中一个词」就够 |
| 语义是扩散激活，近的亮远的暗（[扩散激活模型](https://www.taylorfrancis.com/chapters/mono/10.4324/9780203338001-8/spreading-activation-models-timothy-mcnamara)） | 匹配要允许「有点像」，不是精确子串 |
| 一条线索能同时碰到好几件，人挑最贴合的一件 | **一个词撞多件时排序取第一条，不丢弃**（这条是我们原来最错的地方） |
| 非自主记忆在走神、开车时最多，多由内部念头触发（[驾驶时研究](https://www.tandfonline.com/doi/full/10.1080/09658211.2023.2296826)） | 要有「没抓手也忽然想起」这条路 |
| 很久没想起的事更容易被勾起 | 时间衰减 |

## 五、联想：三条路

### 路一 · 抓手撞上（主力）

- **完整命中**：话里完整出现抓手 → 1 分
- **沾边**：连续 3 字重叠 → 0.5 分
- 一句话里同一个词出现两次不重复算。

### 路二 · 排序，不丢弃

一个词落在好几件事上时：

1. 分数（词分 ×0.65 + 重量 ×0.15 + 想头 ×0.2，再乘时间衰减和情绪乘数）
2. 分数接近时，重的事先
3. 再接近，想头高的先

**取第一条，其余排队。** 丢弃等于把人的常态判成错误。

### 路三 · 随机（没抓手）

- 每小时掷一次，8%；一次之后冷却 3 小时（一天 1~2 次）
- 只从「7 天以上没浮现过」的里抽，概率 ∝ 1/(1+天数)
- **不消耗、不结算**：不降想头、不降天花板、不算「被提到」
- **给得短**：只有一句，不讲完整经过——讲完就成了调阅档案
- 跟陌生人说话时不掷

### 想头怎么涨、天花板怎么沉（2026-11-12 定稿）

| 事 | 怎么算 |
|---|---|
| 想头涨 | `r0 = 0.06 × (0.5 + w)` 每小时；被提到后 30 分钟内 ×1.2 |
| 浮现之后 | 想头 **−0.4**（说过了，饱了） |
| 每次浮现 | 天花板 **×(0.6 + 0.35w)**，重的事削得慢、淡的事削得快 |
| 天花板下限 | **0.42**（沉到底也得能再被提起来） |
| 没人提 | 天花板每周 ×0.98 |
| **被提到** | **不抬天花板**——只让那 30 分钟涨得快一点 |

> 最后一条改过：原来写「被提到 +0.05 天花板」，方向是反的。一件事刚被聊过，短期该是「说过了，饱了」，想头往下走；抬天花板等于「越聊越黏」，会滚雪球到 1.0，那件事就永远压着台面。
> **水位在「被带出来」那一刻就该落，不该因为被提起而涨。**

### 放下 = 完成（2026-11-12 定）

**不另立「放下」状态。** 一件事放下了，就是它「过去了」，按同一档处理：

| 状态 | 涨速 |
|---|---|
| 没过去 | 正常（老惦记） |
| **过去了 / 放下了** | **×0.5**（想得少了，但**还能被提起、还能想起来**） |

原来写的「真的放下 → 谁提都不浮」是错的，太绝对：人做完一件事、放下了一件事，十年后一句话还是能把它带回来——只是不像没完的事那样老惦记。**「不能浮」不叫人话，「变慢」才叫。**

也不再把「放下」挂在 `feel.settle` 上：那个 settle 只降**一句话**的情绪强度，碰不到事。之前那句出口提示等于空口承诺，已改成只留「可以不提它」

### 三条硬门槛

- **情绪只当乘数，不当触发器**：此刻偏负面 + 事没过去 ×1.35；偏正面 + 已过去 ×1.15。情绪极性看 `primary_label`，不看 `slow` 正负。
- **事件结束 30 分钟内不算**（用事件结束时间，不是入库时间——夜里补切昨天的事不算「刚发生」）。
- **浮过一次就沉下去（闸是水位，不是时钟）**：想头 −0.4，多数直接掉到 0；想头低于 0.5 就不再被带出来，靠时间慢慢涨回 0.5 才再浮。重量大、没过去的事约 6~8 小时回来，轻的、过去了的事约 12~20 小时。
  > 2026-11-13 删掉原「30 分钟冷却」：同一件事不该有两道闸——水位已经在管这件事，再加一个时钟是重复。
  > **已落地**（2026-11-13 00:20）：`event_recall.js` 的第 111 行从 `state IN ('台面','待联想')` 改成 `state='待联想'`。重启后生效。
  > 随机浮现那条路**仍然收「台面」**，这是故意的：天花板下限 0.42 比 0.5 低，有些事永远摸不到「待联想」，随机那条路是它们唯一的出口。

## 八、已知边界

1. 当天的事当天浮不出来——要等这段结束才切。
2. 没有抓手的事永远浮不出来（这是设计的必然，不是 bug）。
3. 切分有几处会晃（换目的 vs 换话题），靠补切兜底。
4. `story` 会越写越长，暂时不限制，等实测 token 再收。
5. 复活来的老事会压过新事，先保留。
