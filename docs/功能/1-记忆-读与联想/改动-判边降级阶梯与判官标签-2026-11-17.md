# 改动 · 判边降级阶梯 + 判官标签 · 2026-11-17

## 主人要求

> 模型不行就先本地兜底，再不行规则。加一个标签显示是谁判的。

## 改了什么

### 1. 判边现在是一条降级阶梯

`completeBy()` 按这个顺序试，每一步都留痕：

| 走的谁 | 什么时候 | 判出来的边 |
|---|---|---|
| `main` | 宿主主模型可用 | 正常 |
| `local` | 主模型没通 / 落到规则兜底 / 报错 | 正常，但标签是 local |
| `rule` | 本地也没起来（Ollama 没开、超时） | **一条都不判**（返回空），标签记 rule |

规则层不编边——本地模型挂了的时候，宁可这天先空着，也不能拿"什么都判没关系"当成判过了。

### 2. 每条判断、每条边都带 `judge` 标签

- `judgePair` / `judgeBatch` 返回的每一条结果都带 `judge: 'main' | 'local' | 'rule'`；
- `writeJudgedEdges` 把它写进 `event_edges.judge`（原来硬编码 `'local'`），重复判时 UPDATE 也会刷新这个标签；
- `writeJudgedEdges` 返回里多一个 `judges: { main, local, rule }` 计数；
- `judgeDay` 返回 `judges`，worker 的 probe 行会打出 `judges={"main":…,"local":…,"rule":…}`。

所以现在随便查一条边就知道它是谁下的判断：

```sql
SELECT judge, COUNT(*) FROM event_edges GROUP BY judge;
```

## 3. 落到本地时让路（跟切事同一套规矩）

主人定：判边降到本地模型跑的时候，要像切事一样让路，不能卡人。

- `judgeDay` 加 `canContinue`，**每判一件之前问一次**；
- worker 传的是切事那个 `humanQuiet(d, aid)`：
  - 主人最近一分钟内说过话 → 让路；
  - 本地模型正被别的活占着（摘要 / 产帧 / 另一轮切事）→ 让路；
  - 窗口参数还是 `memory.cut.pause.minutes`，跟切事共用，不另起一套。
- 让路时返回 `stopped: true`：**不写 "这天判完了" 的标记**，判过的件已经记进 `events`，下一轮接着判剩下的。
- probe 行：`causal-judge-yield(<day>) calls=… pairs=…`，一眼能看出是让路不是失败。

## 4. 保护（沿用并加强）

- 主模型 `servedBy === 'fallback'` 不当作成功，直接降级去本地；
- 一整天 `calls === 0` 时不写 `event.causal.judged.<day>` 标记，下一轮重来。
