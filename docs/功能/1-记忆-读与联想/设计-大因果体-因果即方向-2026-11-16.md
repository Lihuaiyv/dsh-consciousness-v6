# 设计 · 大因果体（因果即方向）· 2026-11-16 定稿

> 一句话：**图上只有一种箭头——因果；每件身上带一个「我什么时候知道它」的轮次。时间是点的属性，不是边的方向。**
> 本版综合今晚所有试错，取代 v2（把方向做成实体「轴」）、v3（把时间当方向）。11-14 那份只留"边要有类型、要有证据、读要认意图"三条，结构以本文为准。

## 1 为什么不是时间轴

今晚证过两件事：

1. **拿墙钟当开关很傻。** 这次对话里实测过两回：按“间隔 ≤20 分钟”接，一天里不相干的事被串成一条假线；补记的旧事按墙钟排，方向全乱。时间戳只是记录，不是认知的单位。
2. **说出来的顺序 ≠ 因果的顺序。** 补记一句旧原因，它在叙事上晚，因果上早；因为担心还没发生的事而先动手，叙事上早，因果上晚。拿"谁先被说"当方向，会把这两类全排反。

所以：**方向只取因果**（因→果）。"什么时候知道"退化成点的属性（`hot_events` 的轮次），不参与定方向。

## 2 只有一个箭头、一个数

| 东西 | 存哪 | 说明 |
|---|---|---|
| 箭头 | `event_edges.from_id → to_id` | **因果方向**：因指向果。允许一对多（一个因引出几个果）、多对一（几个因合成一个果）、也允许成环（反馈回路），不强行破 |
| 数 | `event_edges.pull ∈ [−1,1]` | 亲密度：正=顺着（同一件事/下一步/导致/收尾），负=顶着（否定/冲突/推翻） |
| 知道时刻 | `hot_events` 的轮次（`session_id + seq`） | 我什么时候知道这件事；只做属性，不做方向 |
| 标签 | `event_edges.kind` | 只作解释（cause/revise/…），不参与拓扑 |

轴、肉、体都不存。它们是读的时候按门槛现算出来的：

- **轴** = 权重图里按门槛筛出来的那副骨架（最大生成树破环，门槛高只走最重那截）；门槛不同，显出的轴不同，这就是模糊。
- **体** = 密度扩出来的那片（从一点出发，收到密度掉下去为止），边界模糊。它身上带两样东西：
  - **开放环**：`open_loops.state='open'` 或这件 `status='没过去'`，最多挂 2 条（多了就不像"挂着的事"）；
  - **"现在到哪"**：顺着因果箭头能走到的最后一环。它**不是历史终点，是"这次提起之前我记到的位置"**——被提起本身就是新的后续（2026-11-16 主人：提到这件事，不就是要继续发生吗）。
  - **停点分两种，靠状态分、不靠天数**：真结束（`status='过去了'` / 有 resolve 指出去）vs 只是没再记到（`status='没过去'` 或挂着开放环）。
  - **"现在感"三样加起来算**（2026-11-16 主人）：状态（没过去 +）、时间（越近 +）、开放环（还挂着 +）。三样都低的标"搁着"，不进"现在"。**时间只在这里参与，只算远近，不当方向**——方向永远只由因果定。
  - **没有出边 ≠ 没有后续**：世界一直往下推（弱因果永远存在），但存不下——每件事往后都有无限多条弱因果。图上没边只表示"我们记到这儿"（同文档 §1 的开世界假设）。
- **肉** = 骨架外面的边，挂在骨上，限跳数。

> **实现踩坑（2026-11-17，主人当场纠正）**：一度把主轴做成 `kind='spine'` 的存边，等于又把"读出来的东西"做成了"存的东西"。
> **主轴不落表**：读的时候从种子出发，按门槛把节点收进来，按先后排成一条——那条才是主轴，不是建出来的。
> 真库里已写进 1852 条 spine 边，要清掉；`baseEdgesOf` 不再生成 spine。

### 2.2 三条稳定性验收（初始文档 §10，之前漏了两条）

| 指标 | 算法 | 线 |
|---|---|---|
| 骨架凝聚 | 骨架边上平均 \|pull\| | ≥0.6 |
| 负边占比 | 骨架里 \|pull\| 大的负边 / 骨架边 | ≥20%（**现在一条负边都没有，必然不达标，C 期先补 contradict**） |
| 压缩比 | 叶子边数 / 体级边数 | ≥5:1（先测再定） |
| 扰动稳定 | 随机加/删 10% 叶子边，看体边界和"现在到哪" | 变化 <15% |

### 2.1 负边：冲突不是边角料，是转折

`pull < 0` 的边是"否定"：A 否定了 B。它不是旁路，是**改道**——主干也会被它掰弯。三种结局（初始文档 §4.4）：

| 结局 | 意思 | 图里怎么走 |
|---|---|---|
| `sublated` | 两条矛盾统一成第三件 C（最常见） | A↔B 负边 + A→C、B→C 的 `sublate` 正边；从 C 继续 |
| `suspended` | 悬着没定（可能永远悬） | 负边保留，两边都带，标"未统一"，不偷偷判 |
| `invalidated` | 一条真的记错了，才作废 | 负边记 `winner_id`；**只在记错时用，不用于"后来的看法变了"** |

**因果不失效（2026-11-16 主人定）**：一条因果在当时成立，就是真的；后来看到更多，不是推翻它，是**当时的局限性**。所以旧边不封口、不作废；`valid_to` 只标"这条边记错了"或"重复了"，**不标"因果被推翻"**。
`revise` 因此按"加深/补充"读，不按"否定"读：新的事不是把旧的判错，是在旧的后面看到更多。读"为什么"时也不能只说"现在是 C"，要说"当时是 A 导致的，后来又看到还有这一层"。

冲突边也参与门槛：`|pull|` 大的负边和正边一样能进骨架。所以"这条线"读起来可能是"先做 A → 被 B 否定 → 改成 C"。


## 3 亲密度怎么算

四样合起来（初始权重，靠标定调）：

| 分量 | 含义 | 初值 |
|---|---|---|
| 因果强度 | 模型判出的关系种类：cause/revise/resolve 最重，continue 次之，same 折叠用 | 0.35 |
| 共有专名 | 共享"像专名"的抓手数（排掉 IP／路径／URL） | 0.25 |
| 字面重合 | 标题 3-gram + 引文同句 | 0.15 |
| 知道的先后 | 隔了几轮（只作弱加成，不当方向） | 0.25 |

两件只是碰巧挨着、别的都不沾 → 加起来自然低，不会冒充近。

## 4 读：两个问法，两种走法

| 问法 | 走法 |
|---|---|
| 「后来怎么样了」 | 顺着因果箭头走，取门槛高的那条（现在到哪 = 顺着走能走到的最后一环） |
| 「为什么会这样」 | 逆着箭头往回找因，**最多 3~5 个**，只回一跳不往下追。**不融合、不强行总结**——人回忆起原因，脑子里冒出来的是三五个并列的点，不是一句总结。挑完就停。 |
| 「定了没有」 | 看这件的所有出边：有 revise/resolve 指出去 = 收口了；没有 = 还开着（可能悬着好几件，标"未统一"，不硬选一件当结论） |
| 「还有什么挂着」 | 这件的开放环：`open_loops.state='open'` 或 `status='没过去'`，最多带 2 条 |

- 读的时候限跳数（最多 2 跳），防反馈环绕死。
- 只给一句线，不给节点列表；单开额度 `event.causal.budget`（200 字）。
- 不做传递闭包：A→B、B→C 不代表 A→C。

## 5 写：规则 + 模型，两个都不能省

- **规则边**（不调模型）：同一件事（turn 重叠 / 引文同句 / 标题近义）——这种只标"同一"，不标因果方向。
- **模型边**（本地 qwen3:14b）：因果、推翻、收尾、冲突。一次判 6 个候选；**证据必须能在 `cold_events.quotes`（逐字原话）里找到**，找不到不算。摘要冒充不了原话（今天踩过）。
- 判不出方向就不写方向：`pull` 照给，`direction` 标 `uncertain`，读的时候只当"有关"，不当因果。
- 度上限：因果每件 ≤6，桥 ≤2。边只追加，作废用 `valid_to` 封口。

## 5.5 往上长：不是四层，是门槛档位

初始文档 §4.3 写的是 level 0 事件 / 1 体 / 2 项目·阶段 / 3 人生·世界——**固定四层**。这是它没想到的一层：真实里没有层数刻度，只有"这次要问多粗"。

- 同一张图换个门槛就是一档：细到一件事，粗到"那阵子"，再粗到"那几年"。门槛一调，同一个区域可能是一个体，也可能分成两个。
- 新的一档能不能出来，取决于这一层的点攒够没有——量变到质变，不是预设层数。不会天天顿悟，因为新的一层要攒够量才冒头。
- **层的默认叫法**（2026-11-16 定）：`事件 → 体 → 篇 → 卷`。新出的是什么：体是"纠缠成一团"，篇是"有始有终的一段"，卷是"人生的一段"。这是借书的结构（段→篇→卷），叙事心理学也是这么分的（McAdams 的生命故事访谈第一步就是让受访者说"章节"）。
- **层名 ≠ 这个个体的名字**：层叫"篇"，具体那篇还得有它自己的名字（"那阵子在做大因果体"），否则只是"篇"等于没名。具体名字由人或模型写，规则算不出来。
- 默认只长到体：`篇 / 卷` 是留着的档位名，不是已经建出来的层。
- **两个方向都留口子**：往上 `event.causal.level.max`（默认 1）；往下 `event.causal.level.min`（默认 0）——往下是 `事件 → 碎片（逐字原话）→ 句子`，到原话为止，再往下是词，没必要。
- **再往上是什么（待验证的猜测）**：比卷更高的应该不是"更长的一段时间"，而是**模式**——"我总在舍不得收场"这种跨很多段重复出现的形状。它长出来的办法跟密度不一样，是**重复**（跨好几卷找同一形状），所以大概率不会自动冒，得等数据够多再比。名字也没想好，先不占。
- **口子**：`event.causal.level.pattern`（默认 off）。现在只有名字，没有实现——算法（跨段找重复形状）没写，等体/篇攒够量再碰。开之前先验收"能不能说清它和平铺的 N 件事有什么不同"，说不清就不开。
- **递归开关**：`event.causal.level.max`，默认 1（只到体）。往上每加一层要显式打开，一层一层来，防跑飞。
- **发现要记账**：每冒出一个新的密度中心，记一笔 `event.causal.newbody`（哪天、多大、中心是谁）。那是"发现"，不是每天刷一堆。

## 5.1 两路判：因果走反事实，continue 走规则（2026-11-16 定）

一张图上其实有两种东西，不能交给同一个判官：

| 路 | 判什么 | 用什么方法 | 为什么 |
|---|---|---|---|
| **因果路** | A 是不是 B 的因（cause/enable/prevent/revise/resolve/contradict） | **粗判 + 反事实重排**：先让模型粗判关系，再问一句「如果 A 没发生，B 还会这样吗」；还会 → 不是因，删掉 | 这是 ECI（事件因果识别）领域的成熟做法。见 [CRECE](https://ieeexplore.ieee.org/abstract/document/11383282)（粗到细 + 反事实重排，专治"文本强相关被当成因果"）、[ECI 综述](https://dlnext.acm.org/doi/10.1145/3756009)、[NAACL 2024 事件因果是故事理解的关键](https://aclanthology.org/2024.naacl-long.191/) |
| **叙事路** | 这是不是同一话题的下一步（continue） | **规则**：同会话 + 共享专名抓手 + 时间接近；不交给因果判官 | 它只说明"接着做"，不是因果。ECI 只认因果，塞进去会把它判成 none |

- 反事实为什么好用：同段对话里相邻的两句，删掉谁都不影响另一句——一反事实就露馅。今天 16 条里那 4~5 条"把挨着当接着"的，正好是反事实一问就掉的。
- 两路写进同一张边表：因果路给 `kind` + `pull`（负的就是对抗）；叙事路只给 `continue`，`direction` 标 `uncertain`。
- 换不换模型放到最后：先把方法做对（反事实），同样的 14B 再测一轮；还不行，才谈换更大的模型或走宿主。

> **判定全集是九种，不是六种**（2026-11-18 补清楚）：因果路六种（cause / enable / prevent / revise / resolve / contradict）；
> 叙事路一种（continue，接着做，不算因果）；折叠一种（same，同一件事的两个版本，只折不合）；排除一种（none，没关系）。
> 本节说「因果路」时只指那六种——same 和 continue 不在里面，别把它们当因果读。
> 另外：动机（motivate）不属于事件之间的边，它连的是「行为」和「开放环」，见想法集文档。

## 7 与文献的对照

- [Event Horizon Model](https://pmc.ncbi.nlm.nih.gov/articles/PMC5734104/)：人在事件边界换模型，跨边界旧信息不好取 → 我们的"体边界"就是密度掉下去的地方。
- [LLM 事件抽取综述](https://arxiv.org/abs/2512.19537)：LLM 判因果在长上下文里最脆弱，必须 schema + 证据 → 我们的引文校验。
- [TAEG-ANC](https://ieeexplore.ieee.org/document/11729849)：用显式时间事件图防叙事漂移 → 我们不用时间定方向，但用它记"什么时候知道"。
- [Graphiti](https://arxiv.org/abs/2501.13956)：时序 + 社区检索 → 我们的"体"。

## 8 风险

1. **反馈环**：因果可以成环，读必须限跳，不能做闭包。
2. **事后归因**：先后当因果。靠"证据必须原话" + none 率兜。
3. **方向反**：实测有一条「因为担心迁移→去抽适配层」被判成「抽适配层→担心迁移」。人工抽必须专看这类。
4. **权重凭感觉**：B 期先标定再往下。
5. **毛球化**：度上限。
6. **图的错比没有图更糟**：所有开关默认 off，先影子。
