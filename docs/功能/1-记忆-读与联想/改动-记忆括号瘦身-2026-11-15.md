# 改动 · 记忆括号瘦身 · 2026-11-15

## 动了哪
1. `src/modules/passport.js`
   - `statementNote` 文案：`（X 记下的判断，不是说现在）` → `（X 的旧判断）`。
2. `index.js`（注入行 `memLineOf`，约 L941）
   - 先算 `memoryTag`（自带来源/年龄/不一定对）；
   - `passportLine` 的 `statement` 只在 **tag 为空** 时传 `'on'`，避免两个括号叠。

## 为什么
D47：一条记忆常挂 3~4 个括号（来源 + 年龄 + 「记下的判断，不是说现在」+「不一定对」），读起来像审批单。
「不一定对」已由 tag 表达；「不是说现在」对旧判断是默认语义，不必再重复。

## 怎么验
- 有 tag 的行：`（<来源>，<年龄>，不一定对）` + 正文，不再追加「旧判断」括号；
- 无 tag 的行（裸文本）仍会带 `（X 的旧判断）`，不丢时态信息；
- 门禁：**573 / 573，exit=0**。

## 没做的
- 没把两处括号合成一个括号（跨模块，改动面大）；只做到「不叠 + 变短」。
- 网页主检索路径（index.js L606-611 的 `withPassport`）没动——它走 `packInjection` 装饰，tag 在装饰器里生成，拿不到；需要的话下一版统一。

## 怎么退
- passport.js 一行文案还原；
- index.js `memLineOf` 还原成单行拼接（`'- ' + memoryTag(...) + oneLine(...) + passportLine(...)`）。
