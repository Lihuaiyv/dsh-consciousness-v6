## 加了什么

`src/modules/candidate_pool.js`（纯读取，不写库）：

- `collectCandidates(db, aid, { query, memories, limit })` → 统一形状
  `{ source, id, text, detail, score, confidence, meta }`
  四路来源：
  - `event`：用这句话撞事件抓手（内部走 `recallEvents`，只收「待联想」）；
  - `memory`：由调用方传入已召回的记忆（不在池里重跑检索）；
  - `pulse`：`surface_queue` 里 pending 的候选；
  - `loop`：`open_loops` 里 open 的欠事。
- `rankCandidates(list, { limit })`：按 score 排、按「事件 id / 正文前 80 字」去重，**不丢弃只排队**。
- `pickOne(list)`：一轮只留一条「自己想起」。

## 设计约束（写进代码注释）

- 池只出候选，不直接进提示词；排序/预算归将来的 planner。
- 每个来源单独 try/catch：没表、没队列都不该让整池挂掉。
- 不新加评分：事件用 recallEvents 的原分，记忆用调用方给的分，pulse/loop 给固定低分（0.45/0.5）先占位。
