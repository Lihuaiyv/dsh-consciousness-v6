# 改动 · 通道收口（P1.5）· 2026-11-13

> 目标：把「自己想起」从五条各自直塞的通道，先收成一个口。
> 这一版不动结构（planner 还没建），只做两件事：**停直塞**（pulse / 情绪面不再直接往提示词里塞）、**上锁**（水位闸钉成测试）。

## 动了什么

| 文件 | 改动 |
|---|---|
| `index.js` | 新增开关 `surface.direct`（flags，默认 `off`）：关着时 pulse / 情绪面**一个字都不进提示词**，候选不消费（留在队列里等 planner）；开着才恢复旧行为 |
| `scripts/check-event-recall.mjs`（新） | 水位闸锁：临时库造「待联想 / 台面」两条事件，验「只收待联想、台面撞了也不收、只有情绪 0 条」 |
| `test/run-tests.mjs` | 挂上这条锁（561 项里的新一项） |

## 语义

- **pulse 停直塞**：心跳照样排候选、照样写 `surface_queue`，但不再直接进提示词。这是「降候选」——等 P3 的 planner 统一排序。
- **情绪面降乘数**：情绪不再自己当一条「那件事还没过去」的通道；它还留在事件联想的乘数里（`moodMul`），这是设计本来就写好的位置。
- **不回退行为直到 planner 上线**：这意味着这段时间「忽然想起」只剩事件联想一条。这是 P1.5 的代价，写清楚，不假装没发生。

## 怎么验

- `node scripts/check-event-recall.mjs` → 4 项全 PASS：
  - 待联想能撞上；台面不收；台面单独撞也不收；只有情绪 0 条。
- 门禁：`node test/run-tests.mjs` → **561 / 561，exit=0**。

## 怎么退

- 把 `surface.direct` 设成 `on`（flags 一行），pulse / 情绪面立即恢复直塞，不用改代码。
- 水位闸锁若误报，删 `run-tests.mjs` 里那一块即可；不会影响运行时行为。
