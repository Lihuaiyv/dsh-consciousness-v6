## 1 为什么推倒重来

今晚试错三次，每一次都证明"给边贴身份"是错的：

1. **按会话相邻全连** → 一天里找杜邦线、树莓派、熵增、花.md 串成一条 40 件的假线。因为它把"挨着"当成了"同一件事"。
2. **按共享抓手连** → 两千件里只剩 262 条，体几乎全是单件。因为抓手本来就不重复。
3. **建"主轴 spine"每件只接一颗** → 人为的整齐。现实里一句话能带出三件事，三件事能收成一个结论，主轴自己就有一对多、多对一。

三次错在同一个地方：**想先把"这条边属于轴还是属于跳"定下来。** 这个身份不存在。

## 2 唯一的硬规则：先后

- 每条边只能从**先出现的**指向**后出现的**（按轮次序 `session_id + seq`，不是墙钟）。
- 不要再用墙钟当开关：今晚已经证明过“等十分钟才反应”是傻的（老虎那个例子）。先后是“谁在话里先出现、谁接谁后面”，秒数只用来在同一轮内兜底定序。
- 有了这条，图里永远没有环，读的时候永远知道哪头是“后来”。
- 这就是你从一开始要的东西：**事件的先后**。轴是它的影子，不是它的实体。

## 2.1 轴：不存，读时显形

轴不是要建的东西，是**在权重图里按门槛筛出来的那副骨架**：

- 用最大生成树把环破掉，从最早连到最新的那一串就是脊；骨头外面剩下的是肉。
- 门槛高 → 只走最重的那截，出来的是“这条线后来怎么了”；门槛低 → 带出周围。
- 同一个体在不同门槛下会显出不同的轴——这就是你说的模糊。
- 它不落表、不建边、不贴标签；每次查询按当时的门槛现算。


## 3 唯一的数值：亲密度

每条边只存一个数 `pull ∈ [−1, 1]`：

- 正 = 顺着走（同一件事、下一步、导致、收尾）；
- 负 = 顶着走（否定、冲突、推翻）；
- 绝对值 = 有多近。

四样合起来算（先给初始权重，靠标定调）：

| 分量 | 怎么算 | 初始权重 |
|---|---|---|
| 轮次距离 | 两件事在会话里隔几个 turn；隔得越远越低 | 0.35 |
| 共有专名 | 共享的"像专名"抓手数（排掉 IP/路径/URL 噪声） | 0.25 |
| 字面重合 | 标题 3-gram 覆盖 + 引文同句 | 0.15 |
| 模型判的关系 | cause/revise/resolve 最重，continue 次之，same 折叠用 | 0.25 |

不共享任何东西、只是挨着的两件，四样加起来权重自然低——**碰巧挨着不会冒充近**。

## 4 读：按门槛筛，不按身份走

- 门槛高（比如 |pull| ≥0.6）：只走最重的几条，出来的是"这条线后来怎么了"。
- 门槛低（≥0.25）：能带出周围，出来的是"这事跟哪几件有关"。
- 同一个体在不同门槛下会显出不同的"骨架"——这就是模糊。
- 走向永远顺着方向，不做传递闭包（A→B、B→C 不代表 A→C，文档 §8）。

## 5 写：规则 + 模型，都要证据

- **规则边**（不调模型）：同一件事（turn 重叠 / 引文同句 / 标题近义）、时间上紧挨。
- **模型边**（本地 qwen3:14b）：因果、推翻、收尾、冲突。一次判一批 6 个候选，**证据必须能在 `cold_events.quotes`（逐字原话）里找到**，找不到就不算。摘要冒充不了原话（今天踩过：第一版拿 story 验，摘要对摘要怎么写都能对上）。
- **度上限**：因果每件 ≤6、桥 ≤2。防毛球化。
- 只写 `confirmed` 和 `candidate`；作废用 `valid_to` 封口，不物理删。

## 6 分期（每期都能单独退）

| 期 | 做什么 | 验收 | 退路 |
|---|---|---|---|
| A 方向 | 现有边全部强制 from 早于 to；反向的换过来；旧实验边封口 | 反向边 0；门禁 584+ | 不写新边即可 |
| B 权重 | 亲密度公式落地；抽 50 对让人排序，和机器排序比 | 一致率 ≥80%，否则调比例 | 开关回旧权重 |
| C 长边 | 规则边 + 模型边（增量，每晚 23:30 已有任务）；度上限 | 同一件事 precision ≥0.9（30 对）；因果 precision ≥0.75（50 对）；none 率 ≥50% | `event.causal.write=off` |
| D 读 | 门槛 + 有向走，拼一句线（先轴后肉的说法作废，改为"门槛不同给不同的线"） | 10 题「这条线现在到哪」≥8 对；注入 token 中位涨 <10% | `event.causal.inject=off` |
| E 层级 | 事件层 → 阶段层（父体权重 = 子体间跨边 |pull| 最大那条，不是 sum） | 父体人工像 ≥3.5/5；扰动 ±10% 变化 <15% | 只留事件层 |
| F 收边 | 夜里去重、查环降级、重算最晚节点、覆盖率 | 每晚报告 | 关定时任务 |

## 7 验收线

- 方向：所有边 from 早于 to，反向 0 条。
- 权重标定：50 对人工排序 vs 机器排序，一致 ≥80%。
- 误连：随机无关对判成有关系 ≤10%（现在实测 0%）。
- 因果：precision ≥0.75，覆盖 30%~60%。
- 读：10 题 ≥8；token 中位涨 <10%。

## 8 风险

1. **事后归因**：先后当因果。靠"证据必须原话" + none 率兜。
2. **方向反**：实测有一条「因为担心迁移→去抽适配层」被判成「抽适配层→担心迁移」。人工抽必须专看这类。
3. **权重凭感觉**：所以 B 期必须先标定，再往下走。
4. **毛球化**：度上限。
5. **图的错比没有图更糟**：所有写库开关默认 off。
