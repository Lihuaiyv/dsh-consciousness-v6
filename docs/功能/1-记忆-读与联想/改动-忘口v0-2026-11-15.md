## 为什么先不动手

忘是写操作（`HIDE` + 轮次级联 + visibility 层）。误判一次，用户真说过的话就被藏起来，而且 `asof` / 汇流 / 深翻都会一起看不见。所以这一刀只做**识别 + 记账**：

- 用户说「把刚才那句忘掉吧」这类**明确指令**时，记一条 `events.type='forget.intent'`（正文前 80 字）；
- **不调用 `hideMemory`、不改任何记忆状态**；
- 开关：`forget.intent.log`（默认 on；关掉就完全不记）。

## 判定（很窄）

| 必须 | 说明 |
|---|---|
| 动词 | 忘掉 / 忘了吧 / 别再提 / 不要再提 / 不要提了；或 删掉/抹掉/删除 **且** 明确在说记忆 |
| 对象 | 这件事 / 那件事 / 这段 / 那句 / 刚才 / 它 / 我说的话；删类要 记忆/回忆/原话/刚才那句 |
| 排除 | 「你忘了吗」「别忘了我」「我忘了」「记不记得」 |
| 长度 | > 60 字不算（多半在聊别的） |

「这段代码删掉」这类技术讨论不会命中——删类必须有记忆对象。
