# 改动：汇流 L2 加上时间感（2026-11-18）

- 日期：2026-11-18
- 起因：主人问「汇流不是分层了吗」——L2 整段重放只给日期，读到的是原话，不是「那天夜里」。
- 链条：记忆汇流（读），只动注入文本，不动查询与数据。

## 动了哪

`src/modules/confluence.js` 的 `sceneView` 里，L2（整段重放）分支：

- 旧标题：`【记忆汇流 · 整段重放 2026-11-05】`
- 新标题：`【记忆汇流 · 整段重放 2026-11-05 10:20】`
- 正文前加一行：`时间感：那是 10:20，上午。（离你指的那个时刻差 N 分钟）`
  - 钟点走 `localClock`、时段走 `phaseOf`（本地 +08，深夜/上午/中午/下午/晚上/夜里）
  - 差 10 分钟以内不写这一句，免得啰嗦

L1（`runConfluence`）**本来就有**时间感：「时间感：那是 HH:MM，夜里；距上一句话 N 分钟；这段是你先开口的」，每句原话也带钟点。所以这次只补 L2。

## 怎么验

```
node test/confluence.test.mjs   # 89/89（新增一条：整段重放带「时间感：那是 HH:MM」）
node test/run-tests.mjs         # 门禁 596/596
```

改动要重载才生效。

## 怎么退

把 L2 header 改回旧的一行标题即可；数据一行没动。
