## 3 数据结构（`event_edges` 一条边存什么）

- `pull ∈ [−1,1]`：亲密度，符号 = 方向（正顺着 / 负顶着）
- `direction`：因果方向；判不出就 `uncertain`
- `status`：`confirmed` / `candidate` / `weak` / `rejected`
- `judge`：**谁判的** —— `main`（宿主主模型）/ `local`（本地 Ollama）/ `rule`（规则）
- `kind`：只是解释标签（cause/continue/revise…），不参与遍历
- `reason`：模型写的「why」（凭什么这么判）
- `resolution`：冲突三态（sublated / suspended / invalidated）
- `valid_to`：只标「记错了 / 重复了」，**不标「因果被推翻」**

## 4 判边链路（2026-11-17 定）

```
主模型(main) → 没通/返回空 → 本地(local) → 起不来 → 规则(rule，一条都不判)
```

- **跑在插件进程内**，不是独立脚本：宿主模型只有插件进程里拿得到（独立脚本报 `chain: no adapter for chat`）。
- **按天判**：worker 每 30 分钟看一次，挑「切事 done 了但还没判」的那天；判完写 `flags.event.causal.judged.<day>`。
- **让路**：跟切事同一套 `humanQuiet`——主人一分钟内说过话、或本地模型被占着，就停；停了一分钟后重试。
- **判完不写库**：`event.causal.write` 现在是 **off**（影子）。要写库得手动打开。
- **每人一次最多 400 件**；判一件之前问一次「能不能跑」。

## 5 已经踩过的坑（都别再踩）

1. **主轴不能存**：建了 `kind='spine'` 的边 = 把读出来的东西做成存的。删过 1852 条，别再加回来。
2. **head 不是时间最新**：是「没有 revise/resolve 指出去」的那批里最晚的；多个就标未收口。
3. **主轴只走主干边**：底图（adjacent/continue）不参与主轴，只在主干不够时兜底，且要标 `weak`（「挨着」）。
4. **读出来一句线只能取种子前后几件**，整条主轴塞进去就是倒垃圾。
5. **独立脚本调不到宿主模型**（`no adapter for chat`），别在这上面浪费时间。
6. **宿主模型会返回空字符串**：不能当成功，要降级去本地，否则会记一堆「判过了但什么都没判」。
7. **一眼看死的坑**：`cands=0` 的记账 = 模型没吐出东西；这种记账留着会让真判全被跳过。
8. **待判为 0 不等于失败**：那天早判过就要写标记收工，不然每 5 分钟空转一次。
9. **`DSH_NODE_EXECUTABLE` 是宿主 exe，不是 node**（如果以后又要 spawn 脚本，先找 PATH 里的 node）。
10. **验收里的时间别用「几小时前」**，会跨午夜自己变红；用绝对时间点。

1. **先修切事颗粒**（别急着开判边写库）：挑 30 件人工看，标「这一件里是不是装了两件」；如果超过三成是混的，先改切事提示词/分块规则。
