## L0 目标层：为什么做、做成什么样

**为什么要统一**：不是功能不够，是账本没合并。同一段日子被写五遍、五条"自己想起"通道抢一个预算、两套 id 对不上、八套遗忘互不通知。每加一个功能就多一个抽屉，没人回头合并。

**做成什么样（可测，不凭感觉）**：

| # | 验收 | 怎么算 |
|---|---|---|
| 1 | 同一句话在库里最多 **2 份** | 原话 + 事；不再有每轮 episode |
| 2 | 「你上次那个事后来改主意没」答得上 | 10 题答对 ≥8 |
| 3 | 注入 token 中位数 **不涨** | 上限仍 800，事件 400、汇流 1600 单开 |
| 4 | 每轮「自己想起」**≤1 条**，一天 4~5 次 | 从注入日志数 |
| 5 | 一周库增量 **降 ≥50%** | 观测白名单 + 停重复写 |
| 6 | 不删老数据、照片不删、门禁不红 | scene_archive/state_scene 只读保留 |
| 7 | 每个开关能回旧路 | 任何一步出问题，切回去就恢复 |

**不做什么**：不推倒重来，不迁老数据，不合并库文件，不新加"更像人"的评分。

## L1 架构层：整体形状

```
你说了什么
  │
  ├─ 原料层   fragments（只追加：谁、何时、说了什么、当时什么样、接自谁）
  │
  └─ 夜里切事 → 解释层   cold_events（第一刀，只追加）→ hot_events（在用的版本，可合并/拆分/沉底）
                              │
                              └─ 事实库（稳定层）  一直成立的东西：身份/偏好/边界/结论/自我
                                                    memory_items(fact/reflection/self) + fact_archive(历史版本)
                                                    + provenance(原话证据) + timeline(有效期) + claims(还算不算数)
                    │
                    ├─ 叙事层   episodes / diaries：只投影，不拥有事实（写"怎么讲"，不写"记什么"）
                    │
读书时     读口 planner：候选池 → 统一排序 → 统一预算 → 每轮最多一条"自己想起"
           模式一 检索：被问起时找到（内部 S1/S2/S3/锚点/实体/向量/asof/深翻，一个接口后）
           模式二 联想：没被问时忽然想起（事件/自发/情绪/引语都是候选来源，不是通道）
           模式三 汇流：站回某一刻重看（手动、低频、只读，不写回）
```

**三条根**：
- 根一 **检索**——"这句话问的是哪段过去"。
- 根二 **联想**——"没人问，但它自己冒出来了"。
- 模式 **汇流**——"现在让我站回那一刻"。

**一条铁律**：**来源可以多，通道只能一个。** 事件、自发、情绪、引语都是候选来源；插进提示词的只会是 planner。

## L2 契约层：每层一个家、一个口

### 2.1 表契约（谁权威、谁投影、谁观测、谁照片）

| 角色 | 表 | 规矩 |
|---|---|---|
| 原料 | fragments | 只追加，不删不改；快照只写出生那一刻 |
| 解释 | cold_events / hot_events | 冷库只追加；热库可版本化；沉底只动热库 |
| 稳定 | memory_items（fact/reflection/self） | **停写每轮 episode**；一条结论带证据、带有效期 |
| 证据 | memory_provenance | 每条结论尽量挂原话；推断了就标 inferred |
| 历史 | fact_archive | 改口前的旧说法；只读，不参与日常注入 |
| 时间 | memory_timeline | 只定位时间，正文永远去 fact_archive/fragments 取 |
| 叙事 | episodes / diaries | 从"事"投影；不重切原话、不产生新事实 |
| 观测 | events / surfaced_items / retrieval_log | 白名单 + 限龄；不当内容表 |
| 照片 | scene_archive / state_scene | 永不删，只读 |
| 回看账 | confluence_log / revisit | 汇流每跑一次落一行；"这次想起"单独记 |

### 2.2 写口契约

- 原话只经 `archive.appendTurn` 一处写 fragments。
- 结论只经 `memory.addMemory` 一处写 memory_items。
- 汇流留底只经 `confluence.recordScene`；它成功时补一行 `confluence_log(mode=auto)`。
- 其余模块只能调用，不许自己拼 INSERT。

### 2.3 读口契约

- 只有 planner 能往提示词里塞记忆相关内容；检索/联想/开环/引语/汇流都只出**候选**。
- 每轮"自己想起"最多一条；来源必须唯一。
- 三道预算并成一张表：日常 800 / 事件 400 / 汇流 1600（手动才开）。

### 2.4 遗忘契约

- `visibility`（HIDE）唯一说"能不能说"。
- `fade` 只说"说多清"。
- `temps / tiers / heat / claim / conflict` 只影响排序或标状态，不删内容。
- 取原话的路径（asof / 汇流 / 深翻）必须复用同一份 `forgottenTurnIds`，不许另写一条 SQL。

### 2.5 id 契约

- `turn_id` 是血缘：fragments.turn_id → memory_items.source_turn_id → provenance → scene_archive/state_scene。
- chat_turns 补 `turn_id`（新写入带上，老行 null = 明确"无链"不猜）。
- `cht_*` 保留给人格判定（persona_judge 685 条全挂它），**只加列，不改 id**。

## L5 验收层：怎么知道成了

**每步出口**（不过不出）：全量门禁绿 + 该步验收项全过 + 开关能回旧路。

**每日看**：memory_items 日增条数、注入 token 中位、浮现次数、汇流账行数。
**每周看**：库增量、重复文本组数（现 137 组）、extract_queue pending、死表是否归零。

**失败判据（触发回滚）**：token 中位涨 >10%；一天浮现 >8 次或 <1 次；答旧事正确率跌破 8/10；任何一条 HIDE 能通过 asof/汇流 翻出来。
