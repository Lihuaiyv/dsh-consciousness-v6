# 改动：事实库旧路径停用（2026-11-22）

> 主人原话：「那都停了，然后开头都标『事实库旧路径，已经停了』；每轮原话写进 memory_items 那条删了。」

## 为什么

排查完「一轮对话到底烧几次模型」后，主人对事实库这条旧路下了判断：**抽取、判断、门禁全停，
每轮原话不再进 memory_items。** 理由在 `记忆库-备份-2026-11-16-1930.xmind` 里早就写着——
原话进事实库那格（每轮原话 episode）标了「待删，未来将替换为事件 cold_events / hot_events」；
而且 11-12 之后 judge/gate 一条记录都没有，抽出来的条目质量也差（「用户以前是过判判断层之前是判断层吗」）。

碎片照长、切事照跑；停的是**往事实库写**的那条路。

## 动了哪

| 文件 | 改动 |
|---|---|
| `src/kernel.js` | 新增参数 `memory.legacy.fact`，默认 **off**（总闸） |
| `src/features.js` `ingest()` | 开头读总闸，off 时直接返回 `{skipped:'legacy-fact-off'}`：不抽取、不写 memory_items |
| `index.js` `commitTurn` | **删掉**每轮把用户原话写一条 episode 的 `addMemory`（网页 / QQ 链） |
| `src/features.js` `chatReply` | **删掉**同一处 episode 写入 |
| `src/modules/memory_switch.js` | 删 `episodeWriteEnabled`（两个写点都没了，没人再读 `memory.episode.write`） |
| `src/modules/gate.js` `judgeMode()` | 总闸 off 时直接返回 `'off'`：judge / gate 连影子事件都不写 |
| `src/kernel.js` | `memory.judge.enable` 默认本来就是 off |
| 真库实例参数 | `memory.judge.enable` 改成 `"off"`（双保险；改前备份见下） |
| `test/run-tests.mjs` | 旧路径的考卷（自动抽取 / 关系抽取 ×3 / 否认 ×2 / 时间状语 ×3）在跑之前显式把 `memory.legacy.fact` 设成 on——它们测的是「打开时对不对」；另加一条新考卷「事实库旧路径：默认停，ingest 不写条」 |

每处改动的开头都留了注释，第一句是「事实库旧路径，已经停了」。

## 副作用（必须知道）

- **memory_items 不再进新条目**：抽取、事实、每轮 episode 全停；召回仍读存量 8255 条。
- **judge / gate 不再有任何事件**：`memory.judge.pick` / `.gate` 从此不新增。
- **不影响的**：碎片 `fragments` 照写、切事照跑、`events` 观测流水照记、情绪/关系/三观不受影响。
- `memory.episode.write` / `memory.workdigest.write` 这两个旧 flag 还在库里，但已无人读 episode 那个。
