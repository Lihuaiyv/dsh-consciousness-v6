# P2 收身规则（memory_items 只留什么）· 2026-11-13

> 这一版**只定规则 + 出影子数字，不动数据、不翻默认**。
> 依据：`scripts/audit-memory-slim.mjs` 对真库的只读采样（2026-11-13 11:40）。

## 一、规则

| 类型 | 来源 | 留/停 | 为什么 |
|---|---|---|---|
| episode | **manual**（每轮原话，commitTurn / chatReply 写） | **停写** | 和 fragments 同轮同文，1,009 条一字不差；它就是「同一句话写两遍」的第二份 |
| episode | self（自我经历） | 留 | 这是「我自己做过 / 想过什么」，不是原话复制 |
| episode | life（生活流）/ work-digest（工作摘要） | 留 | 生活与工作的沉淀，不是每轮流水 |
| episode | extract（抽取出来的句子） | 留（先观察） | 抽取结论，暂时保留；以后如果和 reflection 合流再收 |
| fact | 全部 | 留 | 事实/结论，带证据与有效期 |
| reflection | 全部 | 留 | 结论/自省 |
| appraisal | 全部 | 留 | 对事/对人的评价，关系与会话都用得上 |

**一句话**：停的是「每轮 user 原话再抄一遍」的那一类，不是停 episode 这个类型。

## 二、影子数字（只读）

| 项 | 数 |
|---|---|
| 停写口径历史总量 | **1,323 条**（episode + manual） |

占全部 5,405 条的 24.5%；按最近 7 天速度，库增量能降一半左右（不是全部——fact/reflection/抽取还在写）。

## 三、代价与护栏

1. **情绪接缝变稀**：566 条带 feel 的原话不再新增。结论/反思仍可挂 feel（`addMemory` 的 fact/reflection 不限），别把整条缝弄丢。
2. **检索少一层**：检索靠 memory_items 的词法/实体；停的是原话，fragments 仍在，但**检索不直接读 fragments**（读口走 memory_items/events）。所以停写前必须确认事件能盖住当天。
3. **老数据不动**：1,323 条历史一行不删；要收身也只停新写。
4. **不翻默认**：翻的条件见 `docs/改动/改动-停episode开关-2026-11-13.md` 第三节（切事跑过一晚 / 每天 ≥5 件 / 影子对比 10 题 ≥8）。
