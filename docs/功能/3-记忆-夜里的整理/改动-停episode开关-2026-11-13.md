## 翻默认的条件（写死，不凭感觉）

1. 重启后切事 worker 真跑过至少一晚，`hot_events` 有当天/前一天的新事件；
2. 事件覆盖 ≥ 每天 5 件（L0 硬信号）；
3. 影子对比：关掉 episode 一周内，问「上次那事」10 题仍能答对 ≥8（先抽 10 天人工看）。

三条有一条不满足，就继续默认 on。

## 怎么翻 / 怎么退

```sql
-- 关（翻默认）
INSERT INTO flags(key,value) VALUES('memory.episode.write','off')
  ON CONFLICT(key) DO UPDATE SET value='off';
-- 开（回滚）
UPDATE flags SET value='on' WHERE key='memory.episode.write';
```

不用改代码、不用重启（`episodeWriteEnabled` 每次写入时现读）。
