# 工具 · 事件质量体检（只读）· 2026-11-13

> 回填 / 切事之后跑：`node scripts/audit-event-hitrate.mjs`
> 量两件事：**自撞命中率**（自己的抓手能不能把自己带出来）和**乱撞率**（普通一句话会不会莫名带出事）。

## 怎么算

- **自撞命中率**：每件 active 事件，拿它自己的前 3 个抓手逐个去撞，任一中就算命中。
  「台面」事件本来就不该被带出来，所以单列；PASS 判据只看「待联想」≥80%。
- **乱撞率**：取最近 3 天 40 句真实人话（6~60 字），逐句跑联想，看有多少句会带出事件；应 ≤30%。

## 用途

- P1b 回填后复跑：**待联想自撞 ≥80%** 才算回填验收通过；低于就停下来改抓手规则，不要拿件数糊弄。
- 乱撞率升高（比如 >30%）说明抓手太泛（「聊天」「代码」这类），要重切或换词。
