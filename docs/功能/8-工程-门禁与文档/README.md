- 提示词快照是人工导出的，没有定时
- 本地队列并发默认 1；`memory.cut.local.concurrency` 可调 2~4，但本机 14B 开 2 并发会互相拖慢
- 宿主读口的断链提示只进提示词（让我自己说），没有自动推消息给主人；要不要接主动开口另立题
