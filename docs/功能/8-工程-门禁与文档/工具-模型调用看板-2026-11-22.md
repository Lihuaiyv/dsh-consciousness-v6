# 工具 · 模型调用看板（2026-11-22）

> 主人原话：「我想做一下谁在调用的可视化可以吗（哪个任务在用哪个模型的），然后新建的进程也能显示出来。」
>
> 做出来的：插件自己开一个只读页面，每秒刷新，回答四个问题——
> 现在哪个槽在给哪个任务用哪个模型、谁在排队、显卡上挂着哪几个模型、本机什么时候**新起**/退出了模型进程。

## 一、怎么打开

```
http://127.0.0.1:<DSH 的 Web 口>/dsh-consciousness/board
```

端口别手写：DSH 重启会变。插件每次处理 API 请求都会把它写进
`runtime/consciousness/gateway-api.json`，脚本（`scripts/lib/exp-call.mjs`）读这个文件自己找。

数据口（前端每秒拉一次，也可自己 curl）：

```
GET /dsh-consciousness/live
```

## 二、页面上有哪几块

| 区块 | 显示什么 | 数据从哪来 |
|---|---|---|
| 14B 槽 | 正在跑的任务名、优先级、已跑/限时、进度条；后面排队的是谁、等了多久 | `local_gateway.quickStatus()` |
| 向量槽 | 同上（语义模型是独立槽，不会等 14B） | 同上 |
| 常驻模型 | 显卡上挂着哪几个模型、显存多少、ctx、什么时候会被卸 | Ollama `/api/ps` |
| 模型进程 | `llama-server` / `ollama-noconsole` 的名字、PID、内存、启动时间；**新起的标「新」** | `Get-Process`（2 秒缓存） |
| 最近调用 | 时间、槽、谁、哪个模型、等待、耗时、ok/失败原因 | 通道的 recent（最近 40 条取 12） |
| 进程事件 | 「起来 / 退出」+ 名字 + PID + 时间 | 相邻两次采样的差集 |

「谁在用哪个模型」怎么算的：任务进通道时就带着槽（`embed` 用语义，其余全在 14B 槽），
槽决定模型；实验通道换模型时，页面顶上会显示「正在换模型：xxx」，那一行的模型也跟着变。

## 三、动了哪

| 文件 | 改动 |
|---|---|
| `src/modules/proc_watch.js` | **新增**。`Get-Process` 取 ollama / llama-server 的 pid、启动时间、内存；2 秒缓存；相邻采样做差集出「起来/退出」事件；第一次采样不把已有进程标成「新」 |
| `src/board.html` | **新增**。看板页面本体（单文件、无依赖、深色）；每秒拉 `/live` |
| `src/modules/local_gateway.js` | `gatewayStatus()` 加 `models`（含显存/ctx/失效时间）与每个任务的 `model`；换模型时记 `swapModel`；recent 记 `slot` |
| `index.js` | 新增两个只读路由：`/dsh-consciousness/live`、`/dsh-consciousness/board`；一起注销 |
| `scripts/check-local-gateway.mjs` | `--live` 增加 4 项：看板能开、两个槽在、模型+进程两段在、看板看到的模型进程 ≤ 2 |

## 四、怎么验（贴数字）

- 看板页面：`GET /board` → **200**，11346 字节，标题「模型调用看板 · 意识体」；页面 JS 通过 `node --check`。
- 数据口：`GET /live` → `slots.chat.limit=1`、`slots.embed.limit=1`，`models = qwen2.5:14b-instruct / qwen3-embedding:0.6b`，
  `procs = llama-server:6224 llama-server:29176 ollama-noconsole:25160`。
- **新进程能抓出来**：跑一次换模型实验（`model=qwen3:14b`），看板每 1.5 秒采样，抓到
  `start:llama-server:33888 / stop:llama-server:23684`，跑完又抓到 `start:llama-server:6224 / stop:llama-server:33888`
  —— 卸 14B、载实验模型、卸实验模型、热回 14B，四步全在事件里；全程同时最多 2 个 llama-server。
- 体检 `--live`：**25/25 通过**；门禁 602/602。

## 五、留意

- 进程采样只在有人开看板时发生（2 秒缓存），关掉页面就停，不占用日常开销。
- 端口变了就刷新页面；`gateway-api.json` 里的端口是「最近一次 API 请求」的，重启后第一次调用前可能还是旧的。
- 看板只读：不写库、不改队列、不触发模型调用。它看到的是通道记的账，不是猜的。
