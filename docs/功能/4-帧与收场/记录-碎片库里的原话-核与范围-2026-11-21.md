### 2.2 切帧已经有一套十条规则（我第一版完全没提）

[思路-怎么切帧](思路-怎么切帧-2026-11-20.md) §6.3：

```
硬切（七条，不看阈值）：line 变 / step 变 / 格拆出子格 / 格 failed 回退 / 开新分支 / 格 done / 事从 open 变关闭（这条现在还是死的）
软切（看阈值）：summary 向量不像 / jolt 三轴差超阈值
时间切：距上一轮超过 N 小时
其余：不切，并进当前帧
```

**这条必须摆在明面上，因为它和「认核」不是一条路。** 十条里七条硬切，看的是**连续树那一层变了没**（line、格、事的状态），不是「这段话的核变了没」。也就是说：现有这套切法绕开了认核——用结构变化代替了语义判断。

所以「核 + 范围」不是来替换它的，是来补它补不上的那一段：**闲聊没有格、没有 line，`step` 判不了**。那一段现在只能靠 `jolt` 软切，而软切的阈值到现在还是空的（§八第 1 条：「现在没有任何依据，只能先拍一个」）。

## 四、把原话和文档摆在一起，看到的两层结构

### 4.1 四条判据是同一个关系的四个面

他自己一句话说完：

> 「**其他的所有。周围所有信息都是为了这个东西，一个词，一个句子，一个一段逻辑而服务的。**」
>
> 「你说的话就是还有一层……**像这种话是不是都为你那些中心的句子来服务呢？所以我们说话好像真的就是。只有几个重点，但是我们为了这几个重点。造很多的话来解释。**」

| 判据 | 在测什么 |
|---|---|
| 抽走塌不塌 | 服务关系断没断（从核这头看） |
| 问答一致性 | 这句话在为谁服务（从卫星这头看） |
| 回指 | 哪一块被反复指回去（服务方向的外显，不全） |
| **加粗** | **我已经在标的那个被服务者**（输出里现成的痕迹） |

四条不是四把尺，是「服务」这一个关系的四个观测面。这也对上他一直要的「统一」：

> 「那这三层那你不又分开了吗？**我们是要找统一。**」

### 4.2 粒度问题：最新那版是用「核」回答的，不是用「写读分离」

先把自己上一版的错记下来：我写过「认核管归属、写读分离管边界」。那是往回找——11-20 那篇的思路稿里有写读分离，但它**没进最新定义**。

最新那版（11-21 凌晨定的）把切点判据直接换成了核：

> 那为什么说它把「最小」变可判了？因为**一个核就是那个「最小」**。**出现第二个核，就该切**——再往下切就只剩半个核，没有核了。
>
> 原来那句「再切一刀就没有意义」，现在能说成「**再切就没有核了**」。前一句靠感觉，后一句能验。

所以在新版里，「一段多长」不是独立问题，它是「有几个核」的推论。11-20 那十条（`line` 变 / `step` 变 / 格 done / 事关闭 …）是按**结构**切的，判据换了之后，它的位置从「切帧规则」降成「结构侧的兜底信号」——结构变了几乎一定换核，但换核不一定结构变（闲聊）。

这也让我看清自己这两天为什么会越调越别扭：**我拿 11-20 的结构切法去顶 11-21 的核判据**，等于用旧结论压新结论。这正是 11-21 那天记下的毛病之一（「只抓一环就说前面那环不对」）的反向版本。

## 五、修正后的推断（标成推断）

**推断一（第三次修正）：粒度不是独立问题，它是「有几个核」的推论。** 最新那版就是这么定的：「出现第二个核，就该切」。所以先别问「一段多长」，先问「这一段里有几个核」；切点自然就是两个核之间的那道缝。我先前写的「写读分离」来自 11-20 的思路稿，它没进最新定义，最多算一个以后可能用得上的约束。

**推断一之附：问答一致性是认核那一步的入口，它同时给出归属。** 每句问一遍「这句话在回答关于什么的问题」，答出同一个东西的句子归一片范围，那个东西就是核。这一条没被最新版否定，而且是「抽走塌不塌」唯一能落地的地方——因为不先有候选，没东西可抽。

**推断二（保留）：问答一致性就是划范围的那把刀。** 每句问一遍「这句话在回答关于什么的问题」，答出同一个东西的句子归一片范围，那个东西就是核。这一条解决的是 4.2 里的「归属」，不是「长度」。

**推断三（保留）：加粗这条用来做自检，不当输入。** 认出来的核和那条回话的加粗比一遍；不重合就查是谁错了。不花钱，因为加粗本来就在。

**推断四（新）：100 轮那条不是范围太大，是已经是另一个尺度。** 一个核被用 100 多轮，那时候管它的不是「帧」，是「域」——域里有多个帧，各帧自己的小核都服务于同一个大核。

## 七、这份稿为什么不是「夯实」

`docs/形式/形式-夯实-2026-11-15.md` 说了：定义类、有骨头的问题该用夯实——**主人一句、我一步，一步一句钉**，而且必须写清「这一步推翻了什么」。

这份稿是我一个人写的，已经不是夯实了。它现在的用处只有一个：**把散在碎片库里的原话和他的怀疑摆到同一页上，供下一步一句一句钉子用。**真要定「核到底是什么」，还得一句一句来，我这边不许自己成篇。

夯实那份形式里还有一条，正好是今天该认的：

> **最容易犯的不是写错，是为了顺着主人硬接一句让它显得成立。这比磨文档更坏。**
