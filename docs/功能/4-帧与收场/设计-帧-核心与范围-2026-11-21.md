# 设计 · 帧：一个核心 + 它的范围 · 2026-11-21

> 一句话：**帧 = 一个核心 + 它的一片范围。** 核是那一刻要说的东西，范围是周围为它服务的部分。

---

## 一、定义

> **一帧 = 一个核心 + 它的一片范围。**

它跟 v0.2 那句「最小的状态切片」**说的不是同一件事，是两件事**：

- **v0.2 管「里面装什么」**：前景、未清算、劲、锚
- **这一条管「从哪到哪」**：一个核，加上围着它的那一片

两个不冲突，合起来才是一个完整的帧：**框（范围）和内容（状态）**。

那为什么说它把「最小」变可判了？因为**一个核就是那个「最小」**。出现第二个核，就该切——再往下切就只剩半个核，没有核了。

原来那句「再切一刀就没有意义」，现在能说成「**再切就没有核了**」。前一句靠感觉，后一句能验。

> 更正：上一版我写「是一回事」，说得太满；后来又写成「状态在话里的形状」，那是硬造的词，两个都改了。

## 二、核怎么认

### 2.1 核没有固定形式

我先判成「一个词」，错；又判成「一个分句」，还错。

**核可以是词、短语、半句、整句、一段逻辑。** 形式是自由的，不能拿形式去认它。

两个反例：

- **名词当核**：「分割和覆盖在数学上是两个不同的概念」——这一段围着「分割」「覆盖」两个词转。抽走它们，剩下的「在数学上不同」「所以第一版按哪个做」全散。核就是这两个名词。
- **分句当核**：「我认为这不成立，因为前提就错了」——核是「我认为这不成立」这半句。抽走它，剩下「因为前提就错了」没头没尾。

我上一版把核写成「不成立」三个字，那是错的：它没有主语，说不清谁不成立。**动作要有个主语才成其为动作。**

### 2.2 唯一能用的判据：抽走它，剩下塌不塌

> **把候选抽走，剩下的还成不成立。**

这个判据的好处是**不问你是什么形状**——它只问抽掉之后塌不塌，所以名词、分句、整段都能用同一把尺。

- 抽走「分割」→ 那一段剩下的话全散 ✔ 它是核
- 抽走「不成立」→ 剩下「我认为，因为前提就错了」，散 ✔ 但这说明核是更大的那半句
- 抽走一句铺垫 → 剩下的照样立着 ✘ 它不是核

**它是个必要条件吗？不是——它只是充分条件。** 方向只有一边：抽走塌 → 是核。反过来「是核 → 抽走一定塌」不成立：同一个核别处还说过一遍，抽掉这一处，别处还在，剩下照样立着。

**但充分就够用，不用去凑充要。** 那种抽掉不塌的核，是因为别处本来就在重复说它，抽掉一处不影响理解——**不判它是核也不亏。** 硬要凑成「当且仅当」，反而得再去处理「别处重复」这种情况，把简单的事搞复杂。

**还要配一个入口**（见 2.3）：光靠抽，得先有候选才能抽；先用「这句话在回答什么问题」找出焦点，再从焦点往周边看，候选就有了。

### 2.3 判焦点的标准测试：问答一致性

判焦点的标准测试叫「**问答一致性**」。

Büring 2016 把它形式化了：**一句话的焦点，就是回答疑问词的那部分。**

换成能操作的话：**问一句「这句话在回答什么问题」，那个问题问的什么，焦点就是什么。**

**这个测试比我自己想的「删测」更站得住**：它是语言学承认的黄金标准，删测是我临时想的。

### 2.4 这解释了核为什么在一句话里基本只出现一次——以及该数什么

核是那一段话的落脚点，说一次就够了。周围的话是**反复回来支撑它**的，所以卫星会说好几遍，核不会。

所以**认核不能数词频**——词频数出来的是卫星。

**但能数回指。**

一个词只出现一次，后面被“它”“这个”“那个”指回去好几次——**回指多的才是核。** 指称概率高，说明这段一直在说它。

例子：

> 「切帧太难了。它一直切不准。我改了好几次它的设置。」

「切帧」只出现一次，被“它”指了两次。词频很低，回指很高。**它是核。**

而“数词频”这条会把它漏掉，把别的说了五遍的修饰词当成核。**不是不能数，是数错了对象。**

**这条路不是空的：指代消解是成熟的 NLP 任务。**

「共指消解」做的事就是“识别文本里所有指向同一个东西的不同说法”——给个“它”，它告诉指的是前面哪个词。中文也有现成做法，在 ACE 2005 中文语料上 F 值能到 63~70。

所以要数回指，不用自己从零搭：**先用指代消解把“它”归到人头上，再数谁被归得最多。** 被归最多的那个，就是这一段一直在说的事。

## 三、三种关系，三个数学工具

**这一条是这次最重要的结构**：不是三种机制，是三种关系，各有各的数学。

| 关系 | 用什么 | 为什么 |
|---|---|---|
| **核 ↔ 核** | 图（graph） | 两边都是点，点对点的边。并列是双向边，对立是带「否」标签的有向边 |
| **核 ↔ 卫星** | 拓扑（topology） | **卫星不是一个点，是一片范围**。范围到哪为止、和别的范围怎么叠，是拓扑的活 |
| **边 ↔ 边**（复合） | 范畴论（category） | 它只问一件事：箭头能不能接起来（A→B 和 B→C 得得出 A→C） |

### 3.1 为什么卫星归拓扑，不归图

一开始我把卫星也判给图，错了。错在把卫星当成「另一个节点」。

**卫星是一片范围。** 一句话围着核展开，它不是另一个点，它是一圈。

这么一分，之前那个难题自己就解了：

**「一个卫星服务好几个核心」不是一条边连两头，是两个范围重叠了。** 重叠区就是共用的卫星区——拓扑里这叫**交**。范围可以相交、可以嵌套、可以只挨着边，都是拓扑现成的对象。

### 3.2 「分割 vs 覆盖」也在这里

- **分割（partition）**：范围互不相交，每句只属于一帧
- **覆盖（cover）**：范围可以相交，每句可属于多帧

这不是图的属性，是**范围的属性**。所以归拓扑。

第一版按**分割**做——互不相交。因为分割好算，覆盖会炸复杂度。等分割跑通了，再去量「到底有多少句子属于多个核」：只有百分之几就忽略，有一半就得换覆盖。

### 3.3 范畴论暂时用不上

第一版只画一层，不复合。范畴论是等我们开始堆「支撑的支撑」时才需要的东西——那时候要回答的是：**卫星的卫星，还算不算卫星。**

## 四、范围怎么划：反过来做

上一版我写「相邻两个核对半分」，那是错的。对半分的前提是「范围既不相交也没空隙」，而实际上三种情况都有：

- 一句同时撑两个核 → 该是**交集**
- 一段两不沾的废话 → 该是**游离**，不属于任何核
- 剩下的才是一对一

对半分会把交集拆开、把游离硬塞给某一方，那是在造数据。

**方向要反过来：不是从核往外划范围，是从话往里归。**

> **每一句自己站队，说它服务谁。**

- 只服务 A → 归 A
- 同时服务 A 和 B → **交集**
- 谁都不服务 → **游离**

这样三种情况各归各位，不用硬切。

**而且第一版不用先定「分割还是覆盖」**——先标，标完看它长什么样：全是一对一，就是分割；出现交集，就是覆盖。是分割还是覆盖，是标完之后的**测量结果**，不是前提。

**「游离」这一类比预想的常见。** 闲聊里大量接话、语气词、客套，它们真的不服务任何核。它们不归任何帧——但也不该扔，它们是**缝**，把两个核接起来的那层布。

## 五、被否掉的（别再提）

下面这些是今晚试过或提过、已经否掉的。写下来是为了以后不再重提。

| 被否的 | 为什么 |
|---|---|
| **`anchor_vec` 算相似度切帧** | 真库 3606 帧跑过：阈值 0.4 → 0.5，段长中位数从 1 跳到 3，中间没有过渡。它编码的是「我这句话」，不是「这一轮在干什么」 |
| **摘要的 n-gram 算相似度** | p25=0.206、p50=1.000，一半一字不差、一半几乎不重叠。跳变，不是连续信号 |
| **「新词首次出现」当帧边界** | 老词也会突然凸显；也可能只用一次；而且限制了形式（不一定是个词） |
| **「复现次数最高」认核（连带 Voronoi 划范围）** | 核在一句话里基本只出现一次，这条被主人当场推翻。跟着废的是**建立在它上面的 Voronoi 划范围**：那套是「点已知、空间自动分」，前提是点找得对。点找错了，分得再漂亮也没用。**注意：废的是那个前提，不是中点本身——第四节暂行的「对半分」就是中点，它只要求核的位置，不要求「服务到哪儿」，所以还能用。** |
| **把核判成「一个词」** | 反例：「分割和覆盖」是名词当核，「我认为这不成立」是半句当核。形式不定 |
| **把核判成「一个分句」** | 同一个反例：「分割 / 覆盖」两个名词就能当核，它们不是分句 |
| **「这句话只说一半是哪半」这个问法** | 它预设了核是「句子里的一部分」。两个名词当核时，不存在「只说哪一半」 |
| **把「焦点」拆成「日常的」和「语言学的」两个** | 纯属自找麻烦。语言学里的 focus 本来就来自日常说的焦点（凸出来的那个），是一条线，不是两样东西。这个区分是我从论文里搬来的，现实里没有 |
| **motive 前置到开口前** | 前置后丢掉的是「我刚说的那句」，而 `step` 恰恰需要它。前置看到的更少，不是更多 |
| **只回写四格** | 会让摘要滞后一轮、四格当轮，两个字段不同步。要么不动，要么两个一起回写 |
| **把「回写」当重要的事** | 内容早就在 flag 里，回写只是搬家。读 flag 的地方永远拿最新，读历史的地方整体偏一格、边界照找。**不用改** |
| **把 `motive` 改成二值判断** | 二值判断和 `step` 变没变是同一件事，加一格等于换个名字说同一句话 |
| **把「世界」当万能词** | 正着说反着说都对。它具体只有三样：门禁、真库数据、实测 |

## 六、还没定的

1. **范围的界线还只有暂行规则（对半分）。** 真正的界线是「核开始为另一个核服务的地方」，但那个没法直接判。对半分在核一近一远时一定错。**这是现在最大的空缺。**
2. **核怎么让模型认。** 判据有了（抽走它剩下塌不塌），但怎么落地没定：是让模型在心里「抽一遍」直接答，还是真把候选删掉重跑一遍看塌不塌？前者便宜但可能糊，后者准但贵。**这一条也没验。**
3. **一个核能带多大范围。** 有没有上限？长到几十句还算一帧吗？
4. **分割 vs 覆盖，实际有多少交叉。** 要量。
5. **核之间相撞怎么裁。** 图能画「两条相反的边」，但谁赢、怎么标，还没定。

---

## 七、怎么验

**主指标**：抽 20 段真对话，人工标「这段有几个核、核是什么」，再让模型认一遍，比对一致率。

**次指标**：同样 20 段，按「一核一帧」切出来，人工看边界对不对。

**先跑这个，再改代码。** 这条判据到底灵不灵，是它先要回答的问题。
