> 这刀动到提件提示词和落表结构，测试全改过一遍。

## 现在的链（frame.write）

```
split → topics → things → assign → fix → literal → coref → links → collapse
→ collect → relate（判官，可选）→ write
```

- **段**：一轮一段（先这样；多段由判官切是下一步）。
- **主核**：段里句子最多的核（结构定，不靠模型）。
- **卫星**：其余核，`head_id` 指向主核，`rel=elaboration`。
- **结构边**（0 调用）：交叉→joint、相邻→sequence、包含→不重复（父子已由 head_id 表达）。
- **语义边**（判官）：cause/evidence/contrast/parallel/sequence；段间 continue/switch/oppose。

- 判官出问题：`relate` 步是 optional，删掉它只留结构边；或整条影子关。
- 结构回退：删 `seg/role/head_id` 写入（列留着无害），回到「一核一行」。
