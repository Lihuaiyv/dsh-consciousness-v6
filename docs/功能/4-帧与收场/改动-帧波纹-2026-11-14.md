## 为什么

电子比喻里「单帧随机、多帧成波纹」，此前只有点的分布（p50/p90），**没有轨迹的形状**。
rho 能区分三种形状：

- `rho ≥ +0.2` → 有方向（连续几帧往同一头偏）
- `rho ≤ −0.2` → 来回摆（偏过去又偏回来）
- 中间 → 看不到波纹（帧间接近独立 = 每帧真是新的随机落点）

样本不足 5 帧返回 `None`，不硬编。

## 怎么验（数字）

```
本会话 ddae4fad（54 帧）：rho=+0.52  符号翻转=21%  → 有方向
历史 (无会话)（15 帧）  ：rho=-0.07  符号翻转=36%  → 看不到波纹
另一会话 50da3606（5 帧）：rho=-0.04  符号翻转=50%  → 看不到波纹
```

**读法：**本会话确实长出方向（连续几帧往同一头偏），不是每帧独立乱跳；历史那组混了多段对话，看不出形状——**和它「不可用于统计」的标签一致**，算是交叉验证。
