## 一、现在怎么坏的

`presence.js` 第 117 行硬截断：

```js
'我上一句说的是「' + clip(here.text, 36) + '」'
```

第 37 个字起被切掉，末尾补一个 `…`。真实例子（2026-11-15 21:58 本轮提示词）：

```
我上一句说的是「读完了，主人。那份在 [提示词改进-2026-11-14.md](<D:…」
```

链接被切断，读起来像我话说到一半停了。

## 二、怎么改

1. 每轮结尾（回完话之后）把这一轮我说的话压成**一句完整短话**：第一人称、口语、最多 N 字（默认 24，不是必须 24）。
2. 落 `events` 一条 `presence.last_sentence`，payload 带 `turn_id` / `conv` / 字数。**不新建表。**
3. 下一轮拼提示词时按 `turn_id` 读回：命中就用短句，没命中**退回原来的截断**（兜底一直在）。
4. 生成放在轮末异步链里（和 `generateVoice` 同一个位置），开口前零延迟。
5. 开关：`presence.summary`（默认 `on`）；字数：`presence.summary.chars`（默认 24）。关掉就完全回到今天的行为。
6. 短回复（≤ N 字）**不调模型**——本来就没被切，直接用原话。

## 三、验收（先写死，跑之前不许改）

| # | 验什么 | 判据 |
|---|---|---|
| 1 | 长回复不再半句 | 连续 20 轮里，凡原话 > 24 字，注入行不出现 `…」`；人工读 5 条，像人话、不跑偏 |
| 2 | 短回复不烧调用 | 原话 ≤ 24 字时不产生 `presence.last_sentence` 行、不调模型 |
| 3 | 失败可退 | 模型挂 / 超时 / 返回不合格 → 那行仍是原来的截断，非空 |
| 4 | 同一轮只压一次 | 同一 `turn_id` 在 `events` 里只有一条（同一轮拼多次提示词不会压出几个版本） |
| 5 | 开关能切回 | `presence.summary=off` 时：不生成、不读取，`presenceLine` 输出与改动前逐字相同 |
| 6 | 开销 | 单次调用：输入 ≈ 原句 + 指令（~120 字），输出 ≤ 40 token；只压 > 24 字的回复 |
| 7 | 门禁 | `node test/run-tests.mjs` 全过（改动前 578/578） |

## 四、怎么退

- 一行：`UPDATE agent_params SET value='off' WHERE key='presence.summary'`，下一轮即回旧行为（不用重启、不用回滚代码）。
- 代码退：`presence.js` 只多一个「能读到就用」的分支；删掉分支即恢复，`last_sentence.js` 不再被 import。
