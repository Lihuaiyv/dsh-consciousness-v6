# 改动 · 分句过滤纯符号（2026-11-23）

> 找核第一步（纯代码，不调模型）的一个小尾巴：纯符号段会漏成一句。

## 动了哪

`src/modules/frame_shadow.js`

- `strip` / `toSent` 改成 `export`（给单测用，行为不变）；
- `toSent` 的过滤条件从「长度 ≥2」加一条「至少含一个汉字/字母/数字」：

```js
.filter((x) => x.length >= 2 && /[\u4e00-\u9fa5A-Za-z0-9]/.test(x))
```

## 为什么

2026-11-23 实测：文本是「——」「……」「!!」时，分句结果各是 **1 句**，会跟着进提件/站队，
模型可能给它分个字母，最后落成一个正文是「——」的核——纯噪音。正常中文句子都含汉字，
加这条不会误伤。

## 怎么验

- 新增 `test/frame-sentences.test.mjs`：**11 / 11**
  三句=3、分号不切=1、加粗链接行内代码不打断、英文 `? !` 切、
  纯符号「——」「……」「!!」=0、代码块只留前后两句、空文本=0。
- 已挂进总门禁：`node test/run-tests.mjs` → **605 / 605，退出码 0**。

## 怎么退

把 `toSent` 的过滤条件改回 `(x) => x.length >= 2` 即可；单测会红 3 条（纯符号那三条），其余不变。

## 已知边界（没动）

英文句号 `.` 不切（只认 `。！？!?`）。中文回复为主，暂不影响；真要用英文写长回复，会并成一句。
要改就是把 `.` 也加进切分字符集，但得先想清楚缩写、小数、版本号（`v0.2`、`3.14`）会不会被误切。
