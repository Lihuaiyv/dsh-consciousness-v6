## 七、02:45 补记：偏离 0 的真相（问题 1 已查清）

**不是重复写，是补算的两个 bug。**

1. **全局 prev 被交替会话清空。**补算时用了一个全局「上一帧向量」，几段对话在文件里交替出现，
   每换一次会话就把 prev 清一次 → 每段的第二帧都被当成链头，偏离记成 0。
   修法：`last = {conv: (vec, tension)}`，每段会话各记各的。
2. **链头记 0 和「真的贴得极近」混在一起。**修法：链头 `deviation = None`，不记 0。
   0 从此只有一个意思：真的几乎没动。

**验证（手算对照）：**

```
18:31:32  dev=None    ← 链头，对的
18:38:13  dev=0.4806  ← 手算 1-cos=0.4806，对上了
18:39:17  dev=0.4741
18:40:10  dev=0.2823
18:40:39  dev=0.3667
```

**教训（写给自己）：** 一个数不能有两种含义。**「没有」和「是零」必须分开**，
不然读表的人（包括三天后的我）会一直在错的地方找原因。
