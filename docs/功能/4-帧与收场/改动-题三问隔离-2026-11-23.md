# 改动 · 题改成三问隔离 · 2026-11-23

> 一句话：把「题」从一句「互不相干的事」改回 11-22 实验的三问，而且**三次调用分开问**，取交集。

## 动了哪

| 文件 | 动什么 |
|---|---|
| `src/modules/frame_shadow.js` | 删掉 `topicsRequest/topicsStep`；新增 `TOPIC_ASKS` 三问、`topicReq(i)`、`topicRun(key)`、`topicsMergeStep`；链里 `topics` 一步换成 `topicsA/topicsB/topicsC + topicsMerge` 四步 |
| `test/frame-chain.test.mjs` | mock 拆成三个 label；ctx 补 `topicSets`；两题场景三个问法都回两题 |

## 为什么

1. **问法错了。** 11-22 实验里题是三种问法（在说哪几件事 / 在回答哪些问题 / 别人问你在说几件你会列哪几件），取交集；线上 11-23 写成了一句「这几件事互不相干吗」——那是判切帧，不是判题，而且只问一遍，所以几乎每轮都答「不止一件」，真库 9/9 标「该切」。
2. **隔离是故意的。** 三问塞进同一个 prompt，模型会顺着上一问的答案答，越答越像；分开三次调用，各自只看这一段原文，答案才独立，取交集才有意义。
3. **上限 4 是工程护栏，不是语义要求。** 11-22 的 v8 时代「恰三候选」导致几乎每轮都是 3 个核（模型凑满），v10 放开 1–4 才稳。所以写「有几件写几件，别为凑数硬分；最多 4 件，再多说明这段太碎，先合并」。

## 怎么合

- 三份都出现的 → 稳定题（交集）。
- 交集为空（换个说法就重了）→ 退到「至少两问都说过」的题。
- `shouldSplit = 稳定题 ≥ 2`，只标记，不改结构。

## 怎么验（数字）

- 链单测：`node test/frame-chain.test.mjs` → **36 / 36**
- 全量门禁：`node test/run-tests.mjs` → 见提交时数字

## 怎么退

删掉 `topicsA/B/C + topicsMerge`，恢复单步 `topics`（旧 prompt 在归档 [记录-找核实验-v10-2026-11-22.md](../../archive/2026-11-23_找核/记录-找核实验-v10-2026-11-22.md) 判据 1）。

## 已知代价

- 每轮多 2 次小模型调用（题从 1 次变 3 次）。v10 实验本来就这么跑，换来隔离和交集。
- 交集按原文比较，措辞不同会重合失败——这是实验里已知的塌方，两票兜底。
