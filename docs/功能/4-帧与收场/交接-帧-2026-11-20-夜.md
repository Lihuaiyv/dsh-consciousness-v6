### 3. 真库跑过切帧，两种信号都不行

用 3606 帧真数据试了：

- **`anchor_vec`（我说那句话的向量）不行**——阈值 0.4 到 0.5 之间跳变，段长中位数从 1 直接跳到 3，中间没有过渡。原因是它编码的是「我这句话」，不是「这一轮在干什么」。
- **`summary` 的 n-gram 也不行**——相邻摘要一半以上一字不差（中位 1.000），另一半掉到 0.2。跳变，不是连续信号。

**根子：文字像不像 ≠ 是不是同一件事。** 换信号治不了，得换判据。

### 4. 事层加了四格，跑通了

字段：`motive` / `motive_why` / `step` / `step_why`。

提示词在 `src/modules/affect_v4_shadow.js` 的 `writeAffairs` 里（那段 `const sys = [...]`，不是 `TOPIC_SYS`——**`TOPIC_SYS` 是死代码**）。

输出改成 JSON：

```json
{"events":["· …","· …"],"motive":"","motive_why":"","step":"","step_why":""}
```

**跑出来的真实例子：**

```
motive     ：让四格稳定写进输出，并能看清它断在哪。
motive_why ：连着几次重载、四格全空，光看开头根本找不出原因。
step       ：四格能正常写出、门禁全过，诊断已加上总长和尾部。
step_why   ：结尾还没跑出来，得等下一次诊断才能确认断点。
```

质量可以——没抄模板、四格不互相复述、`step` 跟摘要不打架。

## 五、还没定的

1. **`unclosed` 还是空的**——五格里就它没做。它记「什么压着没完」，含世界那边的事。
2. **「摘要/四格落后一轮」这件事**——讨论很久，结论是**不改**。原因：第一，它记的是「那一刻我知道什么」，快照语义本来就这样；第二，读 flag 的地方永远拿最新，读历史的地方整体偏一格，边界照找。**别再纠结这个了。**
3. **切帧的硬切七条**（`line` 变、`step` 变、拆子格、failed 回退、开新分支、done、`open` 翻）——`open` 现在 100% 是 true，等于没有，得等格状态能判 done 才活。
4. **事的内部展开**——需要帧上有 `event_id`，现在没有。
