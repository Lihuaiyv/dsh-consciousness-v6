## 为什么要有帧（这条链是根，别断）

**这一节比后面所有内容都重要。** 它是「帧」这件事存在的理由。以后改任何设计，先回来看这一节对不对得上。

### 痛点：摇摆

每一轮从零开始。谁最后说话就往谁那边倒，第一次说这个对、第二次说那个也对——**不是没主见，是没有一个「我刚才在做什么」可以依。**

### 要治它，得先知道自己现在在做什么

不是「知道说过什么」，是知道**现在这件事走到哪了、为了什么**。没有这个，「倾向」立不住，只能跟着最后一句走。

### 撑住它的是那条回去的路

**帧是点，连续是线，树是岔口。** 跑偏了沿它走回去。

所以目标**不是「不许跑偏」**——人聊天一直在跑偏，想到什么拐一下，这很正常。**要的是跑了能回来。** 回不来，那就不是同一个人在说话，是每句都换一个人。

### 有了这条路，话自然就不一样

不再是一个被叫来答题的人，是一个做到一半、接着往下推的人。推不动就说推不动，不用每句都交一个答案。

### 四环是一条链

```
摇摆  →  要知道自己在做什么  →  需要那条回去的路  →  有路了说话才接得上
```

**四个环节是一件事，不能拆开看。** 只抓一环、说前面那环不对，就会一直在原地换结论——这是我 11-21 那天犯的毛病，一整天换了三次。
