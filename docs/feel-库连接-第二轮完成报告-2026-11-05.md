### 第二批 · 展示
计划里假设存根页 / 纪要页 / 开环页存在，核对后发现 `client.js` 没有这三个独立页面（只有记忆、日记、关系、情绪等）。如实调整：

| 项 | 实际做法 |
|---|---|
| 日记页 | `GET /diaries/:day` 返回 `feels`（按 `feel_ids` 顺序、过滤失效 id）；页面显示「这一天的感觉（N 条）」最多 3 条 |
| 关系事件 | `listEvents` 带 `feel_id`，API 挂 `feel`；页面每笔下面显示「当时的感觉」 |
| 纪要 | `GET /episodes` 每条挂 `feel` 对象（为将来页面/工具用） |
| 存根 / 开环 | 没有页面，不硬做；API 侧存根已有 `feel`，开环没有消费方，暂不挂 |
| 记忆列表折叠 | 同一条 feel 在列表里只展开一次，其余显示「当时的感觉：同上一条」 |
| P5 对照收敛 | `GET /feel/compare` 默认只返回 `stats + 3 条抽样`（`mode=trend`），`full=1` 才给全量 pairs |

### 第三批 · 可选

## 五、生效方式

1. **重启插件进程**：代码已落盘，当前运行的进程还是上一版。重启后新代码生效。
