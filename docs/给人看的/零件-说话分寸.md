# 零件：说话分寸

> 这页讲「这一轮她怎么说话」：说几句、主不主动、多暖、多正式、愿意露多少。
> 谁看：主人。不读代码，但要知道它靠不靠谱、哪里会坏。
> 工程件：`src/algo/expression.js`（档位与句长）、`src/modules/expression_state.js`（合成一方语气）、考卷 `test/exam-expression.test.mjs`。

## 1 一句话 + 一个比喻

**它管**：这一轮的语气档——说几句、主不主动、温度、正式度、披露、还有那三行「我想怎么说」；**不管**：说什么内容、此刻情绪怎么算出来、关系怎么变。

比喻：**一个调音台，两个旋钮**。一个旋钮管「音量」（说几句、主动不主动），只有慢情绪能拧；另一个管「温度」（多暖、多正式），由关系拧。性格在旁边偷偷把音量拧大半格，但拧不过「今天低落」。

真的对应到哪：「音量」是 `level / sentences / proactive`，「温度」是 `warmth / formality / disclosure`。

## 2 它什么时候醒（触发）

| 谁叫 | 什么时候 | 醒来做什么 |
|---|---|---|
| 别的零件调 | 每轮组装提示词前 | 合成一次语气档：档位、句长、温度、三行软愿望 |
| 它自己 | 影子档（只算不生效） | 按快情绪算「本来会升一档」，留给评测看 |

没有这两处，它不会自己动；也没有自己的定时器。

## 3 醒来之后走哪几步（流程）

1. 慢情绪定档：安静（一句）/ 简短（两句）/ 正常（三句）/ 热乎（四句）。
2. 这一下的强度压上限：太激动一律一句；偏高最多两句，也不主动。
3. 性格微调：外向多半句、内向少半句——低谷档不给这个待遇（低落压过性格）。
4. 关系只进温度：暖、正式、披露、主动各取关系给的值，合成出她的温度。
5. 迟滞：慢情绪只挪了一点点，先不换脸，免得在门槛上反复横跳。
6. 交三行软愿望：此刻感受（推测口吻）、我想怎么说、这一轮怎么说。

走查：今天下午慢情绪 -0.3（低落），关系再亲近也定成「一句、不主动、偏冷」；感受行会写「提不起劲，话会越说越短；整体心情偏负面」。

## 4 素材从哪来（输入）

| 人话名 | 从哪来 | 缺了会怎样 |
|---|---|---|
| 慢情绪 | 情绪那边的 v3（`slow`） | 缺了按 0（中性） |
| 这一下的强度 | 情绪行里的 intensity | 缺了按 0.4 |
| 关系四轴 | 关系页投影出来的温度/正式/披露/主动 | 缺了按中性 0.5 / 0.4 |
| 外向度 | 人格 | 缺了按 0.6 |
| 上一轮的档 | 上一轮自己的输出（只用于迟滞） | 缺了就不迟滞 |

**它不看什么**：不看内容、不看记忆、不看要不要开口（那是主动开口的事）。

## 5 它怎么判断（判据）

一句话：**今天低不低？这一下猛不猛？跟谁说话？**

- 低落：慢情绪 ≤ -0.2 安静；≤ -0.05 简短；≥ 0.25 热乎；其余正常。
- 太激动：强度 > 0.8 一句；> 0.6 最多两句且不主动。
- 性格：外向度 ≥ 0.65 多半句；≤ 0.35 少半句；安静档不给多半句。
- 温度：关系六成 + 这一档的底色四成；主动取「关系主动」和「情绪主动」里低的那个。
- 迟滞：档位要变、但慢情绪挪动不到 0.08，就保持上一档。

反例：你觉得「她今天跟主人说话应该热一点」——温度确实抬高了一点，但**句长和主动一点没动**，因为低落时音量旋钮不听关系的。

## 6 它交出什么（输出）

- 一份语气档：档位、句数、主动程度、语气标签（暖/平/冷/短）、温度、正式度、披露。
- 三行软愿望：此刻感受、我想怎么说、这一轮怎么说（都是「我想…」，不是「只说一句」）。
- 谁接：提示词组装的语气行、面板、评测。

**不说的几种情况**：没有情绪数据就按中性走；关系缺了按中性；这三行是愿望，模型可以不听——不听不算坏，只是这一轮可能比档位写得长。

## 7 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 「没心情数据」和「正好中性」分不出来 | `Number(null)` 是 0，`moodWord(null)` 给出「中性」而不是留空 | 照现实记着；真要分开得改判据 |
| 心情数明明传了空，行里却没写心情 | 同上 | 同上 |
| 明明低落，关系很亲近也一点不主动 | 故意：音量旋钮不听关系，怕把低落的她逼得多说 | 设计如此 |
| 写了「一句就停」，她还是说了三句 | 输出是软愿望不是命令 | 设计如此；要硬管得另立零件 |

## 8 怎么知道它活着（观察点）

看提示词里那三行：此刻感受 / 我想怎么说 / 这一轮怎么说，语气档和面板上的档位应当一致。异常：同一轮既写「热情 0.9」又写「语气偏冷」（说明又有人绕过这里自己算）。

现在就能看：面板的语气区；或跑 `node test/exam-expression.test.mjs`。

## 9 换它要付什么（代价）

- 能换：档位门槛、强度线、性格加减、迟滞阈值、温度权重、三行文案。
- 不能动：低落压过性格；关系只调温度不逼音量；输出保持软愿望。
- 考卷：52 道，`node test/exam-expression.test.mjs`。
- 回退点：`expression-before-part`。
- 换完记在哪：`src/modules/parts.js` 的 `swaps`。
