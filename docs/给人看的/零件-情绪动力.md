# 零件 · 情绪动力（affect）

> 这页给主人看：它是什么、什么时候醒、看什么、怎么判、交出什么、哪里会错。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；工程件：`src/parts/affect/index.js`（整件实现都在这里），`src/modules/affect.js` 只剩一行转发，考卷 `test/exam-affect-apply.test.mjs`。

## 1. 一句话 + 一个比喻

它管「**一次评价怎么变成她此刻的状态**」——不是「这句话该是什么情绪」（那是情绪评价），也不是「情绪该怎么表达」（那是说话分寸）。

像一锅正在炖的东西：别人一句话是丢进来的一块料（评价），它决定汤面晃多少（快情绪）、底味挪多少（慢情绪）、火候怎么退（余温与半衰期）。丢料的手是别人，火是它自己。

## 2. 它什么时候醒

| 谁叫它 | 多久 | 醒来做什么 |
|---|---|---|
| 每句话进来 | 每轮 | `applyEmotionV3`：把这次评价应用成快/慢/底色 |
| 心跳 / 夜间 | 定时 | `decayAffect`：没人说话时也让强度往下走 |
| 界面 | 拉数据时 | `getAffect` 一类只读口 |

## 3. 醒来之后走哪几步

1. 读现在的状态（`affect_v3` 的快/慢、水位、余温、累积负荷）。
2. 按真实流逝的时间先走一遍（慢情绪按半衰期、快情绪按余温散回水位）。
3. 把这一下的评价乘上放大系数（鱼格 / 边），再做惯性混合。
4. 过事件闸门：够重才成为一次事件，轻的只让快情绪晃一下。
5. 写回 `affect_state` 与 `affect_v3`，需要时开/续一条 `affect_episodes`。

## 4. 素材从哪来（输入）

| 人话名 | 从哪来 | 缺了会怎样 |
|---|---|---|
| 这次评价 | 情绪评价零件（`appraise`） | 没有就不应用 |
| 放大系数 | 边与鱼格（`computeEdgeBias`） | 默认不放大 |
| 现在的状态 | `affect_v3` / `affect_state` | 没有就返回 null，不硬编 |
| 参数 | `affect.*` 一组 | 用默认（半衰期、余温、上涨段…） |

**它不看什么**：不看关系账本、不看记忆正文、不改 `memory_items`。这次也钉了一条：应用一次评价，记忆一条都不许动。

## 5. 它怎么判断

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 这一下够重吗 | 闸门 sig ≥ θ（事件化） | 只晃快情绪，慢情绪不动 |
| 上升段 | 峰值与原值差 > 0.02 | 强度留在原处，不虚抬 |
| 复现 | 同标签、上一段还没散 | 重新点亮并递减加强（不会无限加） |
| 不应期 | 刚散场又来同类 | 只把「这一下抬的那截」打七折 |

## 6. 它交出什么（输出）

| 层 | 长什么样 | 谁接 |
|---|---|---|
| 落库状态 | `affect_state`：标签 / 强度 / 心情 / PAD | 提示词的情绪行、界面 |
| 三层数 | `affect_v3`：慢 / 快 / 总 + 水位、余温、负荷 | 提示词、自述、日记取材 |
| 这次事件 | `affect_episodes` 一条（或续上一条） | 衰减曲线、复盘 |
| 没状态 | `null` | 调用方自己兜底 |

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 被威胁却没反应 | 评价只给标签、不给价（`goal_congruence=0`），强度压回底噪 | 已修：威胁按有向/无向给 −0.6 / −0.3（见 [对照](情绪动力-对照-2026-11-06.md)） |
| 一句话把强度顶到头 | 复现加强以前是固定 +0.12，越叠越高 | 改成按剩余空间给增益，收敛在 1 以内 |
| 睡一夜醒来反而更低 | 累积负荷按小时在循环外一把算 | 改成循环内逐小时衰减 |
| 负面折得太狠 | 折完再折（每条都削残留） | 只在成事件那一路折 |

## 8. 怎么知道它活着（观察点）

- `affect_events` 里 `affect.appraised` 一条一条：有没有 `emitted`、`sig` 与 θ 差多少。
- 抽两条对比：同一句话在不同鱼格下强度有没有差（没有差就是放大没跑）。
- 数值长相：`intensity` 是不是长期贴着 0.2（贴着就是评价一直没给价）。
- 跑 `node scripts/sim-affect-v2.mjs`：现在 **266 / 266**，八类刺激 × 四个鱼格的强度表要稳。

## 9. 换它要付什么（代价）

- **能动**：应用规则（闸门、上升段、复现加强、负向折扣）。
- **不能动**：评价算法（那是情绪评价零件）；记忆写入（只读）。
- **考卷**：`test/exam-affect-apply.test.mjs`，13 道，现在 13/13。守边界不守配方——调参不该改卷子。
- **回退点**：`affect-apply-before-part`。
- **搬家（已完成）**：实现整件搬到 `src/parts/affect/index.js`，`src/modules/affect.js` 只剩一行转发（和开环那次一个做法）。没按「判 / 算 / 取数」拆成三个文件——那三百行拉着 11 个私有件，硬拆会把文件撕成两半、还容易漏；先整件搬，将来要再拆就在零件内部拆。
  验收：`sim-affect-v2` **266 / 266**，八类刺激 × 四个鱼格一个数没变；全量 564 / 564；界桩 13 个零件全绿。
