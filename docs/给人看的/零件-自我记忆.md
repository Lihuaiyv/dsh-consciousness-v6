# 零件 · 自我记忆（self_memory）

> 这页给主人看：她夜里怎么把「今天我怎么过的」写成一条记忆。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；工程件：`src/modules/self_memory.js`，考卷 `test/exam-selfmemory.test.mjs`。

## 1. 一句话 + 一个比喻

它管「夜里把今天怎么过的写成一条第一人称记忆」，不管白天的碎片怎么抽、不管这条记忆以后怎么变淡。像睡前在台灯下把今天折成一张小纸条，塞进自己的抽屉——一天只有一张。

真的对应到哪：`memory_items` 里一行 `source='self'` 的 episode，键是 `self.day.<日期>`。

## 2. 它什么时候醒（触发）

| 谁叫它 | 多久 | 醒来做什么 |
|---|---|---|
| 夜间整理（`nightly.js`） | 每晚一次 | 写当天那条；够料再写「想明白的一件事」 |
| 手动补跑 | 想补时 | 同一套门，补的是缺的那天 |

没有夜里这一下，它不会自己动。

## 3. 醒来之后走哪几步

1. 看门：总开关、日更开关、这一天是不是已经写过。
2. 收素材：她今天自己写的条目、生活流做过的事。
3. 没素材 → 不写，宁可今天空着。
4. 叫模型写成 80~110 字的第一人称。
5. 过闸门：得像她自己写的（第一人称、6~120 字、不是旁白、不是噪音）。
6. 不合格再问一次：太长就收紧；空回复就带着素材重问；旁白、噪音不重试。
7. 过了就落一条，键是 `self.day.<日期>`——同一天再跑会认出「已经写过」。

## 4. 素材从哪来（输入）

| 人话名 | 从哪来 | 新鲜多久 | 缺了会怎样 |
|---|---|---|---|
| 她自己的条目 | `memory_items`，`source='self'` 或 `'life'`，当天 | 当天 | 没有就不写 |
| 生活流做过的事 | `life.done` 事件（想了 / 去看） | 当天 | 没有就少一段素材 |
| 想明白的料 | 自己的条目（不含当天流水那条）+ 夜里想过的 | 当天 | 不够两条就不写「想明白」 |

它不看什么：用户档案、摘要腔的条目、昨天的条目、别的时间段。

## 5. 它怎么判断（判据）

它其实只问三个问题：有没有素材？像不像她自己写的？今天是不是已经写过了？

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 有没有素材 | 当天至少一条她自己的条目 | 不写，记 `no_material` |
| 像不像她 | 第一人称、长度在范围内、不是旁白 / 噪音 | 重问一次；仍不过就不写 |
| 今天写过没有 | `self.day.<日期>` 不存在 | 写；存在就跳过 |

反例：明明今天有事，为什么没写——素材里全是「用户…」，她自己的条目一条都没有；或者模型两次都没写出第一人称。

## 6. 它交出什么（输出）

| 层 | 长什么样 | 谁接 |
|---|---|---|
| 当天那条 | `memory_items`，episode，`source='self'`，键 `self.day.<日期>` | 召回、日记、自我回读 |
| 想明白那条 | `memory_items`，reflection，`source='self'`，键 `self.insight.<日期>` | 召回、自视 |
| 回执 | `{ ok, id, text }` 或 `{ skipped: 原因 }` | 夜间日志 |

不写的情况：总开关 / 日更关掉；没素材；没模型；两次都没过闸门；一天已经写过。

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 编出一条「今天我很开心」 | 没素材也硬写 | 没素材直接不写 |
| 写成了旁白 | 模型顺着「用户 / 助手」说 | 闸门挡；旁白不重试 |
| 同一晚写了两条 | 没有去重键 | 一天一个键，第二次认出 exists |
| 太长的整段 | 模型铺开写 | 第二次请求收紧，闸门不放宽 |

## 8. 怎么知道它活着（观察点）

- `memory_items` 里 `fact_key` 以 `self.day.` / `self.insight.` 开头的行。
- 夜间日志：`no_material`、`gate`、`no_model` 分别说明卡在哪。
- 当天的「想明白」那条：有 insight 词、长度在 16~120 之间。

现在就能看：查 `memory_items` 里最近几条 `source='self'` 的 episode / reflection。

## 9. 换它要付什么（代价）

- **能动**：提示词、闸门（长度 / 旁白）、重试策略、一天一条的键。
- **不能动**：记忆表归记忆域（它只走 `addMemory` 公开函数）、衰减归记忆衰减与分层。
- **考卷**：`test/exam-selfmemory.test.mjs`，31 道，现在 31/31。
- **回退点**：`selfmemory-before-part`。
- **换完记在哪**：`parts.js` 的 `swaps`，外加一份 `docs/活论证-自我记忆-<日期>.md`。
