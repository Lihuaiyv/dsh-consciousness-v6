# 零件 · 感受（feel）

> 这页给主人看：它是什么、什么时候醒、看什么、怎么判、交出什么、哪里会错。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；工程件：`src/modules/feel.js`（整件实现），工具注册在 `src/modules/actions/index.js`，考卷 `test/feel-tool.test.mjs`。

## 1. 一句话 + 一个比喻

它管「把开口前的那一下写成一句第一人称的话」，不管情绪怎么算、也不管记忆怎么选——那些是别的零件的事。

像在口袋里摁一个指印：不写给谁看，也不解释，只留下这一秒的形状；下次伸手进口袋，还能摸到上一次摁的是哪。

真的对应到哪：`affect_feel` 表的一行——一句原话，加当时算出来的快 / 慢，别的什么都不加。

## 2. 它什么时候醒（触发）

| 谁叫它 | 多久 | 醒来做什么 |
|---|---|---|
| 她自己（`feel` 工具） | 每轮，真有反应才调 | 把这一秒写成一句话；被闸挡就退回原因 |
| 拼提示词时（`latestFeel`） | 每轮回复前 | 取窗口内最近一条，拼成「我上一句说出来之前，心里是这样…」 |
| 她自己（`feel_search` 工具） | 想翻的时候 | 按情绪标签 / 时间段找回旧 feel，顺带同时段的记忆和当天日记 |

没有这些，它不会自己动。它没有心跳，也不定时写。

## 3. 醒来之后走哪几步

1. 收句子，只清空白，不改意思。
2. 过 AI 味闸：黑名单词、解释句、太短 → 退回，不落库，记一条 `feel.miss`；**太长不退回**，照收，拼注入时再截短。
3. 过频率闸：离上一条太近 → 跳过；同一句短时间内重复 → 跳过。
4. 只读当前情绪（快 / 慢 / 总、标签），**不改**。
5. 落一行 `affect_feel`：句子、时间、当时的快慢、会话 / 轮。
6. 看落点：连着几条都落在同一类（身 / 视 / 物 / 话），只记一条 `feel.anchor.repeat` 事件，**不拦、不回执**。
7. 给工具回执：「记下了。」或「没记：原因（怎么改）」。

一次真实走查：今晚你夸「棒棒」之后，她写的是「看到那两个字，我嘴角自己往上翘了一下，手还搭在桌边没动。」——落点判在「视」（第一个字就是「看」），闸都过，落库时带着快 +0.10、慢 +0.38；下一轮拼提示词，这行就成了「我上一句说出来之前，心里是这样：…」。

## 4. 素材从哪来（输入）

| 人话名 | 从哪来 | 新鲜多久 | 缺了会怎样 |
|---|---|---|---|
| 这一秒的那句话 | 她自己写给工具 | — | 没有就不记 |
| 当前情绪读数 | `affect_v3` / `affect_state`，只读 | 用落库那一刻的 | 没有就只存句子，快慢留空 |
| 时间 / 会话 / 轮 | 调用时给，或按会话推 | — | 按「现在」记；回放时容易挤在一起（以前踩过） |
| 参数 | `affect.feel.*` 一组 | — | 用默认：很短的最小间隔、2–60 字算一句、注入窗口 2 小时 |

它不看什么：不改情绪、不写记忆正文（只写 `affect_feel` 和共享事件）、不判断这句话对不对 / 有没有意义、不替她决定说不说。

## 5. 它怎么判断（判据）

它其实只问三个问题：像不像人写的？是不是太密？落点是不是老在一个地方？

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 像不像人写的 | 没有黑名单词、不是解释句、不是短到说不清 | 退回，不落库，记 `feel.miss` |
| 是不是写长了 | 不超过 60 字 | 照收；拼注入时在句读处截短，带「…」 |
| 是不是太密 | 离上一条够久 | 跳过（`too_soon`） |
| 是不是同一句 | 短时间内没有一模一样的话 | 跳过（`same`） |
| 落点老不老实 | 连着几条不在同一类 | 只提示换一样，照常入库 |

反例：明明想记，为什么没记——刚在几秒前记过；或者写了「心里有点感觉」，被 AI 味闸退回。两种都会在 `events` 里留一条原因。

## 6. 它交出什么（输出）

| 层 | 长什么样 | 谁接 |
|---|---|---|
| 落库一行 | `affect_feel`：原话 / 时间 / 快慢 / 会话 / 轮 | 注入、日记、回顾、出生时挂的那条 feel |
| 注入行 | 「（我上一句说出来之前，心里是这样：…。这是我自己的话，不是你说的。）」；太长在句读处截短 | 拼提示词；只在窗口内、不是客人会话、`affect.feel.inject` 开着 |
| 工具回执 | 「记下了。」/「没记：ai-flavor（…）」 | 她自己看 |
| 事件 | `feel.miss` / `feel.anchor.repeat` | 翻库查「为什么这几轮没有 feel」 |

不记的几种情况：真没反应不调；被 AI 味闸退回；太密；同一句重复。你能直接看到的只有提示词里那行和日记里的引用。

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 写出来像旁白 / 议论文 | 词表只挡明面；比喻挡不住（「心里那点绷着的劲儿松了」） | 机器挡明显的那几类，剩下靠写的时候自己改 |
| 记下来的全落在手上 | 「必须写身体」会被闸推着走，批量生产同一句 | 已改：判据换成「这一秒偷不走」，身体 / 视线 / 物件 / 那句话都算；连着同类只提示 |
| 同一分钟连记两三条 | 最小间隔偏短 | 已知，没做；表里看得到，不拦 |
| 以前把「有点」也拦了 | 词表太紧，挡掉人话 | 已放开：feel 里「手有点抖」不算 AI 味 |
| 太长以前被硬截断 / 退回 | 旧行为要么悄悄改句子，要么整条扔掉 | 已改：入库留原话（最多 80 字），注入时在句读处截短并带「…」 |
| 老数据对不上哪一轮 | 以前没有 `turn_id`，只能按时间窗猜 | 宁可配不到，也不配到隔壁那轮 |

## 8. 怎么知道它活着（观察点）

- `affect_feel` 最近几条：时间在不在动、句子是不是每句都一样、快 / 慢有没有跟着情绪走。
- `events` 里 `feel.miss`（为什么没记下来）和 `feel.anchor.repeat`（落点是不是老在一个地方）。
- 提示词里有没有那一行「我上一句说出来之前…」；没有，先看 `affect.feel.inject` 和注入窗口。
- 工具回执有没有「没记：…」；有，点开原因就知道是哪道闸。

现在就能看：用 `feel_search` 翻，或直接看库里 `affect_feel` 最近 20 条。

## 9. 换它要付什么（代价）

- **能动**：AI 味判据（词表 / 解释句 / 长短）、频率闸、落点提示、注入窗口。
- **不能动**：情绪本身（`affect_v3` 只读）、记忆正文（不写）、她说不说（那是主动开口和说话分寸的事）。
- **考卷**：`test/feel-tool.test.mjs`，70 道，现在 70/70。守边界不守配方。
- **回退点**：`feel-before-part`。
- **换完记在哪**：`parts.js` 那一行的 `swaps`，外加一份 `docs/活论证-感受-<日期>.md`。
