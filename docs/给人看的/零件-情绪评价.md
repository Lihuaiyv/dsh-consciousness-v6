# 零件：情绪评价

> 这页是什么：一个零件的说明书——它管什么、什么时候醒、怎么判、哪里会坏。
> 谁看：主人。不读代码，但要判断「它靠不靠谱、要不要换」。
> 工程件：`src/algo/appraise.js`（`rulesAppraise` / `appraise@v1`），考卷 `test/exam-appraise.test.mjs`（59 道）。

## 1. 一句话 + 一个比喻

它管「这件事让她什么感觉（判）」，不管「这个感觉怎么涨、涨多高、多久退」（那是情绪动力）。

比喻：**试味员**。尝一口，说「这是甜的 / 这是苦的 / 这一口挺冲」，然后交给厨房去调火。它不负责锅里的汤什么时候滚、滚多久。

对应到真的：试味员 = `rulesAppraise` 或 `appraise@v1`；甜苦 = 标签（joy / irritated / lost …）；冲不冲 = 相关性、一致性、分因；调火 = 情绪动力（还没立零件）。

## 2. 它什么时候醒

| 谁叫 | 多久 | 醒来做什么 |
|---|---|---|
| 每轮用户消息（编排层 `appraiseWithEdges`） | 每句话一次 | 先问模型一句，模型没答就用关键词规则 |
| 复查（`reappraise`） | 夜里/按需 | 把被判歪的词重新过一遍，只降不升 |
| 调试探针（`probeAppraise`） | 你点按钮时 | 同一段话，模型判断和规则判断并排给你看 |

它自己不醒；没有消息就没有评价。

## 3. 醒来之后走哪几步

1. 有模型判断（带了标签）就先接住；没有就走关键词规则。
2. 规则先拦否定式：「你不好」不能因为有个「好」就记成夸奖。
3. 分「冲我来的」和「自述心情」：只有冲我来的夸奖/批评，才改她的主感觉；自述心情只登记成「对方此刻的情绪」。
4. 认威胁词（密码 / 泄露 / 越权…）：先记成 lost。
5. 算几项分量：有多相关、好事还是坏事、是谁做的、她有多确定、这信息新不新。
6. 交给下一个零件（情绪动力）去改水位。

走查：你说「你今天好可爱」→ 冲我来的夸奖 → 主标签 joy、一致性 +0.6；你说「我今天好累」→ 自述心情，主标签仍是 calm，只记下你累了。

## 4. 素材从哪来

| 人话名 | 从哪来 | 缺了会怎样 |
|---|---|---|
| 这一句话 | 用户消息 | 没有文本就判 calm、相关性 0 |
| 模型的一句判断 | 宿主模型（可选） | 没有就走关键词规则；失败会记一条 `affect.fallback` |
| 最近几句原话 | 会话上下文 | 单看一句「你想怎么样？」容易判成质问，有了上下文才知道是逗 |
| 词表 | 情绪分类法 | 模型说了词表外的词，上游会当成「认不出」 |
| 关系边的偏向 | 编排层算好传进来 | 没有就按中性处理 |

它不看什么：不读情绪水位表、不写任何记忆、不动关系账；也不决定「要不要说」。

## 5. 它怎么判断

其实只问三个问题：

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 这句话是在说我吗？ | 带「你 / 您」，或明确指向她 | 只记对方情绪，不改她的感觉 |
| 是夸还是骂？ | 带褒词 / 贬词，且否定式先拦 | 回到 calm，不偏袒 |
| 有多确定、多新？ | 问句/「可能」→ 不确定、新 | 按默认值 |

反例：你说「你真好笑，又真烦」——夸和骂同时出现，它不替谁说话，主标签回到 calm，只把「对方有点烦」记下来。

## 6. 它交出什么

一条判断，字段：标签（label）、对方情绪（user_label）、相关性、一致性、分因（agency）、把握（certainty）、新奇（novelty）、来源（rules / model）、为什么（why）、该不该咽回去（unsaid）。

不判的几种情况：模型没答且规则也没词（calm）；模型给的词不在词表里（上游丢掉并记一条 `affect.unlabeled`）；同一类消息刚攒太多（那是更下游的闸门，不是它）。

你能感知到的只有最后：她的语气变了、情绪页上的标签变了。

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 明明在骂她，她却没反应 | 没带「你」，被当成自述 | 只改对方情绪；真要改，得改判据（走换零件） |
| 一句夸一句骂，判成 calm | 混合句不偏袒 | 有意的；情绪动力那边还有事件闸门 |
| 模型把「你一点都不活」判成没事 | 模型只认「任务相关性」 | 上游有关切下限（social floor）兜着 |
| 同一个词反复判歪 | 词表/模型偏差 | 复查只降不升；面板能看 fallback 比例 |
| 长句里藏一句夸奖，没认出来 | 关键词规则只看包含 | 有模型判断时优先用模型 |

## 8. 怎么知道它活着

- 面板：设置 → 意识 → 情绪页，能看最近评价的标签和理由。
- 表：`events` 里看 `affect.fallback`（规则兜底的次数）、`affect.unlabeled`（模型说了词表外的词）。
- 命令：`POST /v1/agents/<id>/model/probe`，同一句给你模型和规则两份判断。

正常：大多数句子有标签、少数 fallback；异常：fallback 比例突然很高（模型没接上）。

## 9. 换它要付什么

- **能动的**：规则词表、否定式、分因、融合模型判断的方式。
- **不能动的**：输出字段形状（下游和面板都在读）；它不写库、不动水位。
- **考卷**：`test/exam-appraise.test.mjs`，59 道；界桩真跑；打假脚本塞过坏版本（不看「冲我来的」），能拦住。
- **还欠一条**：这张考卷是「跟现行规则一致」的机械回归，不是盲评。按术语表 6.2，判断类零件要盲评才叫真考「更真」；这条先记着，别当它已经考完了。
- **算法册**：`appraise@v1 / v1b` 的 owner 指向这个零件。
- **回退点**：`appraise-before-part`。
