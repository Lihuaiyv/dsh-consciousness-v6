# 零件 · 主动开口（speak）

> 这页给主人看：它是什么、什么时候醒、看什么、怎么判、交出什么、哪里会错。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；怎么改它、每一步怎么落地，留在外面的 `docs/` 工程件里。
> 这页会造几个小词（由头、劲头、额度……），都在第 10 节登记；其余以 [术语表](术语表-2026-11-05.md) 为准。

## 1. 一句话

它管一件事：**此刻要不要由她先开口**。像一个想发消息又怕打扰的人——先掂量「有没有由头」「现在合不合适」，两个都过了才发。

对应到代码里就是：先过 12 道门、再算劲头和打扰成本，两边都过才交给下一步写句子；它不是定时弹消息，是定时「查看要不要发」。

它不管这句话怎么写，也不管怎么送到你手机上——那是后面两步的事。

| 管 | 不管 |
|---|---|
| 说不说；为什么说 / 为什么不说 | 句子怎么写、像不像她 |
| 现在这个时间点合不合适 | 怎么发出去、发到哪个通道 |
| 有由头时优先说那件事 | 你回了之后怎么接 |

## 2. 它什么时候醒

| 谁叫它 | 什么时候 | 醒来做什么 |
|---|---|---|
| **它自己的心跳**（主要） | 每 15 分钟一次，前后差 10%；连续出错会拉长到 30 分钟 | 先判要不要说；要，就写一句、排队、试着送出去 |
| **你按「让她说」** | 你点的时候（接口 `POST /v1/agents/:id/proactive/queue`） | 同上。会更直接：安静段、沉默多久、额度、劲头比成本都不拦；但「今天说满了」「没有能说的方向」照样拦 |
| **别的零件 / 测试** | 被调用时 | 看调的是哪一层：可能只判断，也可能整条走完 |

**每 15 分钟醒一次，不等于每 15 分钟说一句。** 大部分时候醒来只是看一眼，结论是「不说」。心跳还有一档 5 分钟的轻活（情绪衰减、开环到期、在场状态），不碰开口。

没有这几种叫醒，它不会自己动。它不是定时发消息——是定时「查看要不要发」。

## 3. 醒来之后走哪几步

1. **找由头**：先看有没有一件该说的事——答应过没做到的承诺 → 答应过 / 提醒过的开环 → 生活里看到的事 → 普通到期开环。都没有，就从五个缺口里挑最大的那个当方向。
2. **判**：过 12 道门（第 5 节）。不过就记一条「为什么没说」，结束。
3. **写**：过了才让模型写一句，最多 60 字，只给真实材料。材料不够，模型会回 `SILENT`——这次就不说。
4. **内容门**：写出来再查一遍——是不是一句话、有没有问号、有没有「提醒 / 播报 / 通知」腔。不过就退回一句固定的兜底话。
5. **去重**：30 天内说过一样的话（去掉标点比），不说。
6. **排队**：写进待发队列（`proactive` 表，状态 `pending`）。
7. **送**：QQ 开着就先发 QQ；没开就看「推送」开关，开着就推进最近的对话；都没有，就留在队列里，等你下次说话时她自然提起。
8. **记账**：扣额度、记这个方向的成绩、记一条事件。

**一次真实走查**（例子，数字是真的）：

> 15:00 心跳。你上次说话是 12:00，隔了 3 小时。关系缺口 0.24，够 D2 的门槛 0.15；近 7 天她发了 2 句，打扰成本算出来 0.25；劲头 0.31 > 0.25，过。
> 模型写了一句「主人，你上午说的那件事我记着了」。内容门过：一句话、没问号。去重没撞。入队。
> QQ 开着，直接发到你手机上。库里留一条：说了、什么由头、12 道门各是什么、劲头 0.31 对成本 0.25。

## 4. 素材从哪来

**别人递给它的：**

| 东西 | 谁给 | 缺了会怎样 |
|---|---|---|
| 是哪一个她 | 宿主 | 判不了，直接回 |
| 是不是你叫她 | 你 / 心跳 | 默认不是；手动时更宽松 |
| 现在几点 | 调用方 | 用当前时间 |
| 有没有事由 | 它自己找（见下） | 没由头就只靠缺口 |

**它自己翻的：**

| 它看什么 | 从哪来 | 多久算新鲜 | 缺了会怎样 |
|---|---|---|---|
| 醒着没有、上次说话 | 她的档案 | 实时 | 睡着就一句不说 |
| 开关、每天几句、要沉默多久、安静段 | 她的偏好 | 你改就变 | 用默认：每天 1 句、6 小时、23:30–07:30 |
| 五个缺口、档位 | 驱力 | 实时 | 没缺口 = 「没什么想说」 |
| 情绪、气头 | 情绪 | 实时 | 不判气头 |
| 性格（外向等） | 鱼格 | 慢变 | 用中性值 |
| 关系主动性 | 关系 | 实时 | 用中性值 |
| 今天说几句、试几次 | 开口自己的账 | 当天 | 都当 0 |
| 近 7 天发得勤不勤、近 30 天忽略率 | 开口自己的账 | 滚动 | 成本只算基础那 0.2 |
| 手头几条真事 | 记忆（**只数条数，不读正文**） | 近 3 天新增 | 要真事的方向就不说 |
| 额度 | 预算账 | 当天归零 | 用日 2 句 / 月 30 兜底 |

**它不看什么：** 你这一轮说了什么、聊天原文、记忆正文、写出来的句子长什么样。它看的是「状态」，不是「对话」。

这也是为什么它不会因为你刚夸了它一句，就立刻凑上来——那不在它看的范围里。

## 5. 它怎么判断

就两个问题。

### 问题一：有没有由头？（想要吗）

- **五个缺口**：关系 / 探索 / 贡献 / 自主 / 安全，各自「想要 − 现在」，最大那个过了门槛才算。门槛看档位：D0 基本不开口，越急门槛越松。
- **或者有事由**：答应过没做到的承诺 > 答应过 / 提醒过的开环 > 生活里看到的事 > 普通到期开环。有事由可以越过「今天说过了」——只越过这一条，别的安全闸照旧。
- 都没有 → 「它现在哪儿都不缺，不勉强找话说。」

### 问题二：现在合不合适？（会烦到你吗）

按顺序过这些关：

1. **它醒着吗**：暂停 / 休眠 → 不说。
2. **开关开了吗**：关着，或每天上限是 0 → 不说。
3. **在气头上吗**：火气明显超过那条线 → 不先开口。
4. **这个方向今天说过吗、在冷却吗**：说过 → 换方向；两次没被接住 → 这个方向先冷一阵。
5. **要真事的方向，手头有料吗**：探索 / 贡献 / 安全这几维要真事，没有就不编。
6. **沉默够久吗**：默认要等几个钟头；外向的人等得短一点，被忽略得多的人等得久一点。
7. **现在是安静段吗**：默认半夜到清早，不吵你。
8. **今天的额度用完了吗**：每天有固定句数，月度还有兜底。有真事的开口算便宜，纯凑数算贵。
9. **劲头压得过打扰成本吗**（最像人的一条）：
   - 劲头 = 缺口 + 真事 + 隔了多久，再乘性格和心情；
   - 打扰成本 = 基础一笔 + 最近发得勤 + 最近你老不回；
   - 劲头不够 → 先不说。
10. **句子写出来，过内容门**：一句话、不追问、不用提醒腔。

前四道是**硬闸**：一道不过直接回，不再往下算。后面几道一次算完，最后按固定顺序挑第一条「该说的理由」当结论。

**一个反例**：你三天没理她，她很想说——但近 30 天她发的消息你一条没回，忽略率把成本抬得很高，劲儿不够，她会憋着。这是故意的：越没被接住，越不该追着说。

## 6. 它交出什么

| 层 | 长什么样 | 落在哪 | 谁接 |
|---|---|---|---|
| ① 判断 | 说 / 不说 + 原因 + 12 道门 + 方向 + 劲头 / 成本 + 一句人话解释 + 当时输入的快照 | `proactive_decisions` | 面板、你、以后回放 |
| ② 句子 | 一句不超过 60 字的话，或 `SILENT`（没话说） | 内存里 | 下一步 |
| ③ 排队 | 那句话 + 方向 + 理由 | `proactive`（`pending`） | 推送 / 下次对话 |
| ④ 送达 | 真发到 QQ / 推进当前对话 / 聊天里被带出来 | QQ、会话 | 你 |

**你能感知到的只有第 ④ 层。** 前面三层留在库里，出问题时才去看。

**它不说的情况**（你看到「没动静」，大概率是这里）：

- 今天说满了，或这个月的兜底到了；
- 在安静段（半夜）；
- 劲儿没压过打扰成本（最近发太多、你老不回）；
- 没有由头，缺口也不够；
- 要真事的维度，手头没料；
- 在气头上；
- 30 天内说过一样的话；
- 模型看了材料，回 `SILENT`（觉得没什么值得说）；
- 写出来没过内容门，退回兜底句——这时会说，但话会比较干。

## 7. 它什么时候会错

| 现象 | 可能是 | 现在怎么办 |
|---|---|---|
| 一整天没动静 | 没由头 / 额度用完 / 安静段 / 劲儿不够 | 看最新一条判断的「原因」；多半是 `no_intent` 或 `low_benefit`，属于正常 |
| 说了句很干的话 | 模型没给出可用的句子，退回了兜底句（`source=rules`） | 看判断记录里的「来源」；这是设计好的兜底，不是坏 |
| 同一件事反复提 | 开环没被标「已提过」；去重只比句子文本，换个说法就挡不住 | 查那条开环的状态 |
| 半夜还是收到了 | 安静段没开，或这次是手动的 | 看偏好里的安静段；手动会绕过安静段 |
| QQ 没收到 | `qq.push.enable` 没开 / 目标没填 / 桥没连上 | 看 `hook.log` 里的 `qq-push-skip` |

## 8. 怎么知道它活着

- **面板**：自修改 → 零件盒 → 主动开口，展开能看到最近一次判断的理由、12 道门、劲头 / 成本。
- **表**：`proactive_decisions` 最新一条。`will=1` 且 `reason=ok` 是说了；其余是没说，以及为什么。
- **日志**：`hook.log` 搜 `push-ok` / `push-skip` / `qq-push`。
- **零件还完整吗**：`node scripts/check-parts.mjs`。查文件在不在、考卷在不在、可换零件有没有回退点、零件有没有反向 import 宿主——全绿才算零件还立着。
- **正常长什么样**：一天 0–2 条，原因多为 `ok` 或 `no_intent`。如果连续好几天 `ok`、你都没回，说明「怕打扰」的权重该调了。

## 9. 换它要付什么

- **能动**：门槛、权重、气头线、安静段、额度、事由的先后——都是数字和顺序。
- **不能动**：12 道门的结构。拆了，解释和门就对不上，出问题查不出来。
- **考卷**：`test/exam-speak.test.mjs`，21 道，现在 21/21。
- **回退点**：`speak-before-swap`（11-04 打的，当时判断还在 `features.js`；现在判断搬进了 `parts/speak/`，这个点不能一键退到现在的结构，真要回退先定怎么退）。
- **换完记一笔**：改了哪段因果、考卷分、谁批的、回退点在哪；记进零件盒那一行。

## 10. 这页造的词

| 这页说 | 代码里叫 | 一句话 |
|---|---|---|
| 由头 | `trigger` | 一件「该说的事」：承诺、开环、生活分享 |
| 缺口 | `deficit` | 五个方向「想要 − 现在」的差 |
| 劲头 | `benefit` | 有多想说 |
| 打扰成本 | `cost` | 说这一句有多打扰你 |
| 额度 | 日 / 月 `disturb_limit` | 今天 / 这个月还能说几句 |
| 安静段 | `quiet` / `quiet_from` / `quiet_to` | 半夜不吵你 |
| 冷却 | `cooldown_until` | 这个方向两次没被接住，先别提 |
| 气头 | `temper` | 正在气头上，不先开口 |
| 真事 | `evidence` | 手头能引用的具体材料 |
| 判定 | `proactive_decisions` 一行 | 一次「说 / 不说」的完整记录 |

| # | 门 | 查什么 | 没过时 `reason` |

## 附 C · 零件由哪些文件组成

- 零件内：`src/parts/speak/` 的 index（入口 / 编排）、judge（判断）、trigger（事由）、budget（额度）、prefs（偏好）、compose（生成）、store（落库 / 查询）、hooks（模型与测试钩子）。
- 零件外：情绪、驱力、人格轴、关系主动性、开环、模型、记忆、参数、flags、事件、预算服务——只 import 公开函数，不搬内部。
- 表归口：`proactive` / `proactive_decisions` / `proactive_stats` 归开口；`open_loops` / `budgets` / `flags` 是共享表。
- 对外一个口：`runSpeakTick`（宿主心跳调它）；零件里不再有第二套入口。
- 界桩：`scripts/check-parts.mjs` 查四件事（文件存在、考卷存在、可换要有回退点、零件不许反向 import 宿主薄壳 `features.js`），已全绿。

## 附 D · 11-05 改了什么（只留结论，来历在工程件）

1. 到期的事一律破例：只越过「今天说过了」这一条；气头 / 安静 / 开关 / 休眠 / 预算照旧。
2. 气头线从 0.7 降到 0.68（「中间偏晚一点」）。
3. 「她特别看重的事」由她自己标、自己撤，不用分数。
4. 手动叫她可以拒绝，并给「大概安静多久」的钟头数。
5. 每次判断都把当时的输入存快照，留给以后回放。
6. 开口整条收拢成一个零件（`src/parts/speak/`），对外一个口 `runSpeakTick`；宿主薄壳只剩转发，共享件只 import 不搬。
