# 零件 · 三观账本（sgledger）

> 这页给主人看：一句命题怎么记下，清空之后能不能原样重放。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；工程件：`ledger.js`、`events.js`、`fold.js`、`projection.js`，考卷 `test/exam-sgledger.test.mjs`。

## 1. 一句话 + 一个比喻

它管「认下的话记在哪、重放还在不在」；不管什么时候长出新句子，也不管哪几句进这一轮的话。

像一本只许往后写的账。写错整笔记不上；本子烧了，可以按流水一张张抄回来。

真的对应到哪：事件流水，加上由流水折出来的现在状态。

## 2. 它什么时候醒（触发）

| 谁叫它 | 多久 | 醒来做什么 |
|---|---|---|
| 快环、夜巡、升维 | 有一句要入账的时候 | 追加一批事件 |
| 注入、页面 | 要看现在认着哪些话 | 读链头，或按序号看某一刻 |
| 对账的人 | 怀疑投影和流水不一致 | 清空投影，按流水重放 |

它没有自己的定时器。没人送来事件，账本不动。

## 3. 醒来之后走哪几步

1. 批次是空的，当场拒绝，一行都不写。
2. 形状不对，整批回滚。
3. 形状对了，事件写进流水，带出的命题写进实体表。
4. 用同一套折叠，把流水收成现在的状态，落一份投影。
5. 投影可以整份删掉再重放。重放用的还是那条流水。

## 4. 素材从哪来（输入）

| 人话名 | 从哪来 | 缺了会怎样 |
|---|---|---|
| 一批事件 | 调用方递的类型、层、谁写的、时间、内容 | 空的、类型不认识的，整批拒绝 |
| 已经写下的流水 | `claim_events` | 没有就当空账 |
| 幂等键 | 只有「这件事做过了」那种事件能带 | 别的事件带了就拒绝；同一把钥匙再来一次也拒绝 |

它不看什么：不看这轮对话，不调用模型，不决定注不注。

## 5. 它怎么判断（判据）

它其实只问两句：这批事件长得对不对，以及折完之后账还平不平。

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 这批能不能记 | 非空、类型和层对得上 | 整批不写 |
| 这把钥匙用过没有 | 没做过 | 做过就拒绝，不写第二遍 |
| 折完还平不平 | 没有一条结构性违规 | 重放时直接报，不把坏投影留下 |

反例：同一把幂等钥匙送两次。第一笔在，第二笔被拒，账上不会出现两笔同样的「做过了」。

## 6. 它交出什么（输出）

| 层 | 长什么样 | 谁接 |
|---|---|---|
| 这批写下的序号和实体号 | 一批 id | 送事件来的那一方 |
| 流水 | 按序号排的事件 | 重放、对某一刻的查看 |
| 链头 | 现在还有效的命题，带原文 | 注入、页面 |
| 某一刻的状态 | 只在内存里，不另写一份 | 要回看的人 |

你能看见的是三观页上的句子。那些句子是投影，流水才是账。

不交出新句子的情况：批次是空的、形状不对、钥匙重复。环没把句子送进来时，账本自己不会编一句。

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 页上的句子和流水对不上 | 投影是算出来的缓存 | 清空重放，不手改投影 |
| 第二笔「做过了」没写上 | 同一把幂等钥匙 | 这是故意的 |
| 重放报账不平 | 流水被外面改过，或折叠规则和写下时不一致 | 先看违规那几条，不把坏投影留下 |

## 8. 怎么知道它活着（观察点）

- 流水在 `claim_events`，句子原文在 `persona_claims`，现在的状态在 `claim_proj_claim`。
- 考卷 8 道，临时库里写一句再重放，不碰活人的账。

现在就能看：`node test/exam-sgledger.test.mjs`。

## 9. 换它要付什么（代价）

- **能动**：折叠时哪一种迁移算非法、投影怎么落盘。
- **不能动**：快环、夜巡、注入。那是三观环，这次不在这件里。这四个文件别删，环还在调。
- **考卷**：`test/exam-sgledger.test.mjs`，8 道，现在 8/8。
- **回退点**：`sgledger-before-part`。
- **换完记在哪**：`parts.js` 的 `swaps`。
