# 零件 · 归档（archive）

> 这页给主人看：只增不减的那几本底账是怎么记的。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；工程件：`src/modules/archive.js`，考卷 `test/exam-archive.test.mjs`。

## 1. 一句话 + 一个比喻

它管四本「只进不出」的底账：原话（T4）、事实出生照（FA）、纪要（T2）、日记（T3）。它不管抽屉怎么写字条——那是记忆存储的事。

像档案室的四个柜子：原话柜按轮次一格一格放，只进不出；出生照柜一条记忆只拍一张；纪要柜按「一段」放，重跑就换这张不另开格；日记柜一天一格。

真的对应到哪：`raw_turns` / `fact_archive` / `episodes` / `diaries` 四组表，加两个检索索引。

## 2. 它什么时候醒（触发）

| 谁叫它 | 多久 | 醒来做什么 |
|---|---|---|
| 对话落库 | 每轮 | `appendTurn` 存原话 |
| 记忆出生 | 每写一条记忆 | `archiveFact` 拍出生照 |
| 夜里 | 每晚 | `buildEpisode` 压纪要、`buildDiary` 写日记 |
| 手动 / 修复 | 需要时 | 重建索引、补轮次号 |

它没有自己的定时器。

## 3. 醒来之后走哪几步

1. 原话：空文本不写；同一轮同一角色只算一条；没轮次号就按「三秒内同句」算重放；写进去顺手进检索索引。
2. 出生照：一条记忆只拍一次（按 `memory_id` 认），正文、类型、重要度、feel 的 id 一起留下。
3. 纪要：从一段原话（会话或某天）压出标题、摘要、待续、重要度；同一段重跑是更新，不新建。
4. 日记：夜里写成一天一篇；读口按天取。
5. 索引：原文索引和出生照索引清掉后能按表重建。

## 4. 素材从哪来（输入）

| 人话名 | 从哪来 | 缺了会怎样 |
|---|---|---|
| 原话 | 对话落库时一句一句给 | 空文本不写 |
| 轮次号 / 会话 | 调用方给 | 没有轮次号就按三秒重放去重 |
| 记忆正文 | 记忆存储写成功之后 | 没有记忆 id 就不拍出生照 |
| 时段 | 会话或某一天 | 都没有就报错 |
| 日记文本 | 模型夜里写 | 没写就没有那天的日记 |

它不看什么：不判断该不该记、不做衰减、不做召回；只负责把「发生过什么」原样留住。

## 5. 它怎么判断（判据）

它其实只问两个问题：这条是不是已经存过了？这一段是不是已经压过了？

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 原话来过没有 | 同轮次号同角色；没号就看三秒内同句 | 返回旧的，不新建 |
| 出生照拍过没有 | 同一个 `memory_id` | 返回旧照片，不重拍 |
| 纪要压过没有 | 同一会话同一天 | 更新旧纪要，重要度取高的 |

反例：同一句话在相邻两轮说了两遍，为什么只存一条——只有「同一轮次号」才会去重；不同轮次是两句真话，都会留。

## 6. 它交出什么（输出）

| 层 | 长什么样 | 谁接 |
|---|---|---|
| 原话 | `raw_turns` 一行 + `raw_fts` | 深查、倒查、纪要 |
| 出生照 | `fact_archive` 一行 + `fact_fts` | 回溯「当初怎么记的」 |
| 纪要 | `episodes` 一行（标题 / 摘要 / 待续 / 轮数） | 召回 |
| 日记 | `diaries` 一行（一天一篇） | 召回、自视 |

不写的情况：空文本；同轮重放；同一条记忆的第二次出生照；同一段纪要的第二次新建。

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 同一句「好」被吃掉 | 以前按文本去重 | 现在有轮次号就按轮，不按文本 |
| 重放写两条 | 没有轮次号 | 三秒窗口兜底 |
| 出生照越拍越多 | 没有按记忆 id 认 | 一条只拍一张 |
| 索引坏了查不到 | 建表时没建 FTS | 两个 rebuild 能补 |

## 8. 怎么知道它活着（观察点）

- `raw_turns` 的 seq 在涨、`raw_fts` 条数对得上。
- `fact_archive` 条数和抽屉里的活跃条数大致对得上。
- `episodes` 每天/每段在更新；`diaries` 一天一篇。
- 重建索引前后条数一致。

现在就能看：查 `raw_turns` 最近几条，或看 `diaries` 有没有当天那篇。

## 9. 换它要付什么（代价）

- **能动**：去重窗口、纪要生成规则、日记提示词、索引重建。
- **不能动**：抽屉的写入口（记忆存储）、衰减（冷暖）、召回（召回）。
- **考卷**：`test/exam-archive.test.mjs`，31 道，现在 31/31。
- **回退点**：`archive-before-part`。
- **换完记在哪**：`parts.js` 的 `swaps`，外加一份 `docs/活论证-归档-<日期>.md`。
