# 微信收信（不是零件，是接线）

> 这页给人看：微信上别人说的话，怎么变成她自己的账。
> 工程件：`src/modules/wechat_inbox.js`（水位 / 防重 / 落账）+ `scripts/wechat-inbox.py`（只读本地库）；
> 宿主接线：`index.js` 的 `startWeChatInboxWorker`；考卷 `test/exam-wechat-inbox.test.mjs`。

## 1. 一句话

微信没有像 QQ 那样的推送口子，只能自己看本地库：每 60 秒读一次「比水位新的消息」，记进 `chat_turns`（这段会话的账）和 `raw_turns`（原文层）。

## 2. 为什么读库不读窗口

微信 4.x 的聊天界面是自绘的，UIA 冷启动只给 `Qt51514QWindowIcon` 空壳，实测 **0 个控件**；本地库能解密（wechatauto-replica），按会话读得到。读库一次都不点窗口，也不抢焦点——收信不该打扰她。

## 3. 走哪几步

1. 找一个**真装了 wechatauto 的 Python**（机器上 3.14 在 PATH 前面、包却在 3.12，不能只认 `python`）。
2. 起 `scripts/wechat-inbox.py`：列最近有消息的会话 → 按 `sort_seq` 水位筛新消息 → 非文本给占位符 → 系统消息（加好友、撤回）直接丢。
3. 回 Node：按会话去重落账，`role` 是 `user`（对方）或 `agent`（她自己）。
4. 水位推进到这一批最新的 `sort_seq`，存 `flags` 的 `wechat:inbox:<username>`。

## 4. 判据

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 这条是不是新的 | `sort_seq > 水位` | 跳过 |
| 第一次见到的会话 | 只落水位、不灌历史 | 接上那天不会把几年旧消息吞进来 |
| 是不是自己刚发的 | 同会话、`agent`、同文本、10 分钟内已在账上 | 跳过（发信那边记过了） |
| 是不是人说的话 | 类型不是系统消息 / 撤回 | 跳过 |
| 读不到库 | 没装后端 / 微信没开 / 没密钥 | 如实返回原因，退避 10 分钟再试 |
| 是不是主人号 | `qq.owner` 里（逗号分隔，可以有 QQ 号和微信号） | 不是主人：只记账、不回话 |

## 5. 主人号：收到就回

主人说的话不走「只记账」那条：交给 `chatReply` 走完整管线（召回 → 情绪 → 回一句 → 记对话 / 原文 / 关系），再把这句话发回微信。所以同一条话只有一份账——它记了，收信这边就不许再记。

发不出去就吞掉（话已经记了），下一条再说；回调抛错 / 返回 false 时退回普通记账，话不能丢。

## 5.1 回话之前先「正在输入」

微信不给第三方打字状态：对方看到的那行「正在输入」，只跟输入框里真的有人在打字有关。所以这件事只能演真——真在她的输入框里打草稿：

1. 收到主人消息，立刻起 `scripts/wechat-typing.py`：打开会话、往输入框里打一个「…」；
2. 每 2.5 秒改一次草稿，让打字状态不掉；
3. 回复生成好，写进 `wait_file`，脚本整句覆盖草稿、停 `lead_ms`、回车；
4. 任何一步失败都要清草稿；实在打不进去就退回普通发送——「正在输入」没演成，话也不能丢。

开关在 `action_config`：`wechat.typing.enable`（默认开）、`wechat.typing.lead_ms`（默认 1200）。

**实测（2026-11-07 凌晨）**：草稿能打进、能保持；但正式回复那一下打不进去（窗口焦点在多次重试里丢了），所以那两次都退回了普通发送。消息是发出去的，只是「正在输入」还没真的演成——这一条还要再调。

## 6. 赌注（知道就行）

- **陌生人也会进原文层**：只有「跳过名单」里的会话不收。晚上的纪要按会话生成，所以陌生人的一句「我是谁啊」可能出现在某天的场景里——这是真事，不是拿主人的记忆冒充。
- **主人号是登记的**：`qq.owner` 里一串号，谁在名单里谁就是主人。换号 / 加号要记得改，不然会被当陌生人（只记不回）。
- **第一次见到的主人会话**：最后一句在 2 小时内就把那句接住；更旧的不回（接上那天不翻旧账）。

## 7. 观察点

- `flags` 里的 `wechat:inbox:*`（水位）。
- `chat_turns.conversation_id` 以 `wechat:` 开头的行。
- 日志：`wechat-inbox(...) added=N chats=...` / `wechat-reply(名字) sent chars=N` / `wechat-inbox-skip: <原因>`。

## 8. 换它要付什么

- 配置在 `action_config`：`wechat.inbox.enable`（默认开）、`wechat.inbox.skip`（默认 `weixin`）、`wechat.inbox.limit`（默认 40）。
- 轮询间隔写死在 `startWeChatInboxWorker`（60 秒）；读不到时退避 10 分钟。
- 考卷：`npm run exam:wechat`，23 道。
