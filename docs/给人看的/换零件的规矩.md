# 换零件的规矩

> 这页给主人看：什么时候能换、换完盯多久、要交什么证据。词以[术语表](术语表-2026-11-05.md)为准。
> 一页管三件事：变更预算、观察期、活论证。数字是 2026-11-05 先定的一版，觉得紧了松了就说。

## 一、变更预算：一次一个，不抢跑

| 规矩 | 数 | 为什么 |
|---|---|---|
| 一个零件多久最多换一次 | **7 天 1 次** | 防改来改去、来回摆 |
| 换完盯多久 | **3 天** | 观察期内不改它，让状态扰动跑出来 |
| 连续翻几次就停 | **2 次** | 两次翻车，这个零件冷 **7 天**，先查根因 |
| 一个工作区几个写手 | **1 个** | 两个写手会互相踩 |
| 一次换几个零件 | **1 个** | 出问题能指回是哪次换的 |

**翻车** = 考卷掉分 / 全量红 / 回退点用不了 / 事实编了，任一就算。翻车一律先回退，再谈为什么。

## 二、活论证：每次换一份，一页

不是一次性文档，是随每次换更新的一份「主张-证据-反驳」：

- **主张**：这次换，哪里更真？一句话。
- **证据**：考卷分、全量回归、状态扰动、打假结果。
- **反驳**：什么情况下算被推翻？至少写四条——改判据让考卷变绿、状态扰动不跟、回退点不能用、事实编了。
- **结论**：换 / 不换 / 再观察；谁批的、回退点在哪。

每次换新建一页 `docs/活论证-<零件>-<日期>.md`，旧的不改，留着对照。观察期结束，在同一页补一行观察结果。

## 三、记录在哪

- 零件册那一行：`swaps` 写「从什么换成什么、为什么、考卷分、谁批的」；`rollback.pointer` 写回退点，`note` 写回退命令。
- 活论证页：`docs/活论证-<零件>-<日期>.md`。
- 零件盒：点开那一行能看到上面两样。
