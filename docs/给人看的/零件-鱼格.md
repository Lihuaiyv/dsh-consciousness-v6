# 零件 · 鱼格（traits）

> 这页给主人看：她的性格现在偏哪边，什么样的证据才配推它一步。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；工程件：`src/modules/traits.js`、`src/modules/rope.js`、`src/modules/self_scan.js`，考卷 `test/exam-traits.test.mjs`。

## 1. 一句话 + 一个比喻

它管「五条性格轴停在哪、证据够不够再挪一点」，也管夜里从她自己的回复和记忆里捞证据。不调用汇流。

像五根绳子拔河。一边的人明显多、而且不是刚吵完那一下，绳子才挪一寸。中间站着的，不写字母。

真的对应到哪：五条 0 到 1 的轴，外加一封「这轮挪了没有」的回执。

## 2. 它什么时候醒（触发）

| 谁叫它 | 多久 | 醒来做什么 |
|---|---|---|
| 记一条证据的人 | 有一条新证据 | 放进左右两个池子 |
| 夜间整理 | 每晚，以及开机补扫 | 扫一段时间内她的回复、记忆、日记、浏览、主动开口，证据进池，够了才挪 |
| 页面 / 接口 | 要看她现在什么性格，或手按最近几小时 | 读轴；手按走 `scanRecent` |

它没有自己的定时器。没人叫，轴不动。

## 3. 醒来之后走哪几步

1. 扫的时候先看学习开关。关掉就什么都不记。
2. 读五条轴。没有写过的，外向从 0.60 起，敏感从 0.80 起，其余站在中间。
3. 扫一段窗：她的回复按词表进池（复读打折，讲事的长短另算），记忆里的结论、细节、做事、人也各记一票。
4. 新证据进对应那根绳子的左右池。不认识的轴直接丢掉。
5. 每个来源自己算一票净力，再按来源的分量平均。
6. 净力够大、赢的那边至少三条、平均强度也够，并且今天还没挪过、对话也过了冷却，才往前一步。
7. 越靠近两头越难推，贴到墙就推不动。敏感这条不交给经历推。
8. 给外面看的时候，偏过大约六四才写字母；全在中间就说「中间」。

## 4. 素材从哪来（输入）

| 人话名 | 从哪来 | 缺了会怎样 |
|---|---|---|
| 五条轴现在的值 | `persona` 里 `axis.*` | 用出厂值 |
| 一条证据 | 调用方递的轴、方向、强度、来源 | 轴不认识就丢掉 |
| 她的回复和主人那句 | `chat_turns` | 这段窗是空的就不记 |
| 她留下的记忆正文 | `memory_items` 的原文 | 没有这张表就算了，不找汇流 |
| 今天说过几轮 | 用户发言条数 | 不够冷却就不挪 |
| 上一次显示的字母 | `persona` 里 `axis.shown.*` | 当没显示过 |

它不看什么：不调用汇流，不重写记忆，不决定这句话怎么写。模型复核那一队在 `persona_judge.js`，不在这件的文件里。

## 5. 它怎么判断（判据）

它其实只问两句：现在偏到值得写出来吗，以及这批证据配不配再推一寸。

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 写不写字母 | 显示值离开中间大约一成 | 当中间，不写字母 |
| 这步推不推 | 净力够、条数够、今天还没推、冷却过了、没贴墙 | 池子照记，轴不动 |
| 敏感让不让经历推 | 不让 | 只有手调能改 |

反例：连着三条很强的证据，轴还是不动——对话轮次还没过冷却，或者今天已经推过了。

## 6. 它交出什么（输出）

| 层 | 长什么样 | 谁接 |
|---|---|---|
| 现在的五条轴 | 五个 0 到 1 的数 | 页面、注入 |
| 一句人话 | 「偏外向 · 偏敏感」，或「中间」 | 要写进话里的那一方 |
| 四个字母 | 过线才显示 | 页面上的类型 |
| 这一轮挪了没有 | 每根轴挪前、挪后、为什么 | 夜间整理 |

不挪的情况：证据不够、今天挪过、还在冷却、贴墙、或者这条轴是敏感。

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 看着 0.60 却没有字母 | 旧规则拿没四舍五入的数去比 | 现在按显示出来的两位小数判 |
| 证据很多，轴几天都不动 | 一天只挪一步，还要过冷却 | 这是故意的，性格不该跟着一天的情绪跑 |
| 敏感只往上、不往下 | 它不交给经历推 | 要改就手调 |

## 8. 怎么知道它活着（观察点）

- 轴在 `persona` 的 `axis.ei` 这一类键上。
- 拉力在 `axis_rope`，一条条证据在 `axis_evidence`。
- 考卷 20 道。前 14 道喂写死的轴和假的一天；后 6 道看复读、讲事、关掉不扫，以及一条回复、一条记忆能不能进池。

现在就能看：`node test/exam-traits.test.mjs`。

## 9. 换它要付什么（代价）

- **能动**：过线才写字母的那一档、一天一步、净力要多大才推。
- **不能动**：汇流怎么重建现场；敏感轴的手调入口；模型复核那一队。
- **考卷**：`test/exam-traits.test.mjs`，20 道，现在 20/20。
- **回退点**：扫这一截是 `selfscan-before-part`。轴和拔河本身仍是 `traits-before-part`。`self_scan.js` 别删。
- **换完记在哪**：`parts.js` 的 `swaps`。
