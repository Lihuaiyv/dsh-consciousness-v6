# 零件 · 验收（eval）

> 这页给主人看：体检单怎么打分，缺数据时为什么不给绿灯。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；工程件：`src/modules/eval.js`，考卷 `test/exam-eval.test.mjs`。

## 1. 一句话 + 一个比喻

它管「这几项过不过线」；不管治，也不改她说话。

像一张体检单。没抽到血，那一格就空着，不能写成正常。

真的对应到哪：八条门槛，外加「要不要把衰减调快一点」的一条建议。

## 2. 它什么时候醒（触发）

| 谁叫它 | 多久 | 醒来做什么 |
|---|---|---|
| 指标采样 | 记一笔近况的时候 | 把能算的几格填上 |
| 你打开验收页 | 你按的时候 | 跑硬门槛、同一性，或看标定建议 |
| 你按「应用标定」 | 你确认的时候 | 只改那一个衰减参数，并留一条变更 |

它没有自己的定时器。没人叫，单子不动。

## 3. 醒来之后走哪几步

1. 召回和情绪：先看有没有够新、够多的校准记录。没有，这两格空着。
2. 价值观：看近一段时间改了多少，取最大的那一笔。
3. 同一性：手写区里称呼、口头禅、禁用词、语气，凑不齐两样，就不打分。
4. 八条门槛逐条对。缺数的记成「还不知道」，不算过。
5. 情绪强度太高，才建议把衰减调快一档。不是主人，按不下去。

## 4. 素材从哪来（输入）

| 人话名 | 从哪来 | 缺了会怎样 |
|---|---|---|
| 校准记录 | `flags` 里这一个人的校准 | 召回和情绪空着 |
| 价值观变更 | `changes` | 漂移记 0 |
| 手写的称呼和语气 | 人格卡 | 同一性不打分 |
| 注入有多慢 | `metric_samples` | 延迟这格空着 |
| 提案做过影子没有 | `proposals` | 没有提案时，这一格按盖住了算 |
| 现在的情绪强度 | `affect_state` | 不提标定建议 |

它不看什么：不改记忆，不重写汇流，不决定这句话怎么说。

## 5. 它怎么判断（判据）

它其实只问两句：这一格有没有数，以及这个数过没过线。

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 召回命中够不够 | 大约七成以上 | 这道红 |
| 误召回高不高 | 大约一成半以内 | 这道红 |
| 同一性像不像她 | 大约八成以上，而且线索够 | 线索不够就不打分 |
| 价值观漂了多少 | 大约一成以内 | 这道红 |
| 情绪标签稳不稳 | 大约六成以上的一致 | 没校准就不打分 |
| 整张单过不过 | 八格都有数，而且没有红的 | 缺一格也不算过 |

反例：召回命中只有一半。别的能算的都过了，整张单仍然不算过，命中这一道是红的。

## 6. 它交出什么（输出）

| 层 | 长什么样 | 谁接 |
|---|---|---|
| 每一格的数 | 有数，或者空 | 指标采样、验收页 |
| 八条的红绿 | 过 / 不过 / 还不知道 | 验收页 |
| 一条建议 | 衰减从现在的值再快一档 | 你看完再决定 |
| 一条变更 | 按下去才写入 | 变更记录 |

你能看见的是验收页上的格子。说话本身不走这张单。

不给绿灯的情况：没校准、人还太新、手写区太空、还有格子是空的。

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 验收页上一格是空的 | 没跑过校准，或样本过期 | 空着，不填成 0 |
| 刚建的人，轴动没动先没结论 | 出生还不到大约一个月 | 不把「没动」当成断了 |
| 从没提过案，影子那格却是满的 | 没有提案时按盖住了算 | 这是故意的，避免空账本被判红 |
| 按标定没反应 | 当前不是主人 | 只有主人能按 |

## 8. 怎么知道它活着（观察点）

- 验收页上的八格，和指标里的召回、漂移、同一性。
- 标定按下去之后，`changes` 里多一条来源是标定的记录。
- 考卷 15 道，喂的是临时库和写死的数，不动活人的库。

现在就能看：`node test/exam-eval.test.mjs`。

## 9. 换它要付什么（代价）

- **能动**：某一条门槛的线、标定往上加多少。
- **不能动**：谁可以按下去；缺数据不许填成过。`eval.js` 别删，验收页还在用。
- **考卷**：`test/exam-eval.test.mjs`，15 道，现在 15/15。
- **回退点**：`eval-before-part`。
- **换完记在哪**：`parts.js` 的 `swaps`。
