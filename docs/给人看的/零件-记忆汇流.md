# 零件 · 记忆汇流（confluence）

> 这页给主人看：它怎么把「某一刻的现场」重新拼出来，又不把现在弄脏。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；工程件：`src/modules/confluence.js` + `src/modules/visibility.js`，考卷 `test/confluence.test.mjs`。
> 设计地基：[汇流-基石-2026-11-09.md](../archive/2026-11-07_09/汇流-基石-2026-11-09.md)。

## 1. 一句话 + 一个比喻

它管一件事：**把某个过去时刻的现场，只读地拼成一小包**——时间、原话、当时算数的记忆、当时的情绪 / 关系 / 驱力，然后交给上层，让「现在的我」站进去说一句。

像时空胶囊：装的是那一刻的空气，不是那一刻的人。打开之后你还是现在的你，只是手里多了一段当时的味道。

真的对应到哪：`reconstructScene`（拼包）→ `runConfluence`（拼成一段可注入的文字）→ `confluence_log`（落账），另加 `state_scene` / `scene_archive` 两个留底柜。

## 2. 它什么时候醒（触发）

| 谁叫它 | 多久 | 醒来做什么 |
|---|---|---|
| 主人说「回到那天」 | 手动 | 拼一份现场包，默认 L1 |
| 她自己「想起」 | 心跳空档、水位没满 | 默认 L0，最多 L1（P4，尚未接） |
| 写截面 | 每轮一条轻的 / 每 20 轮一条重的 | 冻住当时的状态（P1，尚未接） |
| 问起过去 | 主人明确问 | 走 asof 出证，不走它 |

它没有自己的定时器。**没有“自动巡游”**——定时扫全库就是第二个背景音。

## 3. 醒来之后走哪几步

1. **定档**：L0 想起 / L1 回到（默认）/ L2 沉进去（手动）。档位决定窗口和预算。
2. **选锚**：同一天里离目标时刻最近的一句真话（系统噪声不算）。
3. **划窗**：同会话 ±N 轮；每轮记 `gap_min`（沉默也是现场）。
4. **投影**：按那一刻取情绪、驱力、关系、生活、开环、对方状态。全部只读。
5. **打包 + 标注**：每个字段带时刻；缺失项进 `labels.missing`，不编。
6. **说**：拼成一段带三条硬规则的文字，超预算从窗口尾巴裁、再裁记忆尾巴。
7. **落账**：`confluence_log` 一行；另落一条 `revisit`（这次想起），**不改旧条**。

## 4. 素材从哪来（输入）

| 人话名 | 从哪来 | 缺了会怎样 |
|---|---|---|
| 原话 | `raw_turns`（按 `session_id + seq`） | 那一天没对话 → 拒绝重建 |
| 记忆 | `memory_items` 按 `source_turn_id` 回链 | 回不到就按窗口时间兜底，标记 `via=window` |
| 原话节选 | `memory_provenance.quote` | 现在只覆盖 4.5%，缺了只在报告里标 |
| 记忆落点 | `fact_archive` / `memory_items.source_turn_id` | 落点 `none` 会写进 missing |
| 情绪 | `events` 的 `affect.appraised` | 取不到就 null（**不许拿现在顶**） |
| 驱力 | `events` 的 `drive.evaluated` | D 有时为空，标 `drive_D` |
| 关系 | `rel_event`，只看真实事件 | 不看 `decay`（那是衰减 tick，不是事） |
| 对方状态 | `affect_user_read` | 缺了进 missing |
| 开环 / 生活 | `open_loops` / `memory_items source='life'` | 缺了只是少一段味道 |

它不看什么：不看要不要记、不做衰减、不做召回、不调模型。

## 5. 它怎么判断（判据）

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 这段是不是已经说好要忘的 | `memory_timeline` 里 HIDE / DELETE，或抽屉已软删 | 记忆与它指向的那一轮**整轮不出**；锚点被忘就直接拒绝重建 |
| 这条关系事件算不算「事」 | kind 是 utterance / appraisal / manual / correction | `decay` / `seed` 不算 |
| 情绪取哪一条 | 那一刻之前最近的一条评估 | 没有就 null，绝不拿当前状态冒充 |
| 预算够不够 | 现场包 ≤ `confluence.budget`（默认 1600） | 从窗口尾巴、记忆尾巴依次裁，裁过记 `dropped` |

反例：用户说「忘掉这件事」，但那一轮里还有别的字——**整轮都不出**。留半句比全不给更糟。

## 6. 它交出什么（输出）

| 层 | 长什么样 | 谁接 |
|---|---|---|
| 现场包 | 一个对象：锚点 / 窗口 / 记忆 / 状态 / 标注 / 预算 | 上层、测试、导出 |
| 注入段 | 一段文字，带「回到 …」抬头与三条硬规则 | 说话 / 注入 |
| 截面 | `state_scene` 一行（light / heavy 两档） | 以后回看 |
| 留底 | `scene_archive` 一行（渲染后的注入块） | L2 才用 |
| 审计 | `confluence_log` 一行 | 观测、回看 |
| 这次想起 | `revisit` 一行 | 只在「问起过去」时当证据 |

**永远不写**：`raw_turns`、`fact_archive`、`memory_timeline`。重建的东西一旦进原话层，下次汇流就会把它当「当时真的发生了」。

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 驱力那一栏是空的 | `drive.evaluated` 的 `D` 本来就是空对象 | 标 `drive_D`；要补得在评估链写完整向量 |
| 记忆一条原话都没有 | `memory_provenance` 只有 187 条（4.5%） | 标 `quote_partial`；把 quote 接进写入链 |
| 记忆落不到「那一轮」 | `fact_archive.source_turn_id` 只覆盖 66% | 落点回退到存根，报告里分开说 `hidden` 和 `no_source` |
| 关系「最近一次」是 tick | 以前没过滤 kind | 现在只看真实事件 |
| 中间隔了两小时看不出来 | 以前窗口只存文字 | 现在每轮带 `gap_min` |
| L2 拼出来并不更像 | 还没验 | L2 不排期，等 L1 跑一个月 |

## 8. 怎么知道它活着（观察点）

- 跑一次：`node scratch/e0-confluence.mjs --day 2026-11-05 --clock 15:00`，看报告里的 `missing` 和总预算。
- 预算：第一轮 505 token（L1 上限 1400），说明截面还薄。
- `confluence_log` 的行数应等于真实汇流次数；`revisit` 只增不改。
- 只读自检：考卷里对比六张表行数和 `last_decay_at`。

## 9. 换它要付什么（代价）

- **能动**：选锚顺序、窗口轮数、档位配比、预算裁剪顺序、system 段的措辞。
- **不能动**：只读边界、遗忘优先、产品不写回冷库、`revisit` 不进日常召回、asof 保持只读工具。
- **考卷**：`test/confluence.test.mjs`，56 道，现在 56/56。
- **回退点**：`confluence-before-part`。
- **换完记在哪**：`parts.js` 的 `swaps`，外加一份 `docs/活论证-记忆汇流-<日期>.md`。

## 11. 留底（P1，已接）

- **每轮**：注入块原文 → `scene_archive`（`turn_id` 上唯一，重复调用不写第二行）；轻截面 → `state_scene`（实测约 350 B）。
- **每 20 轮**：一条重截面（约 590 B）；日上限 48 条。
- **开关**：`scene.archive=off` 时一行都不写，行为与接上之前一致。
- **写入点**：系统提示拼好之后 `rememberBlock` 暂存；落轮时 `recordScene` 落库。失败一律静默，不拖慢回复。
- **一年粗算**：轻 1.75 MB + 重 0.15 MB + 注入块 10–30 MB（注入块大小取决于提示词长度）。

## 12. 手动入口（P3，已接）

- **命令**：`node scripts/confluence-scene.mjs --at "2026-11-05 15:00" [--level L0|L1|L2] [--ask "…"]`。只读打开库，不写任何表。
- **API**：`GET /v1/agents/:aid/confluence/scene?at=…&level=L1&ask=…`。只读重建，只写一条审计账（`confluence_log`）。
- **拒绝**：锚点那一轮如果已经被忘（HIDE/DELETE），直接回 `forgotten-anchor`，不重建。
- 实测：11-08 22:18 的 L1 现场包 748 / 1600 token；11-05 15:00 的 L0 只取锚点一轮。
