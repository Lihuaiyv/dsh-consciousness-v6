# 零件 · 记忆整理（consolidate）

> 这页给主人看：夜里怎么把重复的自省合成一条、把一段日子的流水压成一条结论。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；工程件：`src/modules/consolidate.js`，考卷 `test/exam-consolidate.test.mjs`。

## 1. 一句话 + 一个比喻

它管「把重复的、流水账式的记忆收成一条」，不管记忆怎么变淡、也不管白天写不写。像晚上收拾桌子：同一天的几张草稿纸合成一张，草稿退到抽屉底层——找得回来，但不再摊在桌面上。

真的对应到哪：`memory_items` 里新写一条 reflection，旧的几条 `invalid_at` + `superseded_by` 指向它。

## 2. 它什么时候醒（触发）

| 谁叫它 | 多久 | 醒来做什么 |
|---|---|---|
| 夜间整理（`nightly.js`） | 每晚 | 先合并重复自省，再看要不要压一条反思 |
| 手动跑 | 想收时 | 同一套：聚类 → 模型 → 落库 / 退场 |

它没有自己的定时器。

## 3. 醒来之后走哪几步

1. 候选：近期的 reflection（或指定类型），按相似度聚批；一批至少三条，最多六条。
2. 调模型：只让它「用这几段里有的内容」合成一条，或说「没价值」。
3. 解析：拿不到 JSON → 这一批不动。
4. 落库：新写一条 reflection，来源 `consolidate`。
5. 退场：被合并的那几条软删（`invalid_at` + `superseded_by`），默认召回不见、深查还能找回来。
6. 另一条路「反思」：把一段日子的零碎压成一条结论，只压 `importance < 0.5` 且不带未完成状态的。

## 4. 素材从哪来（输入）

| 人话名 | 从哪来 | 新鲜多久 | 缺了会怎样 |
|---|---|---|---|
| 候选记忆 | `memory_items`，active 且没退场的 | 最近 400 条里挑 | 没有就不动 |
| 相似度 | 文本去壳后的字集 Jaccard | — | 不够近就不并 |
| 模型 | 宿主全局模型 | 当次 | 没模型就不跑 |
| 游标 | `reflect_cursor`（累计重要性 / 窗口） | 长期 | 没有就从头算 |

它不看什么：已退场的记忆、别的类型（默认只看 reflection）、带未完成状态的高价值条（反思不吞事实）。

## 5. 它怎么判断（判据）

它其实只问三个问题：这几条像不像？合成一条值不值？哪几条该退场？

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 像不像 | 相似度过线、至少三条 | 不够就不送模型 |
| 值不值 | 模型给 `keep:true` + 文本 | 解析不了 / keep:false → 不动 |
| 该退谁 | 只退被合并的那几条；反思只退 `importance < 0.5` 且没有「还没 / 等…之后」 | 高价值、待办原样留着 |

反例：明明有一堆重复，为什么没合——相似度没到线，或者只有两条（不够一批）。

## 6. 它交出什么（输出）

| 层 | 长什么样 | 谁接 |
|---|---|---|
| 合并稿 | `memory_items`，reflection，`source='consolidate'` | 召回 |
| 反思稿 | `memory_items`，reflection，`source='reflect'` | 召回、自视 |
| 退场 | 旧条 `invalid_at` + `superseded_by` | 深查顺着指针找回原文 |
| 回链 | `memory.reflect_merged` 事件 | 查「这条是从哪几条压出来的」 |
| 游标 | `reflect_cursor` 累加 / 清零 | 下一次反思 |

不写的情况：没模型；解析失败；模型说没价值；候选不够；dryRun。

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 把不相干的硬揉成一条 | 只看相似度 | 一批至少三条；不够不送 |
| 反思吞掉事实 | 压缩时不分轻重 | 只压 `importance < 0.5` 且不带未完成状态的 |
| 合完找不到原文 | 直接删 | 软删 + `superseded_by`，深查能顺着找回 |
| 一天压好几次 | 没有游标 | 累计重要性过阈值才压一次，压完清零 |

## 8. 怎么知道它活着（观察点）

- `memory_items` 里 `source='consolidate'` / `'reflect'` 的新条。
- 旧条的 `invalid_at` 有没有在增加。
- `reflect_cursor` 的 `acc` 在涨、压完归零。
- `memory.reflect_merged` 事件。

现在就能看：查最近几条 reflection 和它们的 `superseded_by`。

## 9. 换它要付什么（代价）

- **能动**：相似度线、批大小、反思阈值、提示词、dryRun。
- **不能动**：记忆的衰减与召回（别的零件的事）、退场必须是软删。
- **考卷**：`test/exam-consolidate.test.mjs`，38 道，现在 38/38。
- **回退点**：`consolidate-before-part`。
- **换完记在哪**：`parts.js` 的 `swaps`，外加一份 `docs/活论证-记忆整理-<日期>.md`。
