# 零件 · 开环（loops）

> 这页给主人看：它是什么、什么时候醒、看什么、怎么判、交出什么、哪里会错。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；怎么改它、每一步怎么落地，留在外面的 `docs/` 工程件里。
> 它现在是「可换零件」：登记 + 考卷（56/56）+ 回退点（`loops-before-swap`）三样齐了。

## 1. 一句话

它管一件事：**哪件事还欠着，以及它什么时候该冒出来**。像衬衫口袋里一张写着「明天交水电费」的便签——不是任务清单，是「还悬着、没连上的那一半」。

对应到代码里：一句话过一遍判据，像就记成 `open_loops` 里的一行；到点了、或者搁久了，那行会自己浮上来一行字，交给回话和主动开口。

它不管这句话要不要说，也不管冒出来之后怎么写。

| 管 | 不管 |
|---|---|
| 一句话算不算「欠着的事」 | 该不该主动开口（那是主动开口） |
| 到点没有、该不该冒出来 | 冒出来之后句子怎么写 |
| 提过几次、要不要先歇一歇 | 这件事的正文记在哪（那是记忆） |
| 你说「好了」时关掉哪一条 | 你回了之后怎么接 |

## 2. 它什么时候醒

| 谁叫它 | 什么时候 | 醒来做什么 |
|---|---|---|
| 对话进来（挂账） | 每轮你说了话 | 一句一句判：这句里有没有欠着的事，有就记一行；你说「好了」就把对的关掉 |
| 拼上下文（浮现） | 每次要回你话之前，60 秒内只算一次 | 取这一轮该冒出来的那行字，准备放进上下文 |
| 它自己的心跳（收账） | 每 5 分钟的轻活 | 把提满 5 次还没解决的那几条收掉，不再念叨 |
| 主动开口问它 | 主动开口每次判「要不要先说」 | 问一句：有没有到期的事可以当由头 |

**心跳每 5 分钟醒一次，不等于它每 5 分钟冒一句话**——心跳只管收账；冒不冒，要等你下一轮说话，或者主动开口来问。

没有这几下，它不会自己动。

## 3. 醒来之后走哪几步

**挂账**

1. 拿一句话（你说的话），过判据（第 5 节）。
2. 不像欠着的事 → 什么都不做。
3. 像 → 先看本子上有没有字面相近的同一件：有，就只补个来源；没有，就记一行，状态「开着」。

**浮现**

1. 取出还开着的行。
2. 到点了吗？没到点的，要搁满两天才算。
3. 6 小时内提过 → 跳过。
4. 提满 5 次 → 跳过（心跳会把它收掉）。
5. 排个序：说了一半的 → 到期的 → 提得少的 → 时间早的。
6. 拼成一行字：「- 还挂着：……（已经到期了）」，交给上下文。

**关账**

- 你说「好了 / 搞定了」：只关两小时内提过的；没提过的，要字面对上连续四个字才关。
- 提满 5 次：自动关，理由写「念够了」。
- 手动：留下是谁关的。

**一次真实走查**：

> 周二晚上你说「明天提醒我交水电费」。她记一行：交水电费，明天 9 点到期。
> 周三早上你跟她说话，那行浮上来：「- 还挂着：交水电费（已经到期了）」，她顺口提一句。
> 你说「交好了」。两小时内提过，这行被关掉，理由写「用户关的」。

## 4. 素材从哪来

**别人递的：**

| 东西 | 谁给 | 缺了会怎样 |
|---|---|---|
| 这一轮你说的话 | 对话 | 没有就不判 |
| 说这话的时间 | 对话 | 用当前时间 |
| 这句话从哪条记忆、哪一轮来 | 对话 | 空着，不影响挂 |
| 挂上那一刻的感觉编号 | 感受库 | 空着，不拿旧的凑 |

**它自己翻的：**

| 它看什么 | 从哪来 | 多久算新鲜 | 缺了会怎样 |
|---|---|---|---|
| 本子上还开着的行 | 自己的表 | 实时 | 没有就什么也不冒 |
| 提过几次、上次什么时候提 | 自己的表 | 6 小时 | 当没提过 |
| 参数：要不要浮现、一轮几条、多久内不重复 | 设置 | 你改就变 | 默认：开着，一轮 1 条，6 小时 |

**它不看什么**：记忆正文、感觉的内容、模型判断、你说这句话时的情绪。它只看「字面」和「时间」。

这也是它为什么容易判歪——它没有读懂你的意思，只是在认字。

## 5. 它怎么判断

它在问两个问题。

### 问题一：这话里有没有一件「还没完」的事？

- 有信号：答应、说好、提醒我、别忘、明天、回头、下次、待办……
- 但得排除：问句不算（除非是「请你帮我」）；已完成的不算；只在汇报进度的不算；纯技术讨论不算；太短、太空的不算。
- 判成什么类型：承诺 / 提醒 / 任务。
- 到期时间只认明确说法：明天、后天、周末、下周、月底、一会儿。认不出就不设死线——不猜。

### 问题二：这条现在该不该冒出来？

- 到点了，或者没设死线但搁满两天。
- 6 小时内提过的，先不重复。
- 提满 5 次的，收掉，不再提。

**一个反例**：你说「这个版本之后再说吧」。里面有「之后」「再说」，但没说「要做什么」——不算欠着的事，不会记。要是把「之后」单独当信号，她的本子就全是你没打算做的假待办。

## 6. 它交出什么

| 层 | 长什么样 | 落在哪 | 谁接 |
|---|---|---|---|
| ① 一行账 | 一句话 + 什么类型 + 到期没有 + 开着 / 说了一半 / 关了 | `open_loops` | 面板、你自己查 |
| ② 浮现候选 | 这一轮该冒的那几条（排好序） | 内存里 | 拼上下文 |
| ③ 一行字 | 「- 还挂着：……（已经到期了）」 | 提示词里 | 她回话时顺口提起 |
| ④ 由头 | 一条「有事由」 | 主动开口 | 判要不要先说 |

**你能感知到的只有第 ③ 层**（她回话里那句话），和主动开口真说出来的一句。前面两层留在库里。

**它不冒出来的情况**：

- 没到点，也没搁满两天；
- 6 小时内已经提过；
- 提满 5 次，被心跳收掉了；
- 你说过「好了」，它已经关了；
- 浮现开关被关掉；
- 那句话根本没被判成「欠着的事」。

## 7. 它什么时候会错

| 现象 | 可能是 | 现在怎么办 |
|---|---|---|
| 你随口一句「好了」，不相干的待办也关了 | 以前按字面重合率关，一个「了」字就够 | 已修：只关两小时内提过的，或字面对上连续四个字 |
| 本子里一堆假待办 | 「之后 / 再说 / 剩下」被单独当信号 | 已修：要配上「确实要做什么」才算 |
| 汇报进度、聊技术也被挂成待办 | 没区分叙述和派活 | 已修：状态汇报、纯技术讨论都排除 |
| 该记的没记 | 只认字面，换个说法就漏 | 这是它最薄的一层，靠考卷盯 |
| 提了五次你还没看到 | 心跳自动收掉，理由「念够了」 | 先看是不是本来就该提；改法在计划里 |
| 「特别看重」的标记以前不在这一行上 | 借了共享表 `flags`，写权分家 | 已收口：改成 `open_loops.important` 列，写权归开环；老标记启动时搬一次 |

## 8. 怎么知道它活着

- **表**：`open_loops` 里 `state='open'` 的条数、`half_said` 的条数、`closed_by` 各多少。
- **注入**：这一轮回话里有没有「- 还挂着：……」那一行。
- **测试**：`test/float.test.mjs`（挂 / 浮现 / 关账）、`test/focus.test.mjs`（注入措辞）、`test/loops-narrow.test.mjs`（判据收窄）、`test/loop-guard.test.mjs`（误关）、`test/loop-important.test.mjs`（重要标记）。
- **正常长什么样**：开着的几条，偶尔一条被提，关的时候都留着 `closed_by`。
- **现在就能看**：用任意 SQLite 工具打开 `~/.dsh/consciousness/app.db`，跑这句（生产库只看不改）：
  `SELECT state, closed_by, COUNT(*) FROM open_loops GROUP BY state, closed_by;`

## 9. 换它要付什么

- **能动**：信号词、到期解析、搁几天、6 小时节流、提满几次收掉、浮现排序。
- **不能动**：状态只有「开 → 说了一半 → 关」三种；关的时候要留是谁关的；同一件事不许挂两条。
- **考卷**：`test/exam-loops.test.mjs`，63 道，现在 63/63。
- **打假**：`node scripts/exam-sabotage.mjs`，塞三个坏版本（关掉节流 / 改高收账线 / 放宽最短字数），三个都要被卷子拦住。
- **回退点**：`loops-before-swap`（打在搬家前那次提交上）。回退 = `git checkout loops-before-swap -- src/modules/loops.js src/modules/parts.js test/exam-loops.test.mjs`，再删掉 `src/parts/loops/`。
- **换完记一笔**：改了哪段因果、考卷分、谁批的、回退点在哪。

## 10. 这页造的词

| 这页说 | 代码里叫 | 一句话 |
|---|---|---|
| 挂账 | `addLoop` / `detectLoop` | 一句话变成一行欠着的事 |
| 浮现 | `pendingLoops` / `loopCandidate` | 该冒出来的时候把它捞出来 |
| 提过 | `markLoopsFired` | 提一次记一笔，转「说了一半」 |
| 关账 | `closeLoops` / `settleLoopsFromUser` | 你说好了 / 念够了 / 手动关 |
| 到期线 | `due_at` | 明确说了哪天，就那天 |
| 搁着线 | `stale_after` | 没说到期，就搁两天算数 |
| 半说 | `half_said` | 提过一次，还没收尾 |
| 由头（借自开口页） | `trigger` | 一件「该说的事」：承诺、开环、生活分享 |
| 重要标记 | `open_loops.important` 列 | 她标「这件事我放在心上」 |
