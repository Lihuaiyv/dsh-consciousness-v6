# 零件：记忆写入闸

> 这页讲「她自己说出来的一句话，值不值得记住、记了要不要先放进冷柜」。
> 谁看：主人。不读代码，但要知道它靠不靠谱、哪里会坏。
> 工程件：`src/modules/memory_source.js`（判据与判决）、`src/features.js` 的 `writeExtractedItem`（落库与名额）、考卷 `test/exam-writegate.test.mjs`。

## 1 一句话 + 一个比喻

**它管**：一条自述进门时判三件事——是不是她自己在说、这件事分量够不够、今天的名额还剩不剩；**不管**：这句话是不是真的、要不要注入到这一轮的提示词里、很久以后忘不忘。

比喻：**门口一个门卫**。每句话都要先过他的岗：转述别人的话，登记一下放冷柜（不扔，想翻还能翻）；值得记的，给号进热层；胡话、噪音、转写残留，直接请回。

真的对应到哪：「冷柜」就是冷层（`temp_state='cold'`），「热层」就是每轮会注入的那批，「请回」就是不写库。

## 2 它什么时候醒（触发）

| 谁叫 | 什么时候 | 醒来做什么 |
|---|---|---|
| 别的零件调 | 一轮对话结束、抽取完记忆之后 | 这条自述值不值得记、记到热层还是冷层 |
| 它自己 | 不走心跳 | 它没有一个自己的定时器：没人递话，它就不动 |

没有这些，它不会自己动；它也不算「今天记了几条」这种账，那是名额那边的事。

## 3 醒来之后走哪几步（流程）

1. 先看这句话像不像「她自己说的」：旁白（主语是用户/对方/助手）→ 走冷柜，不扔。
2. 再看长度和噪音：太短、转写残留、报错堆栈 → 直接请回。
3. 三档：像自己说的（ok）→ 留；明显不要（drop）→ 走第 4 步；拿不准（unsure）→ 有模型判词就听判词，没有就先放冷柜，不真丢。
4. 打分：想明白了、改了主意、承诺、情绪重 → 加分；跑测试、提交、改接口、页面配置 → 减分。
5. 名额：今天记满了 / 这一窗口（3 小时）记满了 → 先放冷柜；「按分量选人」开着时，低分那条也不占热层。
6. 落库：热层一条，或者冷层一条；每次拒绝都留一条事件（为什么被拦）。

走查：今晚她说「我想明白了，以后不把每句都答得那么满」——像她自己说的、有分量、名额还有 → 进热层。如果这句是「用户正在推进需求」，门卫看一眼：旁白 → 进冷柜，深查还能翻到。

## 4 素材从哪来（输入）

| 人话名 | 从哪来 | 缺了会怎样 |
|---|---|---|
| 一句话 | 抽取那一步判成「她自己」的句子（`who: 'self'`） | 没有这句话就不进门 |
| 模型判词（可选） | 拿不准时问一次模型的「留/丢 + 分」 | 缺了也照判：拿不准的落冷柜 |
| 参数 | 自述写入开关、按时间还是按分量选人、最低分 | 缺了按默认：开着、按时间、0.35 |

**它不看什么**：不看这句话有没有被注入回提示词（那是注入的活）；不看温度之后怎么衰减（那是温度与分层的活）；不做事实核对。

## 5 它怎么判断（判据）

一句话说清它在问三个问题：**是谁在说？够不够分量？今天还有位子吗？**

- 是不是她自己：开头是「用户 / 对方 / 助手」的转述 → 旁白，走冷柜不扔。
- 像不像话：不到六个字、开头是转写标记或代码块、正文带报错 → 请回。
- 分量：底分 0.4；想明白、改主意、接受、害怕、答应、以后 → 加；跑测试、提交、部署、改接口、页面配置 → 减。
- 名额：按分量选人时低于门槛的落冷柜；名额满时落冷柜，不扔。

反例：你觉得「我这句明明很走心，怎么没进热层」——它可能被判成了「拿不准」（通篇没有「我」这种自称），模型那一下又没答上来，于是先放冷柜了。冷柜不是删除，深查能翻到。

## 6 它交出什么（输出）

- 判断结果：这是第几档、多少分、为什么拦（`why`）。
- 落库动作：新写一条（热层）/ 落冷柜 / 并进旧条 / 请回。
- 留痕：被拒绝的写一条 `memory.self_rejected`，落冷柜的再写一条 `memory.self_cold`，名额破例的写一条 `memory.self.bypass`。
- 谁接：记忆库、温度状态机（冷柜里的等它老）、深查。

**不说的几种情况**：噪音直接请回（连事件都只在拒绝时写一条）；开关关掉时一条都不收；名额满又不够破例分的，只落冷柜。

## 7 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 「为什么被拦」显示 `head`，明明像是转写残留 | 以前「开头不像自己」排在噪音前面，标签就错记成 head | 2026-11-05 夜已修：噪音判定提前；历史事件里旧的错标还在，看时间戳分新旧 |
| 同一句重复说，会多存一条 | 自述车道没带「同一件事」的指纹（fact_key / turn_id），库那边认不出是同一句 | 已知，还没修；重复的自述会各自占一条 |
| 冷柜里的看不出为什么冷 | 只记了 `why` 和分数，不记当时的原句上下文 | 先看事件表；要更细得另加字段 |
| 分数是规则打的，会偏心 | 加减分是按词表匹配，不真的读懂 | 拿不准的才问模型；规则分只做粗排 |

## 8 怎么知道它活着（观察点）

看两处：`memory_items` 里 `source='self'` 的条（热层还是冷层）；`events` 里 `memory.self_rejected` / `memory.self_cold` 的条数。

正常：一天记几条到十几条，冷柜里有一些。异常：一天几十条全进热层（闸没管住），或者一条都没进还都是 `low_score`（门槛太高）。

现在就能看：设置 → 意识体 → 记忆，按「手记」来源筛；或看最近事件。

## 9 换它要付什么（代价）

- 能换：三档判据、加减分表、最低分、冷柜还是请回、按时间还是按分量。
- 不能动：旁白不丢内容（只降层）；噪音不写库；拒绝要留痕。
- 考卷：51 道，`node test/exam-writegate.test.mjs`。
- 回退点：`wgate-before-part`。
- 换完记在哪：`src/modules/parts.js` 的 `swaps`。
