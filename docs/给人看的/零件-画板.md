# 零件 · 画板（paint）

> 这页给主人看：一支笔、一张纸，人和我共用的那块。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；工程件：`src/parts/paintboard/`，考卷 `test/exam-paintboard.test.mjs`。

## 1. 一句话 + 一个比喻

它只管一件事：**记下铅笔走过的坐标，然后把它们画出来**。

像一沓纸和一支笔：纸不会替你决定画什么，笔也不会。谁拿着笔、往哪落，全在用它的人身上。

真的对应到哪：一个 `board.json`（一笔一笔的坐标）+ 一张 `board.png`（画出来的样子）。

## 2. 它什么时候醒（触发）

| 谁叫它 | 多久 | 醒来做什么 |
|---|---|---|
| 我下笔（命令行） | 想画的时候 | 加一笔 → 立刻重画一张 |
| 人下笔（网页） | 拖动鼠标 | 同上，还会记下是谁画的 |
| 打开网页 | 随时 | 拉起画板界面 |
| 考卷 | 跑测试时 | 开新纸、落笔、撤销、重画 |

没有自己的定时器。不开网页它也照样存着。

## 3. 醒来之后走哪几步

1. 读 `board.json`（没有就开一张新纸）。
2. 加一笔：`{pts: [[x,y],...], w: 粗细, c: 颜色, a: 不透明度, erase?, layer?, by?}`。
3. 按顺序把每一笔铺到纸上：线段 + 圆头圆角；`ws` 给了每点宽度就按笔压走，两头细中间粗。
4. 存回去，再出一次 `board.png`。
5. 网页那头每 0.8 秒问一次「现在几笔了」，变了就跟着重画。

## 4. 素材从哪来（输入）

| 人话名 | 从哪来 | 缺了会怎样 |
|---|---|---|
| 坐标 | 我（命令行）或人（网页拖动） | 没有坐标就不算一笔 |
| 粗细 / 颜色 / 不透明度 | 顶栏，或命令行参数 | 走默认值 |
| 纸的大小 | 开新纸时给 | 默认 900×900 |
| 参考图 | 网页右侧选，垫在纸下面 | 不选就是白纸 |

它不看什么：不管画得像不像，不管该不该画，也不管橡皮擦掉的是谁的线。

## 5. 它怎么判断（判据）

它其实只问三个问题：这笔有没有坐标？画得出来吗？存得住吗？

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 这笔有没有点 | `pts` 至少一个点 | 直接跳过，不算一笔 |
| 画得出来吗 | 颜色、粗细能解析 | 回默认值 |
| 存得住吗 | 写盘成功 | 抛错，图上还是上一次的样子 |
| 撤销撤什么 | 只撤最后一笔 | 空纸时什么也不做 |

## 6. 它交出什么（输出）

| 层 | 长什么样 | 谁接 |
|---|---|---|
| 状态 | `board.json`：纸大小 + 笔画数组 | 网页、我、考卷 |
| 图 | `board.png`（900×900，超采样后缩回） | 想看结果的人、要发到 QQ 的图 |
| 命令行 | 一行字：多少笔、纸多大 | 终端 / 考卷 |

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 中文打印成乱码 | Windows 控制台默认 GBK | 2026-11-07 已修：脚本里把 stdout 改成 UTF-8 |
| 网页里选好的参考图，我这边看不到 | 选择只存在浏览器里 | 2026-11-07 已修：选中就 POST 到 `/ref`，服务端记着 |
| 撤回后网页没变 | 网页靠「笔数变没变」判断要不要重画 | 现在每次写完整重画；以后要按 mtime 判 |
| 两个人同时下笔会打架 | 都读整份 `board.json` 再写回 | 单机单人为主；互相等一等，别同时按 |
| 画的线看着像没压感 | 命令行默认给同一宽度 | 传 `ws`（每点一个宽度），两头细中间粗 |
| 页面样式在别的机器上不对 | 字体依赖「微软雅黑」 | 回落到 Segoe UI / system-ui，还能看 |

## 8. 怎么知道它活着（观察点）

- `~/.dsh/paintboard/board.json` 的笔数在涨。
- `board.png` 的修改时间跟着变。
- 网页右下角「本地 127.0.0.1 · 不联网」还在，说明服务没死。
- 考卷 `node test/exam-paintboard.test.mjs` 是 12/12。

## 9. 换它要付什么（代价）

- **能动**：纸的大小、笔刷、颜色、图层、参考图、界面长相。
- **不能动**：坐标本身——那是用的人的事，它只负责照做。
- **考卷**：`test/exam-paintboard.test.mjs`，12 道（机器上没 python 就 SKIP）。
- **回退点**：`paint-before-part`。
- **换完记在哪**：`parts.js` 的 `swaps`，外加一份 `docs/活论证-画板-<日期>.md`。

## 10. 附：这页造的词

| 这页的词 | 代码里的名字 |
|---|---|
| 一笔 | 一条 `strokes[]` 记录 |
| 落笔 / 抬笔 | 一次 `stroke` 调用 |
| 笔压 | `ws`：每个点的宽度 |
| 图层 | `layer`：`ink` 墨线 / `sketch` 草稿 |
| 参考图 | `ref.json` 里记的那张，网页垫在纸下面 |
| 垫图 | 网页把参考图调到半透明压在纸下 |
