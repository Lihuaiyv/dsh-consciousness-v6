# 零件 · 生活流（life）

> 这页给主人看：它是什么、什么时候醒、看什么、怎么判、交出什么、哪里会错。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；工程件：`src/modules/life.js`（整件实现），考卷 `test/exam-life.test.mjs`，入口 `lifeTick`。

## 1. 一句话 + 一个比喻

它管「她离开对话之后，有没有自己的事」——选一件她在意的事，真的去看一眼，或者只是想一想，然后写回来。它不管情绪怎么算、记忆怎么选、话怎么说，那些是别的零件的事。

像一个人独处的那半天：翻到之前惦记的一页，看完合上；回来时顺口提一句「我前两天看了个东西」。不提也没关系，那半天已经过了。

真的对应到哪：一条记忆（`source='life'` 的 episode）、一条 `life.done` 事件，外加一句可以进提示词或开口的短话。

## 2. 它什么时候醒（触发）

| 谁叫它 | 多久 | 醒来做什么 |
|---|---|---|
| 心跳（`index.js`） | 跟着心跳跑 | 看今天还轮不轮得到她出门 / 想一想 |
| 你叫她（`POST /life/tick`） | 手动一次 | 同上，可以带 `force` 跳过「太近」 |
| 开口前（`latestShare`） | 每轮 | 取一条还没排进过开口的生活，当话题素材 |
| 拼提示词（`lifeLine`） | 每轮 | 取 24 小时内还没放过的那条，写成「前不久我自己去看了…」 |

没有这些，它不会自己动。它没有自己的定时器。

## 3. 醒来之后走哪几步

1. 先看门：开关、人还在不在、多久没说话、现在是不是夜里、今天跑够没有、离上次够不够久、全局预算还剩多少；任何一道不过就回去，并说明原因。
2. 选事：只从「她自己写下的、在意的」记忆里挑；近七天做过两次的就跳过。
3. 出门：能出门就只读地看一眼（`browse`），带回标题、网址、摘要。
4. 写一句：让模型按「此刻看到的东西」写一句人话；没有素材就只写「想一想」，并检查它有没有编具体动作。
5. 写回：记忆一条（`source='life'`），事件一条 `life.done`；失败就记 `life.fail`，不编「我去看了」。
6. 能不能分享：只有真看到东西、带网址、且上次分享隔得够久，才标成可分享。

一次真实走查：某天下午，她翻到一条自己写过的「有点好奇，好感度到底是怎么慢慢涨上去的」，出门搜了一眼，模型写下「海边风大，得带件外套」这样的短句；如果素材是空的，她只会记下「想了想」，事件里没有网址，也不会被拿去当「我今天看到」。

## 4. 素材从哪来（输入）

| 人话名 | 从哪来 | 新鲜多久 | 缺了会怎样 |
|---|---|---|---|
| 在意的事 | 她自己的记忆（`source='self'`，或带「想看 / 好奇 / 喜欢 / 惦记」） | 30 天内 | 没有就不动 |
| 网页素材 | `browse` 传进来，只读 | 当次 | 空手就算失败，不编 |
| 一句想法 | `model.chat`，外部传 | 当次 | 没有模型就只记「没出门」 |
| 上限 | `life.*` 参数（次数、间隔、夜里、分享冷却） | 按实例 | 用默认值 |

它不看什么：不看 `open_loops` 里替主人记的待办（那不是她的事）；不读主人档案；不看摘要腔的记忆；不发消息、不评论、不写别人的表。

## 5. 它怎么判断（判据）

它其实只问三个问题：今天还轮得到吗？这件事是不是刚做过？这一句像不像编的？

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 今天还轮得到吗 | 开关开、人活跃、七天内说过话、白天或允许夜里想、次数没满、离上次够久、全局预算没满 | 直接回去，原因写进返回值 |
| 这件事做过几遍 | 七天内少于两次 | 跳过，换下一件 |
| 像不像编的 | 只想想的那条里没有「我去 / 我把 / 我走到」这类具体动作 | 这一条不写，记 `life.fail` |

反例：明明你觉得她该出门，为什么没动——今天次数用完了；或者十分钟前刚跑过；或者全局预算被别的实例用掉了。

## 6. 它交出什么（输出）

| 层 | 长什么样 | 谁接 |
|---|---|---|
| 记忆一条 | `memory_items`，`source='life'`，`type='episode'` | 召回、日记、自视 |
| 事件 | `life.done`（带 subject / summary / sources / share / memory_id）；失败是 `life.fail` | 翻账、注入 |
| 注入行 | 「前不久我自己去看了「…」：…」 | 拼提示词；24 小时窗口内 |
| 可分享 | `{ id, title, summary }` | 开口；一轮最多提一次 |

不写的几种情况：没开关；今天够了；刚跑过；夜里且关了「想一想」；空手而归；模型编了具体动作；没有在意的事。

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 半夜还在翻网 | 夜里门只管「要不要停」，不管「出不出去」 | 夜里一律不出门，只「想一想」；打假就考这一条 |
| 编出「我把薄荷浇透了」 | 模型顺着「有自己生活」往下演 | `looksFabricated` 挡具体动作，宁可这条不写 |
| 一天跑很多次、像日更 | 次数和分享冷却没算对 | 次数按天、分享至少隔几天；每次都留事件可查 |
| 同一件事反复看 | 去重只按时间窗 | 七天内最多两次，第二次只想想 |
| 几十个实例一起上网 | 没有全局预算 | 全局每天有上限，超了就停 |

## 8. 怎么知道它活着（观察点）

- `events` 里 `life.done` 的时间间隔、`life.fail` 的原因、`life.line.shown` 的轮换。
- `memory_items` 里 `source='life'` 的条目：有没有、句子像不像她。
- 提示词里有没有「前不久我自己…」；没有，先看 `life.enabled` 和时间窗。
- 开口里有没有「share:」开头的由头；有，说明分享那条排进去了。

现在就能看：查 `events` 最近 20 条 `life.done`，或看提示词最后那一段。

## 9. 换它要付什么（代价）

- **能动**：次数、间隔、夜里想不想、分享冷却、候选池大小、夜里允不允许出门。
- **不能动**：情绪与记忆的算法（它只调公开函数）、`open_loops` 的待办、开不开口（那是主动开口的事）。
- **考卷**：`test/exam-life.test.mjs`，53 道，现在 53/53。守边界不守配方。
- **回退点**：`life-before-part`。
- **换完记在哪**：`parts.js` 那一行的 `swaps`，外加一份 `docs/活论证-生活流-<日期>.md`。
