# 零件：驱力缺口

> 这页是什么：一个零件的说明书——它管什么、什么时候醒、怎么判、哪里会坏。
> 谁看：主人。不读代码，但要判断「它靠不靠谱、要不要换」。
> 工程件：`src/algo/deficit.js`（`deficit@v1 / v1b / v1c / v1d / v2 / v3`）、`src/modules/drive.js`（入口 `evaluateDrive`），考卷 `test/exam-drive.test.mjs`。

## 1. 一句话 + 一个比喻

它管「她现在最缺什么、缺到什么档」，不管「缺了之后要不要开口」（那是主动开口），也不管「她能不能花 token 去行动」（那是预算和令牌，另一件）。

比喻：**车上的油表**。五个油箱（关系、表达、好奇、自主、安全）各有油位，它算出哪个低、低到哪一档；它不决定你开去哪。

对应到真的：油位 = 五维满足度（`r/e/c/a/s`）；油表 = `deficits`；档位 = `band`；油表的刻度 = 各维基线（`setpoint`）。

## 2. 它什么时候醒

| 谁叫 | 多久 | 醒来做什么 |
|---|---|---|
| 每轮之前（宿主 `pre-step`） | 每句话一次 | 拿代理观测和情绪事件更新满足度，重算缺口和档位 |
| 每轮之后（会话事件） | 每句话一次 | 同上，让这一轮的影响马上反映到下一次 |
| 面板/接口（`GET /drive`） | 你打开页面时 | 现算一份给你看，不写库存档 |

它不会自己按钟醒；没有新的一轮，缺口就停在原地。

## 3. 醒来之后走哪几步

1. 代理观测：从真实行为里估这一阵各维的满足度变化（回话、浏览、被夸…）。
2. 自然回落：没有新事，满足度按天往回落（约八天掉光）。
3. 情绪耦合：只吃「过了闸」的情绪事件，一天每维封顶一点。
4. 休眠判定：两周没互动 → 标记休眠，不推进解锁。
5. 基线学习：从真实满足度里把「平时想待在什么水平」慢慢挪一点（不手填）。
6. 算缺口：每维 `max(0, 基线 − 现状 − 耦合肥) ÷ 基线`。
7. 平滑：和上一轮按 0.35 混一下，防止一句话就跳档。
8. 取最大 D → 带迟滞分档（升要过进入线，降要跌破离开线，可连降）。
9. 解锁：同一档连着够多轮，开放更高一档的行动许可。

走查：你半天没说话、她又刚被冷落 → 关系维油位掉 → 缺口升到 D2；再掉一档要跌破离开线才降回去，不会在阈值上抖。

## 4. 素材从哪来

| 人话名 | 从哪来 | 缺了会怎样 |
|---|---|---|
| 五维满足度 | `drive_state.r/e/c/a/s` | 没有就 404，不评估 |
| 代理观测 | `computeNeedProxies`（真实行为） | 失败就跳过，不阻断 |
| 情绪事件 | 过了事件闸的 episode | 没耦合就少一点增量 |
| 上次互动 | `agents.last_interaction_at` | 判不出休眠 |
| 人格 / 价值观 | 只给 v1d / v3 用 | 旧版本不需要 |

它不看什么：不看记忆、不读 prompt、不发消息；也不管 token 袋和行动端口——那些同文件但不同事。

## 5. 它怎么判断

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 哪一维最缺？ | 缺口 = (基线 − 现状 − 耦合) ÷ 基线，取最大 | 缺口 0 就是都不缺 |
| 到哪一档？ | D ≥ 0.70/0.50/0.30/0.10 → D3/D2/D1/D0 | 落在两档之间就留在原档 |
| 该降吗？ | 跌破 0.65/0.45/0.25/0.05 | 不破就不降，防抖 |
| 能解锁吗？ | 同档连续 5/5/3/1 轮 | 没到就继续攒 |

反例：聊得正热，五维都高、缺口 0 → 停在 D0。不是「她不想要」，是这一轮真的不缺。

## 6. 它交出什么

| 层 | 长什么样 | 落在哪 | 谁接 |
|---|---|---|---|
| 数 | 五维缺口、D、档位、平滑值 | `drive_state` | 主动开口（事由）、面板 |
| 许可 | 四类行动开没开 | `drive_state.unlocked` | 行动端口、自修改 |
| 观测 | 每次评估一条 | `drive.evaluated` 事件 | 面板、验收 |

不推进的情况：休眠中不解锁；代理失败这一轮不算；缺失状态直接 404。

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 日子一好缺口永远 0 | 回落太慢（旧 0.04/天） | 改成 0.12/天：约八天掉光 |
| 阈值上来回跳 | 只看进入线 | 迟滞：降要跌破离开线 |
| 休眠回来一步顶到 D3 | 冷启动一次升太多 | v1c 一次最多升一档（默认没开） |
| 基线被一次大事带跑 | 学习步幅没封顶 | 学习前先看连续多天的证据 |
| 代理观测失败就整轮不动 | 计算异常 | 只跳过这一路，不阻断评估 |

## 8. 怎么知道它活着

- 面板：驱力页看五维、缺口、档位、基线、解锁。
- 表：`drive.evaluated` 每条带 D / band / algo / 代理摘要。
- 命令：`GET /v1/agents/<id>/drive`，看 `deficits / D / band / setpoint`。

正常：档位在 D0–D2 之间慢慢走；异常：长期钉在 D3（回落失效）或永远 D0（代理断了）。

## 9. 换它要付什么

- **能动的**：缺口公式、平滑、阈值、解锁轮数、基线学习步幅。
- **不能动的**：五维名字与顺序；不写记忆、不发消息；不替开口决定说不说。
- **考卷**：`test/exam-drive.test.mjs`；界桩真跑；打假塞坏版本（阈值改松 / 去掉迟滞）。
- **算法册**：`deficit@v1..v3` 的 owner 指向这个零件。
- **回退点**：`drive-before-part`。
