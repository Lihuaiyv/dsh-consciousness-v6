# 零件：关系动力

> 这页讲「一件事发生之后，亲近 / 信任 / 依赖各挪多少」。
> 谁看：主人。不读代码，但要知道它靠不靠谱、哪里会坏。
> 工程件：`src/algo/reldyn.js`（纯函数）、`src/modules/relations.js`（落到账本的那一段）、考卷 `test/exam-relation.test.mjs`。

## 1 一句话 + 一个比喻

**它管**：每件事该给一段关系加多少、减多少，以及久不往来怎么淡回去；**不管**：这件事算不算冲她来的、该不该记进记忆、要不要开口。

比喻：**一个随身带的小账本**。谁帮了她一次记一笔，谁伤了她一次记一笔更重的；隔久了不联系，账上的字迹会自己淡回原来的底色。

真的对应到哪：账本上的「字迹」就是三个数（亲近 / 信任 / 依赖），「淡」就是往基线回，「记一笔更重」就是伤比暖快。

## 2 它什么时候醒（触发）

| 谁叫 | 什么时候 | 醒来做什么 |
|---|---|---|
| 别人递 | 一轮对话结束、身份认过之后 | 看这一句值不值得记账；值得就结算三轴、写进账本 |
| 它自己 | 夜巡（每天一次） | 久没动的关系按半衰期往基线淡一点 |
| 别的零件调 | 道歉 / 补偿那一路 | 「修复」模式：只补信任，不碰亲近 |

没有这些，它不会自己动。它自己不发起、不说话。

## 3 醒来之后走哪几步（流程）

1. 拿到一件事（效价、来源、类型）和这个人现在的三个数。
2. 算这件事的「分量」：冲她来的、有分量，才挪得动。
3. 打折：同一类事反复来，一次比一次轻；工具或导入来的话更轻。
4. 结算：暖的按「还差多少」乘，伤的直接乘当前值——所以越亲被伤得越狠。
5. 每一步都有上限，不会一笔就把人从陌生记成熟人。
6. 写进账本（一条事件记录），顺带把人物卡上的三个数改掉。

走查：今天有人夸了她一句「你这回答真好」，评价是冲她来的、合意；账本记一笔：亲近 +一点点、信任 +更少一点；如果是同一类夸奖这周第五次，分量已经掉到七成。

## 4 素材从哪来（输入）

| 人话名 | 从哪来 | 缺了会怎样 |
|---|---|---|
| 效价 | 情绪评价那一半算好的「这句话是好是坏」 | 没有效价 = 这件事不记账 |
| 来源 | 这句话是从哪条路来的（面对面 / 界面 / 工具 / 导入 / 系统） | 缺了按「面对面」算，会算重 |
| 类型 | 闲聊 / 夸奖 / 批评 / 帮忙 / 分享 / 越界 / 道歉 | 缺了按闲聊算，依赖涨得最轻 |
| 这个人现在的三个数 | 人物账本 | 缺了按 0.5 / 0.5 / 0.2 起算 |

**它不看什么**：不看这句话有没有点名、是不是在针对她（那是情绪评价和边的活）；不看记忆、不看心情面板、不看要不要开口。

## 5 它怎么判断（判据）

一句话说清它在问两个问题：**这件事算不算冲我来的？该记多重的账？**

- 冲她来了吗：没点名、不是针对她的，分量砍一半；她自己做的事，几乎不动关系。
- 有没有越界：越界和禁忌直接记满格负分。
- 这次算多重：这件事本身多重 × 来源可信度 × 习惯化之后的折扣。
- 哪一轴动：暖的抬亲近，信任涨得最慢；依赖只被「帮忙 / 分享 / 道歉」这类事明显抬动，闲聊只轻轻碰一下。
- 伤还是暖：伤按当前值乘，暖按剩下的空间乘。所以越亲，一句重话掉得越狠；而越亲，夸一句几乎不动。

反例：你觉得「他刚才明明夸我了，怎么亲近没涨」——因为那是同一类夸奖这周第八次，习惯化之后分量只剩三成，再加上有上限，一笔只挪一点点。

## 6 它交出什么（输出）

- 判断结果：这人现在的亲近 / 信任 / 依赖，以及这笔账三轴各挪了多少。
- 落账：账本里多一条事件记录（谁、什么类型、效价、权重）。
- 谁接：人物卡（三轴数）、语气投影（暖不暖、端不端、愿不愿多说）、提示词里的「你怎么称呼对方」那一栏。
- 你能感知到的只有最外面一层：她对他说话的温度和松紧。

**不说的几种情况**：没有绑定到人（不知道该记在谁头上）；这件事太轻，低于记账门槛；三轴都没动（比如完全中性的句子）。

## 7 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 算法册里写着「现行 v1」，其实线上是直接调函数、没走注册表 | 当年先写了算法、还没来得及接开关 | 已在册子上认领给本零件；要按版本切换得先改线（属于「换」，要观察期） |
| 关系的三轴会贴到 0.999 顶 | 接近上限时会去接近，但永远到不了 | 设计如此，提示词里别把 0.999 当真 1 |
| 「修复」为什么只回信任、不亲近 | 亲近修复靠日子，不靠一句道歉 | 故意这样；道歉的上限也只补回这次伤害的九成 |
| 同一句夸奖连说十次，一次比一次轻 | 习惯化，72 小时才恢复大半 | 故意这样；但会让人以为她「听腻了」 |

## 8 怎么知道它活着（观察点）

看人物卡：亲近 / 信任 / 依赖三轴，正常是「慢慢动、有涨有跌」，异常是「一笔就跳到 0.99」或「永远不动」。

现在就能看：设置 → 意识体 → 关系，选一个人；或看账本里最新一条事件（`rel_event`）。

## 9 换它要付什么（代价）

- 能换：三轴结算的公式、步长、上限、习惯化速度、衰减半衰期、修复力度。（现在只有纯函数那一半真被考卷盯着；线上路径是直调，切版本要先改线。）
- 不能动：不能凭一句话把陌生人改成主人（有上限）；不能把「越界」记成暖的。
- 考卷：69 道，`node test/exam-relation.test.mjs`。
- 回退点：`relation-before-part`。
- 换完记在哪：`src/modules/parts.js` 的 `swaps`。
