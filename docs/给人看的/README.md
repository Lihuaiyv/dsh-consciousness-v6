## 什么时候加一页

- 多一个零件 → 先读 [零件说明-写法.md](零件说明-写法.md)，再写一页 `零件-<名字>.md`，跟这里并排。
- 一个词要改意思 → 先改术语表，别在别处临时加；词表里没有的词，要么删，要么先加进来。
- 这层只写「它是什么、哪里还没想清、要一起拍板什么」；「怎么做」进计划、交接那类工程件。

## 一句话规矩

一页只讲一件事；能一眼找到；这页跟代码冲突时，以代码为准，改完代码回来改这页。
