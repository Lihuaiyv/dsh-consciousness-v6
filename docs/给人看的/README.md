# 给人看的

> 这一层只放「人和小汐直接读、拿来聊」的页。工程件（计划、交接、报告、模拟）都留在外面 `docs/`，不混进来。

## 现在有

- [术语表-2026-11-05.md](术语表-2026-11-05.md) —— 桥：词、思想、工程做法，唯一源。说绕了就说「说人话」，回到这页找一个词重说。
- [零件说明-写法.md](零件说明-写法.md) —— 模板：以后每个零件页照这个骨架写（十节：是什么、何时醒、走哪几步、看什么、怎么判、交出什么、哪会错、怎么看、代价、词表）。
- [零件-主动开口.md](零件-主动开口.md) —— 第一篇零件说明：一个想发消息又怕打扰的人，怎么判断此刻要不要开口。
- [零件-开环.md](零件-开环.md) —— 第二篇零件说明：口袋里那张「还欠着」的便签，怎么记、什么时候冒出来、什么时候关掉。
- [零件-总表-2026-11-05.md](零件-总表-2026-11-05.md) —— 草稿：约 35 个零件，一行一个，写清「管什么、吃进什么、吐出什么」，等你圈掉不要的。

## 什么时候加一页

- 多一个零件 → 先读 [零件说明-写法.md](零件说明-写法.md)，再写一页 `零件-<名字>.md`，跟这里并排。
- 一个词要改意思 → 先改术语表，别在别处临时加；词表里没有的词，要么删，要么先加进来。
- 这层只写「它是什么、哪里还没想清、要一起拍板什么」；「怎么做」进计划、交接那类工程件。

## 一句话规矩

一页只讲一件事；能一眼找到；这页跟代码冲突时，以代码为准，改完代码回来改这页。
