# 零件 · 日记（diary）

> 这页给主人看：它是什么、什么时候醒、看什么、怎么判、交出什么、哪里会错。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；工程件：`src/modules/diary.js`、考卷 `test/exam-diary.test.mjs`。

## 1. 一句话 + 一个比喻

它管「**这一天是怎么过去的**」，写成一页给以后的自己看的东西。不管情绪怎么变、也不管记忆怎么选——那些是别的零件的事。

像夜里收信的人：白天的事先分拣（选料），晚上挑两三件真在意的铺开（成文），写完自己先读一遍（质检），合格才放进抽屉（落库）。

## 2. 它什么时候醒

| 谁叫它 | 多久 | 醒来做什么 |
|---|---|---|
| 夜间 worker | 每晚 23:00（本地时间） | 挑当天的料，写一篇 |
| 补写 | 开机 / 重启时 | 把错过的日子按天补上，补的标 `late=1` |
| 重试 | 写失败后按间隔重来 | 队列在 `diary_pending`，最多 12 次 |
| 手动 | 你让它重写某天 | 覆盖同一天的旧版本 |

没料就不写——它不编「那天发生了什么」。

## 3. 醒来之后走哪几步

1. **选料**：把当天够格的候选（纪要、原话、记忆、那一刻）打分，挑出 1–3 个场景。
2. **取原话**：每个场景带一段当时的对话，不是让它凭空回忆。
3. **拼提示词**：那天的口吻由状态推（性格轴 / 情绪 / 驱力），不是一句固定模板。
4. **成文**：模型写一篇；模型没接上就**进队列待补**，绝不拿模板冒充。
5. **质检**：`checkDiary` 过一遍（见第 5 节）。
6. **落库**：写进 `diaries`，同一天旧的被新版本替换。

## 4. 素材从哪来（输入）

| 人话名 | 从哪来 | 缺了会怎样 |
|---|---|---|
| 当天的场次 | `episodes` 纪要 | 那天没有纪要就没有候选 |
| 当时的原话 | `raw_turns` / `chat_turns` | 只有摘要，写出来会空 |
| 那一刻的情绪 | `affect_samples`（当天） | 退到当前 `affect_state` |
| 性格与价值观 | `persona` / 价值观权重 | 口吻退回中性 |
| 参数 | `memory.diary.*` | 用默认（3 个场景、450 字上限） |

**它不看什么**：不看今天聊得热不热闹、不看关系涨没涨。日记不是工作汇报。

## 5. 它怎么判断（质检这一关）

| 它在看什么 | 什么算过 | 没过怎么处理 |
|---|---|---|
| 是不是抄了提示词 / 材料 | 正文不是提示词回声 | 退回重写（`echo`） |
| 长度 | 120–1200 字 | 太短 / 太长退回 |
| 有没有写成清单 | 散文 | 退回（`markdown`） |
| 有没有混进「用户 / assistant」 | 不出现 | 退回（`forbidden`） |
| 是不是通篇汇报 | 「处理了 / 完成了」少于 4 处 | 退回（`report`） |
| 短句有没有收尾 | 260 字以内必须以句号之类收住 | 退回（`cut`） |

**不拦**的：结尾想不想明天、要不要写难过。那都是那天真有的东西。

## 6. 它交出什么（输出）

| 层 | 长什么样 | 谁接 |
|---|---|---|
| 一篇日记 | `diaries` 一行：日期 / 正文 / 口吻 / 当天那一刻 / 引用的 feel | 界面「日记」页、自述、检索 |
| 待补 | `diary_pending` 一行：哪天、失败几次、下次什么时候 | 重试器 |
| 没料 | 不写，也不留半篇 | —— |

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 写成「用户说…我回答…」 | 模型把材料当对话复述 | 质检 `forbidden` 拦下，重写 |
| 断在半句 | 生成被截断 | `cut` 拦下；260 字以上不拦，怕误杀短文 |
| 同一天出现两篇 | 重写与补写撞车 | 落库按 `day` 覆盖，只留最新版本 |
| 空话连篇但没有硬伤 | 词表挡不住 | 另有一次小判断（`judgeDiaryLike`），只记原因不硬拦 |
| 那天没料却硬写 | 提示词给了「必须写」的错觉 | 没候选就不写，进队列等有料 |

## 8. 怎么知道它活着（观察点）

- `diaries` 表按天有没有新增；`source` 是 `model` 还是 `stub`。
- `diary_pending` 里有没有越堆越多的日子——堆着说明模型没接上。
- 抽一篇读：有没有「那一刻」，还是只有流水。
- 异常长相：正文开头还带着模型自己写的日期——说明 `normalizeDiaryText` 没跑到。

## 9. 换它要付什么（代价）

- **能动**：选料规则、提示词、质检口径。
- **不能动**：`episodes` 的原文、`raw_turns` 的历史（只读）；`diaries` 的写权在这一件。
- **考卷**：`test/exam-diary.test.mjs`，25 道，现在 25/25（文本层与口吻层；选料成文管线另在 `diary-v2` 等五份里）。
- **回退点**：`diary-before-part`。
- 换完记在零件册的 `swaps` + 一份活论证。
