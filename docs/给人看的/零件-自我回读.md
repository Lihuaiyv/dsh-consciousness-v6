# 零件 · 自我回读（self_read）

> 这页给主人看：她怎么回头读自己刚说的那句话。
> 骨架照 [零件说明-写法.md](零件说明-写法.md)；工程件：`src/modules/self_read.js`，考卷 `test/exam-selfread.test.mjs`。

## 1. 一句话 + 一个比喻

它管「她说完那句之后，回头读一遍自己的语气」，不管她说什么、也不管情绪下一步怎么走。像合上本子之前，把刚才那句话再念一遍，听听自己当时是什么声音。

真的对应到哪：`affect_v3` 里的快情绪，最多挪一点点；慢情绪和它的时间戳一概不碰。

## 2. 它什么时候醒（触发）

| 谁叫它 | 多久 | 醒来做什么 |
|---|---|---|
| 回复之后（`index.js`） | 每轮一次 | 读这一句的温度，跟当时的快情绪对一对 |
| 页面（`readReplyTone`） | 想看时 | 只读不写，给界面一个温度数 |

它没有自己的定时器；没有这条通路，它不会动。

## 3. 醒来之后走哪几步

1. 读一句的字面温度：长度、语气词、感叹号、冷淡词、短句收句号。
2. 空句、太短（「嗯」「好」）→ 停，不据此改任何东西。
3. 拿温度和现在的快情绪比：差得不够远（不到三成半）→ 不动。
4. 差得远才挪，最多挪一点点；往下改只取一半，防「说得冷淡 → 更低落 → 更冷淡」的自锁。
5. 只写快情绪、总数、`fast_at`；慢情绪和 `slow_at` 不动。

反例：她说了句「算了，随便吧。」，快情绪确实被往下拉了一点；但她之前写过很暖的话、快情绪已经很高，这次只往下修一半——不是每次都能把水位拉回去。

## 4. 素材从哪来（输入）

| 人话名 | 从哪来 | 新鲜多久 | 缺了会怎样 |
|---|---|---|---|
| 她这一句 | 刚发出去的回复正文 | 当次 | 空句就不动 |
| 现在的快 / 慢情绪 | `affect_v3`，只读慢、只写快 | 落库那一刻 | 没有状态就不动 |
| 开关 | `affect.selfread` | — | 关掉就完全不碰 |

它不看什么：不调模型、不做语义判断、不改慢情绪、不改 `slow_at`、不判断这句话说得好不好。

## 5. 它怎么判断（判据）

它其实只问两个问题：这句话有多暖？跟此刻对不对得上？

| 它在问什么 | 什么算过 | 没过会怎样 |
|---|---|---|
| 有多暖 | 长句、语气词、感叹号加分；冷淡词、短句收句号减分 | 只有温度，不改任何东西 |
| 对不对得上 | 跟快情绪差三成半以上 | 差得不够就不动 |
| 改多少 | 一次最多两分 | 超了就夹回来 |
| 往下改多少 | 只取一半 | 防自锁 |

反例：明明是句很暖的话，为什么没改——她现在快情绪本来就在那个温度上，或者那句话太短，读不出东西。

## 6. 它交出什么（输出）

| 层 | 长什么样 | 谁接 |
|---|---|---|
| 情绪 | `affect_v3.fast / total / fast_at` 更新——经由情绪动力的公开写口 `writeFastOnly`，自己不对这张表写 SQL | 情绪动力、说话分寸 |
| 回执 | `{ observed, warmth, delta, applied, reason }` | 调用方 / 日志 |

不写的情况：开关关掉；空句；太短；读出来的温度和现在差不多；没有情绪状态；写库失败。

## 7. 它什么时候会错（已知坑）

| 现象 | 原因 | 现在怎么办 |
|---|---|---|
| 越会哄人，长期情绪越高 | 以前把「说得多暖」直接灌进慢情绪 | 已改：语气只碰快情绪 |
| 说得冷淡 → 更低落 → 更冷淡 | 向下修正没有阻尼 | 往下只取一半 |
| 开关关了还在跑 | 参数目录里没有 `affect.selfread`，`getParam` 读不到 | 已补进参数目录（11-06 立零件时发现） |

## 8. 怎么知道它活着（观察点）

- `affect_v3.fast_at` 在不在动；动了说明回读在写。
- `events` 里没有它的事件——它太轻，不记账；要查就看参数和表。
- 开关：`affect.selfread=off` 时，快情绪不再被回读推动。

现在就能看：看 `affect_v3` 的 `fast` 与 `fast_at`，或把开关关掉跑一轮对比。

## 9. 换它要付什么（代价）

- **能动**：温度怎么算、差多少算对得上、单次上限、往下折半、开关。
- **不能动**：慢情绪与 `slow_at`（那是情绪动力的事）、`affect_v3` 这张表（归情绪动力；回读只走它的 `writeFastOnly` 写口）。
- **考卷**：`test/exam-selfread.test.mjs`，28 道，现在 28/28。
- **回退点**：`selfread-before-part`。
- **换完记在哪**：`parts.js` 的 `swaps`，外加一份 `docs/活论证-自我回读-<日期>.md`。
