# 自我记忆闸门 v2：实施报告（2026-11-05）

目标：不再让「我自己」的话被一刀切扔掉；判不了的交给模型，超限额的退到冷层，真垃圾才丢。

## 改了什么

| 文件 | 改动 |
|---|---|
| `src/modules/memory_source.js` | 新增 `classifySelf()`：三档（ok / drop / unsure）。放宽：不再要求「我」开头，含我即 ok；长度 6–200，超 200 截断而不是整条丢；旁白/噪音才 drop（旁白落冷）。 |
| `src/features.js` | `writeExtractedItem` 改走三档；不确定的用 `opt.selfDecision` 判；超配额（每天 8 / 每 3 小时 2）落冷层而不是丢；`selfCountToday` 不计冷层；新增 `selfWindowState`、`forceCold`、`selfJudgedCache`；ingest 里对拿不准的批量问一次模型。 |
| `src/model.js` | 新增 `judgeSelf()`（ModelPort）与 `judgeSelfByChat()`：批量、两问（主语是不是她 / 是不是真事）、回 `{keep:[]}`、条数对齐。 |
| `src/modules/retrieve.js` | `selfCandidates` 补冷层过滤：冷条目不再借「她自己的名额」硬塞回常规注入（这是本轮找到的漏）。 |
| `src/kernel.js` | 新参数：`self.per_window`(2)、`self.window_hours`(3)、`memory.write.self.judge`(on)、`memory.write.self.judge.per_day`(60)。 |
| `scripts/audit-self-memory.mjs` | 按本地日切（原来按 UTC，跨零点差一天）；新增模型判留 / 落冷两段读数。 |
| `scripts/sim-self-gate.mjs` | 新增：真库头部按新规则分流 + 临时库跑完整写入流程。 |
| `test/self-judge-gate.test.mjs` | 新增 24 条测试。 |
| `test/memory-self-lane.test.mjs` | 契约更新：满额/旁白改为「落冷不丢」。 |

## 数据对比（改动前 → 改动后）

| 指标 | 之前 | 之后 |
|---|---|---|
| 内容闸「开头不像我」误伤 | 8 次 / 近 7 天，全部整条丢 | 含「我」即留，误伤 0 |
| 超每天 8 条 | 408 次，全部丢弃 | 落冷层，0 丢失（深查可翻） |
| 真库抽样 153 条被挡头部 | — | 规则直接留 148（96.7%）、交模型 4、真丢 1 |
| 模型调用 | 无 | 只问拿不准的；抽样里 153 条只问 4 条，一批一次，缓存去重 |
| 冷层误入常规注入 | `selfCandidates` 无过滤，会硬补回来 | 已修：冷层不进 S1（S2/S3 深查仍可见） |
| 模拟 12 条候选写入 | 按旧规则：热 8、其余丢 | 热 2、冷 10、丢 0，存下来的+明确丢掉的=候选数 |

> 注：模拟里的「热 2」是因为窗口配额（每 3 小时 2 条）被 12 条连续候选一次占满，属于瞬时情况；正常一天是 8 个窗口 × 2 条。
