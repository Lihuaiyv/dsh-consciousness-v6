# 声学：让耳朵也听见「怎么说」（2026-11-08）

> 一句话：转写只交字，声学补上快慢、起伏、停顿、音高；只量，不猜情绪。

## 为什么现在做

主人按空格说话，问「你听得见我的语气吗」。答案是不能：`transcribeVoice` 只回
`{ text, audioSeconds, inferenceSeconds }`，音频转完就丢。同一段声音里「说得多快、
声音稳不稳、中间停没停」全在识别那一步没了。

## 量的是什么

20ms 一帧，算每帧 RMS；静音门用本段自己的 p10/p90 之间切
（`min(hi*0.5, lo+(hi-lo)*0.22)`），不写死绝对阈值——设备音量和距离都不一样。

- `voicedRatio` 有声帧占比
- `pauses` 句中停顿次数（连续 ≥60ms 静音，首尾不算）
- `phrases` 被停顿切出来的小段数（一口气一段）
- `loudness` 说话时平均响度（相对满幅）
- `dynamic` 音量起伏（变异系数）
- `pitchHz` 中位音高（**自相关**，不是过零率）
- `periodicity` 周期性 0~1（自相关峰的高度：周期越齐越高，气声 / 沙哑会掉下来）
- `pitchSlopeSt` 句尾相对全句的音高偏移（半音，正 = 往上挑）

### 音高为什么不用过零率了

过零率对气声、噪声会飙到顶，女声和耳语偏得离谱。换成 40ms 窗的自相关，
在 60–500 Hz 的 lag 区间找峰，抛物线插值到亚采样精度。

### 但自相关有个坑：八度错误

440 Hz 的周期是 36.36 个采样。三倍周期 109 反而更接近整数，自相关在
lag=109 的峰比 lag=36 更高——**直接取全局最高峰会把音高判成 147 Hz**。
（第一版就是这么错的，考卷当场抓住。）

修法：取「第一个够高的局部峰」（r ≥ 全局峰 90%、且是局部极大），
而不是全局最高。考卷里专门有 220 / 330 / 440 三条守着它不再回来。

### 第二个坑：假装成 jitter 的语调

第一版还算了 `jitterPct`——拿「相邻 20ms 帧的音高差」当声带抖动。
真机一跑，**每句话都算出 14% 左右**，于是每句都被判成「声音发颤」。

原因：20ms 一帧量到的是**语调**，一句话里音高本来就在动；真正的 jitter 是
毫秒级、相邻周期之间的差，20ms 的帧根本看不见。`shimmerPct` 同理，
它量的是音节之间的响度变化，跟 `dynamic` 重复。

所以删掉这两个，换成 `periodicity`（自相关峰的高度）：周期齐 → 接近 1，
气声、沙哑、绷着说 → 峰掉下来。这是 20ms 粒度上真正看得见的东西。

第一版存进 `voice_baseline` 的那几行旧值一并清掉了，旧列留着不管。

`describeShape` 用字数/时长估语速，拼一句「说得快（6.2 字/秒）· 音量正常 · 声音很稳」。

## 边界（重要）

- **只量不猜**。这些数字不等于「他在生气」，翻成情绪仍然是模型的事，会错，跟现在靠字猜一个水平。
- 声学失败了不能拖累转写：`pcmShape` 量不出就返回 `null`，转写照走。
- 那一行只活一轮：`takeVoiceShape` 读后即删，不留给后面几轮冒充。
- 没碰注入顺序、没碰 `hostSpec`、没加表。

## 怎么验证

1. 刷新页面（前端）；宿主要重载插件（设置 → 插件里关再开）才有 `shape`。
2. 按空格说一句，看回来那轮的系统提示里有没有「刚才那段语音的声儿：…」。
3. `node test/acoustics.test.mjs`、`node test/exam-ear.test.mjs`、`node scripts/check-parts.mjs`。

## 个人基线（2026-11-08 晚补）

绝对音高没意义——男声 120Hz 和女声 220Hz 都正常。有意义的是「他今天比**自己平时**高了多少」。
所以加了一张一人一行的小表：

```
voice_baseline(agent_id, speaker, pitch_hz, loudness, periodicity, cps, samples, updated_at)
```

- **冷启动**：前 5 次只记不判（样本太少，平均一抖就离谱），第 6 次开始才敢说「比平时」。
- **滚动**：冷启动内用简单平均（α = 1/(n+1)），之后 α = 0.15（约七次语音跟上一半）。
- **顺序**：先拿旧基线算这一句的漂移，再把这一句滚进基线——不然它是跟自己比。
- **门槛**（低于这些一律不提，免得每句都在说「差不多」）：
  3 个半音 / 响度差 35% / 周期性掉 0.15 / 语速差 30%。
- **不进基线**：有声占比 < 0.15、或没估出音高的（一句「嗯」没有代表性）。
- **输出**：最多两项，「比平时高」「比平时快」「比平时虚」「比平时响」。
  **不解释原因**——「比平时高」能量出来，「紧张了」不能。

进注入那行时拼成：

> 刚才那段语音的声儿：说得快（6.4 字/秒）· 声音发稳，比平时高

旋钮都在 `src/modules/voice_baseline.js` 的 `VOICE_BASELINE_TUNING`，改一处就够。

## 没做的

- 声学还没喂进 `affect_user_read` 的校准——那是再下一步：让「读你情绪」不只看字。
- periodicity 的 0.55 / 0.80 门槛是从纯音（≈0.99）和白噪声（≈0.1）两头夹出来的，
  **真人嗓门的落点还没校准**，第一次真机跑完要按实际数再调。
- 基线只分 default 一个人。认人（rel_person）接上之后，才按 speaker 拆开。
- 没接情感模型（sherpa-onnx / funasr 那类），也没做实时流式。
