## 四点半、复查修正（第二次整体检查）

复查抓到并修了 3 个 bug、1 个误判风险：

1. **QQ 召回路径没接护照/挤出**（只接了网页路径）→ 已修；eject 测试加 QQ 入口用例 9/9。
2. **S4 开关没注册进 PARAMS**（`getParam` 返回 undefined，开关永远 off）；且 `decideWrite` 判「新增」时不带 target，S4 永远不触发 → 已注册参数；new 分支带 target；S4 统一放到 `applyWrite` 入口，只对 conflict/new 生效。集成测试 8/8。
3. **同主题判定太宽**：104 对里 96% 是「同主题、不同事」（如「QQ机器人」vs「配置 allowUsers」），直接挤出会丢事实 → 收紧为「2-gram 重叠 ≥3；同 key 或状态反转才挤，其余只标」。真实库强判从 104 降到 2。
4. **跨库误报**：2 字主题（「标签」「错误」）命中一堆无关纪要/日记 → 主题 ≥3 字才查，且正文 2-gram 要相关。跨库命中从 15/200 降到 2/200。

回归：run-tests 560/560（复查后重跑），新增用例 52/52。
