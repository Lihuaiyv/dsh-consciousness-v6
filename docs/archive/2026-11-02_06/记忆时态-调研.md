# 记忆时态与过时事实：外部研究 / 产品调研

> 2026-11-04 夜。为「把过去当现在」找参照。抓取只到 2026-11-04 可见的资料；标「仅标题」的是页面抓取失败、只确认了存在与方向。

## 一句话结论

这不是我们独有的问题。2026 年的研究已经把病理写得很清楚：**过时的旧说法和正确的新说法同时出现在上下文里时，模型会被旧的那条带偏**；**压缩会把「大概/听说」写成确定的事实，而模型服从的是语气里的确信度，不是来源**。所以「加个标注」不够，要靠「把旧版挤出注入 + 保留原话语气 + 冗余来源」。

## 研究

### LongMemEval（ICLR 2025）
[arXiv:2410.10813](https://arxiv.org/abs/2410.10813)

- 500 题，考五件事：信息抽取、多会话推理、时间推理、**知识更新（knowledge updates）**、拒答。
- 商业聊天助手 / 长上下文模型在多轮持续交互上掉 30%。
- 把长期记忆拆成三阶段：**indexing / retrieval / reading**。
- 三个优化：会话分解（值粒度）、事实增强的键扩展（fact-augmented key expansion）、**时间感知的查询扩展（time-aware query expansion）**，用来收窄「该找哪段时间」。
- 对我们的启示：知识更新是独立的评测能力；时间感知检索是标准动作；没有评测集就先自建小回放。

### When Retrieval Is Not Enough: Obsolete Facts in Agent Memory（NeurIPS 2026 PALM）
[arXiv:2610.36308](https://arxiv.org/abs/2610.36308)

- 在 MemoryAgentBench 的 FactConsolidation 单跳任务上：Qwen2.5-7B 的 BM25 准确率从 45% 掉到 32%，仅仅因为检索证据预算从 64 增到 512 token——**检索到更多证据反而更差**，而 gold 审计显示最新说法每次都在检索集里。
- 受控实验：证据 4 条、同样的提示词，把一条无关证据换成**过时的竞争陈述**，准确率从 100% → 44.6%（Qwen2.5）/ 87.8%（Qwen3-14B）。50 个有害翻转全部归类为「过时（stale）」。
- 结论原话：**「检索到正确事实并不够。一条过时的竞争陈述，可能比同尺寸的一条无关证据更有害。」**
- 对我们的启示：这就是「旧结论当现状」的实验室版。旧条和新条平权地进注入，模型会挑错；所以必须让旧条退场或明确降级，不能只靠我读标签。

### Manufactured Confidence: How Memory Consolidation Turns Hearsay into Confident Facts
[arXiv:2606.29279](https://arxiv.org/abs/2606.29279)

- 记忆产品（mem0、LangMem 被测）把对话压成「事实」时，会把一句带保留的话（「大概/听说」）改写成一条确定的、带日期的断言；下游 agent 就按「经过核实的事实」来用。
- 关键发现：agent 服从的是**措辞里的确信度**，不是来源——带署名的、甚至伪造「system of record」的说法，服从率一样高（0.81）；而带 hedge 的说法服从率接近 0。
- 不需要攻击者也会发生：一个曾经真实、后来过时、但从没被纠正的说法，就是平的「事实」（表 3：自然过时 → 授权错放 0.69 / 0.75）。
- 修法：
  - 被动「unverified」标签被忽略（有时有用、有时没用，依赖模型）。
  - 主动「不要信」指令只会让 agent 放弃判断（正确记忆也一起 refuse）。
  - **真正有效的修法在存储端：保留当时不确定的措辞，不要升级成确信**。
  - 单条承载性记忆本身是风险；**加一条冗余来源**才能恢复判别力（错误授权 0.00，且不 escalations）。
- 对我们的启示：我们的 reflect 压缩把「情绪快照还没做完」压成一句「用户较真」——正是 de-hedging；而且它还是「确信」语气。只加「（后来还有更新的）」标签，在论文里对应「passive tag 被忽略」，所以不能只做标签。

## 产品 / 项目

- **Zep / Graphiti**：双时间知识图，边上带 `valid_at` / `invalid_at`；更新边时可以清空时间戳、替换属性（[changelog](https://help.getzep.com/changelog/2026/6/25)）。论文：[Zep: A Temporal Knowledge Graph Architecture for Agent Memory, arXiv:2501.13956](https://arxiv.org/abs/2501.13956)。思路与我们 `invalid_at + valid_from + 冷库原句` 完全同族。
- **Mem0**：被指出 ADD-only 架构**不做语义相似记忆的冲突消解**（[issue #4896](https://github.com/mem0ai/mem0/issues/4896)），后续有 PR 补「语义冲突消解」；还有「update 与 delete 竞态会复活已删记忆」的修复（[PR #7788](https://github.com/mem0ai/mem0/pull/7788)）。说明连头部产品也在补这一课。
- **Letta（MemGPT）**：memory blocks 常驻 + 后台整理（sleep-time compute），把「整理记忆」当独立的后台任务。[GitHub](https://github.com/letta-ai/letta)、[sleep-time-compute](https://github.com/letta-ai/sleep-time-compute)。
- **LangMem**：整合 / 更新记忆；被 Manufactured Confidence 点名与 mem0 同类的 de-hedging 问题。
- **Generative Agents**（Park et al., 2023）：memory stream + 反思；检索按 recency / importance / relevance 加权。[arXiv:2304.03442](https://arxiv.org/abs/2304.03442)。它的 recency 是「时间衰减」，但没有处理「同主题新旧冲突」。

## 对照我们的六库

我们已经有：`memory_timeline`（事件流水，含 reason）、`fact_archive`（冷库版本原句）、`raw_turns`（原话）、`invalid_at + superseded_by`（取代链）、`asof` 查询。方向与 Zep 同族，**不用重建**。

缺的三件，按证据强度排：

1. **过时条目仍与现状同权地进注入**（Obsolete Facts 的核心）。标签不够——研究里旧证据在场就能把准确率打到 44.6%。修法：同一主题只让最新一条进注入，旧条退场或降为「深查可见」。
2. **压缩抹平不确定性**（Manufactured Confidence 的核心）。reflect 的合成稿是「确信」语气，而且把「还没做完」这类未完成状态吞掉。修法：压缩稿必须保留原措辞的不确定/未完成；别把「大概」写成「是」。
3. **没有冗余来源**：我们其实有（冷库原话 + 记忆条目），但注入时没并用。研究说判别力来自冗余，不是标签。修法：涉及「现在怎样」的条目，注入时同时给「当时条目」和「原话/最新条目」。

## 对计划的调整

- **P2 的重心从「加一行最近变动」改成「同主题旧条退出注入，新条顶上来」**。标签只作辅助，不作主修。
- **P3（同主题 key 归一）优先级提高**：它是唯一能确定性地把旧条挤出注入的机制。先 dry-run 量能接上多少对。
- **P4（reflect 压缩）**：按「保留不确定措辞」改，而不只是保护待办词。
- **新增 P1.5 小回放集**：从真实库取 20–50 对「旧结论 + 新进展」，测「注入后回答现在怎样」的准确率，对标 LongMemEval 的 knowledge update。先量基线，再谈改没改好。
