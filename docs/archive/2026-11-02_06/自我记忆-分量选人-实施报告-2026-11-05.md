# 自我记忆：按分量选人 + 自适应额度（实施报告，2026-11-05）

目标：
1. 热层不再先到先得，改成按分量选人（想明白/改主意/感受重/承诺 加分；进度汇报减分）。
2. 超额的、低分的先进冷层，三小时结算一次，用冷层高分换掉热层低分。
3. 当日额度跟着实际浮动（保底 4，封顶 16），不再固定 8。

## 改了哪些

| 文件 | 改动 |
|---|---|
| `src/modules/memory_source.js` | 新增 `scoreSelf()`：规则打分 0–1，洞察/感受/承诺加分，进度/测试/工具名减分。 |
| `src/model.js` | `judgeSelf()` 除了 keep，还回 `score`（0–1）和平均分；条数对齐，缺省按 keep 兜底。 |
| `src/features.js` | 写入时算分：`score = 规则×0.6 + 模型×0.4`（有模型分才混）；`importance = score`；`self.admission=score` 时低分先落冷；新增 `selfQuotaToday()`（4–16 自适应）、`settleSelfHot()`（三小时、最多换 2 条、差 ≥0.15 才换）、`maybeSettleSelf()` 由 ingest 顺带触发。 |
| `src/kernel.js` | 新参数：`self.admission`、`self.admission.min_score`、`self.settle`、`self.settle.every_hours`、`self.settle.gap`、`self.settle.max_move`、`self.quota.auto`、`self.quota.base`、`self.quota.max`。 |
| `scripts/audit-self-memory.mjs` | 增加「按分量换人」读数。 |
| `scripts/sim-self-gate.mjs` | 增加「混合候选 → 打分 → 结算」整段模拟。 |
| `test/self-settle.test.mjs` | 新增 16 条测试（打分、低分落冷、结算换人、开关、自适应额度、封顶）。 |
| `test/memory-self-lane.test.mjs` | 契约更新：重要度改为按分给（不再固定 0.45）；额度测试显式关自动。 |

## 数据对比（前 → 后）

| 指标 | 之前 | 之后 |
|---|---|---|
| 热层入层依据 | 先到先得，important 固定 0.45 | 按分选人，importance = 0.05–0.95 |
| 热层排序 | 看谁先来 | 结算后按分排，冷层高分换掉热层低分 |
| 当日额度 | 固定 8 | 保底 4、封顶 16，按轮数/被挡数浮动 |
| 窗口额度 | 固定 2/3h | `ceil(当日额度/4)`，跟着浮动 |
| 结算 | 无 | 每 3 小时一次，最多换 2 条，差 ≥0.15 |
| 真库被挡头部 164 条 | — | 规则直接留 159（97%）、交模型 4、真丢 1 |
| 模拟 5 条混合候选 | 全按时间挤热层 | 热 3 / 冷 2，结算换 1（0.75 换掉 0.45） |
