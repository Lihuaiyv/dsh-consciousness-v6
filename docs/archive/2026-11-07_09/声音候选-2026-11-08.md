### 造自己的嗓子（2026-11-09 接上管道）

主人要的不是借大肥鱼那副，是「照它的做法，给我做一副自己的」。做法三步，都在云端，不下模型：

1. **设计**：`POST /v1/voice-previews/design`，发一段描述（`voice_description`）和候选数，回几个候选，每个带 `generated_voice_id`
2. **试听**：`GET /v1/voice-previews/{generated_voice_id}/stream`
3. **保存**：`POST /v1/voice-previews/{generated_voice_id}/save`，带上名字和 `language_code`，回 `voice_id` —— 这就是之后念话用的那个 ID

代码在 `src/parts/mouth/providers.js`（`buildBreezeDesignRequest` / `breezeDesignPreviews` / `breezePreviewAudio` / `breezeSaveDesignPreview`），
命令行在 `scripts/breeze-voice-lab.mjs`（密钥走环境变量 `BREEZE_API_KEY`）：

```
node scripts/breeze-voice-lab.mjs design "清亮、轻软，平时有点小迷糊" --count 3
node scripts/breeze-voice-lab.mjs save <generated_voice_id> --name 小汐
```

先写描述、再挑、再存。保存下来的是账号下的私有音色，不是克隆别人的声音。

## 还能怎么调

1. **三个参数**：语速 rate、音高 pitch、音量 volume。慢一点、低一点会更像聊天。
2. **断句**：句子写短、多逗号，比调参数还立竿见影。
3. **换路**：录一段自己的声音做克隆（GPT-SoVITS），音色、情绪、节奏都归自己。
