# 病例 · 读数念错了对象（2026-11-07）

> 只记事实，不写方案。给以后修情绪 / 修读数的人。

## 现象

提示词里那行「（上一句落在我身上的样子：你说「…」，那一刻 读出的是 X…）」，把**跨小时的慢状态标签**，写成了**这一句的判读**。

## 现场（2026-11-07 17:51:54，本地）

- 用户原话：「现在你系统里面都有啥啊」——一句普通问话。
- `affect_events` 那条：`label=irritated`、`sig=0.01`、`gate=0`（没过闸，几乎没推动）。
- 同时段 `affect_samples`（17:34–17:55 前后）：标签先是 `confused`，17:45 起变成 `irritated`，强度 0.66 上下——这是状态，不是这一句。
- 提示词实际念出：
  「（上一句落在我身上的样子：你说「现在你系统里面都有啥啊」，那一刻 读出的是有点烦——绷着（几乎全是我自己的反应，从你那儿来的只有一点点）。这是那时候的样子。）」
- 「绷着」来自 `arousal > 0.3`，也是状态轴。

## 错在哪

- 配对（`felt_snapshot.js` 的 `pickPair`）只看两件事：时间差 ≤ 2 秒、`label` 相同。
- 不读 `gate` / `sig` / `intensity`。
- 念出来的 `label` 取的是样本的（状态的），不是事件判出来那一句的。

所以：闸门自己说「这句几乎没推动」，那行还是把它念成了「那一刻读出的是有点烦」。

## 期望（不写方案，只写想要什么）

- 事件那一句只说「推动」：几乎没动 / 动了一下 / 被砸了一下。不给情绪词。
- 要说靶子就带靶子：冲我来的 / 不是冲我来的 / 说不清。
- 状态那一层如果要说，单独一句、带「这阵子」，不和「你这句」混在一句里。
