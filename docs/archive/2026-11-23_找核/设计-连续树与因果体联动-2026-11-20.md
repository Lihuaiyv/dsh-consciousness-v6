## 一、先纠正一个错：节点不共用

我一开始说「两套网共用节点」。错的。

- **大因果体的节点是「事」**（`hot_events` 一行）
- **连续树的节点是「帧」**（最小状态切片）

不是同一个东西，不能共用。正确的是三层嵌套：

```
帧  ⊂  事  ⊂  连续线
```

**事由帧组成。** 一件事展开就是一串帧；一条连续线展开就是一串事。

这件事顺带解决了一个我一直标成「最大未解项」的麻烦——「帧按轮切、连续格按状态切，两者对不齐」。**按三层嵌套看，它们本来就不该对齐。** 帧是细尺度，事是粗尺度，粗粒度的边界本来就是若干细粒度单元聚合出来的。硬要对齐，才是错的。

这不是我拍脑袋，是现成的机制：Baldassano / Zacks 那套 **Event Segmentation**（Neuron 2017）就是说，大脑里每个区域按自己的偏好时间尺度切 event——早层切短、高层切长，**event 层次是嵌套的**，人标的粗边界对应层级顶上的长 event。见 [Discovering Event Structure in Continuous Narrative Perception and Memory](https://pmc.ncbi.nlm.nih.gov/articles/PMC5558154/)。

## 二、联动一：用连续树给因果边做「结构证据」

### 2.1 现在判边的弱点

大因果体判边靠模型给 `pull`（−1~+1）。文档里自己写过这条的风险：

> `pull` 是模型判的，不是物理量；不校准就会「看着很合理，其实在编」。

现在唯一的硬约束是「必须抄得出证据引文」。但引文只证明**两件事提到了同一个东西**，不证明它们之间有因果。

### 2.2 能补上的那种证据

连续树记下来的东西是另一回事——**它记的是「我确实沿着这条线走过」**。

所以候选边 A→B 可以多问一句：

> **A 那些帧，和 B 那些帧，是不是走在同一条 `under` 线上、前后相接？**

| 结构关系 | 判什么 |
|---|---|
| 同一条线、前后相接 | **强旁证**。这条因果不只是「文字像」，是「我走过」 |
| 同一条线、隔了很远 | 弱旁证。可能是同一条线上的两个阶段，不是直接因果 |
| 不同线、但两条线在某一格上相交 | 中等。可能是「做了 A 才腾出手做 B」这类间接关系 |
| 完全不同、无关的两条线 | **降级**。这条「因果」多半是硬连的 |

### 2.3 这不推翻 `pull`，是给它一个锚

`pull` 还是模型给，但**它的强度要能被结构证据校准**：

- 结构证据强 + 引文硬 → 可以进主干
- 结构证据强 + 引文软 → 进候选，不进主干
- 结构证据弱 + 引文硬 → 进候选（引文有时比路径更可靠：两件事真有关，但我当时是间断做的）
- 结构证据弱 + 引文软 → 不进

**四个格子都留着**，不把结构证据当唯一标准。原因跟大因果体文档里那条一样：**图的错比没有图更糟。**

### 2.4 一个必须承认的偏差

连续树只记「我走过的」。**没走过的不等于不相关。** 所以结构证据只能用来**降级**，不能用来**确证**——「没走过这条线」不等于「这两件事没因果」。

这条跟大因果体文档 §7.1 的「开世界假设」是同一条：没有边 ≠ 没有因果，只代表还没证据。

## 三、联动二：摊开事内部的索引逻辑

### 3.1 现在事是黑的

`hot_events` 一行只有摘要、抓手、引文。**事内部怎么走过来的，看不见：** 开头在哪、中间拐了几次、哪一步被否、结论落在哪。

现在要问「这件事后来怎么定的」，只能看摘要，摘要里只有结果。

### 3.2 挂上帧之后能看见什么

一件事 = 一串帧。这串帧上有 `under`、有状态、有 `tried`。于是：

| 能答的问题 | 靠什么 |
|---|---|
| 这件事拐过几次 | 帧里 `under.step` 的变化次数 |
| 哪一步被否了、因为什么 | `tried` 里带 `why_failed` 的条目 |
| 结论落在哪一帧 | 最后一帧的 `state = done` |
| 这件事卡了多久 | 帧的 `at` 跨度，以及中间有没有空档 |
| 当时是不是想岔了 | 帧里的 `prev` 与 `under` 是否对得上 |

**这是「事节点内部的索引逻辑」的具体内容。** 不是给事加一个字段，是让事的内部可展开。

### 3.3 但不要把内部全摊进检索

跟失败记录只注入一行同一条理由（Ghost Action）：**内部结构是查的时候用的，不是每轮都摊出来的。** 检索时最多给一句「这件事中间被否过一次，后来从 B 走通了」，细节留在库里。

## 四、颗粒度怎么对齐（这是这份文档最要紧的一节）

三层各有各的切法，不对齐——但三层之间必须有锚，否则上面两节都是空话。

**锚就是帧，因为帧同时知道两件事：**

```
一帧上同时有：
  prev           → 我在时间线上接哪句（帧链）
  under.line     → 我属于哪条连续线（连续树）
  under.step     → 我在那条线的哪一格（连续树）
  事（事的 id） → 我属于哪件事（因果体节点）   ← 本节要加的第三个指针
```

**帧是唯一同时挂在这三套结构上的东西。** 所以：

- 事 ← 帧（`frame.event_id`）→ 事的内部可展开
- 线 ← 帧（`under.line`）→ 连续线可回溯
- 因果体的边 ← 两端事各自的帧 → 可以问「走没走过同一条线」

**对齐不是让三种切法一样，是让帧同时提供三个指针。** 这就是这一节的答案。

## 五、研究参照（2026-11-20 检索）

| 工作 | 做了什么 | 跟这里的关系 |
|---|---|---|
| [Event Segmentation（Baldassano & Zacks, Neuron 2017）](https://pmc.ncbi.nlm.nih.gov/articles/PMC5558154/) | 各脑区按偏好时间尺度切 event，**event 层次嵌套**，粗边界对应长 event | **本文件第一节的根据**。三层不对齐是对的，不是缺陷 |
| [Event Horizon Model / Landscape Model](https://psycnet.apa.org/manuscript/2027-27655-001.pdf) | event 边界支持多时间尺度上重构结构关系 | 支持「粗尺度靠细尺度重建」；也支持内部可展开 |
| [Narrative Grammar](https://onlinelibrary.wiley.com/doi/pdf/10.1111/cogs.12016) | 叙事有递归的相位结构（head + phase），不是一串平铺 | 每格有 head；「这件事说到哪了」不是看时间最新，是看 head |
| [ETAMem](https://export.arxiv.org/pdf/2610.37443) | 多视图记忆：解耦并对齐异构信息，原子记忆单元 | **最接近「解耦 + 对齐」的做法**；它的对齐也是靠统一单元，跟我们靠帧一样 |
| [MAGMA](https://aclanthology.org/2026.acl-long.1709/) | 语义/时间/因果/实体四张正交图，按意图路由 | 强证据：**多张图正交是对的**，不要合成一张 |

**我们的不一样在哪：** 上面这些要么是「一次感知里的event 切分」，要么是「文档/对话的记忆框架」。这里要的是——**用细尺度的记录（帧）去验粗尺度的猜（因果边）**。这个方向它们都没做。

## 六、被否掉的方案

| 方案 | 为什么不行 |
|---|---|
| 两套网共用节点 | 错。事和帧是不同尺度，共用就把「一个事 = 一串帧」这个结构压平了 |
| 把 `event_edges` 和 `under` 合成一张边表 | 不行。一个是「因为」，一个是「为了」，混了读的人分不清。文档里混网的坑已经踩过一次 |
| 结构证据命中才连边 | 不行。没走过 ≠ 不相关（开世界假设）。结构证据只能降级，不能确证 |
| 只靠结构证据，不看引文 | 不行。我可能间断地做了两件真有关的事，路径上断开了，但因果是真的 |
| 事内部全摊进检索 | 不行。Ghost Action。 |
| 三层切法强行对齐 | 不行。是嵌套关系，硬对齐等于把细尺度噪声当边界 |

## 七、验收

1. **结构证据有没有降噪**：抽 100 对已判的候选边，看「结构证据弱 + 引文软」那格里的边，**precision 是否低于「结构证据强 + 引文硬」那格 20 个百分点以上**。是 → 这个信号有用；否 → 别用。
2. **不误杀**：抽 30 对「结构证据弱但人工判真有因果」的，不能被当成假的丢掉。丢掉超过 20% → 降级规则太狠，要放宽。
3. **事内部能展开**：取 10 件事，摊开它们的帧序列，人工看「这一段像不像这件事的来龙去脉」，1~5 分，平均 ≥3.5。
4. **检索不涨**：注入 token 中位涨 ≤10%。
5. 门禁 599/599。
6. **这一版只读**：只做「算结构证据 + 摊开内部」的只读脚本，不写 `event_edges`，不改判边逻辑。

## 八、退路

- 全部只读，第一步不落任何库。
- 结构证据只作一个**旁注字段**，不进 `pull` 本身；要关就关。
- 事内部的展开是查询时算的，不落表。

---

## 九、还没定的

1. **事 ↔ 帧的对应由谁写。** 一帧属于哪件事，是切事时写、还是事后回填、还是算出来的。这个没定，第四节的第三个指针就落不了地。
2. **「同一条线」怎么判「前后相接」。** 相邻格算相接，隔一格算不算？没定。
3. **结构证据的强度怎么给数。** 现在是四个格子（强/弱 × 引文硬/软），要不要进一步给连续权重，没定。
4. **一件事跨了多条线怎么办。** 一件事可能同时推进两条连续线。这时候内部展开会分叉，怎么处理，没定。
