## 二、按新定稿（11-17 01:12）要重做的

1. **事帧字段**：代码里现在是 `summary / what / target / act / who / agency / material`；
   设计定稿是 `事 / 材料 / 冲谁`。要收敛。
   「事」= 对**最近十轮摘要**的总结，最多 50 字，不设下限（2026-11-17 13:56 主人定）；这就是「正在发生什么」。
   现在的代码里 `summary` 是这一句的总结（规则帧更粗，是「主人在批我」），对不上。
2. **判断层提示词**：现在是打补丁版（被否区分、工作事务一律 0、原话门槛、三条反例、平常就 0/0.1/0）；
   按三问重写，不要场景清单和反例。
3. **判断输入**：现在喂整帧（summary + 这一句 + 六摘要 + 六原话）；按「事 / 材料 / 冲谁」喂。
4. **时序口径**：已定（2026-11-17 主人）：上一轮结束后异步只做到「事帧的总结」；这一轮用户说话后，代码拼事帧 → 判断层 → 情绪 → 提示词。判断属于这一轮。设计文档 §2.1 的旧说法以这条为准，设计文档不动。
