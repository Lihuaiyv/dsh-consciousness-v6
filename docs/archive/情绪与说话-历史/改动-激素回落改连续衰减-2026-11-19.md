# 改动 · 回落从「开关」改成连续衰减 + 判断层肯给小数（2026-11-19）

> 主人：「现在先全都按照你的搞，然后你测试呗，测试看看能不能跟现实情况差不多。」
> 起因：影子表 2,695 轮真实数据里，s（安）中位 **0.758**、P90 **1.000**，59% 的轮次落在「安住」格，
> 而判断层给的三个 delta **93.4% 全是 0**。情绪要么冻着，要么顶在天花板。

## 一、查出来的病（按严重程度）

1. **回落是开关，不是连续的**：只在贴顶（≥0.85）或贴底（≤0.15）连续 45 分钟后才启动，落到 0.78 停。
   日常值就在 0.7-0.78 之间，永远够不到触发线——空调设 32 度，屋里常年 31.8 度。
2. **判断层在源头被压住了**：`JUDGE_SYS` 里明写「没动到就给 0，**不要为了有数硬给一个**」。
   模型照做，93.4% 三轴全 0。这不是模型懒，是提示词不许它给。
3. **三条轴的时间尺度反了**：欲 2.0h 比安 1.2h 还慢。可「这事有没有奔头」该是短的。
4. **维持窗 0.5 小时**：连续聊天时一直在加热。
5. **「越靠边越推不动」+「不回落」**：推到边上就住下了。

## 二、改了什么

### 1. `affect_v4.js` · `advanceState`

默认换成**连续指数衰减**（`decay !== 'step'`）：

```
新位置 = 基线 + (旧位置 − 基线) × exp(−(经过时间 − 维持窗) / tau)
```

每一轮都算，没有阈值、没有带子、没有疲劳窗。离基线远落得快，近落得少。

| 轴 | 旧 tau | 新 tau | 理由 |
|---|---|---|---|
| 安 s | 1.2h | **6h** | 底色，跟着日子走 |
| 觉 n | 0.5h | 0.5h | 猛一下，很快就过去（不变） |
| 欲 d | 2.0h | 2.0h | 这事成不成，过了就淡（不变） |

维持窗 0.5h → **0.02h（约 1 分钟）**：一轮对话间隔常常就一两分钟，给长了等于每轮都不落。

旧那套（贴顶才回落 + 0.78 带子）完整保留，`affect.v4.decay=step` 一键退回。

### 2. `affect_v4_shadow.js` · `v4Opts`

**这处是「检查两遍」查出来的**：`advanceState` 里的默认值会被 `v4Opts` 显式传的 `hold`/`tau` 覆盖，
只改 `advanceState` 等于白改。所以 `v4Opts` 的默认也一起改成 0.02 / 6.0，并新增 `decay` 参数
（`affect.v4.decay`，默认 `exp`）。

### 3. `affect_v4_shadow.js` · `JUDGE_SYS`

删掉「没动到就给 0，不要为了有数硬给一个」，换成：

> **别习惯性给 0。** 真人每聊一句，心情都会轻轻挪一下——被接住一点、被搁了一下、有点想继续、有点走神。
> 这些都很小，但它是真的，给 ±0.02~±0.15 就对了。只有这一句跟上一句完全一样，才给 0。
> 正负都要有：全是正数会一路涨到顶，全是负数会一路掉到底。

三处「→ 0」也改成给小数（`顺了一点 / 钝了一点 → ±0.05~±0.15`、`一直在预料里 → +0.02~+0.05`、
`和预期差不多 → ±0.05 以内`）。

### 4. `check-affect-delta.mjs`

那些测「维持窗 / 0.78 带子 / 贴顶 45 分钟」的断言，全部显式标 `decay: 'step'`——它们测的是**旧规则**，
旧规则还在，就该继续被守住。另外新加两条测新规则：
- 新规则：半小时内已经在回落，不再死等
- 新规则：0.75h 后觉比安落得多

## 三、实测（只读重放，2,695 轮真实位置）

| | 球心 | 安住 | 沉沦 |
|---|---|---|---|
| 改前（表里存的） | 11% | 48% | 23% |
| 改后（连续衰减） | **39%** | **35%** | **14%** |

球心从 11% 涨到 39%：情绪现在会掉回平静，不再钉在 0.75 那一带。

**但 s 的均值几乎没变**（0.593 → 0.596）——因为判断层 93.4% 还在给 0，没有推动，衰减只能把它拉回基线；
少数大幅推动又直接顶到天花板，中间是空的。所以第三步（改提示词）才是补中间那段的。
