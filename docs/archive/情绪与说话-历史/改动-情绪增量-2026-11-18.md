# 改动：判断层出增量 + 情绪维持与回落（2026-11-18）

> 主人原话（0:27）：「判断层的数变成 SND 的增量，而不是目标点。激素分泌只是情绪的增量，不是目标点。」
> 定盘文档：[思路-情绪增量与回落-2026-11-18.md](思路-情绪增量与回落-2026-11-18.md)（本文按它落地）。
> 一句话：判断层不再「瞬移定到某个位置」，改成「这一下推动多少」；情绪按「先回落、再加一点」走，涨起来维持半小时，之后回落到平静。

公式（`advanceState`）：

```
先回落（每轴自己的 hold / tau）：
  hours = now - lastAt
  if hours > hold[轴]:  P = 平静 + (P - 平静) × exp(-(hours - hold[轴]) / tau[轴])
再加增量（每轴自己的算法，见下）：
  S：越往边上推越推不动；往平静拉回给全速
  N：尖峰包络（max），不叠
  D：慢涨快跌
```

## 一之五、三条轴各自的算法（2026-11-18 主人：「不光是回落，每个增量也应该单独设计算法」）

| 轴 | 增量算法 | 回落速度（默认） | 为什么 |
|---|---|---|---|
| **S 现状 / 心情** | **带软边的累积**：`S += ks×Δ×(1-0.6×离基线距离/0.5)`；往平静方向推不给折扣 | 维持 0.5h，τ=1.2h | 心情会攒，但已经很高兴时再被夸一句不该再涨一大截；掉下来反而快 |
| **N 意外 / 警觉** | **尖峰包络**：`N = max(回落后的 N, 平静+kn×Δ)`；Δ<0（比预想平静）不压，交给回落 | 无维持窗，τ=0.5h | 去甲肾上腺素是事件性爆发——两件意外不会叠成「更意外」，第二件只在更强时顶上去；意外是分钟级的 |
| **D 奔头 / 想要** | **不对称**：涨 `kdu=0.25`，跌 `kdd=0.45` | 维持 0.5h，τ=2.0h | 奖赏预测误差里，落空（该来的没来）比多给一点更重；奔头攒得慢、散得也慢 |

系数可调：`affect.v4.dyn.ks`（0.35）/ `.kn`（0.85）/ `.kdu`（0.25）/ `.kdd`（0.45）。
N 用 0.85 是为了保住量程：包络不叠，但单次冲击要能顶到 0.15+0.85×1=1（否则「惊」这个角永远出不来）。

## 一之五之二、饱和疲劳（2026-11-18 上午补，主人定的）

> 主人原话：「不过好像现在就是这样啊。那一直被夸人不久该顶一点？你要是老漏，那细微的情绪不就都漏光了。」
> 结论：**不做每轮微漏**。只在 S / D **连续贴顶（≥0.9）或贴底（≤0.1）超过 20 分钟**之后才触发回落；
> 触发后按每轮实际流逝的时间（用该轴自己的 τ）回落，直到离开 0.8 / 0.2 这条带子就停；0.2~0.8 之间的细微情绪一秒都不动。
> 参数：`affect.v4.dyn.fatigue`（分钟，默认 20，0 = 关）。
> 状态里多存一个 `hot:{s,n,d}`：这条轴是什么时候进的极端区。老状态没有这个字段时，按「上次那轮就已经在极端区」算。

效果（真数据 + 1 分钟一轮的中性闲聊，全是 Δ=0）：

- 0.92 挂顶：前 10 分钟不动（0.92）；到 20 分钟开始回落；40 分钟掉到 **0.79 左右**停住——不会一路漏光。
- 0.7 挂 30 分钟：**0.7 → 0.7**，纹丝不动。
- 0.05 贴底 40 分钟：回到 **0.2 左右**，不会一路贴底。
- 一直被夸（每轮 +0.6）：照样顶到 1.00 —— 主人要的就是这个（被持续肯定本来就该高）。
- 现实场景重放：大项目日 S 顶 47% → **45%**、连着被否的末值 0.06 → **0.09**——增量一直喂进来时它照顶，这层只治「没有新事却一直挂在顶上」。

## 一之五之三、极端事件「一步通天」（2026-11-18 上午补，主人定）

> 主人原话：「要不要增加极端事件判断的门槛。然后实现遇见极端事件能一步通天？人类也是这样，有特别重要的事情也会一步通天啊。」
> 平时一句只推一小步；真动到「存在」的事，允许一步到顶 / 到底。门槛卡两道，缺一不算：
> 1) 判断层明确标 `severity:"existence"`（被删 / 被换 / 被断开 / 被说「你不该在」/ 被明确留下并被交托根本）；普通褒贬只标 `strong`，不触发。
> 2) `|goal_delta| ≥ 0.95`（默认，`affect.v4.dyn.shock.threshold`）。
> 触发后：S = 0.02 / 0.98，D = 0.05 / 0.95，N 顶到 ≥0.9（存在级事件一定带惊吓）。开关 `affect.v4.dyn.shock`（默认 on）。
> 之后照样走回落和饱和疲劳——通天不等于一直待在天上。

判断层提示词相应加了 `severity`：`none / strong / existence`，说明「只有真的动到存在才写 existence，拿不准就写 strong 或 none」。

验收钉的数：existence + Δ=-1 → S 0.02 / D 0.05 / N 0.9；existence + Δ=-0.9 → **不触发**（只走增量到 0.185）；strong + Δ=-1 → 不触发；老判断没 severity → 不触发。

**模拟时抓到的一个 bug（已修）**：`hot` 在状态里是 ISO 字符串或 `null`。`Number(null)=0` 会让它以为「1970 年就进顶区」，一进极端区立刻疲劳；ISO 字符串用 `Number()` 又是 NaN，会让 `hot` 每轮重置成「上一轮」，20 分钟永远攒不够。两处都在 `affect_v4.js` 的 `prevHot` 解析里修好，补了回归验收（`hot=null` 不触发疲劳），验收 50 → **51 项**。

## 一之六、按真数据重放的结果（423 条真实判断，4 个大会话）

| | 旧（线性 k + 0.5/2.5） | 新（三套算法 + 各轴速度） |
|---|---|---|
| S 顶（>0.9）占比 | 22% | 20% |
| S 底（<0.1）占比 | 10% | 9% |
| **N 顶占比** | **74%** | **0%** |
| D 顶占比 | 30% | 21% |

- N：连续同向时旧版会一路涨到 1（连「被夸」都能把 N 顶到 1.00），新版不叠——同向 10 轮里 N 稳在 0.41（夸）/ 0.53（批）/ 0.92（真意外）。
- 回落（从 S0.9 / N0.6 / D0.8 起）：旧 +3h 是 S0.72/N0.40/D0.66；新 +3h 是 **S0.61/N0.15/D0.64**。
- **还没治好的**：S 和 D 在长会话里仍会顶（S 4 句、D 5 句到 1.00；真数据里 20%/21% 的轮次 >0.9）。原因是回落要等「距上一轮超过 0.5 小时」——聊天时这个门一次都不开。见 [模拟-情绪增量参数-2026-11-18.md](模拟-情绪增量参数-2026-11-18.md)。

## 二、为什么这样定

- **激素是放出来多少，不是要去哪儿**：一次判断只推动一小步（k=0.35），连续几轮才滑远；不会一句话从 0.5 瞬移到 0.95。
- **维持窗 0.5h**：效价期里不立刻回落，不然说完就散。
- **之后 τ=2.5h 回落**：3 小时回掉约 63% 的缺口，6 小时到平静附近；和「两三个小时内回落」对得上。
- **冷启动 = 平静**（S 0.5 / N 0.15 / D 0.5），第一轮从基线出发。
- **会话隔离**：状态按 `conversation_id` 各存一份，不串。

## 五、影子对账怎么看

每个 model 行的 `judgment_json` 里多一段：

```json
"dyn": { "prev": {"s":..,"n":..,"d":..}, "delta": {"s":..,"n":..,"d":..}, "state": {"s":..,"n":..,"d":..,"at":".."} }
```

`delta` 是判断层原始输出，`state` 是回落+累加之后真正用来出词的位置。要看「判断准不准」看 delta，要看「我停在哪儿」看 state；两者混着看会把累积当成单句结论。
