# 思路：判断层出增量 + 情绪维持与回落（2026-11-18 早上定）

> ⚠️ **已废弃（2026-11-18 上午，落地时）**：本文的「三条轴共用一个 k、共用一个 2.5h 回落」已经作废——主人当天定的是**三条轴各有各的回落速度、也各有各的增量算法**。
> **现在该看**：[改动-情绪增量-2026-11-18.md](改动-情绪增量-2026-11-18.md)（实现 + 参数 + 验收）。本文只留作「当时怎么想的」。
>
> 主人原话：「判断层的数变成 SND 的增量，而不是目标点。激素分泌只是情绪的增量，不是目标点。」
> 「先维持一段时间半小时。然后半小时之后维持了之后，两三个小时之内回落到平静。」
> 本文覆盖前一版「弹簧加速度」的口头方案——不做弹簧，做增量 + 维持 + 指数回落（这条总方向仍有效）。

## 一、现状（为什么改）

> ✅ 这节仍有效：问题描述没变。

现在判断层给 `goal_cong / expectation / future` 三个数，`transmitters()` 直接把它们映射成 **S/N/D 的位置**：

```
S = 0.5 + 0.5 × goal_cong     // 0.9 → S=0.95，直接落到目标点
```

问题：每轮情绪是「瞬移」到新位置，点会在方块里跳（昨晚游走测出来的 慌↔激动 92 次就是跳的副作用）。而且不符合激素：判断层放出来的是**变化量**，不是终点。

## 二、新模型：增量（⚠️ 公式已废弃，见改动文）

判断层输出改成 **-1 ~ +1 的增量**（这一下让我变好/变差多少）：

```
goal_delta = 这一句让「好/坏」变了多少（-1 ~ +1）
expect_delta = 意外增量
future_delta = 奔头增量

S_new = clamp(S_old + k × goal_delta, 0, 1)   // ← 已废弃：S 现在是带软边的累积
N_new = clamp(N_old + k × expect_delta, 0, 1) // ← 已废弃：N 现在是尖峰包络，不累加
D_new = clamp(D_old + k × future_delta, 0, 1) // ← 已废弃：D 现在慢涨快跌（0.25 / 0.45）
```

`k` 是每轮吸收系数，参考 `affect_dyn.js` 的 `mix(prev, target) = 0.45 × prev + 0.55 × target` 精神，取 **k ≈ 0.35**（一句事只推动一小步，连续好多句才滑远）。

## 三、维持与回落（⚠️ 数值已废弃：现在三轴各自 hold/tau）

> 现在：S 维持 0.5h / τ=1.2h；N 无维持 / τ=0.5h；D 维持 0.5h / τ=2.0h。见 [改动-情绪增量-2026-11-18.md](改动-情绪增量-2026-11-18.md)。

现有 `src/algo/affect_dyn.js` 的 decay 模式：

```js
intensity = intensity × exp(-hours / (6 × decayScale))   // 强度 6 小时时间常数
mood      = mood      × exp(-hours / (24 × decayScale))  // 心情 24 小时
```

新模型照它写，但分三段：

1. **维持窗（0~0.5 小时）**：情绪涨起来后半小时内不回落（激素还在效价期）。
2. **回落窗（0.5 小时后）**：按 2~3 小时时间常数，指数回落到基线（平静，S=0.5 / N=0.15 / D=0.5）。
3. **无新事件**：每轮按距上轮的 `hours` 结算回落；有新事件时先加增量，再落回落。

公式（⚠️ 下面这条已废弃——三条轴不再共用一个 τ）：

```
hours = (now - lastAt) / 3600000
if (hours > 0.5):
    τ = 2.5 小时（可配 affect.v4.dyn.tau）
    S = 平静S + (S - 平静S) × exp(-(hours - 0.5) / τ)
    N、D 同理
```

## 四、存哪（✅ 这节仍有效）

`flags['affect.v4.state|<conv>']`：`{ s, n, d, at }`，每轮读→加增量→回落→写回。
影子期同时记两行：**原始增量帧**（判断层输出）和**累积位置帧**（平滑后的 S/N/D + 词），方便对账。

## 六、验收（✅ 已落地，见改动文）

- 连续两轮正向事件，S 逐步升，不一步到顶。
- 一轮大负面事件后，半小时内维持，不立刻掉。
- 半小时后 2~3 小时内回到平静（用假时钟测）。
- 影子对账：原始帧 vs 平滑帧的差，每天看一次。

## 七、怎么退（✅ 仍有效）

- 开关 `affect.v4.dyn=off` 时回旧逻辑（目标点直落）。
- 老数据不动，`affect_v4_shadow` 表结构不变。
