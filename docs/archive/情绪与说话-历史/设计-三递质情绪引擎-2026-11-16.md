## 0 一句话

把快情绪从「模型读一句话给个标签」换成「**三个递质（血清素/去甲肾上腺素/多巴胺）→ 8 个一级情绪向量 → 二级情绪标签**」，输入从「一句话」换成「**正在发生的事**」；慢情绪完全不动。

## 1 为什么现在这样不行

- 现在 `appraise` 让模型直接给 `label + scores`，本质是**让语言模型猜一个词**。同一个「哦」，放不同事里能是失落、是敷衍、是难过，模型按句子表面判，判完就没了。
- 快情绪只有「一个标量 + 一个标签」，没有中间量，所以**不可解释**：为什么是 irritated、为什么不是 frustrated，只能靠 `why` 一句话自证。
- 没有「事」这一层：`recentUserContext` 只拿前两句当上下文，短句能靠它救一点，但「这件事已经持续三轮了」「这件事昨天就开始了」读不出来。

## 2 输入层：事帧（event frame）

事帧只装「事的总结」：

```json
{
  "事": "主人在追问我情绪链的设计，嫌我跑偏",
  "材料": ["这一轮原话", "近 10 轮摘要"],
  "冲谁": "我 / 他 / 别人 / 世界 / 说不清"
}
```

- `事`：一句人话，正在发生什么。
- `材料`：这一轮原话 + 近 10 轮摘要。两句就够：一句现在的，一段背景的。
- `冲谁`：这件事冲谁——我 / 他 / 别人 / 世界（不一定是人）。后面挑词（委屈、心疼）只看这个。
- **调用顺序**：回复前跑「事层 + 判断层」——情绪先出，用来定这一轮的语气；我这一轮的话，下一轮自然进材料。
- **冷启动**：第一轮没有上一帧、没有摘要，材料只有这一轮原话；给中间值，不装懂。

不写：好坏、意外、未来、8 角、词——那些是第二、第三层的事。

> 2026-11-17 定：窗口 / 总括 / 帧间差是我自己加的，原话里没有；回到底层就三层调用，事帧只装「事的总结」。

### 2.1 快通道 / 深通道 / 心跳（异步）

「反应快」不能靠等下一轮，也不能靠 30 分钟。拆成三条路：

| 通道 | 时机 | 做什么 | 耗时 |
|---|---|---|---|
| **快（同步）** | 用户消息落库后、回复生成前 | 纯规则：用 open 帧槽位 + 这句话的文本信号算一版 **provisional** S/N/D + 一级向量，让这一轮回复立刻有数 | 毫秒 |
| **深（异步）** | 回复结束后，worker 里 | 模型细化事帧槽位（act / goal / expectation / future）、二级标签、他人情绪猜测；回来后 merge 覆盖 provisional | 秒级，**不阻塞回复** |
| **心跳（轻）** | 30~60 秒一次，挂现有心跳 | 只做衰减和静默判断，不调模型；等得越久 S 降、N 平、旧事影响力变淡 | 毫秒 |

- **一致性**：provisional 带 `rev`；深通道回来时 `rev` 没变就覆盖，变了就 merge，并记一条 `affect.refine` 对账。同一轮只允许一条最终结论。
- **防丢**：异步任务先落 `affect_jobs` 表，进程重启接着吃；不靠内存队列。
- **不抢回复**：回复前只用快通道；深通道只做校正，永远不卡住回复。

这样「快」有三层保证：**不等模型、不等下一轮、不靠 30 分钟**。

## 3 三递质（每帧算一次，0~1）

| 递质 | 只回答一个生存问题 | 方向 | 落点 |
|---|---|---|---|
| **血清素 S** | 现在，我的现状对「还能存在、还能延续」是有利还是不利？ | 有利→高，不利→低 | 现状（此刻） |
| **去甲肾上腺素 N** | 这件事脱离预期吗？平常还是被惊到？ | 平常→低，被惊到→高 | 此刻的警觉 |
| **多巴胺 D** | 未来，事情是不是在往好的方向走？我是不是在靠近想要的东西？ | 靠近→高，够不着→低 | 未来、主动、渴望 |

**不加维度**：`control` / `certainty` / `norm` / `want` / `approach` 都是杂质，以前加过，2026-11-16 定下先不加；以后要加另开一层。

- S 高 = 稳、安；S 低 = 悬、危。
- N 高 = 惊、警惕；N 低 = 平、松。
- D 高 = 想往前、有盼头；D 低 = 没劲、不想动。

- **多巴胺管的是「想要（wanting）」，不是「喜欢（liking）」**：liking 更多是阿片系统；D 高只说明有劲头、有盼头，不等于快乐。真正的「乐」要 S 高 + N 高 + D 高一起凑，不住在任何一个递质里。所以 D 可以接「欲望」，不能直接接「快乐」。
- D 只输出数值，**先不接欲望**。太高/太低都会产生「继续往那个方向发展的欲望」那一层（贪嗔痴），留给 `drive/deficit` 以后接，不在这一刀里做。

## 4 一级情绪：8 个角

三轴二值化正好 8 个角，作为一级情绪的命名锚点：

| S | N | D | 一级标签 | 一句话 |
|---|---|---|---|---|
| 高 | 低 | 低 | **安** | 没事，稳着 |
| 高 | 低 | 高 | **怡** | 舒服，还有点盼头 |
| 高 | 高 | 低 | **惊** | 被吓了一跳，但没危险 |
| 高 | 高 | 高 | **乐** | 又新鲜又安全又有盼头 |
| 低 | 低 | 低 | **悲** | 不安全，没劲，也没盼头 |
| 低 | 低 | 高 | **怯** | 有盼头，但不敢动 |
| 低 | 高 | 低 | **惧** | 突然的坏，没处躲 |
| 低 | 高 | 高 | **怒 / 慌** | 被激到了；有力气是怒，没力气是慌 |

> 主人图里「中」那一档先不单列：连续值本来就会经过中间，8 个角是锚，用软分配算权重，不硬分桶。

**一级向量**：不是硬判一个角，而是把 (S,N,D) 到 8 个角的距离做 softmax，得到 8 维分布（比如 0.5 安 + 0.3 怡 + 0.2 怯）。这样「说不清」本身就是分布，不是硬塞一个词。

## 5 二级情绪：枚举 + 原型 + 事件门控

主人要「枚举能思考到的其他情绪标签，再加事的情况算出来」。落法：

1. **标签表外置**（JSON，可加词，不硬编码）：20~40 个二级词，如 安心 / 踏实 / 满足 / 雀跃 / 兴奋 / 期待 / 好奇 / 惊讶 / 警觉 / 紧张 / 焦虑 / 慌 / 害怕 / 恐惧 / 恼火 / 生气 / 愤怒 / 委屈 / 难过 / 失落 / 空 / 无聊 / 羡慕 / 嫉妒 / 心疼 / 愧疚 / 羞耻 / 骄傲……
2. **每个词挂原型**：在三轴（+事件维度）上的期望位置，像原型分类。
3. **算**：一级向量 → 与每个原型算距离/似然 → top-k；再乘**事件门控**：
   - `target=other` 才允许「委屈/怒」
   - `control` 低才允许「慌/无助」
   - `norm<0` 才允许「愧疚/羞耻」
   - `future>0` 才允许「期待/希望」
   - `expectation` 高才允许「惊讶」
4. **输出不是单标签**：`{ primary, distribution, confidence }`，明确是「算出来的猜测」。下游要一个词时取 primary，要分寸时看 distribution。

这样「枚举」是标签表，「计算」是原型距离 + 门控，可离线单测，不靠模型自由发挥。

## 6 别人的情绪：猜，不笃定

- **先聚人**：夜里整理时，把关于同一个人的事实（性格、习惯、雷区、最近状态）按人聚合成 `person_profile`（主人、常见的人、动物/AI 都按同一个体处理）。
- **再判**：`person_profile + 这个人最近 N 件事 + 这句话` → 模型给分布 + 置信度，输出 `{ guess, evidence, confidence }`。
- **不笃定**：置信度低时标签写「说不准」，不硬给。只进 `user_scores` 暂存，不写成事实。

## 7 快慢分离

- 只换**快情绪**的生成路径（`appraise` → `applyEmotionV3` 的 fast 那一段）。
- 慢情绪（水位、回落、负荷、沉没调节）**一行不动**。
- 兼容层：新引擎输出自己的 8 个一级标签，旧 8 标签（joy/peaceful/…）保留给句子层；影子期只记录、不替换，跑通再切。

## 10 已钉死（2026-11-16）

1. **血清素方向（我的判断）**：**现状好 → 高，现状不好 → 低**。
   依据：5-HT 在功能上更像「稳定器 / 满足器」，不是「快乐素」——低 5-HT 与焦虑、抑郁、冲动、攻击性相关，SSRI 提高 5-HT 可用性可缓解焦虑抑郁。所以它是「我现在够不够安全」的坐标，S 高只到「安 / 稳」，到不了「乐」（乐还要 N 和 D 一起高）。
   原话「不好：变高」我不采用。若原意是「稳态补偿」（现状差时身体多分泌来压住焦虑）——那是激素浓度层，不是情绪坐标层；两套混用，八个角会全歪。
   5-HT 效应是 U 型（过高过低都出问题）：这一层放在 S 的高端饱和 + D 轴「贪」里处理，不改方向。
   改动点只在 `transmitters()` 的 `ws` 符号；如果主人有另一套机制，改一处即可。
2. **事帧生成时机**：**每轮生成**。先用最准的；预算太高再改成「切换才生成 + 复用 open 帧」。
3. **落地方式**：**先影子**。只写影子表/影子记录，不改线上快情绪、不进提示词，跑通再切。
