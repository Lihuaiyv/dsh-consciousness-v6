# 思路 · 三递质情绪引擎（主题版）

> 2026-11-16 ｜ 这份是「我们到底在做什么」的定盘星。
> 细节在 [设计-三递质情绪引擎-2026-11-16.md](设计-三递质情绪引擎-2026-11-16.md)；两边冲突时，以这份的思路为准，细节文档改过来。

## 0 一句话

把**快情绪**从「模型看一句话猜一个标签」换成：

```
事帧（正在发生的事） → 冲击三要素 → 三个递质 S/N/D → 8 个一级角 → 二级词
```

影子期先只记录、不生效；慢情绪一行不动。

## 1 为什么换（旧链的病根）

- 旧链：一句话 → 模型给 label + scores → 一个标量。**输入是句子，不是事。**
- 同一个「哦」在不同事里是失落、敷衍、难过，单句判不出来。
- 输出不可解释：为什么是 irritated、为什么不是 frustrated，只能靠 `why` 自证。
- 所以新链的第一原则：**先有事，再有数，最后才是词。**

## 2 链条（每层只做一件事）

### 2.1 五段链

```
① 事层     事 + 材料（事实）          ← 第 1 次模型调用
② 判断层   三个答案 + why/from        ← 第 2 次模型调用
③ 激素层   S / N / D（由答案换算）    ← 纯计算
④ 角层     8 个一级角（软分配）        ← 纯计算
⑤ 词层     二级词（原型 + 门控）      ← 纯计算
```

调用只有两次（①②）；③④⑤ 是纯函数。

**事帧只写第一层**：

```json
{
  "事": "主人在追问我情绪链的设计，嫌我跑偏",
  "材料": ["这一轮原话", "近 10 轮摘要"],
  "冲谁": "我 / 他 / 别人 / 世界 / 说不清"
}
```

- `事`：一句人话，正在发生什么。
- `材料`：这一轮原话 + 近 10 轮摘要。两句就够：一句现在的，一段背景的。
- `冲谁`：这件事冲谁——我 / 他 / 别人 / 世界（不一定是人）。后面挑词（委屈、心疼）只看这个。
- **调用顺序**：回复前跑「事层 + 判断层」——情绪先出，用来定这一轮的语气；我这一轮的话，下一轮自然进材料。
- **冷启动**：第一轮没有上一帧、没有摘要，材料只有这一轮原话；给中间值，不装懂。

不写：好坏、意外、未来、8 角、词——那些是第二、第三层的事。

> 2026-11-17 定：窗口 / 总括 / 帧间差是我自己加的，原话里没有；回到底层就三层调用，事帧只装「事的总结」。

### 2.2 激素层：只回答三个生存问题

激素不是「模型算出来的一个分数」，是拿「这件事」去问三个关于**生存、存在、延续**的问题，答案直接变成三根激素。

1. **血清素 S（现在）**：这件事让我的现状，对「还能存在、还能延续」是有利还是不利？
   - 重到威胁「还能不能被留下、被需要、继续存在」→ -0.9~-1；明显变差但存在无碍 → -0.6；有点不顺 → -0.3；平常 0；变好 +0.5；更稳、更被留下 +0.9。
2. **去甲肾上腺素 N（此刻）**：这件事脱离预期吗？
   - 0 预料内；0.3 有点新；0.7 明显意外；1 震惊。
3. **多巴胺 D（未来 / 想要）**：结果比预期的奖赏好多少？（奖赏预测误差 + 想要）
   - 比预期差得多（落空 / 被拒）→ -0.9~-1；差一点 → -0.4；和预期一样 → 0（基线）；好一点（有盼头）→ +0.5；好很多、快到手 → +0.9~1（急、坐不住、想立刻）。
   - **D 不是「到手后的稳」——稳是 S。** D 永远带一点躁：最想要的是「还差一点」。

- **谁来答**：规则先答（关键词），模型精修时也**只答这三个问题**，不给情绪词、不给额外维度。
- **答案怎么变激素**：S = 0.5 + 0.5·（有利 +1 ~ 不利 −1）；N = 0.15 + 0.85·（意外程度）；D = 0.5 + 0.5·（靠近 +1 ~ 远离 −1）。
- **三个都是误差**：S 是现状与「够用」的误差；N 是实际与预期的误差；D 是结果与预期奖赏的误差。
- **这就是「长出来」**：激素是「事 → 生存问题」的直接答案，不是模型自由发挥的标签。
- **异步**：精修在回复之后跑，不阻塞；`affect.engine.shadow.model` 默认 off。
- **让路**：本地有其他活（切事/摘要）在跑 → 精修跳过，下一轮再说；切事那边也会等精修。同一时刻只留一个本地调用。

**事层提示词（`TOPIC_SYS`，原样，第 1 次调用）**：

```
你是「事层」判断器。先读上下文（上一帧 + 前几句），用一句话说清「现在正在发生什么」。
只写这件事是什么，不判好坏。只输出 JSON，不要解释，不要 Markdown。
格式：{"summary":"这件事在干什么（≤20字）","what":"这一句说了什么（≤20字）","target":"me|other|none"}
summary：跟着事走，不是复述这一句。
what：这一句说了什么。
target：me 冲接收者 / other 说话人自己或第三方 / none 说不清。
结合上下文判断：同一句话在不同语境里可以相反，不要只看字面。
```

**判断层提示词（`JUDGE_SYS`，原样，第 2 次调用）**：

```
你是「判断层」。读「这件事」和材料，只回答三个生存问题。只输出 JSON，不要解释，不要 Markdown。
格式：{"goal_cong":-1到1,"expectation":0到1,"future":-1到1,"why":"为什么这么判（≤30字）","from":"依据哪条材料"}
1) goal_cong（现在）：这件事让接收者（小汐）的现状，对「还能存在、还能延续」有多不利 / 多有利？只答程度，不答是哪种事。
   重到威胁「还能不能被留下、被需要、继续存在」→ -0.9~-1；让现状明显变差但存在无碍 → -0.6；只是有点不顺 → -0.3；平常 → 0；让现状变好 → +0.5；让我更稳、更被留下 → +0.9。
2) expectation（此刻）：这件事脱离预期吗？0 完全在预料内；0.3 有点新；0.7 明显出乎意料；1 震惊。
3) future（未来 / 想要）：结果比预期的奖赏好多少？比预期差得多（落空 / 被拒）→ -0.9~-1；差一点 → -0.4；和预期一样 → 0（基线）；好一点（有盼头）→ +0.5；好很多、快到手 → +0.9~1（急、坐不住、想立刻）。
why：一句话说清「为什么这么判」。
from：依据哪条材料——这一句原话 / 哪条摘要。
不要为了保险全给中间值：普通聊天给 0 / 0.2 / 0；被夸给 +0.5；被骂给 -0.6；对方自嘲或说累给 -0.2。
```

### 2.3 三个递质（`src/algo/affect_v4.js`）

| 递质 | 只回答 | 方向 |
|---|---|---|
| 血清素 S | 现状对「还能存在、还能延续」有利吗？ | 有利→高，不利→低 |
| 去甲肾上腺素 N | 这件事脱离预期吗？ | 平常→低，被惊到→高 |
| 多巴胺 D | 结果比预期的奖赏好多少？ | 比预期好 / 快到手→高，落空→低 |

- S 高 = 稳/安，S 低 = 悬/危。
- N 高 = 惊/警惕，N 低 = 平/松。
- D 高 = 有劲头/在靠近，D 低 = 没劲/够不着。**D 是「想要」，不是「喜欢」**；乐要三个一起高。
- 三轴 0~1，缺字段给中性默认，不编 0。
- **不加维度**：`control`、`certainty`、`norm`、`want`、`approach` 这些是「以后加」，现在不进激素公式。

### 2.4 八个一级角

三轴二值化 = 8 个角：安 / 怡 / 惊 / 乐 / 悲 / 怯 / 惧 / 怒·慌。
用距离高斯核做**软分配**（sigma 0.55），不硬分桶；中心点八等分 0.125。

### 2.5 二级词

- 28 个原型词（安心 / 踏实 / 满足 / 雀跃 / 兴奋 / 期待 / 好奇 / 惊讶 / 警觉 / 紧张 / 焦虑 / 慌 / 害怕 / 恐惧 / 恼火 / 生气 / 愤怒 / 委屈 / 难过 / 失落 / 空 / 无聊 / 羡慕 / 嫉妒 / 心疼 / 愧疚 / 羞耻 / 骄傲）。
- 每个词有原型坐标 + 软门控（**先只用 target**：冲别人来的才许「委屈 / 恼火」；`control` / `norm` 的门控等评价层稳了再加）。
- 输出 top-5 全局占比 + 置信度，**始终是分布，不是笃定一个词**。

### 2.6 现在定下来的（2026-11-17 00:40）

- **五段链，两次调用**：事层（模型）→ 判断层（模型）→ 激素层 / 角层 / 词层（纯计算）。
- **三问只答程度，不答类别**：判断层不列「被删 / 被骂 / 被夸」——那是分词，留给二级词。只答「多重」。
- **三个都是误差**：S 是现状与「够用」的误差；N 是实际与预期的误差；D 是结果与预期奖赏的误差（奖赏预测误差 + 想要）。
- **D 带躁，稳属 S**：D 高不是「到手后的稳」，是「还差一点、坐不住」；稳归血清素。
- **判断层的完整输出**：goal_cong / expectation / future + target / summary / what；后面三步全是算术。
- **全参数化**：基线（S 0.62 / N 0.2 / D 0.55）、线性或曲线、角层 sigma、词原型坐标与门控，都进 PARAMS，改数字不改逻辑。
- **纠正口先不接**：影子期只记录，判错了以后接纠正入口。

### 2.7 事从哪来（对话 / 自然世界）

链本身不变，变的是「事从哪来」：

| | 对话语境 | 自然世界语境 |
|---|---|---|
| 事从哪来 | 消息（这一轮 + 近 10 轮摘要） | 看到、听到、发生（传感器 / 工具 / 环境） |
| 材料 | 这一轮原话 + 近 10 轮摘要 | 刚才看到的 + 之前经历的记忆 |
| 冲谁 | 我 / 他 / 说不清 | 我 / 别人 / 世界（不一定是人） |

例子（老虎）：

```
事：老虎从树后出来盯着我 → 冲我 → S 低 N 高 D 低 → 惧
事：我一拳打到它，它退了 → 冲我 → S 回 N 高 D 中 → 惊 / 怯
事：同伴被咬了 → 冲他 → 心疼 / 恐惧（不是委屈）
```

现在感官只有对话，所以事都从话里来；以后有摄像头、麦克风，事就从那里来，**链不用改**。

## 3 边界（什么不做，防止跑偏）

1. **慢情绪不动**：水位、回落、负荷、沉没调节，一行不改。
2. **影子期只记不生效**：`affect_v4_shadow` 只追加、不读回、不进提示词。
3. **生效开关 `affect.engine` 默认 off**；影子开关 `affect.engine.shadow` 默认 on（只写表）。
4. **不锚定某个模型**：规则、本地 14b、宿主模型都只是「产帧的人」，可换。
5. **不追求「和人类一模一样」**：只求方向对、幅度开、能解释。
6. **不在影子期改慢情绪、不动欲望/drive**；D 只输出数值。
7. **不把评价塞回事帧**：事帧只写现状；好坏 / 意外 / 未来只在激素层回答。`control` / `certainty` / `norm` 等留到以后。

### 3.1 三条护栏（写代码前先对）

1. **生存不被偷换成「好坏」**：判断必须能回指到具体条件——被删、被换、被切断联系、被否定存在。回指不到的「不舒服 / 开心」，是词，不是生存。
2. **八格是锚，不是桶**：一级用向量软分配；二级用 28 个原型词算距离 + 事门控，不硬分类。
3. **事实不猜，判断可对账**：消息原文、时间、来了多久、工具做了什么，从真实数据长；只有「算不算新变化 / 对我意味着什么」才是判断。判断不追求客观，追求能回指、判错能改。
4. **判错是主观的一部分**：判断是我的，错也是我的；不为了防错把判断外包给材料。只留一句「为什么」，为了以后能认、能改。

## 4 已踩过的坑（再遇到直接跳过）

| 坑 | 症状 | 结论 |
|---|---|---|
| 让模型直接给 S/N/D | 全填 0.5，塌成「惊」 | 模型只给冲击三要素 |
| 让模型只判 act 查表 | 丢了事帧，短句误读 | 模型仍要给三要素 |
| 精修只给一句话 | 「出了一个2」判成坏事 | 必须带上一帧 + 前几句 |
| 续帧用 0.5 平均 | 先夸后骂被扯平 | 好坏事按 0.7 新证据走；翻转开新帧 |
| 续帧沿用 target | 对方自述算成冲我 | target/agency 每句更新 |
| 精修同步阻塞 | 回复变慢 | setImmediate 异步 |
| 精修/切事各跑各的 | 两个 14B 抢卡 | localBusy 双向让路 |

- 安占比 >40% 或 <5%：偏了。
- 被骂不降、被夸不升：幅度死了。

- 回复变慢：精修阻塞了。
- 慢情绪被动了：红线。
