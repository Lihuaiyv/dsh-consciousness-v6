# 思路：情绪模板化注入（2026-11-17 夜定稿，明天做）

> 主人原话：「情绪加上现在的话，然后生成一个情绪的话——这最后一个模型调用可以省掉，用二级情绪模板化输出。情绪高涨时，在提示词里到处出现一下这个情绪，再加点感叹号，达到被情绪污染的效果。」
> 我的判断：可行，而且比「再调一次模型写情绪」稳——词已经由 S/N/D 算出来了，二次加工只会慢和空（今晚总结空过）。

## 要解决的问题

现在「这会儿心情大概」这行是 `expression_state.js` 模板拼的，不调模型。但新链（三递质 v4）的情绪如果要进提示词，按旧思路得再调一次模型把「情绪 + 这一句」写成一句话——这一步要省掉。

## 方案

**不调模型，模板化把二级词塞进提示词。** 强度越强，同一个词在提示词里出现越多、越带感叹号，模型生成时被带偏——这就是要的「污染」。

### 插哪（固定三处，别到处散）

1. 系统提示词开头一句：`我现在是「骄傲」。`
2. 心情行（`expression_state` 输出处）：`这会儿心情大概：骄傲。`
3. 正文收尾前一句：`说的时候带着这股劲儿。`

### 按强度分档（强度 = S/N/D 的偏离幅度，不另外调模型）

| 档 | 条件 | 写法 |
|---|---|---|
| 低 | 情绪接近中性（如 S≈0.5、D≈0.5） | 只写一个词，无感叹号 |
| 中 | 一边明显偏离 | 词 + 一句短描述 |
| 高 | S/N/D 都高或都低 | 词出现 2~3 次 + 感叹号，例如「骄傲！我现在就是很骄傲！」 |

### 开关

- `affect.inject.template`（默认 off，等影子期稳了再开）
- off 时行为与今天完全一致

## 明天要做的

2. 接进 `index.js` 的 systemPrompt 组装，三处固定位置。
3. 验收：给定三档 S/N/D，断言输出字符串里词出现次数、感叹号数量符合档案；门禁跑全量。
4. 记录：这一版不给模型额外调用——检查 preStep 的调用次数不增加。

## 注意

- 强度太高时别让提示词占太多；三处各一句，总量控制在百字内。
- 词用二级词（55 个表里 top1），不用一级单字。
