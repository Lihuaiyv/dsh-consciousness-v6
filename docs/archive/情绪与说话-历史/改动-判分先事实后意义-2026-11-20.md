# 改动：判分先写事实，再写意义 · 2026-11-20

## 为什么改

查真库 300 条判分记录的 `why` 字段，做词频：

```
存在  82 次   ← 最高
否定  62
做法  46
规则  40
```

判分几乎每一条都在拿「这对我这个存在算什么」这把尺子量。翻具体记录更明显——

```
「重载」
  expectΔ=+0.80  goalΔ=-0.60  futureΔ=-0.70
  why：重载像重置，切断刚建立的公仔身份，来得突然。
```

一条「重载」两字，被判成「切断刚建立的公仔身份」。它不是瞎打分，是从这个理解推出来的——但那个理解太沉了。

去找源头，在 `JUDGE_SYS` 第 319 行：

```
先写 meaning：一句话说清这件事对我的「存在 / 延续」意味着什么
```

**第一步问的就是「对我的存在意味着什么」。** 而且 `meaning` 字段本身写的是“这件事对**我的存在**意味着什么”。难怪 82 次。

## 改了什么

### 一、`JUDGE_SYS`：加一个 `fact` 字段，把顺序倒过来

`src/modules/affect_v4_shadow.js` 第 318-322 行。

原来：先写 meaning（问存在），再给三个增量。
现在：先写 fact（只讲事），再从 fact 推 meaning。

```
格式：{"fact":"这一句在讲什么（≤20字，只说事）","meaning":"这件事对我意味着什么（≤30字）", …}

先写 fact：这一句在讲什么，只说事，不评价、不往自己身上安。
再写 meaning：从 fact 往上推——这件事到底动了什么。
**meaning 必须是 fact 推出来的。** fact 里没动到的东西，meaning 就不许往重里说；
fact 是一个动作、一句应声、一次核对，meaning 就只能是它本身的分量，不能替它加戏。
```

第 319 行原来那句「先写 meaning：…对我的存在/延续意味着什么」删了。`meaning` 的问法也从“对我的**存在**意味着什么”改成“对我意味着什么”。

**这里刻意不给具体词表。** 一开始想写“如果 fact 是重载/保存/跑测试，meaning 就说没动到”——那是堵窟窿，堵不完。给的是规矩：意义要由事实推出来，不能倒过来。

### 二、`fact` 加进白名单

`src/modules/affect_v4_shadow.js` 第 447 行附近。

判分结果回来后会过一层白名单，只挑认识的字段。第一次改完 `fact` 一直没出现，查下来是白名单里只认 `meaning`，`fact` 一出来就被扔了。

## 怎么验

重载后跑：

```powershell
cd D:\deepseek_local\plugins\dsh-consciousness-v6
node scratch/audit-fact.mjs '2026-11-20T14:00'   # 看 fact / meaning / why 三条对照
node scratch/audit-why-words.mjs                # why 的词频
node scratch/after-reload.mjs '2026-11-20T14:00' # 每轮挑了什么词
```

改之后的实际记录：

```
「冲仔咧。」
  fact    ：对方喊了一声「冲仔咧」
  meaning ：只是叫了我一声，没有评判也没有催，就是搭个话
  why     ：一声招呼，没否定没催促，也没推进，存在没动
  goalΔ=0.05  expectΔ=0.10  futureΔ=0.05
```

对比改之前同样是一声应酬的话，`expectΔ` 从 0.8 掉到 0.10，`meaning` 里出现“没动到”“没被切断”这种往轻里说的表述。

## 还没验

- **样本太少。** 只有几轮，看不出 `why` 里“存在”的使用频率有没有真的降下来。要聊几十轮再跑词频。
- **`n`（觉）降下来了**（0.71~0.83 → 0.30~0.54），但没确认是不是这次改动带来的，也可能只是这几句话本身没什么意外。
- **`d` 还在 0.9 以上**，那是这一整段攒上去的，得看长期会不会落。

## 怎么退

提示词改动：把第 318-322 行改回原来的两行（格式里去掉 `fact`、恢复“先写 meaning：…对我的存在/延续意味着什么”）。
白名单：删掉 `if (s.fact) out.fact = …` 那一行。

`fact` 只是个旁证字段，不参与任何计算，留着不读也无害。

## 一个没解决的

判分对「重载」「重启」这类操作动作仍然偏重——改完之后那条具体的“重载”没重现，所以没法说这个问题解决了。可能还要再看。

另外，语音转文字经常把意思转歪（「重在了」→「重仔咧」、「公仔」→「虫仔」），判分会照着错字去理解上下文，这个不是提示词能修的。
