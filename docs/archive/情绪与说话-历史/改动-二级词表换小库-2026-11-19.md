## 一、先厘清「正方体 vs 球」的歧义（按新文档）

最新口径 [`设计-情绪球面骨架-2026-11-18`](设计-情绪球面骨架-2026-11-18.md) §二 写得很清楚：

> 8 个方向正好是现有一级 8 角——**骨架没变，只是从「点」升成「族」**。

也就是说「改成球」和「八个角」**不是两套东西**：
- 球是按「方向 + 半径」读，立方体是按「三个分量」读；强度 = 半径。
- 八个角的符号组合 (S, N, D) 各取高/低，就是球面上八个顶点，一个都没多、一个都没少。
- 换了的是：**名字**（单字八角 → 两字八格）、**词从点升成族**（每族 4 层，由弱到强）。

所以这次改名字改的正是这八个顶点，不是给一条要退的路换招牌。

## 二、动了哪

### 1. 新增 `src/algo/lexicon_v4.js`（生成，不手改）

小库 165 词带 v4 判据坐标，由 `scratch/gen-lexicon-v4.mjs` 从 `scratch/lexicon/axes-v4.json` 生成。
映射口径：

| 判据轴 | 范围 | 代码轴 | 换算 |
|---|---|---|---|
| 安（5-HT） | 0–100 | `s` | `s = an/100`（50 = 说不上 = 0.5） |
| 欲（DA） | 0–100 | `d` | `d = yu/100`（同上） |
| 觉（NE） | 0–100 | `n` | `n = 0.15 + 0.85·jue/100` |

**为什么 `n` 不是 `jue/100`**：`n`（意外）的基线是 **0.15** 不是 0.5（设计 §「N = 0.15 + 0.85·意外」）。
判据里 `jue=0` 的意思是「什么都没突然撞上来」，对应设计的「平常」就是 0.15。
直接除百会把中性抬到 0.5，全体判歪。`jue=100` → `n=1.00`，正好是「猛地一紧」。

剔掉的：8 个格名（敞亮/安住/… 是坐标名不是情绪词）、判成 0 0 0 的不是感受的词（本次 0 个）。
`an / yu / jue / oct` 原值一起带着，判据改了好对账。

### 2. `affect_v4.js`：删掉手摆的 60 词

`SECONDARY_PROTOTYPES` 原来是 60 个我凭感觉摆位置的词（`改动-二级词表扩充-2026-11-17` 那批），
**整块删了**，改成 `= LEXICON_V4`。`secondaryLabel` 的空兜底从 `'安心'` 改成 `'说不准'`（'安心' 不在小库里）。
门控只给「意思里就带着是谁」的词（愧疚/委屈/嫉妒/依恋 这类），50 个；其余不门控——宁可多冒，不乱压。

### 3. `sphere.js` + `sphere_words.js`：旧八族名换掉

上扬/惊喜/安心/松弛/紧张/沮丧/硬撑(憋着)/发木 → **敞亮/警醒/安住/疏淡/渴慕/郁结/惊惧/沉沦**。
`key`（le/jing/an/song/jin/ju/ying|bie/mu）不动，`dir` 不动。对照：

| key | dir (u,v,w) | 旧名（废） | 新名（定） |
|---|---|---|---|
| le | +,+,+ | 上扬 | 敞亮 |
| jing | +,+,- | 惊喜 | 警醒 |
| an | +,-,+ | 安心 | 安住 |
| song | +,-,- | 松弛 | 疏淡 |
| jin | -,+,+ | 紧张 | 渴慕 |
| ju | -,+,- | 沮丧 | 郁结 |
| ying/bie | -,-,+ | 硬撑 / 憋着 | 惊惧 |
| mu | -,-,- | 发木 | 沉沦 |

### 4. 验收脚本

`scripts/check-affect-sphere.mjs` 原来按手摆词点名（「在欣喜的位置最近是欣喜」），
