## 1. 这一轮到底改了什么

### 1.1 评委（两版分寸盲评）换成 DSH 的模型

- 旧路：`model.json` 里 `judge` 段指向本机 Ollama（gemma4:12b）。实测两个坑：**500 token 全被 reasoning 吃掉、content 返回空**（`finish_reason=length`，等 50 秒白等）；本机冷启动慢。
- 新路：`createHostJudgeModel(modelId)`（`src/model.js`）走宿主 `llm` 服务，不再碰本机。
- 参数 `affect.speech.judge`：`auto`（默认，走 DSH 模型）/ `same`（明确自评）/ `off`。
- 参数 `affect.speech.judge.model`：**留空 = 跟回话那个是同一个模型（自评）**；填另一个模型 id 才是真独立。
- 事件 `expr.judge` 现在带 `independent` / `judge` / `swap` 三个字段。**留空时 `independent: false`，别把它当独立信号看。**
- `OpenAIAdapter.complete` / `HostLlmAdapter.complete` 现在都接受调用方给 `maxTokens`（推理模型必需）。

线上实证（重载后）：

```
14:14:13  expr.judge  {"pick":"model","why":"参数完整更像真人","confidence":0.8,
                       "ms":1872,"independent":false,"judge":"dsh:default","swap":false}
```

1.87 秒，不再有 `reason:"empty"` 的 miss。

### 1.2 feel 增加"别写得像 AI"的闸

`src/modules/feel.js`：新增 `feelFlavorIssue` / `feelFlavorHint` / `noteFeelMiss`。

- **拦**：黑名单词（感觉 / 情绪 / 情感 / 仿佛 / 似乎 / 莫名 / 一丝 / 涌上 / 不禁 / 五味杂陈 / 百感交集）、解释句（因为…所以… / 说明我 / 意味着 / 可能是）、少于 3 字、多于 40 字。
- **不拦**：`有点`——感受行（给主人看的那句）里它油，feel（自己看的）里「手有点抖」是人话。这是被主人当场纠过一次的。
- 被退回时：返回 `{ok:false, skipped:'ai-flavor', issue, word, hint}`，工具渲染成「没记：ai-flavor（别用「感觉」这类词；写这一秒的样子）」；**同时往 `events` 写一条 `feel.miss`**（带 reason / word / 前 80 字原文），查"这几轮为什么没有 feel"不用猜。
- `FEEL_GUIDE` 当时改成「写身体和动作（手、呼吸、喉咙、想动没动）」。QQ 通道与网页共用这一句。**当天下午又改了一次，见 §1.3。**
- 太长**不再硬截断到 80 字**（旧行为），直接退回。

线上实证（`affect_feel` 216 条，8 小时内 12 条）：

```
07:10:47  feel.miss  {"reason":"ai-word","word":"有点",
                      "text":"看到这张图，我指尖有点发紧……"}   ← 旧的紧版拦错了一次好句子
```

### 1.3 当天下午：判据从「写身体」改成「偷不走」

**为什么改**：换上新规则后，06:00Z 之后 18 条 feel 里有 13 条起手就落在手 / 指 / 肩 / 胸口 —— 旁白腔是没了，但换进来的是一套更整齐的模板（「手指停在…」「指节蹭了一下」）。等于规则在推着我走：写身体最容易过闸，也最容易批量生产。完整数据与外部依据见 [草案-feel写法-2026-11-06.md](../../archive/2026-11-02_06/草案-feel写法-2026-11-06.md)。

**改了什么**（都在 `src/modules/feel.js`）：

- `FEEL_GUIDE` 换成：这一秒的样子 —— 手停在哪、视线钉在哪、旁边有什么东西、那句话还在不在耳朵里，**挑一样**。
- 新增 `feelAnchorOf`：粗分 身 / 视 / 物 / 话 / 无，取句子里**最先出现**的那一类（判的是第一下落在哪，不是句子里有没有手）。
- 新增连续同类软提示：连着 `affect.feel.anchor.repeat`（默认 3）条落在同一类，工具返回里带一句「换一样」，**照常入库**；同时写事件 `feel.anchor.repeat` 留痕。
- 参数：`affect.feel.anchor.window`（默认 5，往回看几条）、`affect.feel.anchor.repeat`（默认 3）。

**为什么不拦**：拦会把好句子拦掉。词表那条老教训还在——词表挡不住比喻（§4.2），也拦错过一次「有点」（§1.2）。提示只花一个字，改不改在我。

**验证**：feel 考卷 43 → 54 条全绿；全量 `380 / 380`；零件册界桩 10 个零件全绿；`check-params` / `check-ownership` 通过。

## 4. 已知坑 / 我判断错过的

1. **评委默认是自评。** 留空 `affect.speech.judge.model` 时，判的和说的是同一个模型，天然偏向"模型版"。事件已标 `independent:false`，但**别把它当独立证据**。
2. **词表挡不住比喻。** 「心里那点绷着的劲儿松了」一个禁词都没有，照样是旁白腔。机器只挡得了明显的那几类，剩下靠写的时候自己改。
3. **每轮都问会推动状态。** [Don't Ask (arXiv 2603.18893v3)](https://arxiv.org/abs/2603.18893v3) 说提问本身会改变被问的状态。我曾提议"只在情绪动过才记"，被主人当场否掉——**看过数据，那个提议的理由不成立**（记录不多，水位也在动）。**不要重提这个改动。**
4. **同一分钟连记两三条**是唯一真实的小毛病（07:28、07:38 各两条），现有 12 秒闸偏短。小优化，没做。
5. **`.ps1` / `Get-Content -replace` + `Set-Content` 会把 UTF-8 中文写坏**（本轮踩过一次，把 `test/feel-tool.test.mjs` 写成乱码，靠 `git checkout` 救回）。改测试文件请用编辑器工具，别用 PowerShell 重写。
