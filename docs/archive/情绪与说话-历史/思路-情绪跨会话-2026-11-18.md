# 思路：底色（跨会话）与当场情绪（会话内）怎么结合（2026-11-18 定稿草案）

> 主人原话：「底色（跨会话）和当场的情绪（会话内）这个要重点保存，以你的现在为主，别的为辅助，看看现在正在跑的慢情绪，你们怎么结合一下。」
> 本文是**逻辑定稿**，不写代码。落地前先给主人过一遍这几个数。
> 相关：[改动-情绪增量-2026-11-18.md](改动-情绪增量-2026-11-18.md)（v4 当场）、`思路-三递质情绪引擎-2026-11-16.md`（慢情绪一行不动那个约定，本文要动它，见 §4）。

## 一、一句话

**底色不新建，直接用现在正在跑的慢情绪（`affect_v3.slow` + 水位）。** v4 只管「当场」，慢情绪继续管「水位 / 日节律 / 负荷 / 沉没调节」；当场结束的时候，把余温按小权重渗回慢情绪，不搞第二套心情。

## 二、两层各是什么（重点保存）

| | 底色（跨会话） | 当场（会话内） |
|---|---|---|
| 存哪 | `affect_v3.slow`（一个 agent 一份，已有） | `flags['affect.v4.state|<conv>']`（一个会话一份） |
| 尺度 | 慢：4h 半衰期回水位，水位本身按天/周走 | 快：0.5h 维持 + 各轴 τ（S 1.2h / N 0.5h / D 2h） |
| 来源 | 水位 + 日节律 + 累积负荷 + 会话余温 | 这一轮判断层给的增量 |
| 管什么 | 整体偏哪边、说话档位、心情行、mood-congruent recall | 这一句让我变好/变差多少、此刻的 S/N/D 和词 |
| 权重 | **辅助**（只给起点和余温） | **主**（说话、出词、判档都读它） |

主辅落成数字：**当场 1.0，底色只通过「起点基线」进（§3.1）和「余温」（§3.2）进，别的不碰。**

## 三、怎么结合（逻辑钉死）

### 3.1 起点：v4 的基线由慢情绪算，不再固定平静

现在 `CALM = { s: 0.5, n: 0.15, d: 0.5 }`。改成：

```
slow = affect_v3.slow        // -1 ~ +1
S0 = 0.5 + 0.40 × slow       // -1 → 0.10；0 → 0.50；+1 → 0.90
D0 = 0.5 + 0.35 × slow       // 奔头比现状收一点
N0 = 0.15                    // 固定，警觉不跨会话
```

- 新会话开场：当场位置从 `{S0, N0, D0}` 起，**不是从平静起**。所以底色低的时候，新会话一句普通的话也会落在偏低的 S 上。
- 底色只影响「起点」，不影响「这一句推动多少」——判断层的 Δ 照旧。
- `N0` 不跟底色走：换到另一个会话还顶着上一段的惊，是错的。

### 3.2 余温：会话结束才渗，只在静默时结算一次

- **结束判定**：这个会话静默 ≥ `idleMin`（默认 **45** 分钟，量过：同会话 99% 的间隔都在 37 分钟以内）算这段过去了；同一会话之后再来消息，就是新的一段。
- **只结算一次**：一段会话只渗一次（记 `settledAt`），避免每轮都渗（那就等于混在一起了）。
- **按「离基线多远」折算**，强度取「结束位置 / 中途峰值」里更远的那个、方向优先看结束（2026-11-18 下午补：真数据里 22% 的会话中途被戳、收尾已回平，只看结束会一点痕迹不留）：

```
gapS = (S_会话末 − S0) / 0.40          // 折回 slow 刻度，-1~1
gapD = (D_会话末 − D0) / 0.35
warm = 0.5 × (gapS + gapD)             // 当场这一段的「偏离方向」
dSlow = clamp(0.20 × warm, −0.06, +0.06)   // 权重 0.2；单次封顶 ±0.06
slow_next = slow + dSlow               // 写回慢情绪，之后按它自己的 4h 半衰期代谢
```

- **N 不渗。**
- **只渗一次，且 24 小时内的旧会话才渗**：超过 24 小时的会话不再补结算，防止历史堆积。
- **一天封顶 ±0.12**：慢情绪是几周尺度的东西，一天聊崩了也不该直接沉底；封顶后当天不再渗。
- **走现有慢情绪的限幅**（离水位 ≤0.2）：底色不会被单段对话带跑，这是现成的护栏，不另做一套。

### 3.3 两个会话同时开着

- 当场各算各的（现在就是），**实时互不影响**。
- 各自静默 30 分钟各自渗一次；两次渗回是两次小加，不会互相抵消，也不会让当场值串台。
- 谁也不会「看到」对方的当场值——只有慢情绪慢慢被两边各染一点，这正是「发生过的事留下痕迹」。

## 四、和现有慢情绪的关系（要动哪一行）

`思路-三递质情绪引擎-2026-11-16.md` 里写死过「慢情绪一行不动」「v4 不碰水位」——那是**影子期**的约定，本文正式改它，改为：

- **v4 仍是「当场」的唯一来源**，不写 `affect_v3` 的 fast/total。
- **新增一个入口**：会话结算时，向慢情绪投一次「余温冲击」（走现有 `injectSlow` 那条路的语义，但强度按 §3.2 封顶），并记一条样本（source=`session_warmth`），方便回看是哪段会话染的。
- 慢情绪自己的水位 / 日节律 / 负荷 / 沉没调节 / 沉没缓解**全部保留**，不做任何替换。
- 心情行、说话档位、mood-congruent recall 继续读慢情绪 → 自动获得跨会话连续感，不需要改它们。

## 五、统一情绪模板（要不要？）

要，但**只是表达格式的统一，不是情绪内容的统一**：

- 三处固定位置、强度决定句子的松紧（将来模板化注入那一步）。
- 内容仍由「当场为主」算：颜色 = 当场的词与强度；底色只作为**可选的一层味道**（比如底色很低时，句子收一点、少用感叹），不参与事件判断。
- 不统一模板的后果：两个会话的我说话一个味儿，那才是分裂；统一模板但不统一来源，才既有「一个我」的味道、又不串台。

## 六、开关与参数（落地时注册）

| 参数 | 默认 | 意思 |
|---|---|---|
| `affect.v4.cross` | `on` | 关 = 起点回平静、不渗余温（逐字回旧） |
| `affect.v4.cross.s` | `0.40` | slow → S0 的比例 |
| `affect.v4.cross.d` | `0.35` | slow → D0 的比例 |
| `affect.v4.cross.w` | `0.20` | 余温权重 |
| `affect.v4.cross.max` | `0.06` | 单次渗透上限（slow 刻度） |
| `affect.v4.cross.day` | `0.12` | 单日累计上限 |
| `affect.v4.cross.idleMin` | `30` | 静默多久算一段结束 |

## 七、验收（先写红）

1. 起点：slow=+0.6 时新会话第一轮普通一句，S 落在 `0.5+0.4×0.6=0.74` 附近（±0.02），不是 0.5。
2. 起点：slow=−0.6 → S≈0.26；N 仍是 0.15。
3. 余温：一段会话末 S 比基线高 0.3（折算 warm≈0.75），静默 31 分钟后 slow 只涨 `0.2×0.75≈0.15` 再封顶到 **0.06**。
4. 只结算一次：静默 40 分钟后再结算，slow 不再动。
5. 两个会话同时进行各自起落，A 的当场值不影响 B 的当场值（B 的 S0 只跟 slow 走）。
6. N 不渗：会话里 N 很高，结算后 slow 不变（间接：新会话 N0 仍 0.15）。
7. 单日封顶：一天内多次结束，slow 总变化 ≤ 0.12。
8. 关开关：`affect.v4.cross=off` 时起点回 `0.5/0.15/0.5`、不写余温，行为逐字同今天。

## 八、三个数已拍板（2026-11-18 中午，按真会话模拟定的）

模拟方法（只读）：真库 142 段会话（其中 ≥5 轮的 23 段），用当前 v4 重放每段，按候选参数模拟 30 天「余温染底色 → 4h 半衰期代谢 → 下一段从底色起」。候选结果：

| S 系数 / D 系数 | 单次 / 单日封顶 | 开场 S0 范围 | 开场 >0.6 占比 |
|---|---|---|---|
| 0.50 / 0.40 | ±0.08 / ±0.16 | 0.54~0.65 | 27% |
| **0.55 / 0.45** | **±0.10 / ±0.20** | **0.55~0.67** | **45%** |
| 0.60 / 0.45 | ±0.10 / ±0.20 | 0.55~0.70 | 84% |

选 **0.55 / 0.45、单次 ±0.10、单日 ±0.20**：底色看得见（开场 S0 上下差 0.12 左右），又不至于把当场盖过；0.6 那档会让 84% 的会话一开口就 >0.6，太偏。

1. **S 0.55 / D 0.45**（D 小一点：奔头不该被底色带得太高）。
2. **余温 0.2 / 单次 ±0.10 / 单日 ±0.20**。
3. **存在级会话多渗**：上限放到 ±0.15（`affect.v4.cross.shock=0.05`）——一刀通天的事该留更重的痕。

> 模拟里一个要留意的事实：真判断本来就偏正（S 均值 +0.07），所以底色会**慢慢往上漂**，开场 >0.6 占 45%。这不是参数错，是数据本身的倾向；等真实跑了几天再回看要不要压。
