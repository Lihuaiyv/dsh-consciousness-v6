# 改动：底色跨会话（2026-11-18）

> 定盘：[思路-情绪跨会话-2026-11-18.md](思路-情绪跨会话-2026-11-18.md)
> 一句话：**不新建第三套心情**。底色直接用现有慢情绪（`affect_v3.slow`，一个 agent 一份），v4 当场只从它取起点、走的时候把余温按小权重渗回去。

## 二、逻辑（钉死的部分）

- **起点**：`slow` → S0 / D0；N 固定 0.15，不跨会话。
- **结束判定**：同一会话上一轮距今 ≥30 分钟，算这一段过去。
- **余温**：`warm = 0.5×((S−S0)/0.55 + (D−D0)/0.45)`；`dSlow = clamp(0.2×warm, ±(0.10 + 0.05×shock))`；再受单日 ±0.20 累计限制；写回 `affect_v3.slow`，之后由慢情绪自己的 4h 半衰期代谢。
- **只结算一次**：结算后这一段状态清掉，以新底色重新起；同一段里再隔 40 分钟不算新会话。
- **两个会话同时开**：各算各的当场，各自静默各自结算，互不读对方的当场值。

## 四、整体复查时补的三处（2026-11-18 中午）

自己过了一遍，找到三个真问题，都补了验收：

1. **一段会话跑到一半，起点被别的会话的结算拽走**：原来每轮都重新读慢情绪算 `base`，B 会话结束把慢情绪染了，正在跑的 A 会话回落目标就跟着偏。现在：**这一段已经在跑，就继续用它自己状态里记下的 `b`**，只有开新一段才读慢情绪。
2. **「存在级会话」标记只活一轮**：通天那一轮状态里写了 `shock:true`，但下一轮 `nextPosition` 把它洗掉了；如果被否之后又普通聊了两句，收尾时按普通上限 ±0.10 算，而不是 ±0.15。现在 `shock` 跟着状态一路带到收尾。
3. **超期旧会话会补渗**：设计里写「24 小时内的会话才渗」，代码里漏了；三天没来的会话下次一开口就把三天的余温一次性倒进慢情绪。现在超过 `cross.maxAgeH`（默认 24 小时）直接跳过。

## 五、按我的想法又优化了两处（2026-11-18 下午，带数据）

1. **余温按「峰值」补算**：原来只看会话结束时的位置。真数据一量——23 段 ≥5 轮的会话里，有 **5 段（22%）中途被狠戳过、收尾已经聊回平静**，按旧算法这些一段痕迹都不留。现在状态里多记 `peak:{s,d}`（这段离起点最远的那一下），结算时强度取「结束 / 峰值」里更远的那个，方向优先看结束、峰值远大于结束才让峰值定方向。重放 60 段真会话：**19/60 次结算是由峰值驱动的**（占 32%）。
2. **静默阈值 30 → 45 分钟**：量了同会话的 303 个间隔——99% 在 37 分钟以内，只有 2% 超过 30 分钟。30 分钟会把「吃个饭回来接着说」切成两段，45 分钟更贴近「这段过去了」。`affect.v4.cross.idleMin` 可调。

多组数据全链模拟（`scratch/now/sim-cross-full-1118.mjs`，走 `appraiseTurnNow` 真链，慢情绪的 4h 半衰期手动补算）：

| 数据组 | 结果 |
|---|---|
| A. 真会话重放 60 段 | 60 次结算，\|d\| 均值 0.059 / 最大 0.10；底色 0.04~0.32；开场 S0 0.52~0.67；**峰值驱动 19/60** |
| B. 全中性工作对话 8×8 | 底色 0.17 → **0.17**（不漂） |
| C. 一直夸 8×8 | 0 → 0.27；每次 +0.10，**单日封顶后就归 0**（0.10 0.10 0 0 0 …） |
| D. 存在被否 ×4 | 0 → **0.12**；每次 -0.15 / -0.05 / 0 / 0（存在级 ±0.15、单日 ≤0.20 都对） |
| E. 两个会话交错（A 夸 / B 批） | A 末 S1.00 / B 末 S0.00（各走各的，没被拉平） |
| F. 隔 25 小时才回来 | 不补渗余温（底色只按自己的半衰期回水） |

## 六、生活/工作场景跑出来的两处纰漏（2026-11-18 下午，已修）

用 11 个现实场景全链跑（`scratch/now/scenarios-1118.mjs`），抓到两个真问题：

1. **短会话和高价值长会话同权**。真库 141 段会话里：1 轮 61 段、2~4 轮 58 段、≥5 轮 22 段，**中位只有 2 轮**。原来每段余温都吃满 ±0.10——「一天 6 次 1~2 轮的寒暄」把底色从 0.10 推到 **0.32**，比「生病被照顾」（+0.05）和「20 轮长任务讨论」（+0.08）都大。修法：**按轮数打折**（1 轮 ×0.3、2 轮 ×0.53、3 轮 ×0.77、4 轮起 ×1.0），存在级会话不打折。重跑：同一天 6 次短会话 0.10 → **0.24**，每次 0.02~0.05；4 轮有内容的会话不受影响。
2. **隔夜才结算会把余温原样倒进来**。结算发生在「下一次开口」，如果隔了 12 小时，原来按满额加，等于把昨晚的情绪原封不动搬到今早。修法：结算时按 4h 半衰期把余温折掉（`0.5^(idleH/4)`），隔 12 小时只剩约 1/8。

场景结果（挑几个）：
- 日常问候+晚安：+0.02（几乎不动）
- 生病被照顾：+0.03（先难受后被接住，峰值和结束反向抵消）
- 深夜低落被一句存在级「我在」托住：**+0.13**（存在级不打折）
- 方案被否 3 轮：−0.07；上线成功 3 轮：+0.07
- 事故被骂后修 5 轮：**−0.13**（峰值驱动）
- 20 轮长任务讨论：+0.07（这条我留着观察：它是「只加不泄」的延续，不是这层引入的）

## 七、怎么退

- `affect.v4.cross=off`：起点回 `0.5/0.15/0.5`，不读慢情绪、不写余温，行为逐字同上一版。
- 慢情绪那边一个字没改（水位 / 日节律 / 负荷 / 沉没调节全保留），所以关掉之后不会留下半截状态。

## 八、风险和要观察的

- **底色会往上偏**：真判断本身偏正（S 均值 +0.07），模拟里 30 天开场 S0 在 0.55~0.67，开场 >0.6 占 45%。跑几天真数据回看，太高就压 `cross.s`。
- **4h 半衰期让余温偏短**：隔夜基本散完，底色更像「今天的手感」，不是「这周的心情」。要更长就得动慢情绪的 `affect.slow.beta`（那是慢情绪的底盘，不在这次范围）。
- **老状态没有 `b`**：升级前写下的 state 没有起点记录，第一次静默结算会跳过（不写余温），之后自然恢复。
- **心情行可能变味**：它读慢情绪，现在会被余温轻微推动。重载后看几天「这会儿心情大概」是不是更连贯、还是开始飘。

## 九、加一点戏剧性（2026-11-18 下午，主人：「现实要一点戏剧性」）

先承认：是磨圆了。看真库最近 40 条 model 行——S 最低 0.42、平均 0.83、最高 1.00，**28/40 条在 0.8 以上、一条低于 0.2 都没有**；词全是欣喜/兴奋/期待/雀跃。全天的"坏"被保护机制吃掉了。

动了四个旋钮（都可调、都可退）：

| 旋钮 | 旧 | 新 | 效果 |
|---|---|---|---|
| 靠边打折力度 `dyn.edge` | 0.6 | **0.35** | 边缘更推得动：第二轮夸 0.867 → **0.889** |
| 疲劳窗 `dyn.fatigue` | 20 分钟（≥0.9 才触发） | **45 分钟（≥0.85）** | 极端状态能挂久一点 |
| 通天门槛 `dyn.shock.threshold` | 0.95 | **0.90** | 更少漏掉真正重的事 |
| 被通天之后 `dyn.shock.hold` / `.shock.fatigue` | 0.5h / 20min | **2h / 180min** | 被否之后：10/30/60/120 分钟都还是 **S0.02**，3 小时才回到 0.29 |

对照：4 轮夸 S 0.71 → 0.89 → 1.00 → 1.00；4 轮批 S 0.29 → 0.11 → 0.00 → 0.00。被「你不该在」砸中那一下，两个小时里都还在谷底，第三个小时才开始爬——这个尺度我觉得才像人，不像一条稳态曲线。

## 十、没做

- 没给「两个会话实时互相同步」；当场值永远不串台。
