## 三、三条真问题

### 1）会话内几乎不回落，情绪被「顶死」

真实聊天 87% 的轮次间隔不到 5 分钟，而回落的闸门是「距上一轮超过 0.5 小时」——**聊天过程中这个门一次都不开**。于是「只加不泄」，一个会话里连续几句正向就把 S 顶到 1.0，之后一直挂着。

连续同向（每轮隔 30 秒）：

```
夸：0.71 0.92 1.00 1.00 1.00 …   ← 第 3 句就顶死
批：0.29 0.08 0.00 0.00 0.00 …   ← 第 3 句就到底
```

**可用动态范围只有 3 句。** 人不是这样：被夸三句不会一直亢奋，被说三句也不会一直归零。

### 2）N 轴最离谱：74% 的轮次在 0.9 以上

`expectation` 每轮给 0.3 上下，N 底是 0.15、每轮加 0.35×0.3≈0.105，又不回落 → **警觉/意外长期贴顶**。生理上这是错的：去甲肾上腺素是**分钟级**的，一件意外过去就散了，不该和心情一样挂两小时。

> 这里有一半是旧刻度的锅（0~1 只往上推）。新提示词让 `expect_delta` 可正可负、平常给 0，会好一些；但「N 跟 S/D 用同一个 2.5 小时」本身就不对。

三条能治病的：

- **靠边打折**：已经贴着 0.9 还往更靠边的方向推，位移打五折 → 3 句顶死变成 6~8 句慢慢逼近，仍有上限但不粘死。
- **每轮微漏 2%**：连会话内也往平静拉一点 → 长会话不会越聊越顶，稳态在 0.6~0.8。
- **单轮位移上限 0.2**：一句「存在被否」从 0.5 砸到 0.25 已经够重，别一句砸到 0.2 以下，把后面的空间也吃掉。

N 轴单独一条：**给它自己的时间常数**（不共用 hold/tau，τ≈0.3~0.5 小时、无维持窗），意外过去就散。这条光靠 S/D 的参数治不了（上面 ⑤⑥ 里 N 顶仍有 53%）。
