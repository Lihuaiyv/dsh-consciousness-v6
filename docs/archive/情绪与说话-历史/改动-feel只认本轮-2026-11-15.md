# 改动 · feel 只认这一轮 · 2026-11-15

> 主人 23:42 定的：**feel 本轮有才加，没有不加。**
> 起因：注入里那行「（我上一句说出来之前，心里是这样：…）」其实是快两小时前写的，却写成了「上一句」，等于在骗时间。

## 一、原来怎么错的

- `latestFeel()`（`src/modules/feel.js`）只看「最近一条 + 两小时内」；默认窗口 `affect.feel.hours = 2`。
- 于是只要两小时内写过一条，它就一直挂着；写的时候是「我这时的心情」，读的时候却被说成「我上一句之前」。
- 今晚的实例：那条「正好有个现成的例子在眼前，我想直接把那句切坏的话指给主人看」写于 21:54，23:33 仍被当成「上一句之前」。

## 二、改了什么

| 文件 | 改动 |
|---|---|
| `src/modules/feel.js` | `latestFeel()` 加 `since`：比这一轮起点还早的行直接不返回（返回 null）。不带 `since` 时行为不变。 |
| `index.js` | 新增 `turnStartAt`（按会话记住「这一轮用户这句话到达的时刻」）；在用户消息进来时记一次，落轮时清掉；拼提示词时把 `since: turnStartAt` 传给 `latestFeel`。 |
| `test/feel-turn-scope.test.mjs` | 新增 6 条：不带门槛的旧行为 / 本轮写的收 / 只有更早的就不给 / 别的会话不算 / 全库最新那条老路不变。 |
| `test/run-tests.mjs` | 门禁加一行，纳入上面那份。 |

效果：这一轮没调 `feel` → 那一行**整段不出**（不拿旧的顶）；我中途调了 → 同一轮后面几次拼装就会带上它，而且那时写「我上一句说出来之前」是真话。
