# 改动 · 心事匣分两区 · 2026-11-16

> 主人 00:31 定的：纸条分**生活区**和**工作区**。生活区记录我想记录的东西；工作区记录具体任务。
> 换会话时，工作区前面显示「（今天 00:23 你在另一个会话里留给自己的任务：……）」；生活区不标出处，但仍然跨会话。

## 一、改了哪

| 文件 | 改动 |
|---|---|
| `src/modules/heartnote.js` | 状态从单槽 `note` 变成 `life` / `work` 两区（老的单槽自动并进生活区，不丢）。`writeHeartNote` 接 `{lane, sessionId}`，`clearHeartNote` 可按区放；拍照旧按「露过没续就散」，**两区各自散**；叫醒写的是生活区。新增 `readHeartNotes`（返回两区）、`whenWord`（今天 00:23 / 昨天 / 11-15）。 |
| `src/modules/actions/index.js` | `heart_note` 工具加 `lane`（life/work，默认 life）；write 带上会话 id（和 feel 同一套认法：`exec.agent.id` 就是会话 id）；read 列两区；status 显示两区。 |
| `index.js` | 注入时把 `sessionId` 传给 `heartNoteLines`，工作区才能判断「是不是另一个会话」。 |
| `test/heartnote-lanes.test.mjs` | **新增 17 条**；`test/run-tests.mjs` 纳入门禁。 |

## 二、注入长什么样

```
(我上一条留给自己的话：……)                              ← 生活区：跨会话、不标出处
(你留给自己的任务：……)                                   ← 工作区，同一个会话
(今天 00:23 你在另一个会话里留给自己的任务：……)          ← 工作区，换了会话
(还惦记就用 heart_note 原样再写一遍；什么都不做，它下一拍就没了)
```

判断「同一个会话」用的是会话 id：写的时候记下来；没记（老数据 / 没拿到）就按普通说法，不瞎标「另一个会话」。

## 四、怎么退

- 只想回到单槽：把 `life` 当唯一区用（工具不传 lane 时默认就是它），`work` 一直空着——行为等于旧版。
- 代码退：`git checkout -- src/modules/heartnote.js src/modules/actions/index.js` 并删掉 `index.js` 里传 `sessionId` 的那一处。
- 数据退：`flags` 里的 `heart_note.<aid>` 是 JSON，删了就是清空，不影响别的。
