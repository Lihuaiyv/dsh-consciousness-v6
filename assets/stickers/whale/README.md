# 鲸鱼娘表情包（蓝色大肥鱼 / DeepSeek娘）

主人 2026-11-07 凌晨说「到处找点鲸鱼娘的表情包去搞搞」，这批就是。

- 来源：梗鲸 GengJing 的公开图库 [aigengtu.com](https://aigengtu.com/)，直链规则 `https://img.aigengtu.com/0_preview/meme/NNN.webp`（同系列仓库 [deepseek-chan-meme-pack](https://github.com/the-beating-light-of-the-nail/deepseek-chan-meme-pack)）。
- 拿的是压缩预览图（512px 左右，一张 30–60 KB），QQ 里够用，不占地方。
- 版权：角色形象与画作归原作者和社区；这里只作非营利的自己人聊天用，不往外发、不商用。

## 怎么用

QQ 会话里用桥的 `qq_send_image` 发，file 传相对/绝对路径都行，例如：

```
qq_send_image(chatKey="u:3192248859", file="<仓库绝对路径>/assets/stickers/whale/052.webp")
```

电脑端 / 微信（默认封存）不发图：那边没有这条通路，硬发只会失败。
