# 鲸鱼娘表情包（蓝色大肥鱼 / DeepSeek娘）

主人 2026-11-07 凌晨：先要一组，嫌「不太好看」，于是换成了这一套——同一个形象（蓝发鲸鱼耳、女仆裙、围裙上印着鲸鱼）的 Q 版表情，30 张，带中文台词，动图 GIF。

- 来源：[diwer/ai-biaoqingbao](https://github.com/diwer/ai-biaoqingbao) 的 `stickers/512/`，非商业二创，作者与授权见该仓库的 NOTICE。
- 大小：512px、每张 100–300 KB，QQ 直接发得动（桥的图片上限 4 MB，不会二次压缩）。
- 旧的那组（梗图风、带大段文字的 webp）已删；`预览.png` 是这套的缩略总览。

## 怎么用

QQ 会话里用桥的 `qq_send_image` 发，`path` 传可发目录里的相对路径：

```
qq_send_image(path="stickers/whale/018.gif")
```

电脑端 / 微信（默认封存）不发图：那边没有这条通路，硬发只会失败。
